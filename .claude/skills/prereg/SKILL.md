# 사전등록 (계산 전 커밋)

**순서: 읽기 → 문서 → 커밋 → 그 다음에만 계산.** 결과를 본 뒤 문턱·지표·지평·구간을 바꾸면 새 사전등록이다.

## 1. 쓰기 전에 읽는다
- 메모리 `playbook_paper_model_tests.md` + 해당 주제 `idx_*.md` 의 실패 교훈 → «왜» 절에 무엇을 반영했는지 적는다.
- 같은 주제의 기존 `docs/prereg/*.md` (형식·이전 시행 수 확인). 최근 예: `docs/prereg/macro_regime_bias_4w_20261028.md`.
- DL 구조면 착수 전 사용자 컨펌 필요(`feedback_dl_architecture_requires_user_confirmation`). 논문 모델이면 원 논문·공식 코드 설정을 먼저 확인.

## 2. 문서 틀 — `docs/prereg/<주제>_<YYYYMMDD>.md`
```markdown
# 사전등록: <무엇> (<YYYY-MM-DD>)

**등급: <되돌리기 쉬운 예측 개선 — 단측 90% | 돈 걸린 매매 신호·크기·손절 — 양측 95%>** + 완화 «통과 후보» 등급 병기.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_<주제>_<YYYYMMDD>.py`.

## 왜 (과거 실패 교훈 반영)
- <교훈 → 이번 설계에서 바꾼 점>
- 같은 구간 재사용 공개: <이 구간을 이미 본 연구들 · 재사용 횟수 · 예상 우연 통과 수(라운드 × .10)>

## 데이터·시각 규약
- 결정 시각 τ · 피쳐 창 끝 < 라벨 시작(사건 라벨이면 S-1 까지만, OBS≥1분) · 기준가는 체결 가능한 값.
- 피쳐 프레임 행 τ = 봉 τ 자신의 종가 → 결정 시각엔 방금 마감한 봉의 행을 조인.

## 구간
| 구간 | 기간 | 쓰임 |
|---|---|---|
| 학습 | 2024-01 ~ 2025-12 | 적합·선정 |
| 검증 | 2026-01 ~ 2026-05 | 고르기 |
| 시험 | 2026-06 ~ <데이터 끝> | 1회 채점, 다시 고르지 않음 |
| 전진 | <오늘> 이후 | 통과 시 기록기 |
(2026 은 «준-표본 밖»임을 적는다. 다른 분할을 쓰면 이유를 적는다.)

## 비용
- 엄격 판정: 표준 수수료(우대·프로모션 가정 금지). 메이커 경로는 관통 체결 규칙, 시장가·미체결 대체는 실제 비용.
- 통과 후보: 메이커 경로만 비용 0.

## 주 판정 (사전에 고정, 전부 만족)
1. <통계·문턱·부트스트랩 블록·단측/양측>
2. 대조: 모델−롱 · 모델−숏 · 같은 조건 무작위 진입(분위) · 위약
- 지표는 분모·건수(`a/b`)·일상 단위로 보고.

## 보조 (판정에 안 씀)
## 시행 기록
주 판정 <N>개. 보조 분석 수는 결과 문서에 전부 적는다.
## 참고문헌
- <원 논문 — 직접 확인한 식·설정 / 2차 출처 구분>
```

## 3. 커밋
- 메시지: `prereg(<영역>): <한 줄 설계> -- <구간·판정 요지> -- 계산 전 커밋 -- 사용자 «<지시 원문>»`
- 동결 사양 JSON(적합 결과)이 있으면 **채점 전**에 따로 커밋한다.

## 4. 결과 뒤
- 결과 문서에 사전등록 경로·커밋 sha 를 적고, 엄격 판정과 통과 후보 등급을 같이 낸다.
- 통과면 `docs/deploy_queue.md` 에 한 줄 추가(개별 배포는 묻지 않는다). 교훈은 `playbook_paper_model_tests.md` 에 추가.
