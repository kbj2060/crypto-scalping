## Red-Team Notes

Pass:

- No saved ledger is used as input.
- No saved parent entry/exit timestamp is used.
- Parent decision cache is not used.
- All entries are generated by runtime-native parent forward on the current bar.
- Overlay decisions use only current parent output, current router expert, current
  side, current loss streak, and current-bar policy state.
- Notional contract remains `notional = margin_fraction * leverage`.

Residual risk:

- Validation PnL is only +1.95%; this is a stabilization fix, not a high-return
  promotion.
- Max hold is still 63.17h on validation. Attempts to force 8h/24h exits failed
  validation, so hold compression needs a learned or state-conditioned exit
  layer rather than a hard time exit.
- Long side remains weak. The selected overlay reduces long exposure instead of
  solving long alpha.

## Conclusion

The paper-inspired overlay fixes the immediate corrected fresh-forward failure:
validation becomes positive and MDD moves inside -20%, while OOS remains close
to the baseline. It should be treated as a pass candidate for the overlay layer,
not as a final live promotion until the hold-time and long-side residual risks
are addressed.
