# 스냅샷 대시보드 12신호 점검 및 매매 의사결정 활용성 평가 (2026-08-23)

## 3줄 요약

1. **점검**: 12개 전부 정상 계산·정상 표시 확인. 단 실질 독립 정보는 11개(고래 포지션은
   수급 흐름의 파생 — 이번 세션 코드 감사로 확정, 대시보드에 표기 완료).
2. **재량 매매 보조**: **가능** — 단 "확률 이동 컨텍스트"라는 검증된 용도 안에서만.
   아래 사용 규칙 5개 참조.
3. **매매 자동화**: **불가(증거신호 6종은 반증 완료, 모델지표 6종은 이미 자동화되어
   있으며 그 시스템이 always-long을 못 이기는 게 현재 실측)**. 열려 있는 것은 9월의
   사전등록 게이트 2개뿐(09-15 청산, 09-30 microstructure veto).

이 문서는 새 백테스트를 돌리지 않았다 — 증거신호 재검정은 registry retest 금지 대상이고,
09-30 전에는 깨끗한 OOS 창 자체가 없다. 대신 기존 검증 결과(2026-08-14 라운드 1~10,
이번 세션 중복 감사)를 12개 신호에 매핑하고, **현재 레짐 발동 빈도만 새로 실측**했다.

## 2. 재량 매매 보조 — 가능, 단 이 규칙 안에서

증거신호 6종의 검증된 용도가 정확히 이것이다(검증 근거: 2개 독립 창에서 순위 재현,
Spearman 0.976/0.924). 사용 규칙:

1. **단일 신호 발동 = 진입 트리거가 아니다.** 최강 신호(orthogonal_combo)조차 발동 시
   실제 바닥 근처일 확률이 43.9%(1h 기준) — 베이스라인(12.5%)의 3.5배지만 **여전히
   절반 미만**이다. "확률이 3배로 뛰었다"이지 "반전 확정"이 아니다.
2. **서로 다른 정보 패밀리의 동시 발동에 가중하라.** 같은 패밀리 중첩(가격위치 지표
   2개)은 +10%밖에 못 더했지만, 오더플로우+가격위치 조합은 +54% 리프트를 더했다
   (orthogonal_combo가 top-1인 이유 자체가 이 조합이라서다). net_score |2|+ 이면서
   구성 신호의 패밀리가 다른 경우가 진짜 주목 대상 — 현재 레짐에서 |2|는 5.2일간
   55봉, |3|+는 32봉(하루 ~6회) 발생.
3. **발동 후 즉시 추격하지 마라.** 역사적으로 진양성조차 실제 피벗 전에 평균
   0.5~0.85% 추가 역행했다. 발동은 "관심 구간 진입"이지 "지금이 바닥/천장"이 아니다 —
   사이즈와 스탑에 이 여유를 반영해야 한다.
4. **스트립을 추세지속 확인으로 읽지 마라.** 이 연구에서 지속/브레이크아웃 신호 6종은
   전부 lift 0.89~1.07x(동전던지기)였다. 이 대시보드의 모든 신호는 **반전** 증거이지
   지속 증거가 아니다.
5. **모델지표 6종은 "봇의 눈"이지 검증된 방향신호가 아니다.** 용도 분리:
   - 꼬리 리스크: 방향이 아니라 **"지금 시장이 위험한가"**(관망/사이즈 축소 판단)에만.
     탐색 스캔에서 방향 lift는 미미했고 vol-lift 1.59x만 관찰됨 — 변동성 예고 신호다.
   - 나머지 5종: 봇이 지금 무엇을 보고 있는지의 컨텍스트. 인접 축의 방향 검증은
     전부 CLOSED(L2 요약 피쳐)거나 판정보류(microstructure veto, 09-30) 상태다.

## 3. 매매 자동화 — 반증 완료 / 이미 자동화됨 / 9월 게이트

### 3.1 증거신호 6종: 자동화는 **반증 완료** (미지수가 아니라 검증된 부정)

2026-08-14 하루 동안 4개의 독립 메커니즘으로 시도됐고 전부 실패했다:

| 메커니즘 | 결과 |
|---|---|
| ① 강제청산 veto (Candidate C) | VAL PnL −29.92pp — 발동 6~11회가 각각 치명적 |
| ② exit_head 학습 피쳐 | bar-level 상관이 VAL에서 **역부호**(rho +0.056, p=0.0006) |
| ③ 사이징 사이드카 피쳐 (Candidate D) | zig075 교과서적 VAL승(+9.3pp)→OOS반전(−3.4pp) |
| ④ 단독 투표공식 (K=1~6 전수) | **36셀 전패** — 느슨한 K는 비용복리 −95%, 엄격한 K는 표본 고갈 |

④의 해부가 결정적이다: **승률이 모든 K에서 32~42%로 TP:SL 손익분기(~38.5%)에 정확히
붙어 있었다** — 비용 문제 이전에 방향 엣지 자체가 0이라는 뜻이다. 이번 주 발견한
USDC-M maker 0%가 이 판정을 뒤집는지 자문하면: 비용항은 줄지만, 승률=손익분기 관측이
말하는 gross 엣지≈0은 그대로다 — 0수수료여도 "크게 잃는 churn"이 "기대값 0의 churn"으로
바뀔 뿐이다. 재검토가 정당화되려면 09-30 이후 새 OOS + 사전등록 설계가 필요하고,
사전확률은 낮다.

### 3.2 모델지표 6종: **이미 자동화되어 있다** — 그리고 그게 답이다

이 6개는 "자동화 후보"가 아니라 라이브 봇의 결정 경로에 **이미 배선된 입력**이다
(trading_bot이 매 사이클 계산, playbook_router 등이 소비). 즉 "이걸로 자동화가
가능한가?"의 답은: **이미 그렇게 하고 있고, 그 시스템 전체가 5개월간 always-long을
못 이겼다**가 현재 실측이다. 지표가 나빠서라기보다, 이 저장소의 지배적 결론(현재 정보
유니버스에 5분봉 방향 alpha 없음)이 이 지표들에도 그대로 적용된다.

### 3.3 열려 있는 것 — 날짜 박힌 게이트 2개

| 게이트 | 날짜 | 내용 | 12신호와의 연결 |
|---|---|---|---|
| 청산 컨트래리언 | **≥09-15** | 사전등록 판정(§12 3개 arm + 오늘 추가된 §13 크라우딩 arm) | **꼬리 리스크**의 원천 데이터가 바로 이것 — 12신호 중 유일하게 "판정 예정일이 박힌" 신호 |
| microstructure veto 재개 | **≥09-30** | cheap-gate 약한 양성이었으나 OOS-Q2 N=8 표본부족으로 보류 | obi/독성 계열의 veto(방향 아님) 용도 재판정 |

이 두 게이트가 통과하면 해당 신호는 "재량 컨텍스트"에서 "자동화 요소(veto/리스크
레이어)"로 승격될 수 있다 — 단 그때도 방향 트리거가 아니라 거부/축소 레이어로서다.
