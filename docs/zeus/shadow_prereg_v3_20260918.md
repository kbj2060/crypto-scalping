# Zeus Baseline v3 섀도우 — 사전 등록 (2026-09-18)

**이 문서는 전방 데이터를 한 건도 보기 전에 작성한다.** 켠 뒤에 기준을 고치면 섀도우의
유일한 가치(선택편향 없는 표본)가 사라진다. 수정하려면 섀도우를 **중단하고 다시 시작**한다.

## 1. 동결 사양 (docs/zeus/README.md §2 와 바이트 일치해야 함)
```
입력 109열 = base 96(레짐 6열 제거) + POS 13(진입 시 0)
부모  TabM 3head(k8·h192·L3) · zigzag 양두 · 손실 ld+0.8·lq · 6시드 확률평균
TRAIN 2022-01-01 ~ (판정일 − 30일 purge)
게이트 롤링분위 창 1,000 후보 · shift(1) 인과 · 워밍업 확장창
청산  더블배리어 TP1.5% / SL0.7% · 시간청산 없음 · intrabar 고·저가 · SL 우선
집행  슬롯 1개 · mingap 없음 · 대기 주문도 슬롯 점유
크기  실거래는 **고정**, 원장에 half-Kelly(명목 ~5.8배) **가정 손익을 병행 기록**
```
🔴**실거래를 half-Kelly 로 하지 않는 이유**: CAGR 485% 는 오늘 4폴드에서 수십 번 고른
탐색의 생존자다. 선택편향 없는 표본이 쌓인 뒤에 전환 여부를 판단한다.

## 2. 기대값 (4폴드 실측, 비용 0% / peg 5.52bp)
| | 비용 0% | peg 5.52 |
|---|---|---|
| 체결/일 | 0.80 | 0.80 |
| 건당bp | +12.56 | +7.04 |
| 순/일 | 10.1 | 5.7 |
🔴**체결 0.80건/일은 사용자 목표(최소 1건/일)에 미달이다.** 섀도우는 이 미달 상태로 시작한다.

## 3. 사전 등록 판정 (n ≥ 60 체결 또는 90일 경과 중 먼저)
| # | 지표 | 통과 | 실패 |
|---|---|---|---|
| A | **건당bp(peg 5.52 기준)** 날짜블록 CI | 하한 > 0 | 상한 < 0 |
| B | **체결/일** | ≥ 0.6 | < 0.4 (모델이 사실상 안 뛴다) |
| C | **건당bp 점추정** | ≥ +3.5 (기대 +7.04 의 절반) | < 0 |
| D | **라이브 파리티** | 섀도우 결정 vs 오프라인 재현 **불일치 0건** | 불일치 > 0 ⇒ 즉시 중단·원인규명 |
⭐A~C 중 **둘 이상 실패면 중단**. D 는 단독으로 중단 사유다.
⚠️A 의 CI 는 **진입일 날짜블록**으로 낸다(보유가 겹치므로 건 단위 SE 금지).

## 4. 기록할 것 (봉 단위 원장)
`timestamp · 확신도 · 롤링임계값 · 방향 · 슬롯상태 · 진입가 · 청산가 · 청산사유(TP/SL) ·
보유봉 · 체결비용 · 고정크기 손익 · half-Kelly 가정 손익 · f*(그 시점 추정 p)`
⭐**거절된 신호도 기록한다** — 슬롯 경합 손실(현재 85%)이 실측과 맞는지 확인해야 한다.

## 5. 중단 사유 (판정 전이라도)
- 파리티 불일치 1건 이상
- 롤링 임계값 버퍼가 재시작 후 복구 실패
- 실현 최악 1건이 **−1.5%**(= SL 0.7% + 미끄러짐 0.8%)를 초과 ⇒ 갭 가정 붕괴
- 서버 자원 경보(2026-09-18 OOM 재발 방지)
