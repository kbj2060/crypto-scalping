## Track 3 — 저주파 팩터

### F3-A. 펀딩 캐리 팩터 (우선순위 1, 지금 실행 가능, 공수 2~3일)

**논리**: perp 펀딩비는 crypto의 캐리다. 펀딩이 높을 때(롱 과밀) 숏 포지션은
8시간마다 펀딩을 수취한다. 방향 예측이 아니라 **프리미엄 수확** — Sigma6(모멘텀)과
근원이 다른 팩터라 직교 가능성이 있다.

- **전략 정의(사전 등록)**: 8h 펀딩 확정 시점마다, |예상 펀딩| ≥ 임계값 θ면
  펀딩 수취 방향으로 진입, 다음 펀딩 시점까지 보유(8h) 또는 무보유.
  레버리지 1~2x, Futures Risk Sizing Contract 준수.
- **변형 격자(탐색 구간에서만)**: θ ∈ {0, q50, q75, q90 of |funding|},
  보유 {8h, 24h}, 자산 {ETH, BTC, SOL, 3자산 균등}. 격자 전체 보고 + BH-FDR.
- **핵심 검정**: 펀딩 수취액은 확정적이므로 진짜 질문은 "**펀딩 수취가 가격 역행
  손실보다 큰가**". 분해 리포트 의무: PnL = 펀딩 수취 + 가격 변동 + 비용, 세 항 분리.
- **Kill 게이트**: 탐색 구간에서 cost1 기준 연환산 양수 + 펀딩 항이 가격 항 손실을
  상회하는 변형이 0개면 종료. 통과 시 val → OOS(1회) → fresh 순서.
- **함정 경계**: 펀딩이 극단인 순간은 변동성 폭발과 동시라 8h 보유 중 청산 위험 —
  MDD와 최악 8h 손실 분포를 반드시 병기. 2025-10 캐스케이드류 이벤트가 표본에
  있는지 확인.

### F3-B. 크로스섹션 모멘텀 (우선순위 3, 공수 2일)

**논리**: Sigma6는 ETH 단일 시계열 모멘텀. 크로스섹션(자산 간 상대 순위)은 시장
방향 노출이 상쇄되는 다른 팩터다.

- **정의**: k일 수익률로 3자산 순위 → 1등 롱 / 3등 숏 (달러 중립), 일 1회 리밸런스.
  k ∈ {7, 14, 30} (탐색 구간에서만 선택).
- **정직한 한계 명시**: 유니버스가 3개뿐이라 크로스섹션이라 부르기 민망한 규모.
  통계적 검정력 낮음을 전제로 "방향성 확인" 수준의 기대치. 통과 시 SOL 파일럿
  템플릿으로 유니버스 5~10개 확장이 후속(그 자체가 별도 공수).
- **Kill 게이트**: 탐색 구간 cost1 양수 실패 시 유니버스 확장 없이 종료
  (3자산에서 안 보이는 걸 10자산에서 찾는 건 다중검정 낚시).

### F3-C. 직교성 게이트 (F3-A/B 통과 시 필수 관문)

새 팩터가 val 구간에서 살아남아도, **기존 라이브 스택과 상관이 높으면 채택 불가**
(WS-C에서 배운 정보 중복 교훈의 팩터 버전).

- 검정: 새 팩터 일별 수익률 vs Sigma6·Omega4.6.1 fresh-forward 일별 수익률의
  스피어만 ρ. |ρ| < 0.3이면 통과.
- 통과 시에만 F4-B(포트폴리오 결합)에 후보로 편입.

### F3-D (선택). OI/롱숏비율 팩터 — F3-A 결과 확인 후 착수 여부 결정
metrics 데이터의 OI 변화율·롱숏비율은 포지셔닝 팩터 후보지만, WS-C에서 유사 계열
(청산 포지셔닝)이 기각된 전례가 있어 우선순위 최하. F3-A가 성공해 "포지셔닝 계열에
신호가 있다"는 방증이 생길 때만 착수.

## Track 4 — 실행 최적화 + AI

### F4-B. 포트폴리오 결합 최적화 (우선순위 2, 지금 실행 가능, 공수 1~2일)

**논리**: 월가 방식의 핵심은 "약한 무상관 신호의 결합". 이미 검증된 전략이
2개 있다(Sigma6 1h, Omega4.6.1 5m — 서로 다른 시간프레임/기법). 새 알파 없이
**결합만으로** 포트폴리오 샤프/MDD가 개선되는지가 질문.

- **입력**: 각 전략의 기존 fresh-forward 일별 수익률 시계열 (저장 원장 replay가
  아니라 이미 유효한 fresh-forward 결과의 일별 집계 — 규칙 위반 아님을 명시).
- **결합 방식 격자**: 균등 / 역변동성 / 상관 페널티(risk parity 근사). 학습 없는
  단순 규칙만 — 가중치 최적화 학습은 과적합 지름길이라 금지.
- **사이징 규칙**: PER_TRADE_PCT + MAX_TOTAL_EXPOSURE_PCT 프레임 재사용
  (1m 스캘핑 조사에서 확립된 "슬롯 수가 아니라 총 노출 상한" 교훈).
- **판정**: 결합 포트폴리오가 최고 단일 전략 대비 (a) MDD 개선 **그리고**
  (b) 샤프 비열화(-10% 이내)면 채택. 상관이 이미 낮아야 성립하므로 먼저 두 전략의
  일별 수익률 상관부터 보고.
- **주의**: 두 전략 모두 트레이드가 희소(Omega 6개월 24건)해서 일별 상관 추정치
  자체가 불안정 — 상관의 부트스트랩 CI 병기, 점추정 단독 사용 금지.

### F4-A. 생존분석 체결모델 (게이트 대기 — 2026-10-14 해금)

기존 T-B4 설계 그대로. 전제조건: WS-E 72h 소크 통과(진행 중, ~07-22 완료) +
연속 스냅샷 3개월 누적. **지금 할 수 있는 유일한 준비**: 소크 완료 직후 72h
데이터로 10초 해상도 라벨 구축 파이프라인만 검증(모델 주장 금지, 배관 확인 전용).

### F4-C. 대체데이터 수집기 (지금 심고, 검정은 3개월 후)

**논리**: AI의 실제 용처는 비정형→정형 신호화. 단, 신호 주장은 데이터가 쌓인 후.
WS-E와 같은 플라이휠 원칙 — 오늘 심어야 10월에 검정 가능.

- **1단계(지금, 공수 반나절)**: 수집기만. 후보(전부 무료/공개): Binance 공지
  (상장/상폐/점검), Fear&Greed index, 거래소 간 펀딩비 스프레드. 일 1회 cron,
  `data/research/altdata.duckdb`에 append. WS-D의 D4 감시에 편입.
- **2단계(≥3개월 후)**: 사전 등록 이벤트 스터디 — 예: "상장 공지 후 24h 수익률
  분포가 무조건부와 다른가". 지금 가설을 등록해두고 데이터가 쌓이면 1회 검정.
- **명시적 비목표**: 뉴스 감정분석 LLM 파이프라인 같은 대형 구축은 이벤트 스터디가
  신호 존재를 먼저 보여주기 전엔 착수 안 함.

## 실행 순서와 현실적 기대치

```
지금:      F3-A 펀딩 캐리 (2~3일) → 실패해도 캐리 계열 종결이라는 정보 가치
동시:      F4-B 포트폴리오 결합 (1~2일) — 새 알파 불요, 가장 싼 개선 후보

~07-22:    WS-E 소크 판정 → F4-A 배관 검증
~2026-10:  F4-A 본실험 + F4-C 이벤트 스터디
```

기대치 관리: F3-A/B는 문헌상 실재하는 팩터지만 3자산·소표본이라 kill 확률이 낮지
않다. **가장 성공 확률이 높은 것은 F4-B** — 이미 검증된 두 전략의 결합은 새 엣지를
요구하지 않고 상관만 낮으면 수학적으로 개선되기 때문. 전부 실패해도 각 계열의
종결 기록이 남는 것 자체가 이 프로젝트의 자산 축적 방식이다.
