# 박스 유지 확률 — 국면 이동에 강한 보정 사전등록 (2026-10-25)

대상: `dashboard/box_hold.py` (HGB, 30분·1h 27칸 · 4h 6칸, 2022~24 학습). 목적 = **확률 정확도·보정**(매매 수익 아님 — 크기·주문 방식 사용은 10-24 따로 불통과, 다시 안 봄).
문제(10-19 재검증): 4h 2026 과소 예측(월별 예측−실제 −1.2~−6.7pp · 최근 90일 예측 25.2% vs 실제 28.1%). 30분·1h 는 ±2pp 안.
주의: 배포 변형은 2025~26 AUC 를 보고 골랐다 → 2026 시험은 «배포 모델 대비 보정층의 증분»만 깨끗하다.

## 문헌 근거(읽기만, 외부 코드·자료 안 받음)
- Platt 스케일(로짓 위 로지스틱 2모수) · 등조(isotonic) — 고전 정적 보정.
- 베타 보정(Kull·Silva Filho·Flach 2017, AISTATS · EJS «Beyond sigmoids»): σ(a·ln p − b·ln(1−p) + c), 이미 보정된 모델엔 항등에 가깝다.
- Ovadia 외 2019(NeurIPS): 고정 검증셋으로 맞춘 온도/정적 보정은 분포 이동 아래 오히려 나빠지는 일이 잦다 → 정적 보정만으론 부족할 수 있다.
- Gibbs·Candès 2021(ACI): 관측마다 목표 수준을 γ 만큼 고치는 온라인 갱신 → 임의 이동에서도 장기 빈도 보장. 여기선 «절편만 굴리는 보정»과 OPS 의 근거.
- Gupta·Ramdas 2023(ICML, Online Platt Scaling): Platt 2모수를 온라인 뉴턴(ONS, γ=0.1·ρ=100, (1,0) 시작, 조율 없음)으로 갱신. 창 Platt(WPS)도 실제 자료에선 OPS 와 비슷.

## 공통 규칙
- 데이터: ETHUSDT 선물 1분봉(data.binance.vision, 10-08~10-23 일 파일 CHECKSUM 대조) 2021-12~**2026-10-23 23:59 UTC 까지만**.
- 결정 격자 = 배포 학습과 같음(30분·1h 분%5==4 · 4h 분%60==59). 행 = 배포 칸이 유한한 행.
- 라벨(독립 재구현): y[i] = max 고가[i+1..i+W] < 종가[i]+½창폭 그리고 min 저가[i+1..i+W] > 종가[i]−½창폭, 창폭 = 고가[i−W+1..i] 최대 − 저가 최소.
  시험 행은 라벨 창 끝(i+W) ≤ 2026-10-23 23:59.
- 라벨 관문(결과 보기 전 통과해야 함): L1 기존 산출(decisions.parquet, ~10-14)과 겹치는 행 100% 일치 · L2 무작위 3,000행 반복문 직접 계산 일치
  · L3 경계: 대시보드 `features()` 를 i 까지 자른 1분봉으로 계산 = 연구 피쳐(피쳐 끝 i < 라벨 시작 i+1) · L4 국면 피쳐는 i−W 이후 라벨을 망가뜨려도 불변
  · L5 굴림·온라인 보정의 적합에 쓴 행은 전부 (ts + W) ≤ 적합 시각.
- 분할: 적합 ≤2024(HGB·로지스틱) · 보정층 적합/선택 2025 · **시험 2026-01-01~10-23 라운드당 1회**.
- 굴림·온라인 보정은 배포 HGB 의 표본 밖 예측(2025-01-01~)만 쓴다(2024 는 학습 표본 안 예측이라 과신).

## 선택(2025만)
척도마다 C1~C8(변형 포함) 중 **2025 Brier 최소** 1개 = S. 정적 C2~C4 의 2025 점수는 반기 교차 적합(상반기 적합→하반기 채점, 반대도)으로 낸다(제자리 적합 점수 금지).

## 시험(2026, 1회) · 판정
모든 후보를 보고하지만 **판정은 S 하나**. S 가 «이김» = 아래 넷 모두:
- W1 ΔBrier(S − C0) 일 블록 부트스트랩(2,000회) 95% CI 상한 < 0
- W2 로그손실 S ≤ C0
- W3 ECE(10 등빈도 칸) S ≤ C0
- W4 AUC S ≥ C0 − 0.002
보고: 척도별 Brier · 로그손실 · ECE · 보정 최대 차 · AUC(ΔAUC 블록 CI 300회) · 화면 라벨(배포 q20·q80 고정 문턱: «깨질 쪽» < q20 · «머물 쪽» > q80)의 시간 비율·실제 유지율
· 4h (예측 평균 − 실제) 2026 전체·최근 90일(07-26~)·월별, 일 블록 CI.
