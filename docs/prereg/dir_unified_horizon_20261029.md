# 사전등록: 15분·1시간·4시간 방향 예측 — 구간 합 통합 모델 · 결합층 vs 현재 3모델 (2026-10-29)

**등급: 되돌리기 쉬운 예측 개선 — 단측 90%**(화면 예측 값, 끄면 원래 모델로 복귀) + 완화 «통과 후보» 등급 병기.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_dir_unified_horizon_20261029.py`.
사용자 10-29 «지금 대시보드에 있는 15분, 1시간, 4시간 예측을 모델 1개가 모두 예측하게 하는건 어때? … 너무 독립적이야» → «구간 합 통합 모델과 결합층을 현재 3모델과 비교하는 실험을 사전등록하고 진행해줘».

## 왜 (사전 관찰 · 과거 교훈)
- 사전 관찰(배포 예측, 2026-06-01~10-18, 40,321봉 — **이 문서의 시험 구간과 겹친다**): 예측 상관 15분↔1시간 .79 · 15분↔4h .26 · 1시간↔4h .27. 상·하위 20% 신호가 같이 날 때 15분·4h 같은 부호 74%. 같은 부호일 때 적중 57.1/56.9% vs 반대일 때 54.4/52.0%. 교차 IC 는 각 모델이 자기 지평에서 최고(.062/.062/.054). → 정보를 나눠 쓰면 오를 여지, 억지로 같게 하면 특화가 깎일 위험.
- playbook: **리지를 강한 기준선으로**(xsec 10-26) → 결합층은 리지. **시드 앙상블 효과와 구조 효과 분리** → 통합 모델은 기준과 같은 시드 수(5). **호가 깊이는 4h 에 넣으면 시험 IC .036→.013**(depth_incr 10-28) → 통합 모델이 4h 를 깎는지 지평별로 따로 본다. **같은 행·같은 라벨·같은 평가 표적**으로 짝 비교.
- 시험 구간 재사용 공개: 2026-06~ 은 15분·1시간 배포 모델을 고른 창(연구 시험 .061/.059)이고 위 사전 관찰도 이 창이다. 4h 모델도 depth_incr 등에서 이 창을 썼다. → 통과해도 «조건부», 전진 확인 필요. 예상 우연 통과 ≈ 2팔 × .10.

## 데이터·시각 규약
- 원천(서버): `data/live/dirshort_panel/*USDT.parquet`(20코인 vision 5분) · `data/live/dirshort_book.parquet`(ETH bookDepth, 2024-01-01~2026-10-27). 입력 행렬은 배포 코드 `live_eth_dir_short_20261028.dataset()` 그대로: 결정 시각 t = 봉 마감, 입력 = 봉 t−5분 행(65피쳐 `live_eth_dir4h.build_features` + 호가 깊이 10열), ret_t = 다음 봉 단순수익, σ24_t.
- 평가 표적(모든 팔 공통): 지평 h ∈ {3, 12, 48}봉 앞 단순수익 합 Σ ret_t..t+h−1 (σ 로 나누지 않음). 평가 지표 = 스피어만 IC(순위 상관), ETH 하나.
- 학습 행은 표적이 학습 끝(적합 시점 m 의 첫 봉) 전에 확정된 행만: 배포 `train_rows(…, h)` 규칙(i ≤ m0−h−2).

## 구간·적합 시점
| 구간 | 기간 | 쓰임 |
|---|---|---|
| 학습 | 2024-01-01 ~ 적합 시점 | 모든 팔 적합 |
| 검증 | 2026-01-01 ~ 2026-05-31 | 적합 시점 A = 2026-01-01 모형으로 예측 · 결합층 적합 · 통합 모델 검증 ΔIC |
| 시험 | 2026-06-01 ~ 2026-10-27 | 적합 시점 B = 2026-06-01 모형(검증까지 학습)으로 예측 · 1회 채점 |
(배포는 매달 재적합 — 이 실험은 모든 팔을 같은 두 시점에만 적합해 공평 비교. 시험 끝으로 갈수록 모든 팔이 같이 낡는다.)

## 팔
- **기준 B(현재 3모델, 배포 레시피 그대로)**: 15분 = LightGBM BASE × 표적 4종(rg·clip2·huber·sign) × 배포 SEEDS 5개, 2024-01~ 확장 창 · 반감기 180일 가중 · 학습 예측 표준편차로 나눠 합 · 시드 평균. 1시간 = 같은 것, 가중 없음. 4h = HGB(배포 `HGB`, random_state 0) · 65피쳐 · 적합 시점 4h 전까지 365일 · 학습 행 [::2] · 표적 y_4h = 48봉 로그수익(bp).
- **S(구간 합 통합 모델 — 모델 1개)**: 쌓은 행(행 × 구간 3개) + 구간 번호 열 `seg` ∈ {0,1,2} + 75열. 구간 = [t, t+3) · [t+3, t+12) · [t+12, t+48) 봉의 단순수익 합을 σ24·√구간길이(3·9·36)로 나눈 값. LightGBM BASE 하나 × 목적 2종(clip ±2 L2 · huber α1, ±10 절단) × 무작위 시드 5개(`np.random.default_rng(2026102904)`) — 단위 보존을 위해 표준편차로 나누지 않고 그대로 평균. 확장 창 2024-01~, 가중 없음, 학습 행은 48봉 확정 기준.
  예측: p15 = ŝ0·√3 · p1h = p15 + ŝ1·3 · p4h = p1h + ŝ2·6 (σ24 단위 — 1시간은 15분을, 4h 는 1시간을 구조적으로 포함).
- **C(결합층)**: 지평마다 리지(α = 1) — 입력 = 기준 B 의 [p15, p1h, p4h](검증 구간 평균·표준편차로 표준화), 표적 = 그 지평 앞 수익 / σ24(±5 절단). 검증 구간(적합 시점 A 예측, 표적이 검증 안에서 확정된 행)으로 적합 → 시험에선 적합 시점 B 의 기준 예측에 같은 표준화·계수 적용.

## 주 판정 (팔마다, 시험 구간)
ΔIC_h = IC(팔) − IC(기준 B), 같은 행. 부트스트랩: 시험 날짜를 5일 블록으로 2,000회 다시 뽑아(행은 날짜 따라감) 세 지평 ΔIC 를 같은 표본으로 계산(순위는 전체에서 한 번 매긴 뒤 피어슨).
- **채택(조건부)**: ① 세 지평 평균 ΔIC 의 단측 90% 하한(10분위) > 0 ② 어느 지평도 «유의하게 악화» 아님 = 지평별 ΔIC 90분위 ≥ 0 ③(S 만) 검증 평균 ΔIC > 0.
- **비열등(일관성 목적)**: 채택 못 해도 ①′ 평균 ΔIC 10분위 > −0.005 ② ③ 이면 «비열등» — 이때 일관성 지표가 기준보다 나아야(아래 엇갈림 비율 감소) 화면 교체 후보.
- **통과 후보(완화)**: 검증·시험 평균 ΔIC 둘 다 > 0(C 는 검증이 적합 구간이라 시험만).
- 지표는 행 수·지평별 IC·ΔIC·CI 로 보고.

## 일관성 지표 (보조, 비열등 판정에만 씀)
- 엇갈림 비율 = 15분·4h 둘 다 신호(검증 구간 예측의 20/80 분위 밖)일 때 반대 부호 비율(기준 사전 관찰 26%). 15분↔1시간, 1시간↔4h 도 보고.
- 같은 부호·반대 부호일 때 각 지평 적중률.

## 보조 (판정에 안 씀)
검증 IC 전부 · 월별 IC · S 의 구간별 IC · C 계수 · 지평 바꿔 본 교차 IC.

## 시행 기록
주 판정 2팔(S, C). 설정 탐색 없음(모두 고정). 이 주제 첫 사전등록.
