## 왜 (과거 실패 교훈 반영)
- 세 칸은 이미 화면에 있는데 달력에 판정이 없다. 판정이 없으면 언제까지 믿을지 정할 수 없다.
- 시험 창(2026-06~)은 재사용이 많아 깨끗하지 않다(`session_vwap_div_momo_result` 기준 최소 9개 연구). 깨끗한 증거는 전진뿐이다.
- 점프 위험 칸은 시험 ΔAUC +.021 이 전진에서 +.0046 으로 사라졌다(`dashboard_candidates_forward_20261103`) → 시험 통과만으로 표시를 유지하지 않는다.
- 전진 9일(10-24~11-01)은 추세장 한 구간이라 크기를 믿을 수 없었다 → 이번엔 구간 길이를 먼저 계산했다. 독립 창 4개 시험이 국면 하나로 판정을 정한 매크로 교훈과 같다.
- 신호가 추세일에 몰리면 초과 적중이 왜곡된다(`stock_dir_short_zeroshot_20261104`) → 같은 날 기준선을 보조로 함께 낸다.
- 위약·Holm 검정력 함정(`meta_label_race_b1_20261101`): 이 문서는 칸마다 독립 판정이고, Holm 보정 p 는 보조로만 낸다. 위약 순위 검정은 쓰지 않는다.

## 데이터·시각 규약
- 15분·1시간·4h 코인 간: 서버 `data/live/pred_record/{COIN}.jsonl`, `xsec.jsonl`. 대시보드 5분 루프가 쓴 **실시간 기록만** 쓴다. `pred_record_backfill`(재구성)은 쓰지 않는다.
- t = 결정 시각(봉 시작 + 5분), px = 그 봉 종가. 수익 = px[t + H] / px[t] − 1. H = 3봉(15분)·12봉(1시간). 수익이 0 이거나 끝 가격이 기록에 없는 결정은 뺀다.
- 신호 = 화면과 같다: 분위 ≥ 80 롱, ≤ 20 숏.
- 띠 안·이탈: 서버 `data/live/regime_band_forward_scored.jsonl`(기록해 둔 지지·저항으로 4시간 뒤 채점). 필드 `y`·`correct`·`confidence`(= |p − .5| × 2) 그대로.
- 재학습: 15분·1시간은 서빙 파이프라인을 판정한다(매달 재학습은 설계의 일부, 동결 아님). 구간 안 재학습 시각은 결과 문서에 적는다. 띠 안·이탈 모델은 동결(md5 `f62774c6…`, 학습 2026-10-23 까지)이라 판정 때 md5 를 기록한다.

- 15분: 전진 9일 하한으로 역산한 일 SD ≈ 7%p → 60일 SE ≈ 0.9%p. 참값 +4%p 면 검정력 > 99%.

## 주 판정 (사전에 고정) — 10개

**M9 · 띠 안·이탈 (4코인 합침)** — 셋 다 만족:
1. 정확도 점추정 ≥ 64.8% (시험 기하 로지스틱 61.8% + 3%p, 11-02 제안 그대로. 전진에서 기하 기준선을 다시 낼 수 없어 고정값을 쓴다)

3. 확신 0.6↑(p ≥ .8 또는 ≤ .2) 정확도 점추정 ≥ 80%

**M10 · 4h 코인 간 반전**: 9코인 4h 격자에서 (직전 4h 수익 순위, 다음 4h 수익 순위) 상관의 평균. 통과 = 일 블록 단측 90% 상한 < 0.
