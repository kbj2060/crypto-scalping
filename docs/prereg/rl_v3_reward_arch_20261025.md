## 축 1 — 보상(점수 규칙) 3종
슬리브 하루 순수익 r(수수료·펀딩 포함) · UNIT = 0.25/√365 · 회전 비용 항 κ = 10bp × 회전 명목/순자산(학습에만).
- **Z (Zhang·Zohren·Roberts 2019)**: R = (r − κ·회전) / UNIT. (v2-A 와 같음, 기준)
- **DSR (Moody·Saffell 2001 차분 샤프)**: x = (r − κ·회전)/UNIT · A ← A + η(x − A), B ← B + η(x² − B), η = 1/60 · R = (B₋ΔA − ½A₋ΔB)/(B₋ − A₋²)^{3/2}, ΔA = x − A₋, ΔB = x² − B₋ · 초기 A = 0, B = 1 · R 을 [−10, 10] 로 자름.
- **DD (하방 위험형)**: R = Z − λ·max(0, dd_t − dd_{t−1})/UNIT, dd = 1 − 순자산/에피소드 최고, **λ = 2 고정(결과 전에 정함, 튜닝 안 함)**.
- 보상 크기 점검(채점 전): 교사 경로에서 보상별 걸음당 |R| 평균을 재서 엔트로피 항(0.001 × ln3 ≈ 0.0011)과의 비를 기록한다(09-14 관망 수렴 교훈).

- **MLP**: 관측 = 그날 시장 13 + 포지션 3 → pi·vf [64, 64] tanh (v2-A 와 같음).
