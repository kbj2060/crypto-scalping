## 왜 (과거 교훈 반영)
- 앞선 SMC 검정(09-14 스윕 · 09-16 ICT 3종 · 09-27 CHoCH/BOS)은 전부 **매매 손익**으로 판정했다. 이번엔 사용자 지시(10-10 «목적 정확도로 판정»)대로 **지표 하나하나의 주장 자체**를 확률로 잰다.
- 09-16 교훈: «FVG 가 봉의 27% 를 덮는다 = 존 터치는 신호가 아니라 배경». → 모든 주장은 **기하 위약**(같은 변동성, 방향 기억 없는 가짜 가격)과 비교한다. 무작위 가격에서도 같은 비율이 나오면 그 «의미»는 그림이 만든 착시다.
- 09-16: 피벗·스윕은 적중 우위 +3~6pp 가 실재했다(수익은 못 냄) → 이번 판정은 손익 없이 그 «적중»만 본다.
- 공개 파이썬 패키지 `smartmoneyconcepts`(joshyattridge) 원본을 읽은 결과 **미래참조가 설계에 들어 있다**: 스윙은 뒤 N봉으로 확정, BOS/CHoCH 는 «나중에 실제로 뚫린 것만» 남기고, 유동성 허용폭은 **전체 기간 고저폭**으로 정한다. 차트에서 «잘 맞아 보이는» 이유의 일부일 수 있다 → 이번 구현은 전부 **그 시점에 알 수 있는 것만**(LuxAlgo 방식 인과 판정)으로 다시 쓴다. 패키지 식과 다른 점은 아래에 적는다.
- 사건 라벨 경계 계약: 사건이 알려지는 봉 S 의 마감 뒤부터 결과를 센다. 기준가는 체결 가능한 값(봉 종가 또는 존 가장자리).
- 재사용 공개: 4코인 2022~26 가격은 수천 시행이 지나갔다. 이번엔 적합·선택이 없으므로(모든 매개변수는 원 지표 기본값) 고르기 편향은 없고, 다중 검정만 Holm 으로 다룬다.

## 데이터·시각 규약
- 바이낸스 USDT-M 1분봉 ETH·BTC·SOL·XRP, 2022-01-01 ~ 2026-11-13. 15분·1시간 봉으로 집계(1분이 다 찬 봉만). 시가 열이 없어 **시가 = 직전 봉 종가**.
- ATR = 참범위 14봉 단순평균(봉 t 마감까지).
- 모든 사건은 «알려진 봉» S 의 종가 시점에 생기고, 결과는 S+1 봉부터 센다.

## 지표 정의 (원 기본값, 인과)
- **스윙**(LuxAlgo 기본 길이 5 = 내부 구조 · 50 = 스윙 구조): 봉 p 의 고가가 앞뒤 N봉 최고 → 스윙 고점, **알려지는 시각 p+N**.
- **BOS/CHoCH**(LuxAlgo): 가장 최근 확정 스윙 고점(아직 안 뚫린 것)을 **종가가 위로 넘으면** 상방 돌파. 직전 추세가 하락이었으면 **CHoCH(전환)**, 아니면 **BOS(지속)**. 추세 = 마지막 돌파 방향. 하방 대칭. 알려지는 시각 = 돌파 봉.
- **오더블록 OB**(패키지·LuxAlgo 공통): 상방 돌파 때, 돌파된 스윙 고점 다음 봉 ~ 돌파 직전 봉 중 **저가가 가장 낮은 봉**의 [저가, 고가]. 하방 대칭. 알려지는 시각 = 돌파 봉.
- **FVG**(패키지 식): 봉 i 가 양봉이고 high[i−1] < low[i+1] → 상방 갭 [high[i−1], low[i+1]]. 음봉 대칭. 알려지는 시각 = i+1.
- **같은 고점·저점 EQH/EQL**(LuxAlgo): 길이 3 스윙, 연달아 나온 두 스윙 고점 차이 < 0.1 × ATR(200) → EQH, 수준 = 둘 중 높은 값. 알려지는 시각 = 두 번째 스윙 확정 봉. (패키지의 «전체 기간 고저폭 1%» 허용폭은 미래참조라 안 씀.)
- **전일 고점·저점 PDH/PDL**(ICT 핵심 가격대): UTC 전날 고가·저가. 그날 처음 닿는 봉.

## 주장과 측정 (사전에 고정)
| # | 지표가 뜻하는 것 | 측정(실제 비율) |
|---|---|---|
| S1 | CHoCH = 추세 전환 | CHoCH 뒤 **다음 구조 돌파가 같은 방향**(= 새 추세가 한 다리 더 감) 비율 |
| S2 | BOS = 추세 지속 | BOS 뒤 다음 구조 돌파가 같은 방향 비율 |
| S3 | OB = 되돌아오면 지지·저항 | 생성 뒤 100봉 안 첫 터치에서 «버팀»: 존 가장자리 + 1 ATR(반응 방향)에 **존 먼 쪽 종가 이탈보다 먼저** 닿음(터치 봉은 이탈만 검사, 목표는 다음 봉부터, 100봉 안 미결 = 못 버팀) |
| S4 | FVG = 갭은 메워진다 | 알려진 뒤 50봉 안에 갭 안으로 되돌아옴(상방 갭: 저가 ≤ 갭 위쪽) |
| S5 | FVG = 되돌아오면 지지·저항 | S3 와 같은 «버팀» 규칙을 갭에 |
| S6 | EQH/EQL = 유동성이 쌓여 가격이 끌려간다 | 알려진 뒤 100봉 안에 수준을 넘음(스윕) |
| S7 | 스윕 = 유동성 사냥 뒤 반전 | EQH 를 넘은 봉 종가 기준, 100봉 안에 −1 ATR 이 +1 ATR 보다 먼저(EQL 대칭) |
| S8 | PDH/PDL = 핵심 가격대에서 반응 | 그날 첫 터치 봉 종가 기준, 100봉 안에 반대쪽 1 ATR 이 먼저 |
- 칸: S1·S2·S3 × 스윙 길이 {5, 50} × 봉 {15분, 1시간} = 12 · S4·S5·S6·S7·S8 × 봉 2 = 10 → **22칸**.

## 대조 (위약)
- **P1 기하 위약(주 대조, 모든 칸)**: 1분 로그수익의 부호를 1분마다 무작위로 뒤집은 가짜 가격(1분 안 고가·저가 폭도 같이 뒤집음). 변동성 경로·거래량은 실제와 똑같고 방향 기억만 없다. 코인마다 20벌(시드 20261115+k). 같은 탐지기·같은 측정.
- **P2 바로 옆 가격대(존·수준 칸 추가 대조)**:
  - S3·S5: 같은 존을 **존 높이만큼 위나 아래로 한 칸 옮긴 띠**(무작위)에 같은 규칙 — «정확히 그 자리»가 특별한지.
  - S6: 같은 봉의 **평범한(같지 않은) 길이 3 스윙 고점·저점**의 스윕 비율을 «현재가와의 거리(ATR) 10분위»로 EQH 거리 분포에 맞춰 가중 — «같은 고점»이 아무 고점보다 더 끌어당기는지.
  - S7: 평범한 스윙 고점·저점을 넘은 봉에서 같은 반전 규칙.
  - S8: PDH/PDL 을 ±1 ATR 옮긴 가짜 수준(무작위)에서 같은 규칙.

## 주 판정 (사전에 고정)
칸마다 «의미 맞음» = 아래 전부:
1. 실제 − P1(20벌 합동 평균) > 0, 실제 쪽 달력일 군집 부트스트랩(2,000회) 분산 + 위약 벌 사이 분산(/20) 으로 만든 **단측 90% 하한 > 0**, 22칸 **Holm(α .10)**.
2. P2 가 있는 칸은 실제 − P2 도 단측 90% 하한 > 0(같은 부트스트랩).
3. 코인 4개 중 3개 이상, 두 구간(2022-01~2024-12 / 2025-01~2026-11) 모두 같은 부호.
- **통과 후보**: 1·2 의 점추정 > 0 + 3 충족(유의성 없이).
- **반대로 맞음(의미가 거꾸로)**: 1 의 부호를 뒤집어 같은 기준을 넘으면 따로 보고.

## 보조 (판정에 안 씀)

## 한계 (먼저 적음)
시가 = 직전 종가 · 1분 안 고가·저가 순서 모름(같은 봉에서 목표·이탈 동시면 이탈 먼저 = 보수) · P1 은 변동성 군집은 보존하지만 «1분 안» 방향 구조는 그대로 · LuxAlgo 의 OB 고변동 봉 거르기(ATR 필터)·FVG 자동 문턱은 생략 · 현재 상장 코인만.
