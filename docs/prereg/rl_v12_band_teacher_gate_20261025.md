# RL v12 — 청산 띠 교사(방향) + PPO «쉬기» 게이트 · 202 피쳐 (2026-10-25, 채점 전 커밋)

## 왜
사용자(10-25): «청산띠로 기본으로 방향을 정하고, RL 에이전트가 다른 입력 피쳐들의 상관관계와 현재 상황을 학습하면서 여기서는 쉬어야겠다는 결정을 배웠으면» · «입력 피쳐는 호메로스·일리아스 등에서 추출한 최종 202 피쳐를 참고».
방향은 RL 이 찾지 않는다(v4~v9: IC ≤ .06 방향은 PPO 가 못 찾음). RL 은 교사 거래마다 «들어갈까 / 쉴까»만 정한다(잔차 게이트, v5 구조). v5 퇴화 원인(DD λ2 보상 → 쉬기 최적) · v6 고장(BC 초기화) 을 피해 **Z 보상 · BC 없음 · 0 걸음 체크포인트 제외**.
🔴 사전 근거: 같은 띠 후보의 지도학습 «이 거래가 이길까» AUC 는 .50~.54(10-14 pingpong_v2 대시보드 벽판 · 10-12 띠 스윕) — 게이트가 쓸 정보가 적을 가능성이 크다. 그래서 같은 피쳐의 지도학습 게이트(HGB)와 같은 비율 무작위 쉬기를 함께 대조한다.

## 교사(고정, 튜닝 없음)
- 띠 = 10-12 `edges_long.parquet`(대시보드 풋프린트 보이는 칸 t≥0.25, 2022-01~2026-10-10). 행 t = 봉 t **끝** 계산 → 봉 k 는 행 k−1 만 쓴다(10-24 정정).
- 평탄일 때 봉 k 안 1분봉에서 처음 저가 ≤ 아래 가장자리 → 롱 지정가 체결가 = min(가장자리, 직전 1분 종가) / 고가 ≥ 위 가장자리 → 숏 = max(가장자리, 직전 1분 종가). 같은 1분에 둘 다면 사건 버림.
- 청산: 익절 = 반대 띠 가장자리(진입 봉의 행 k−1 값 고정, 지정가) · 손절 = 진입가 ∓5% · 시간 24h. 체결 **다음 1분부터** 1분 고·저로 판정(손절 먼저).
- 비용: 진입 메이커 2bp · 익절 메이커 2bp · 손절·시간 테이커 5bp. 명목 1배 · 한 번에 한 포지션(청산 뒤 다음 봉부터 새 사건).
