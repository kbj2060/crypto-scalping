## 규칙 (탐색에서 고정, 조율 없음)
- **R1 마감 30분 되돌림**: 거래일 d 에 s = sign(px(15:30) ÷ 전 거래일 px(16:00) − 1). s ≠ 0 이면 15:30 에 **−s** 방향 진입, 16:00 청산. 비용 전 수익 g = −s × (px(16:00) ÷ px(15:30) − 1).
- **R2 첫 1시간 이어짐**: s = sign(px(10:30) ÷ px(09:30) − 1). s ≠ 0 이면 10:30 에 **+s** 방향 진입, 15:30 청산. g = s × (px(15:30) ÷ px(10:30) − 1).
- 크기 1배 고정(명목 = 자본). s = 0 인 날은 거래 없음(건수 보고).

## 비용
- 엄격: 테이커 5bp × 2 + 미끄러짐 1bp × 2 = **왕복 12bp**(스프레드 실측 1.1bp, 10-22). R2 는 보유 중 펀딩 시각(16:00 UTC)을 한 번 지나므로 방향과 무관하게 **+1.5bp**(평균 펀딩 1.37bp/8h 를 늘 내는 쪽으로 가정) → 13.5bp. 수수료 우대 가정 없음.
- 통과 후보(메이커 진입판): 결정 시각 T 에 px(T) 지정가. [T, T+5분) 1분봉 저가(롱)·고가(숏)가 지정가를 **넘어 지나가면** 그 값에 체결, 아니면 그날 거래 없음. 비용 = 메이커 2bp(USDT 무기한은 0 이 아니다) + 청산 테이커 5bp + 미끄러짐 1bp = 8bp(R2 는 +1.5bp).

## 주 판정 (규칙마다 따로, 전부 만족하면 «엄격 통과»)
거래일 단위 부트스트랩 10,000회(시드 20261117). 순수익 n = g − 비용.
1. **순수익**: 평균 n > 0 이고 양측 p(부트스트랩 평균이 0 이하일 비율 × 2) 가 **Holm**(두 규칙 중 작은 p < .025, 큰 p < .05, 작은 쪽이 떨어지면 둘 다 탈락)을 통과.
2. **날짜 섞기 위약**: 신호 s 를 다른 날의 수익 창과 짝지은 10,000회 순열 대비 실제 평균 g 의 분위 ≥ 97.5.
3. **양쪽 다리 초과**: 같은 창을 늘 롱·늘 숏으로 든 것보다 평균 g 가 둘 다 큼(차의 평균 > 0, CI 는 보고).
4. **두 절반**: 08-15 경계 앞·뒤 모두 평균 g > 0.
- **존재 확인**(돈 주장 아님): 1 을 비용 전 g 로 바꿔 Holm 통과 + 2 + 4.
- **통과 후보**: 메이커 진입판 순수익 평균 > 0 · 2 의 분위 ≥ 50 · 3 · 4.
- 보고는 분모·건수로: 거래일 수, 거래한 날, 이긴 날 `a/b`, 평균·중앙 bp, 90%·95% CI, 롱/숏 다리별 평균과 건수, 1배 기준 누적·최대 낙폭.
- 검정력(미리 적음): 탐색 전체 크기(−21.6bp, 일 표준편차 147bp)면 125일 순수익 t 기대 0.7 — **엄격 통과 가능성 낮음**. 2025~26 크기(−36~−46bp)면 t 1.8~2.6. R2 는 +37bp·표준편차 약 430bp → 순수익 t 기대 0.6. 즉 엄격 불통과 ≠ 효과 없음이고, 이때 읽을 줄이 «존재 확인»과 방향·절반 일치다.
