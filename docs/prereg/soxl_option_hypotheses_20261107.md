# 사전등록: SOXL 옵션 가설 검증 — 반도체 대리 IV · 자체 체인 5일 (2026-11-07)

**등급: H1 되돌리기 쉬운 예측 개선 — 단측 90%. H2 방향(돈이 걸릴 수 있는 신호) — 양측 95%.** 완화 등급: H1 은 후보 없음(통과/불통과만), H2 는 매매를 재지 않아 해당 없음.
**이 문서는 계산 전에 커밋한다.** 내려받은 IV 는 결측·급변만 봤고 SOXL 수익·변동성과의 관계는 보지 않았다. 스크립트: `scripts/research_soxl_option_hypotheses_20261107.py`. 사용자 «soxl에서 옵션 가설들은 들어맞는지 검증해줘».

## 왜 (과거 실패 교훈 반영)
- 코인에서 옵션은 방향 불통과·크기 통과였다(`option_flow_direction`, `vrp_timing`, `vol4h_forecast_horserace`). 같은 두 축만 먼저 잰다.
- SOXL 자체 체인은 2026-11-02~06 5거래일뿐이라 자체 데이터로는 판정할 수 없다. 공개 DB(DoltHub `post-no-preference/options`)에 SOXL·SMH·SOXX 는 없고 구성 종목은 있다 → **SOXL 옵션이 아니라 대리 지표 검정**이다. 통과해도 «SOXL 옵션이 맞는다»가 아니라 «반도체 옵션 IV 가 SOXL 변동성에 정보가 있다»까지만 말한다.
- 30일 IV 로 하루 변동성을 재면 기간구조 착시가 난다(`vrp_timing` 1b) → 지평을 5거래일로 두고, 만기 불일치는 한계로 적는다.
- 느린 피쳐는 지연 위약으로 재야 한다(liqlab 검수) → 위약을 주 판정에 넣었다.
- 0건 결과엔 양성 대조가 필요하다 → 미래 실현변동성을 넣은 판과 무작위 판을 함께 돌린다.
- 옵션 검증은 2026 만(사용자 규칙) → IV 는 2026-01-02 부터만 쓴다.
- 재사용 공개: SOXL 2026 가격은 10-22 추세 규칙·11-04 방향 제로샷에 쓰였다. 이 IV 로는 처음이다. 주 판정 2개, 우연 통과 기대 약 0.15개.

## 데이터·시각 규약
- **바스켓 IV**: `volatility_history.iv_current`, 11종목(AMAT·AMD·AVGO·INTC·KLAC·LRCX·MU·NVDA·ON·QCOM·TXN) log 평균, 11종목 중 ≥ 8 있는 날만. 고정 가중치(지수 비중 안 씀). MRVL 은 07-01 부터라 뺐고, TSM·ASML 은 원천에 없다. `iv_current` 의 정의(만기·계산법)는 원천에 문서가 없다 — 한계.
- **시각**: d 일 종가 결정에는 **d−1 거래일 행**만 쓴다. 행 날짜가 종가 전인지 후인지 확인할 수 없어 미래참조를 원천 차단한다. d 일 행을 쓴 값은 보조.
- **SOXL 실현변동성**: 저장된 ETF 60분봉(`soxl_etf_60m.csv`, 2026-10-21 까지). 봉 수익 = close[t]/close[t−1], 첫 봉에 밤사이 포함. |수익| > 40% 인 봉은 액면 변경으로 보고 뺀다(건수 보고). RV_d = 그날 봉 r² 합.
- **표적**: log(다음 5거래일 RV 합). 피쳐 창 끝 = d, 표적 시작 = d+1.

## 주 판정 2개
**H1 · 크기**: A = HAR(log RV 1·5·22일) vs B = A + log(바스켓 IV). 평가 구간 ΔMSE(B − A, 로그 오차²).
1. 주(週) 블록 부트스트랩(B = 2,000, 시드 20261107) 단측 90% 상한 < 0
2. 지연 위약: 바스켓을 21·26·…·61거래일 과거로 민 9판보다 실제 ΔMSE 가 낮은 수 ≥ 8/9

둘 다 만족해야 통과. 일 평가 행 < 60 이면 «보류(표본)».

**H2 · 방향**: z = 바스켓 log IV 의 직전 60거래일 z 점수 → 다음 5거래일 SOXL log 수익. 스피어만 IC 의 주 블록 양측 95% CI 가 0 제외. 불통과면 방향으로 쓰지 않는다. 지표는 z>1·z<−1 칸의 오름 비율을 `a/b` 로 함께 낸다(기저 오름 비율 병기, 추세장 왜곡 확인).

## 대조 (판정 전 통과해야 함)
- 양성: 바스켓 자리에 **미래 5일 실현변동성**을 넣은 판은 H1-1 을 통과해야 한다. 못 하면 장치 불량 → 판정 중단.
- 음성: 바스켓 자리에 같은 분포의 무작위 값(시드 고정)을 넣은 판은 ΔMSE ≥ 0 이어야 한다(적합 벌점). 어기면 원인을 먼저 본다.
