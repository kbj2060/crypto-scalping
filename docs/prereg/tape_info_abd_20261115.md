## 주 판정 (사전에 고정)
칸 c 마다 행별 손실 차 d = loss_새팔 − loss_⓪(음수 = 새 팔이 나음)를 4코인 합동 시험 행에서 UTC 일 블록 부트스트랩 2,000회 → 평균의 단측 90% 상한(`research_ob_info_map_gbm_20261115.boot` 그대로).
- 계열 QA(A vs ⓪) · QB(B vs ⓪) · QD(D vs ⓪) 각 31칸.
- **엄격 통과**: 단측 90% 상한 < 0 **그리고** 계열 안 Holm(α .10, 31칸) **그리고** 같은 칸 위약보다 나음(d_새팔 < d_Z, 같은 행).
- **통과 후보**: 단측 90% 상한 < 0 그리고 코인 4개 중 ≥3 같은 부호(개선) 그리고 d_새팔 < d_Z.
- 위약 Z 가 어떤 칸에서 «엄격» 조건(상한 < 0 · Holm)을 혼자 만족하면 결과 문서 맨 앞에 적고 그 칸의 A·B·D 판정은 «위약 통과 — 판정 보류».
- 보고: 칸마다 행 수 · 일 수 · 코인별 행 · 기준 손실 · 상대 개선(%) · 보조 지표(IC·AUC·QLIKE) · 판정 등급. 시험 14일 → 1시간 칸 독립 창 ≈ 336 — 넓으면 «판정 불가»(통과·불통과와 구분).
- 사전 가설(틀려도 판정 안 바뀜): QA = 체결 확률·급변 1~5분에 작은 개선, 방향은 1~10초만. QB = 지연 1 에서는 1~10초 방향 작은 개선 또는 0(Albers 2021: 바이낸스가 선도 쪽). QD = 흐름 10·60초 대상은 ⓪ 만으로도 상당히 맞고(지속성), D 가 300초 흐름에서 추가 · 가격 방향은 0.
