## 판정 트리 (칸마다, 판정 창 안 사건만 · 일 블록 부트스트랩 2000 · `SM.judge` 그대로 + 아래)

1. 건수 n < 30 → **판정 불가(건수 미달)**.
2. Holm 생존 & lo1 > 0 & lo2 > 0 & 두 반쪽 d1 > 0 → **엄격 통과**.
3. d1 단측 p_rev ≤ .10/묶음 크기 & 두 반쪽 d1 < 0 & d2 < 0 → **거꾸로**.
4. 기준 효과 ref1(가짜)·ref2(대조, 기준이 ≤0 이면 이 비교 빼고) 중 하나라도 hi < ref 이면 → **불통과**(SOXL 효과가 원 효과보다 작다고 90% 로 말할 수 있음).
5. 그 밖 → **판정 불가(검정력 부족)** — 구간이 0 과 원 효과를 둘 다 품어 «같은 뜻»도 «다른 뜻»도 말할 수 없음.
