## R2a — T5 방향 + EMA/VWAP 지정가 진입 (격자 10)
- 목표 방향 = 다음 봉의 T5 부호(UTC 00시에 어제 종가까지로 바뀜, 봉 t 마감에 알려짐). 보유 중 목표가 바뀌면 봉 t+1 시가(= c_t) 테이커 청산. 손절·익절 없음.
- 평평하고 목표가 있으면 진입 `entry` ∈ {mkt(00시 시장가 = 기준 T0), VW, E20, deep(롱 = min(VW,E20), 숏 = max)} 지정가(롱이면 레벨 < c_t 일 때만, 한 봉짜리, 매 봉 다시 걺).
- 미체결 대체 `fb` ∈ {없음, 48봉(4h), 144봉(12h)} — 목표가 선 뒤 그 봉 수 동안 못 채우면 시장가.
- 선정: 학습 샤프(후보 비용) 최대. 기준 T0 = entry mkt 는 항상 같이 보고.

## R2b — 전 재료 4h ML 방향 (고정 1개)
- 결정 시각 = 4h 격자(봉 03:55·07:55·… 마감 = 00·04·…시 UTC), 코인 4개.
- 피쳐 = 1라운드 메타 피쳐 35열 그대로(EMA5·20·세션 VWAP 거리·기울기·VWAP σ, 세션·시각, 수익 1~288봉, σ, 거래량, 테이커 매수비, OI 변화(한 봉 늦게), 톱트레이더·테이커 롱숏비, BTC 수익, T5, 코인).
- 표적 = 다음 48봉 단순수익 합 / σ. 학습 행 = 2024-01-01 ~ 표적이 2025-12-31 23:55 전에 끝나는 행. LightGBM 회귀(n_estimators 300·lr .03·leaves 31·min_child 200·subsample .5·colsample .8·λ 10) × 시드 5(rng 2026102902) 평균.
- 규칙: 예측 > 학습 예측 80분위 → 다음 4h 롱 · < 20분위 → 숏 · 사이 → 평평. 같은 방향이 이어지면 그대로 보유(비용 없음). 진입·청산 = 결정 봉 다음 시가(= c_t) 테이커.
- 보조: 학습·검증 IC(예측 vs 표적, 4h 격자 행).
