# 사전등록: ETH 4시간 고점·저점 돌파 순간의 매매 강도로 «크게 이어짐 / 크게 되돌림» 판별 (2026-11-18)

**등급: 되돌리기 쉬운 예측 개선 — 단측 90%**(판별 정확도, 매매 주장 없음). 네 조건을 모두 넘어야 통과. 완화 «통과 후보» 병기.
**이 문서는 계산 전에 커밋한다**(2026 구간의 사건·피쳐·라벨은 이 커밋 뒤에 처음 만든다). 스크립트: `scripts/research_sr_intensity_20261118.py`(selftest · minutes · hilo · runhilo) · 원자료 가공 `scripts/build_eth_aggtrades_1s_20261118.py`.

사용자 11-18 /goal: «매매 강도를 계산해서 지지/저항을 뚫을 수 있을지 알 수 있는 모델을 다시 연구 · 통과할 때까지 지지/저항 돌파 혹은 되돌림 연구 · 과거 데이터와 실시간 데이터 · 이더리움만 우선».

## 학습 구간에서 본 것 (2024-01 ~ 2025-12, 이 설계의 출처 — 판정 아님)
탐색은 전부 2025-12-31 이전 자료로만 했다(`tmp/sr_intensity_20261118/explore*.py`). 본 조합은 약 150칸이다.
1. **화면 지지·저항선(11-10 연구의 ETH 첫 터치 4,648건 그대로)**: 초 단위 강도 27개를 더해도 결정 지연 5·30·60초 × 지평 5·15·60분 × 배리어 2종 72칸 대부분 AUC .48~.52 → 접음. 11-10(.518)·11-12(.491)와 같은 결론.
2. **4시간 고점·저점 첫 돌파(5,515건)**: 돌파 1초 뒤엔 «0.1σ 이어짐이 먼저» 57%(네 반기 55~58%), 5초 뒤엔 51% — 이어짐은 첫 몇 초에 끝난다.
3. 돌파 5초 뒤부터 60초 안에 ±0.25σ(약 15bp)를 닿는 «큰 움직임»은 36%(큰 이어짐 C 22.5% · 큰 되돌림 R 13.2%).
4. 강도 피쳐는 «큰 움직임이 나오느냐»를 잘 맞히고(AUC C .70 · R .78), **두드림·끌림 같은 맥락을 더하면 «이어짐이냐 되돌림이냐»도 갈린다**: 결판 난 것 중 C 대 R 교차검증 AUC .600(토막 .564~.663). 레벨을 직전 4시간에 많이 두드린 돌파는 C 비율 69%, 적게 두드린 돌파는 55%(네 반기 차 +10~+18%p). 직전 분 종가에서 멀리 뛰어 넘은 돌파(끌림 큼)는 C 50%, 가까이서 넘은 돌파는 69%.
5. 지평 5분은 방향 AUC .53 으로 약하다 → 주 판정은 60초, 5분은 보조.

## 왜 (과거 실패 교훈 반영)
- 11-10·11-12 지지·저항 연구: 봉 종가 시점 재료·호가 두께는 정보 0, «초 단위 체결이 쌓이면 다시» → 이번에 Vision aggTrades(2024-01~) 1초 묶음을 처음 썼다. 같은 사건·라벨 재현은 위 1번(정보 없음)으로 닫는다.
- 11-12 «합친 토막 밖 AUC 는 기저율 차로 치우친다» → 탐색은 토막 평균, 판정 위약은 **월 안에서** 라벨을 섞는다.
- 11-15 ORB «결판 난 경주만» 함정: 결판 비율이 다른 대조와 비교하면 오염된다 → 대조와 비교하지 않는다. 방향 판정(조건 2·4)은 «큰 움직임이 난 사건 중 어느 쪽이었나»를 모델 점수로 가르는 것이고, 전체 사건 기준 수치(조건 1·3과 C·R·N 표)를 같이 낸다.
- 11-17 «검증에서 고른 것은 뒤집힌다 · 가장 단순한 기준선을 주 판정에»: 모델·피쳐·문턱을 전부 학습 구간에서 고정하고(검증으로 고르는 것 없음), **강도 없는 기준선(평소 변동성·시각·24시간 고저 여부)** 대비 초과를 주 판정에 넣는다.
- 11-17 «기준 비율이 50% 가 아닐 수 있다»: 방향 기저(C÷(C+R))는 학습 63% 다. 판정은 정확도 문턱이 아니라 AUC·집단 간 차로 한다.
- 09-08 사건 라벨 경계: 사건(돌파 초 k)은 초 단위로 알려진다. 결정 = k+5초, 피쳐 = 초 ≤ k+5 와 분 < 돌파 분, 기준가 = k+5 까지 마지막 체결가, 라벨 = k+6 초부터. 1분봉 연구의 «OBS=0 무효» 규칙은 봉 안에서 일어난 사건을 봉이 끝나야 아는 경우의 것이고, 여기는 초 단위 자료라 5초 관찰로 충족한다.
- 같은 구간 재사용 공개: ETH 2026 은 여러 연구의 시험에 쓰였으나 **이 사건 정의(고저 돌파 초)·이 라벨은 2026 에서 계산한 적이 없다**. 이 /goal 의 1번째 채점. 탐색에서 본 조합이 많으므로(약 150칸) 학습 구간 수치는 낙관적일 것으로 본다.

## 데이터·시각 규약
- Binance USDT 선물 ETHUSDT aggTrades(Vision 일 파일) 2024-01-01 ~ 2026-11-15 → 1초 묶음(가격 첫·고·저·끝, 테이커 매수·매도 수량, 체결 수). 1분봉은 이 묶음에서 만든다.
- **사건**: 분 i 의 고가(저가)가 직전 240분 고점(저점) L 을 넘는 첫 분 — 직전 60분에 같은 쪽 돌파 없음.
  - **채점 전 수정(스크립트 자체점검이 잡음, 2026 자료 계산 전)**: 처음 적은 «같은 분에 반대쪽도 넘으면 제외»를 뺀다. 그 규칙은 돌파 분의 끝까지(결정 뒤 최대 55초) 고가·저가를 써서 사건 선택에 미래가 들어간다. 탐색(학습 구간)은 그 규칙이 든 채였다. 뺀 판의 학습 수치: 사건 5,544 → 5,549(4건 추가) · C 1,241 · R 736 · N 3,572 · 교차검증 방향 AUC .603(토막 .565~.669, 기준선 .533) · 방향 점수 상위 20% 는 C 129 대 R 37, 하위 20% 는 C 374 대 R 314 — 결론은 같다. 돌파 초 k = 그 분에서 체결가가 L 을 넘은 첫 초. σ1h = 직전 1,440분 1분 수익 표준편차 × √60(분 i 이전).
- **결정** t_d = k + 5초. 기준가 P = t_d 까지 마지막 체결가.
- **라벨(3분류, 전체 사건)**: t_d+1 초부터 60초 안에 P·e^{±0.25σ1h} 중 돌파 쪽을 먼저 닿으면 **C(큰 이어짐)**, 반대쪽 먼저면 **R(큰 되돌림)**, 둘 다 아니면(또는 같은 초) **N**.
- **피쳐**(고정): 기준선 4(log σ1h · 시각 sin·cos · 24시간 고저 여부) + 강도 11(돌파 전 60·10초 거래량·체결 수·가속, 매수 비중 60·10초, 접근 속도 60·300초, 돌파 뒤 5초의 거래량·매수 비중·레벨 대비 위치) + 맥락 10(레벨 나이, 직전 4시간 두드림 수, 4시간 범위, 15·60분·1일 흐름, 끌림, 60·240분 테이커 비중, 방향).

## 주 판정 (시험 구간 · 달력일 블록 부트스트랩 2,000회 · 시드 20261118 · 전부 만족)
1. **크기**: 3분류 로그손실(모델) − 로그손실(기준선)의 단측 90% 상한 < 0.
2. **방향**: C·R 로 결판 난 사건에서 r 의 AUC 단측 90% 하한 > 0.5, 그리고 월 안 라벨 섞기 위약 1,000회의 95분위보다 큼.
3. **집단 차**: r 이 학습 80분위 이상인 사건 집단과 20분위 이하인 집단의 «결판 중 C 비율» 차 단측 90% 하한 > 0.
4. **모델 몫**: 방향 AUC(모델) − 방향 AUC(기준선)의 단측 90% 하한 > 0.
- **통과** = 1~4. **통과 후보** = 검증·시험 모두에서 점 추정이 1(차 < 0) · 2(AUC > 0.5) · 3(차 > 0)을 만족.
- 보고(분모·건수): 구간별 사건 수와 C·R·N 건수 · 집단별 C·R·N 건수(상위 20% / 가운데 / 하위 20%) · AUC C·AUC R · 강도만/맥락만 모델의 방향 AUC · 위·아래 돌파 따로 · 월별 · 24시간 고저만 · 단변량 방향 AUC 상위.
- 누수 신호: 방향 AUC > 0.75 이거나 단일 피쳐 방향 AUC > 0.70 이면 누수부터 의심.
