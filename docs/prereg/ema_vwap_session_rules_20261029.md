## 데이터·시각 규약
- 원천: 서버 `data/live/dirshort_panel/{ETH,BTC,SOL,XRP}USDT.parquet`(바이낸스 vision 5분봉, timestamp = 봉 시작, 시가 = 직전 종가). 4코인 같은 규칙.
- 결정 시각 = 봉 t 마감. 피쳐·신호는 봉 t 까지(EMA5·EMA20 = 종가 지수이동평균 adjust=False, 세션 VWAP 은 봉 t 포함), σ = 288봉 5분 단순수익 표준편차(봉 t 까지).
- 주문은 봉 t+1 에서만 체결: 시장가 = 봉 t+1 시가(= c_t). 지정가 매수 L = 봉 t+1 저가 < L 일 때 L 에 체결(관통), 매도 대칭. 지정가는 한 봉만 살고 매 봉 다시 건다.
- 체결 봉엔 익절 지정가를 보지 않고, 손절은 그 봉 저가(숏은 고가)가 손절가를 넘으면 그 봉에 손절(보수적). 한 봉에서 익절·손절 둘 다 닿으면 손절 먼저.
- 펀딩 무시(보고서에 명시). 코인당 명목 1배, 포트폴리오 = 4코인 일 손익 평균(bp). 일 = UTC 날짜, 봉 단위 시가평가.

## 1단계 A — 기본 재료만 (격자 192 = 변수 6)
- 정렬 `align` ∈ {A1: c > VW ∧ E5 > E20, A2: E5 > E20 > VW}(숏 대칭)
- 진입 `entry` ∈ {시장가, 지정가@E5, 지정가@E20, 지정가@VW}(롱이면 레벨 < c_t 일 때만 건다)
- 청산 `exit` ∈ {X1: 정렬 깨지면, X2: 반대 정렬이 서면}(봉 t+1 시가, 테이커)
- 익절 `tp` ∈ {없음, 1·σ1h, 2·σ1h}(σ1h = σ·√12, 진입가 기준)
- 손절 `sl` ∈ {없음, 1.5·σ1h}
- 세션 정리 `sflat` ∈ {0, 1}(1 = 세션 마지막 봉 마감에 청산)
- 선정: 학습 구간 4코인 포트폴리오 일 손익 샤프(통과 후보 비용) 최대. CSCV: 학습 24개월을 4개월 6묶음 → C(6,3)=20 분할, PBO = IS 최고 설정의 OOS 순위가 중앙 아래인 비율. DSR(시행 192).

## 2단계 (A 와 무관하게 미리 고정, 셋 다 학습에서만 적합)
- **B1 = A 격자 × 일봉 추세 필터**: `dashboard/trend_rule.py` 와 같은 T5 신호(완결 UTC 일봉 종가, L=7·14·28·56·90 부호 평균) 부호 쪽 방향만 거래. 같은 192 격자에서 학습 샤프로 선정.
- **B2 = ML 메타 라벨**: B1 선정 설정이 학습 구간에서 실제로 체결한 거래(4코인)마다 «통과 후보 비용 순손익 > 0» 라벨. 피쳐 = 주문 시각 t 값만: (c−VW)/σp·(E5−E20)/σp·(E20−VW)/σp·(c−VW)/VWσ · E5·E20·VW 3봉 기울기/σp · 세션 경과 봉·세션 이름·UTC 시·요일 · 수익 1·3·12·48·288봉/σ · σ·σ48/σ288 · 거래량 z · 테이커 매수 비율(봉·12봉) · OI 로그 변화 12·48·288 · 톱트레이더 롱숏비 z · 테이커 롱숏 거래량비 · BTC 수익 12·48(BTC 자신은 0) · T5 · 코인 번호 (σp = σ·c). LightGBM(n_estimators 300·lr .03·leaves 31·min_child 200·subsample .5·colsample .8·λ 10) × 무작위 시드 5개(`np.random.default_rng(20261029)` 에서 뽑음) 평균 확률. 주문을 p ≥ θ 일 때만 건다, θ ∈ {.50, .55, .60} 를 검증 샤프로 고른다(통과 후보 비용).
- (깊은 학습은 사용자 컨펌 규칙상 이번에 쓰지 않는다.)

## 고르기
