# 사전등록: 추세 거르개 묶음 — 일목 구름·슈퍼트렌드·EMA200 «롱 추세면 숏 금지» (2026-11-15)

**등급: 되돌리기 쉬운 거르개 — 단측 90%** + 완화 «통과 후보». 수익 전략 아님.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_trend_filter_bundle_20261115.py`.
사용자 «추세 거르개 묶음» — 직전 검정(`docs/experiments/choch_state_short_filter_20261115.md`, CHoCH 상태 불통과 · 일봉 SMA50 이 조금 나음) 다음으로, 흔히 «추세 확인»에 쓰는 지표 셋이 같은 일을 더 잘하는지.

## 왜
- 사용자 목적: 예측이 아니라 «지금 롱 추세면 숏을 잡지 않는다». 그래서 판정은 **상태별 숏 수익 차이**(직전 검정과 같은 측정)와 **상태가 얼마나 자주 뒤집히나**.
- 직전 결과: 15분 큰 스윙 CHoCH +2.3bp(4h, 유의 아님·25-26 거꾸로) · 일봉 SMA50 +3.6bp(4h)·+19.5bp(24h), 둘 다 유의 아님. → 같은 틀·같은 자료로 나란히 둔다.

## 정의 (원 지표 기본값, 봉 마감에 알려짐)
- **일목 구름**(9·26·52, 선행 26): 전환선 = (9봉 최고+최저)/2, 기준선 = 26봉, 선행A = (전환+기준)/2, 선행B = 52봉 (최고+최저)/2, 둘 다 26봉 앞으로 → 봉 t 의 구름 = t−26 에 계산된 A·B. 종가 > 구름 위 = **위**, < 구름 아래 = **아래**, 구름 안 = 중립.
- **슈퍼트렌드**(ATR 10 · 배수 3, TradingView 기본): hl2 ± 3×ATR(RMA 10), 최종 띠는 통상 규칙(위 띠는 내려가기만·직전 종가가 넘으면 새로), 종가가 위 띠 넘으면 위, 아래 띠 깨면 아래, 아니면 유지.
- **EMA200**: 종가 > EMA(200) = 위.
- 시간 단위: 각각 **1시간 · 4시간 · 1일** → 9개 상태. 15분봉 시점 t 에는 **t 까지 마감한** 그 단위 봉의 상태만 쓴다.
- 비교 기준(직전 검정 그대로): 일봉 SMA50 · 15분 큰 스윙(N50) CHoCH 상태.
- 결과: 15분봉 t 종가 숏의 H 시간 뒤 수익 = −(c[t+H]/c[t] − 1)×1e4 bp, H ∈ {1, 4, 24}. 비용 없음.

## 주 판정 (사전 고정)
9개 상태 각각, **4시간** 숏 수익 «아래 상태 − 위 상태»(중립 제외):
1. 7일 블록 부트스트랩(2,000회) 단측 90% 하한 > 0 · 9칸 Holm(α .10).
2. 기하 위약(1분 부호 뒤집기 20벌, 11-15 와 같은 시드) 같은 차이의 95분위 초과.
3. 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호.
- 통과 후보: 1 의 점추정 > 0 + 3.
- **SMA50 대비**(보조, 판정 안 씀): 차이 − SMA50 차이, 같은 7일 블록 부트스트랩 95%.
