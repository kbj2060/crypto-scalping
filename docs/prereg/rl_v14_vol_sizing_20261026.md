# RL v14 — 방향 모델 + 변동성으로 «크기»를 배우는 ETH 에이전트 (2026-10-26, 채점 전 커밋)

등급: **돈 걸린 매매** → 사용자 RL 상대 기준(교사·같은 노출 무작위 대비, 절대 손익은 보고만).

## 왜
- 사용자(10-26): «변동성이고 박스고 이것보다 매매를 잘하는 강화학습 에이전트가 필요하다».
- v4~v13 교훈: 방향 정보가 거의 없는 입력으로 «언제 들어갈지»를 배우면 우연 수준(띠 교사 게이트 72~89분위) · 낙폭 벌점 보상은 «항상 쉬기»로 퇴화(v5) · 장치 검증 없이 학습하면 실패 원인을 모름(v6).
- 바꾼 것: **방향은 기존 4h 방향 모델(표본 밖 예측)이 주고, RL 은 «얼마나 실을지»(크기·방향 강도·쉬기)를 배운다.** 문헌: Zhang·Zohren·Roberts(2019, J. Financial Data Science «Deep Reinforcement Learning for Trading») — 변동성 목표 크기 + 비용 포함 보상으로 선물 RL 이 기준 전략(보유·TSMOM·MACD)을 이김. 우리 연구: 4h 변동성 크기 조절이 꼬리 −19%·MDD −14%.

## 자료
- 방향: `data/live/eth_dir4h_oos_seed.parquet`(라이브 B2 HGB 매달 재학습 표본 밖 예측, 5분, 2023-01~**2026-09-14**) — 행 τ = 5분봉 시작, 값은 그 봉 마감 시점 예측(다음 4h 수익 bp). 결정 시각 t(정시)에는 τ = t − 5분 행.
- 가격: ETHUSDT 5분봉(바이낸스 vision 패널, 2026-09-14 까지).
- 분할(사용자 10-25): 학습 2024-01-01~2025-12-31 · 검증 2026-01-01~05-31 · **시험 2026-06-01~09-14**(방향 예측 끝 때문에 10-23 아님 — 공개).

## 환경(1시간 결정 · 1시간 보유)
- 크기 기준 σ̂ = 직전 24h 5분 수익 실현 σ(1시간 환산), σ* = 학습 구간 σ̂ 중앙값(고정). 명목 = a × σ*/σ̂, 상한 2배(규칙 B).
- 행동 a ∈ {−1, −0.5, 0, +0.5, +1}.
- 상태(전부 t 이전): 방향 예측/학습 표준편차 · ln(σ̂_1h, σ̂_4h, σ̂_24h, σ̂_7d / σ*) · 지난 1일·7일·30일 수익 / 같은 창 σ · 지난 4h 수익/σ · 현재 명목.
- 보상 = (명목 × 다음 1시간 수익 − 4bp × |명목 변화|) / σ*. 낙폭 벌점 없음(v5 퇴화 교훈).
- 교사(같은 크기 규칙 σ*/σ̂·상한 2배): T1 항상 롱 · T2 방향 모델 규칙(예측 > 학습 80분위 롱, < 20분위 숏, 사이 0 — 라이브 문턱과 같은 꼴) · T3 TSMOM(지난 30일 수익 부호).

## 학습
- stable-baselines3 PPO, MLP 64×64, 걸음 30만/시드, 에피소드 336걸음(2주) 학습 구간 무작위 시작, 체크포인트 3만마다 검증 샤프 최대(0걸음 제외).
- 시드 = `np.random.default_rng(2026102614).integers(1, 2**31-1, 5)`.
- **장치 검증(먼저, 1시드)**: 상태에 «다음 1시간 수익 × ρ=.3 + 잡음» 열을 심어 검증 샤프가 교사보다 크게 높아지는지 — 안 되면 환경·학습 버그로 보고 멈춤.

## 관문(시험 2026-06-01~09-14, 5시드 행동 다수결 = 평균 명목)
- **G1**: RL 샤프(시간 손익, 연환산) > max(T1, T2, T3) 샤프(점추정).
- **G2**: RL 총 순손익 > 원형이동 귀무(RL 행동 수열을 7일 이상 1,000회 밀기 — 노출·회전 같고 타이밍만 깸) 95분위.
- **G3**: 시드별로 검증·시험 모두 «최고 교사 샤프보다 높음»인 시드 ≥ 4/5.
- 통과 = 셋 다 → «후보(상대 기준)» → 전진 기록. 보고: 총·건당 bp, MDD, 회전, 평균 |명목|, 행동 분포, 교사별 표.
- 🔴 공개: 시험 구간(06~09-14)은 방향·변동성 연구에서 여러 번 열림(방향 모델 예측 자체는 표본 밖).
