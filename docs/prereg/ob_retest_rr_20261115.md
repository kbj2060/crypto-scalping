# 사전등록: 15분 오더블록 재진입 2라운드 — 손익비 재설계 (2026-11-15)

**등급: 돈 걸린 매매 신호 — 양측 95%** + 완화 «통과 후보». 1라운드 `docs/prereg/ob_retest_strategy_20261115.md`(d9db54cb·69b8685d)와 신호·진입·체결·비용·관문·대조를 **그대로** 쓰고, **손절·익절 구조만** 바꾼다.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_ob_retest_strategy_20261115.py` (환경변수 `OB_ROUND=2`).
사용자 «손익비 바꾼 OB 재설계».

## 왜
- 1라운드(`docs/experiments/ob_retest_strategy_20261115.md`): 존 자리 우위는 실재(옆 띠 대비 +15~21bp)하나 손절 = 존 반대편, 익절 = 1 ATR 이라 평균 이익 +49 / 손실 −82bp, 손익분기 적중 62.7% ≈ 실제 63.6%. → 손절을 **존 안쪽·좁게**, 익절을 **위험의 배수 또는 직전 고점(유동성)**으로 바꿔 손익분기 적중률을 낮춘다.
- 위험: 손절이 좁으면 체결 분 손절·잡음 손절이 늘어 적중이 손익분기보다 더 떨어질 수 있다. 판정 전에 설정마다 «실제 적중 − 손익분기 적중»을 같이 보고한다.

## 바뀌는 것 (이것뿐)
진입 = 1라운드와 같은 존 가까운 쪽 지정가(롱 = 존 위 L). 위험 r = L − 손절가.
| 변수 | 값 |
|---|---|
| 스윙 길이 N | 5, 50 |
| 손절 | **mid** = 존 가운데(존 안쪽) · **a50** = L − 0.5 ATR · **a25** = L − 0.25 ATR |
| 익절 | **2R** = L + 2r · **3R** = L + 3r · **leg** = 돌파 다리의 고점(OB 봉 ~ 돌파 봉 T 중 최고가, T 에 알려짐; 숏은 최저가) |
| 최대 보유 H (15분봉) | 16, 96 |
| 일봉 추세 거르개 | 끔, 켬 |
→ 2 × 3 × 3 × 2 × 2 = **72설정**(변수 5개). DSR 시행 수 72.
- 나머지(관통 체결·체결 분 손절만·같은 분 둘 다 손절·15분 종가 취소·100봉 만료·교체·코인당 1포지션·명목 0.25·비용 엄격 메이커 2/시장가 6, 후보 메이커 0/시장가 6)는 1라운드 그대로.

## 구간·관문
- 개발 2022-01~2025-12 에서 고르기. 관문(엄격·후보)은 1라운드와 글자 그대로 같음(일 손익 5일 블록 CI · CPCV 7경로 · PBO · DSR · 연도·코인).
- **2026 잠금은 이 전략 계열의 두 번째 사용이다**(1라운드가 2026-11-15 에 후보 설정 1개로 열었음, 결과 +0.3bp 불통과). 관문을 넘은 설정만 1회 채점하되:
  - 잠금 판정 기준은 1라운드와 같다(엄격: 군집 부트스트랩 양측 95% 하한 > 0 · 실제 > 옆 띠 · 낙폭 ≥ −20% · 코인 ≥ 3/4 · 두 쪽 양수 / 후보: 두 쪽 > 0 · 코인 ≥ 2/4 · 실제 > 옆 띠).
  - 두 번째 사용이라 **엄격 통과여도 배포 대기 A(통과)가 아니라 C(전진 대기)**로 올리고, 전진 기록으로 확인한다.
- 실원장 적용은 하지 않는다 — 진입 규칙이 1라운드와 같아 «내 진입이 존 안이었나» 분류가 바뀌지 않는다(1라운드: 같은 방향 존 안 −38.6bp [−146, +51]).
