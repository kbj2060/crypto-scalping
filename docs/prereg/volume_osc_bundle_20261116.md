## 왜
- 아직 안 잰 것 가운데 널리 쓰이는 것: CCI(원저자 Lambert 는 +100 위로 넘으면 «새 추세 시작» = 따라가기), MFI(거래량 실은 RSI, 80/20 = 되돌림), OBV(Granville «거래량이 가격보다 먼저 간다»), 적삼병·흑삼병(Nison, 하락 뒤 = 반전).
- 틀은 묶음 1~3 과 같음(1 ATR 경주 · P1 기하 위약 20벌 · 지표별 실제 가격 대조 P3 · 지표별 Holm 2칸).
- 오늘 교훈 반영: 오실레이터 극단은 대부분 «이어짐» 쪽이었고 추세 지표 몫은 일반 모멘텀과 같았다 → 거래량 지표는 **같은 식에서 거래량만 1로 바꾼 판**을 P3 로 두어 «거래량이 보태는 몫»만 본다. CCI 는 일반 모멘텀 P3.
- 거래량 열은 2026-10-30 앞까지만 있어 모든 사건을 그 앞에서 자른다(앵커드 VWAP 과 같음).

## 공통
- 15분봉·1시간봉(4시간 보조) 4코인(BTC·ETH·SOL·XRP), 1분봉 Vision 2022-01~2026-10-29. ATR = 참범위 14봉 평균. 봉 시가 = 직전 봉 종가.
- 측정 = 사건 봉 t 종가 기준 100봉 안 주장 쪽 1 ATR 먼저(`first_hit_race`, 같은 봉 동시·미결 = 불리 — 양쪽 같은 폭).

|---|---|---|---|
| E1 | CCI(20) ±100 | 전형가 CCI 가 +100 을 위로 넘음 → 위, −100 아래로 → 아래 (Lambert) | 표본 봉(15분 4봉마다·1시간 모든 봉) 20봉 모멘텀 부호 쪽 |

## 주 판정 (사전 고정)
칸 = 4 × {15분, 1시간} = 8칸. **Holm(α .10) 지표별 2칸.** «맞음» = 실제 − P1 단측 90% 하한 > 0 · 실제 − P3 하한 > 0 · 코인 ≥ 3/4 · 두 구간(2025-01-01 앞뒤) 같은 부호. 통과 후보 = 점추정 > 0 + 코인·구간. 부호 뒤집어 넘으면 «거꾸로».
