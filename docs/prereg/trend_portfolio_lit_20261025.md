## 문헌 근거(읽기만, 외부 코드·데이터 안 받음)
- Moskowitz·Ooi·Pedersen (2012) «Time Series Momentum»: 신호 = 과거 수익 부호, 자산별 크기 = 40%/σ̂, σ̂ = 질량 중심 60일 EWMA(평균 제거) 일 수익 분산.
- Hurst·Ooi·Pedersen (2017) «A Century of Evidence on Trend-Following»: 1·3·12개월 세 지평을 동일 가중 묶음, 포트폴리오 연 10% 사전 변동성 목표.
- Baltas·Kosowski (2013/2020) «Demystifying Time-Series Momentum»: 부호 신호 대신 연속 신호 TREND = 지평 안 일 로그수익 t 통계를 ±1 로 절단 → 회전 1/3 이상 감소 · 범위 기반 변동성 추정 · 상관 계수 CF(ρ̄) = √(N/(1+(N−1)ρ̄)), ρ̄ = 신호 가중 짝 상관(3개월) 로 레버리지 조정(포트폴리오 목표 12%).
- Harvey 외 (2018) «The Impact of Volatility Targeting»: 위험 자산은 변동성 목표로 샤프 개선, 모든 자산에서 극단 손실·낙폭 감소 — 전략 자체 실현 변동성으로 맞춤.
- Daniel·Moskowitz (2016) «Momentum Crashes»: 붕괴는 «공황 상태»(시장 24개월 수익 < 0 이고 시장 변동성 높음)에서 반등과 함께 난다 → 그때 노출 축소(동적 가중 w ∝ μ/σ²).
- Liu·Tsyvinski (2021) «Risks and Returns of Cryptocurrency»: 크립토 시계열 모멘텀은 1~수주 지평에서 강함 → 지평 1~12주.
- 앞선 저장소 실패(반복 금지): VWMA/이평/히스테리시스 148구성 · 추세 위 ML(HGB) · 규칙 간 온라인 가중(PBO .87) · 크기 ∝ σ · 추세 −3% 손절.

## 공통 정의
- 신호(지평 묶음 K): «sign» = mean_k sign(c/c₋ₖ − 1) (현재 검증 규칙, 등급형) · «trend» = mean_k clip(t_k, −1, 1), t_k = k일 일 로그수익 평균 ÷ (표준편차/√k) (Baltas·Kosowski).
- 지평 묶음: A = 7·14·21·28(현재) · B = 7·14·28·56·90(대시보드) · C = 7·14·21·28·42·56·70·84(1~12주).
- 변동성 σ̂(연율): cc20 = 일 로그수익 20일 표준편차 · ewma60 = MOP 질량중심 60 EWMA · pk20 = Parkinson 20일(일 고저) · rv20 = 5분 실현분산 20일 평균. (Yang–Zhang 은 시가가 가짜라 제외.)
- 코인 비중 w_i = τ · s_i / (N σ̂_i) × 포트 조정, N = 4.
- 포트 조정: none · cf = Baltas·Kosowski CF(신호 가중 90일 상관, 분모 하한 0.1) · pv = Harvey: 단위 책(τ=1) 직전 60일 실현 변동성(연율)으로 나눔.
- 순위용 τ = 0.4(MOP 자산별 40%). 고른 구성의 배포 τ = {0.1, .15, .2, .25, .3, .4, .5, .6, .8} 중 개발 구간 MDD ≥ −20% 인 가장 큰 값(없으면 0.1).
- 현재 규칙(비교 기준): A·sign·cc20, 크기 min(2, 0.5/σ20)÷4, 매일 재조정, 같은 체결·펀딩.
- 보유(비교 기준): 4코인 동일 비중 1배 매일 재조정, 종가 대 종가(펀딩 없음 — 현물 보유 대안).
