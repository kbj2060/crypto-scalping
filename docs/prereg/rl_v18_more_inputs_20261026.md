# RL v18 — v17 + 파생·흐름·BTC 입력 (2026-10-26, 채점 전 커밋)

등급: 돈 걸린 매매 → 사용자 RL 상대 기준. **v17 과 같은 굴림 3창·마지막 체크포인트·TSMOM 위 조정·거울·관문(H1·H2·H3)·시드.** 바뀐 것 = 상태 열 추가(전부 t 이전, 2023~ 전 구간 존재):
- OI: ln(OI_t / OI_{t−4h}) · ln(OI_t / OI_{t−24h}) · OI 7일 z (부호 없음 — 거울에서 안 뒤집음)
- 테이커 매수 비중: 지난 1h·4h (2·매수/거래량 − 1) (부호 있음 — 거울에서 뒤집음)
- 상위 트레이더 롱숏 비율: ln(비율) 7일 z (부호 있음)
- 펀딩: 직전 확정 펀딩률 / 학습 표준편차 (부호 있음)
- BTC: 지난 4h·24h 수익 / BTC σ (부호 있음) · ln(BTC σ̂_24h / ETH σ̂_24h) (부호 없음)
- 왜: v14~v17 은 방향 예측·변동성·모멘텀만으로는 TSMOM 에 더하는 것이 없었음(v17 조정 58분위). 문헌(Zhang 외 2019 는 가격만)·우리 화면 원소 중 RL 이 조건부로 쓸 만한 파생·흐름 정보를 한 번에 넣어 본다. 이 원소들은 단독 방향 예측으로는 대부분 기각됐음(OI·테이커·롱숏 = 동행/재표현) — 낮은 사전 기대를 공개.
- 장치 검증: R3 심은 신호 1시드(마지막 체크포인트).
- 🔴 공개: R1·R2·R3 시험 구간은 v17 에서 한 번 사용(이번 두 번째).
