# 사전등록: 고전 지표 6종 묶음 의미 검증 (2026-11-15)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_classic_indicator_bundle_20261115.py`.
사용자 «너가 생각하는 지표들 모두 테스트해줘. 계속 자동으로 넘어가줘».

## 왜
- 남은 목록 가운데 널리 쓰이고 오늘 아직 안 잰 6종을 한 사전등록·한 스크립트로 묶는다(설계 틀은 오늘 MACD·ADX·AVWAP 과 같음).
- 오늘 교훈: 실제 가격엔 기본 이어짐(+0.5~1.4pp)이 있다 → 지표마다 **실제 가격 대조(P3)** 를 주 판정에. ORB 교훈: «미결 = 실패» 규칙은 대조와 결판 비율이 다르면 오염 → 이번엔 전부 양쪽 같은 폭(1 ATR) 경주라 결판 비율이 대조와 비슷함.
- 빠진 것: 와이코프 스프링(=스윕 반전, 11-15 SMC 에서 반전 없음으로 이미 검정) · 쌓인 불균형·봉 안 POC(가격대별 체결 원자료가 로컬에 없음 — 5분 집계·일별 칸만 있음).

## 공통 (봉 마감에 알려짐)
- 15분봉·1시간봉 4코인(ETH·BTC·SOL·XRP), 1분봉 Vision 2022-01~2026-11-13. ATR = 참범위 14봉 평균.
- 측정 = 사건 봉 t 종가 기준 100봉 안 주장 쪽 1 ATR 이 반대 1 ATR 보다 먼저(`first_hit_race`, 같은 봉 동시·미결 = 불리).
- P1 = 기하 위약 20벌(1분 수익 부호 뒤집기). P3 = 아래 지표별(실제 가격만).
- P3 «모멘텀 대조» = 같은 봉 단위 표본 봉(15분 4봉마다·1시간 모든 봉)에서 방향 = sign(c[t] − c[t−M]).

## 지표 (주장 · P3)
| 키 | 지표 | 사건·주장 | P3 |
|---|---|---|---|
| K1 | 스토캐스틱(14,3,3) | 느린 %K 가 %D 를 위로 넘는데 %D < 20 → 위(반전) · 아래로 넘는데 %D > 80 → 아래 | 같은 교차·같은 방향, %D 20~80 |
| K2 | 볼린저(20, 2σ, 종가) | 종가가 하단 밖으로 처음 나감(직전 종가 안) → 위(평균 회귀) · 상단 대칭 | 같은 봉 수 «되돌림 대조» = 방향 −sign(c[t]−c[t−20]) |
| K3 | 하이킨 아시 | 같은 색 ≥3 뒤 색 바뀜 → 새 색 쪽 | 보통 봉 색(종가 vs 직전 종가) 같은 규칙 |
| K4 | 파라볼릭 SAR(0.02, 0.2) | 뒤집힘 → 새 방향 | 모멘텀 대조 M = 12 |

## 주 판정 (사전 고정)
칸 = 6 지표 × {15분, 1시간} = 12칸. **Holm(α .10) 은 지표별 2칸**(따로 사전등록했을 때와 같은 엄격도 · 묶음 전체 6가족임을 결과에 공개). «맞음» = 실제 − P1 단측 90% 하한 > 0 · 실제 − P3 단측 90% 하한 > 0 · 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호. 통과 후보 = 점추정 > 0 + 코인·구간. 부호 뒤집어 넘으면 «거꾸로».
