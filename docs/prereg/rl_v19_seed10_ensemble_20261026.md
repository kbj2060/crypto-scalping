# RL v19 — v18 을 새 시드 10개 앙상블로 (2026-10-26, 채점 전 커밋)

등급: 돈 걸린 매매 → 사용자 RL 상대 기준. **v18 과 같은 프레임·입력·굴림 3창·마지막 체크포인트·TSMOM 위 조정·거울·관문 H1·H2·H3.** 바뀐 것 하나:
- 시드 = `np.random.default_rng(2026102619).integers(1, 2**31-1, 10)` 의 **새 10개**(v14~v18 시드 재사용 안 함 — 그 시험 성적은 이미 봄). 앙상블 = 10시드 평균 명목.
- 왜: v18 은 시드 간 차이가 컸음(R2 시험 −.02~1.31, R3 .67~2.56) — 앙상블 크기를 늘리면 조정의 분산이 줄어 조건부 신호가 드러나는지. 근거: Yang·Liu·Zhong·Walid(2020, ICAIF «Deep RL for Automated Stock Trading: An Ensemble Strategy»).
- 장치 검증: 생략(같은 환경·코드, v18 에서 통과). 출력 tmp/rl_v14_20261026/v19_{창}_{시드}/ · test_report_v19.json.
- 🔴 공개: R1·R2·R3 시험 구간 3번째 사용(v17·v18 다음). 통과해도 전진 판정 필수.
