# 사전등록: 아시아 세션 고저 스윕 뒤 반전(ICT «Judas swing»)이 맞는가 (2026-11-15)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_asia_sweep_meaning_20261115.py`.
사용자 «추천 3개 차례로» 중 첫째(다음 검증 지표 목록 13번).

## 왜
- ICT 주장: 아시아 세션이 만든 고저(유동성)를 런던·뉴욕 시간에 먼저 «사냥»하고(가짜 움직임) 반대로 간다.
- 11-15 SMC 검증: 같은 고점 스윕 뒤 반전 없음(47~48% ≈ 위약) · 전일 고저는 되밀기보다 뚫고 감(15분 «거꾸로»). 세션 고저도 같은지 본다.
- 11-14 손절 구간 연구: 24h 새 고저 돌파 순간엔 이어짐 쪽(손절 몰림 뒤 이어짐). 기하 기준선이 50% 가 아니므로 위약·옮긴 수준 대조 필수.

## 정의 (사전 고정)
- 15분봉 4코인(ETH·BTC·SOL·XRP), 1분봉 Vision 2022-01~2026-11-13, ATR = 15분 참범위 14봉 평균.
- **아시아 범위** = 그날 00:00~08:00 UTC(도쿄 09~17시) 15분봉 32개의 최고·최저. 08:00 UTC 에 알려짐.
- **사냥 창** = 08:00~21:00 UTC(런던·뉴욕). 그날 15분봉 84개가 다 있는 날만.
- **스윕** = 사냥 창에서 처음으로 고가 > 아시아 고점(또는 저가 < 아시아 저점)인 봉. 고점·저점 각각.

## 주장과 측정 (2칸)
| # | 주장 | 측정 | P2 |
|---|---|---|---|
| A1 | 스윕 뒤 반전 | 스윕 봉 종가 기준 100봉 안 «범위 안쪽» 1 ATR 이 «바깥쪽» 1 ATR 보다 먼저 | 아시아 고저를 ±1 ATR(08:00 봉) 무작위로 옮긴 가짜 수준에 같은 규칙 |
| A2 | 가짜 움직임 뒤 반대 끝까지 | 그날 첫 스윕(먼저 깬 쪽) 뒤 21:00 UTC 전에 아시아 범위 반대쪽 끝 도달 | (P1 만) |
- P1 = 기하 위약 20벌(1분 부호 뒤집기, 11-15 와 같은 함수·시드).
- 1분 안 순서 모름 → 같은 봉 동시는 주장에 불리하게(first_hit_race).

## 주 판정 (11-15 SMC 와 같은 규칙)
칸마다 «의미 맞음» = 실제 − P1 단측 90% 하한 > 0(달력일 군집 + 위약 분산) · 2칸 Holm(α .10) · P2 있는 칸은 실제 − P2 하한 > 0 · 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호. 통과 후보 = 점추정 > 0 + 코인·구간. 부호 뒤집어 넘으면 «거꾸로».

## 보조 (판정 안 씀)
고점·저점 따로 · 스윕 봉이 범위 안으로 되돌아 마감한 경우만(«회수») · 런던(08~13)·뉴욕(13~21) 따로 · 2026 만.
