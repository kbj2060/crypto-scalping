# 4h 변동성 QX4I(QX4 + 옵션 IV 보정) 전진 사전 등록 (2026-10-25, 전진 자료 보기 전)

## 왜
12라운드(`vol4h_round12_option_iv_20261025.md`) 시험 ΔQLIKE −0.0066 [−0.0144, +0.0035] — 방향은 문헌(Busch 외 2011)과 같고 월 5/6 개선이지만 4.7개월로는 유의 미달. 계수를 고정하고 새 자료에서만 판정한다.

## 고정
- 기반 = 동결 서빙 아티팩트 `tmp/vol4h_qx4/qx4_2026-10-23.joblib`(md5 2fce43f5…, 기존 vol 판정과 같음).
- QX4I = ŷ_QX4 + a + b·x1, **a = −0.04709, b = +0.17636**(12라운드 검증 적합값, `research_vol4h_round12_option_iv_20261025.py::BETA_I`). x1 = ln(IV²·4/8766) − ŷ, IV = [d−1h, d) |델타| 0.35~0.65·만기 1시간~10일 ETH 역옵션 체결 iv 중앙값(6시간 앞 값 채움, 없으면 x1 = 0).
- 눈금 c = 기존 vol 판정 규칙(아티팩트 눈금 구간 2026-05-23~10-23 에서 모형마다).

- 관문 I1: ETH QLIKE(QX4I) − QLIKE(QX4) 일 블록 CI 상한 < 0.
