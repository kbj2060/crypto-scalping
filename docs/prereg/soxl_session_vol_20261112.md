## 데이터·시각 규약
- 바이낸스 USDT 무기한 **SOXLUSDT 1분봉**(Vision 일 파일, 상장 2026-05-15 ~ 2026-11-10). 복제용 SNDKUSDT 같은 기간.
- 결정 시각 τ = 5분 경계(UTC). 피쳐는 시작 < τ 인 1분봉만. **표적 = [τ, τ+H) 의 실현 변동성** RV_H = √(Σ 1분 로그수익²), 첫 수익은 τ 직전 봉 종가 대비. H = 15분(주), 60분(보조). 표적 창에 봉 구멍이 있으면 그 행 제외. RV 바닥 = 1bp(0 인 창의 로그 보호, 건수 보고).
- 세션(미 동부 시각, 서머타임은 zoneinfo): 정규장 09:30–16:00 · 프리장 04:00–09:30 · 애프터 16:00–20:00 · 야간(평일 20:00–04:00, 일 20:00~ 포함) · 주말(금 20:00 ~ 일 20:00) · 휴장일(NYSE 휴장 2026-05-25·06-19·07-03·09-07·11-26·12-25 는 그날 04:00–20:00 을 «휴장»으로).
- 피쳐(고정): 로그 RV 5·15·60·240분·1일·7일 · 직전 15분 고저폭(로그) · 직전 15분 거래대금 ÷ 1일 평균(로그) · 직전 5분 |수익| ÷ 60분 RV · 세션 코드 · 정규장 개장 뒤 분·개장까지 분·마감까지 분(각 0~1,440 절단) · 요일 · 동부 시각 분. 전부 τ 에 시계와 지난 봉만으로 정해진다.

## 팔 (조율 없음)
- **B0 현행**: 화면이 지금 쓰는 값 — 직전 7일 1시간 로그수익 표준편차 × √(H/60분). 시간대를 모른다.
- **HAR-S(기준이자 후보)**: 로그 RV_H 를 로그 RV 15분·60분·1일·7일 + 세션 더미 + «표적 창이 정규장 개장 09:30 을 포함» + «개장 뒤 첫 60분» + «마감 전 30분» 에 OLS.
- **HGB**: 위 피쳐 전부, 로그 RV 제곱오차 · 깊이 4 · lr .05 · 400회 · 잎 최소 100 · l2 1 · 조기 종료 없음 · 시드 0(시드 1 은 차이 확인용).
- **AVG**: HAR-S 와 HGB 의 로그 예측 평균.
- 눈금: 모든 팔에 같은 규칙 — 적합 구간에서 평균(RV²/예측²) = 1 이 되게 상수 c.
- 고르기: {HGB, AVG} 중 검증 QLIKE 가 낮은 쪽 = «고른 ML 팔».

## 주 판정 (H = 15분, 시험 구간, QLIKE = 평균(RV²/ĥ − ln(RV²/ĥ) − 1), 달력일 블록 부트스트랩 2,000회)
1. **현행 대비**: HAR-S − B0 의 QLIKE 차 단측 90% 상한 < 0.
2. **모델 몫**: 고른 ML 팔 − HAR-S 의 QLIKE 차 단측 90% 상한 < 0.
- **통과** = 1·2 모두 → 배포 후보 = 고른 ML 팔. **1만 통과** → 배포 후보 = HAR-S(식 하나, 모델 파일 불필요), ML 은 «통과 후보» 등급으로도 올리지 않는다. 1 불통과 → 불통과.
- 보고(판정 아님): 팔 전부 검증·시험 QLIKE 와 로그 R² · 세션별 QLIKE 와 행 수 · 예측 σ 10분위별 실제 RV 중앙(보정표) · 세션별 예측 σ 중앙(%, 일상 단위) · «15분 안 최대 이동이 예측 σ 의 1배·2배를 넘은 비율» `a/b` 세션별(익절·손절 거리용) · H = 60분 같은 표 · SNDK 복제(같은 레시피, 같은 분할) · HGB 시드 0 vs 1 차 · RV 바닥 건수.
- 누수 신호: 시험 로그 R² > .8 이거나 HGB 가 HAR-S 보다 QLIKE 30% 넘게 낮으면 누수부터. 채점 해석 전 독립 누수 검토(leak-auditor).

## 보조 (판정에 안 씀)
