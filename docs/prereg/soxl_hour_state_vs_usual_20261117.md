# 사전등록: SOXL «앞 1시간이 이 시각대 평소보다 조용한가·격한가» 판정 (2026-11-17)

**등급: 되돌리기 쉬운 예측 개선 — 단측 90%**(화면 표시 값, 매매 주장 없음). 완화 «통과 후보» 병기.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_soxl_hour_state_vs_usual_20261117.py`(selftest · run).

사용자 11-17: «새로운 통과 모델이 나올 때까지 계속 연구 진행해줘». 오늘 배포한 SOXL «앞 1시간» 칸은 세션 이름과 1시간 σ 만 보인다 — 코인 칸의 «조용/보통/격함» 판정은 SOXL 에서 검정한 적이 없어 비워 두었다. 그 빈칸을 검정한다.

## 오늘의 연구 순서와 우연 통과(미리 밝힘)
«통과가 나올 때까지»는 라운드를 거듭할수록 우연히 통과할 확률이 쌓인다. 오늘 라운드: ① SOXL 시계 규칙 2개(매매 등급, 불통과) ② 이 문서(예측 등급). 이 문서가 통과해도 그것은 **폭(변동성) 계열 예측**이지 방향·수익 모델이 아니다 — 보고에 그대로 적는다. 이 라운드의 우연 통과 기대는 0.10 이다.

## 왜 (과거 실패 교훈 반영)
- 11-15 코인 레이더 ④: «조용/격함» 정확도는 96~98% 였으나 비교 기준선(7일 고정값)이 «조용»을 한 번도 안 내서 **비교가 성립하지 않아 글자 그대로 불통과**였다 → 이번엔 주 판정을 «정확도 하한 + 최소 발동 비율»로만 두고, 기준선 비교(직전 1시간 지속성)는 **두 상태를 다 내는 기준선**으로 골라 보조 판정(«모델 몫»)에 둔다.
- 같은 문서: 평균형 예측(σ̂)을 중앙값 «평소»와 비교하면 격함 쪽으로 기운다 → **중앙값형 예측**(로그 RV 예측의 exp, 눈금 상수 c 를 곱하지 않은 값)을 중앙값 «평소»와 비교한다.
- 11-12 SOXL 세션 변동성: 세션 평균만으로 로그 RV 분산의 48% 가 설명된다 → «평소»를 세션이 아니라 **같은 시각대**(동부 시각 ±15분, 평일/주말 따로)로 잡아 «개장 시각이라 크다» 같은 시계 정보가 판정을 채우지 않게 한다.
- 11-17 서빙 검토: `clock()` 서머타임 결함은 고쳤다. 휴장일은 표본이 없어 판정에서 뺀다.
- 11-17 시계 규칙 불통과 교훈(«해마다 부호가 갈리면 믿지 않는다 · 필요한 표본을 미리 계산»): 이 판정은 5분마다 한 번(하루 288개)이고 변동성 지속성에 기대므로 표본 문제가 작다. 시험 구간 약 44일 × 288.
- 같은 구간 재사용 공개: SOXLUSDT 2026-10-01~11-10 은 변동성 예측 QLIKE 로 한 번(11-12), 오늘 계수 내보내기 확인(띠 포함률·분 위치 편향)으로 한 번 썼다. «평소 대비 상태 정확도»로 채점한 적은 없다. 변동성 계열로는 3번째 사용.

## 데이터·시각 규약
- SOXLUSDT 무기한 1분봉(Vision 일 파일) 2026-05-15 ~ 2026-11-15.
- 결정 시각 τ = 5분 경계. 피쳐·표적은 `research_soxl_session_vol_20261112.frame(k, 60)` 그대로: 피쳐는 시작 < τ 인 봉만, 표적 RV60(τ) = [τ, τ+60분) 1분 로그수익 제곱합의 제곱근(창에 구멍이 있으면 제외).
- **모델(이미 동결)**: 배포된 계수 `dashboard/risk_radar_params_soxl_20261117.json` 의 `beta60`(적합 05-22~09-30). 중앙값형 1시간 예측 m̂(τ) = exp(har_x · beta60).
- **평소 U(τ)**: τ 와 **같은 날 유형**(평일 세션 / 주말·휴장 세션)이고 동부 시각이 τ 의 ±15분 안인 5분 격자 τ′ 중, 동부 날짜가 τ 보다 **앞선 날**이고 30일 안인 것들의 RV60 중앙값. 60개 미만이면 U 없음(제외, 건수 보고). 앞선 날만 쓰므로 U 는 τ 에 이미 끝난 창만 본다.
- 예측 비 ρ = m̂ ÷ U. **조용** ρ ≤ 0.7 · **격함** ρ ≥ 1.5 · 그 사이 보통(문턱은 코인 레이더와 같은 값, 조율 없음).
- 실제 = RV60(τ) > U(τ) 이면 «평소보다 큼».
- 휴장 세션(코드 5)의 τ 는 판정에서 제외.

## 주 판정 (시험 구간, 달력일 블록 부트스트랩 2,000회 · 시드 20261117, 전부 만족)
1. **격함 정확도**: ρ ≥ 1.5 인 τ 중 실제 «평소보다 큼» 비율의 단측 90% 하한 ≥ 75%.
2. **조용 정확도**: ρ ≤ 0.7 인 τ 중 실제 «평소보다 크지 않음» 비율의 단측 90% 하한 ≥ 75%.
3. **발동 비율**: 조용·격함 각각 채점 τ 의 5% 이상(판정이 거의 안 나오면 쓸모가 없다).
- 기준 비율은 정의상 약 50% 다(U 가 중앙값). 실제 «평소보다 큼» 비율을 같이 보고한다.
- 보고는 `a/b` 로: 채점 τ 수·날 수, 상태별 건수와 맞은 수, 세션별(정규장·프리장·애프터·야간·주말) 같은 표.

## 보조 판정 «모델 몫» (통과 여부와 별개로 보고)
- 기준선 = 지속성: ρ_p = (방금 끝난 60분의 RV) ÷ U, 같은 문턱.
- 맞힘 점수 = 상태를 냈고 맞으면 +1, 냈고 틀리면 −1, 보통이면 0 의 평균. **모델 − 지속성**의 단측 90% 하한 > 0 이면 «모델 몫 있음».
- 주 판정 통과 + 모델 몫 없음 → 판정은 통과(칸에 상태 표시 가능)지만 «지속성과 같다»고 적는다.

## 통과 후보(완화)
주 판정 1·2 를 하한이 아니라 **점 추정 ≥ 75%** 로 바꾸고 3 을 만족.

## 누수·검토
- selftest: 합성 1분봉에서 ① U 가 τ 이후 봉을 바꿔도 안 변함 ② 변동성을 두 배로 올린 날에 격함이 나오고 실제도 큼 ③ 평소 정의의 «같은 날 제외».
- 통과로 나오면 해석 전에 독립 검토(leak-auditor): U 의 인과성·날 유형·서머타임·휴장 제외·부트스트랩.
- 탐지 신호: 정확도가 99% 를 넘거나 지속성보다 20%p 넘게 높으면 누수부터 의심한다.

## 결과 뒤
- 통과 → 배포 대기 후보(«앞 1시간» 칸에 상태 표시 — 화면은 `/impeccable` 시안으로 따로, 사용자 결정). 서빙은 워커가 U 를 같은 식으로 계산해야 한다(31일 캐시면 충분).
- 불통과 → 종결, 다음 라운드.
