# 사전등록: CHoCH 구조 상태를 «숏 금지» 거르개로 (2026-11-15)

**등급: 되돌리기 쉬운 거르개(예측 개선) — 단측 90%** + 완화 «통과 후보». 수익 전략 아님.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_choch_state_short_filter_20261115.py`.
사용자 «예측할 필요 없어. 지금 내가 롱 추세인데 숏을 잡고 싶지 않아서야.» — CHoCH 를 «전환 예측»이 아니라 **지금 구조가 위쪽인지 아래쪽인지 알려 주는 상태 표시**로 쓰고, 위쪽 상태에선 숏을 안 잡는 거르개가 실제로 나쁜 숏을 걸러 주는지.

## 왜
- 의미 검증(11-15): CHoCH 뒤 «다음 돌파 같은 쪽» 50% = 위약, 24봉 뒤 방향 47%(오히려 되돌림). 그러나 그건 **전환 순간**의 예측력이다. 거르개는 **상태가 유지되는 모든 시간**에 숏을 막으므로 다른 질문이다.
- 구조 돌파 직후 짧은 되돌림 때문에, 위쪽 상태로 막 바뀐 직후엔 숏이 오히려 나을 수 있다 → 지평별(1·4·24시간)로 보고, 상태 유지 시간·하루 바뀜 횟수도 같이 본다.
- 켈트너·OB 연구에서 남는 몫이 일봉 추세였다 → **일봉 SMA50 상태**를 비교 기준으로 둔다(CHoCH 가 그보다 나은지, 그 위에 보태는지).

## 정의 (인과)
- 15분봉 4코인(ETH·BTC·SOL·XRP), 2022-01~2026-11-13. 구조 = 의미 검증과 같은 인과 BOS/CHoCH(스윙 길이 5 = 단기, 50 = 큰 스윙). **상태** = 봉 t 마감까지 마지막 구조 돌파의 방향(위 = 롱 추세, 아래 = 숏 추세). 15분 봉 t 마감 시각에 알려짐.
- 비교 상태: 일봉 SMA50(전날 마감까지, 종가 > SMA50 = 위) · 1시간봉 큰 스윙(N50) 구조 상태(보조).
- 결과: 봉 t 종가에 숏을 잡았다면 H 시간 뒤 수익 = −(c[t+H]/c[t] − 1)×1e4 bp, H ∈ {1, 4, 24}. 비용 없음(거르개 비교라 양쪽 같음).

## 주 판정 (사전 고정)
**주 칸 = 큰 스윙(N50) 상태 × 4시간.** «거르개 맞음» = 아래 전부:
1. 숏 수익(아래 상태 봉) − 숏 수익(위 상태 봉) > 0, 7일 블록 부트스트랩(2,000회) 단측 90% 하한 > 0.
2. 기하 위약(1분 부호 뒤집기 20벌, 의미 검증과 같은 시드)의 같은 차이 95분위 초과.
3. 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 모두 같은 부호.
- 통과 후보: 1 의 점추정 > 0 + 3.
- 보조 칸(판정 안 씀, 전부 보고): N5 × {1,4,24h} · N50 × {1,24h} · SMA50 × {1,4,24h} · «SMA50 위 날 안에서» N50 상태 차이(보탬) · 상태 바뀜 하루 횟수·평균 유지 시간·위 상태 시간 비율 · 상태가 막 바뀐 뒤 4시간 안 vs 그 뒤 · 2026 만.
