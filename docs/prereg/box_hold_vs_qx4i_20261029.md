# 사전등록: 4h 박스 유지 — 박스 HGB vs 옵션 변동성 QX4I σ(반사 원리) (2026-10-29)

## 질문
«옵션 변동성(QX4I 4h σ)이 4h 박스 유지 확률(HGB)보다 박스 유지를 더 정확히 맞히나?» — 같은 결정 시각·같은 반폭·같은 사건 행에서 Brier 로 맞댄다.

## 왜 (과거 실패 교훈 반영)
- 10-22 박스 깨짐 DL: «상한 = 미래 σ» — 박스 깨짐의 병목은 변동성 예측이었다 → 박스 피쳐 대신 가장 좋은 4h σ 예측(QX4I)을 무접촉 확률로 바로 바꿔 본다.
- 10-22 «고변동 → 가까운 지지/저항»: 실제 닿음률 = 같은 변동성 무작위 경로 닿음률 → 무작위 걸음(반사 원리) 가정이 1차 근사로 맞을 수 있다. 꼬리·표류·점프 몫은 등조 보정판으로 따로 본다.
- 10-19/10-25 박스 4h 2026 과소 예측(−2.6pp, 10월 −5.6) → 치우침(평균 예측 − 실현)을 지표로 같이 본다.
- 10-25 변동성 6라운드 결합 퍼즐(가중 적합이 동일 가중보다 나쁨) → 섞은 것은 로짓 동일 가중 하나만, 가중 적합 금지.
- 같은 구간 재사용 공개: 시험 창 2026-06~10-23 은 이미 박스 보정 4·5(W3)·6·7라운드와 변동성 경주 4·5·6·7·9·10·11·12라운드(QX4I 의 계수 자체가 12라운드)에서 채점에 쓰였다 — **최소 12회 재사용, 예상 우연 통과 ≈ 12 × .10 = 1.2회**. «준-표본 밖»이다. 검증 창 2026-01~05 는 QX4I 의 β·c 를 적합한 구간이라 QX4I 에겐 표본 안이다(보조로만 쓴다).

## 데이터·시각 규약
- 사건 행 = `tmp/box_calib_20261025/rows.parquet`(박스 보정 연구 산출, 라벨 관문 L1~L5 통과, 1분봉 ~2026-10-23 23:59) 의 4h 행 그대로. 라벨·피쳐 새로 안 짠다.
  - ts = 결정 직전 마감 1분봉 시작(hh:59) → **결정 시각 τ = ts + 1분(정시)**.
  - 라벨 y = 1분봉 i+1..i+240 의 고가 최대 < c_i + 반폭 그리고 저가 최소 > c_i − 반폭(한 번도 안 닿음), 반폭 = ½(직전 240분 고가 최대 − 저가 최소). `labels()` 그대로.
- 박스 HGB = 배포 `dashboard/box_hold_hgb_20261016.joblib` 4h(기하 6칸, 2022~24 학습) `predict_proba` 그대로. 재적합·보정층 없음.
- QX4 = 변동성 경주 4라운드 동결 예측 `pred_{val,test}_r4_ETH.parquet`(학습 2024~25, 정시 결정, 인덱스 = 5분봉 시작 hh:55 → **τ = 인덱스 + 5분**). 피쳐는 τ 에 마감한 5분봉까지, 타깃은 τ 이후 48봉 RV.
- QX4I = `research_vol4h_round12_option_iv_20261025.qx4i()`(BETA_I = (−0.047088, 0.176358) 동결, 라이브 `live_vol4h_qx4_20261025.BETA_I` · forward_verdicts voliv 와 같은 값) + 눈금 c = 12라운드 report.json QX4I c 0.2831459943. IV = `iv_hourly()` 정시 d 의 [d−1h, d) ATM 체결 중앙값(τ 이전만). **다시 적합하지 않는다.**
  - 재현 관문 P1: 시험 QX4I QLIKE 평균 = 0.2685710195(12라운드 test_qlike) ±1e-9, 검증 0.2831459943 ±1e-9. 실패면 채점 안 함.
- σ → 유지 확률: σ√T = √exp(ŷ + c)(평균 RV 눈금, 4h 로그 수익 표준편차), 반폭 a = ½·rng/c_i(= exp(log_rng)/2e4), s = σ√T / a,
  P_stay = (4/π) Σ_{k=0}^{399} (−1)^k/(2k+1) · exp(−(2k+1)² π² s² / 8) (구간 가운데서 출발한 표류 없는 브라운 운동의 두 벽 무접촉 확률), [0,1] 로 자름, s < 0.02 면 1.
- 등조 보정판: `IsotonicRegression(y_min=.001, y_max=.999, out_of_bounds="clip")` 를 **학습 창에서만** 적합 — x = QX4(옵션 없음) σ 의 P_stay, y = 같은 행 박스 라벨.
  학습 창 QX4 는 표본 안 예측이 없어 **굴림 원점 5라운드 W1·W2 의 표본 밖 예측**(`pred_{val,test}_r5W1_ETH` = 2024-01-01~10-23, `r5W2` = 2025-01-01~10-23, 각 창 c = 그 창 report QX4 c)을 쓴다. τ+4h ≤ 2026-01-01 확인(assert).
  - 🔴비대칭: 옵션 IV 가 2026 자료뿐이라 등조 지도는 QX4(보정 없음)로 적합하고 QX4I 에 적용한다. 2024·25 의 1~5·6~10월만(11~12월 없음) 쓴다.
- 섞은 것 = σ((logit p_HGB + logit p_QX4I등조)/2) 하나. 가중 적합 없음.
- 상수 = 그 채점 창 자신의 실현 유지율(사후 기후값 — 무정보 기준 중 가장 엄한 판).

## 지표
- Brier(주) · AUC · ECE(10 분위 칸, pp) · 치우침(평균 예측 − 실현, pp). 사건 수 n · 독립 일수(τ 의 UTC 날짜 수) · 실현 유지율을 같이.
- 짝 차 ΔBrier = Brier(m) − Brier(HGB) (음수 = m 이 더 정확). CI = `day_boot`(1일 블록 부트스트랩 2,000회, 박스 보정 연구와 같은 함수) — alpha .2 의 [10%, 90%] 분위가 단측 90% 경계, alpha .05 = 양측 95%(참고).
- 각 모델 − 상수 ΔBrier 도 같은 방식.

## 주 판정 (사전에 고정)
1. **주**: 시험 창 QX4I 등조 − HGB ΔBrier 단측 90% 상한 < 0 → «QX4I 가 더 정확(통과)». 하한 > 0 → «HGB 가 더 정확(통과)». 둘 다 아니면 «구분 못 함(불통과)».
2. **부**: 시험 창 섞은 것 − HGB 같은 규칙.
- 보조(판정에 안 씀): QX4I 원판 − HGB(같은 규칙으로 표시만) · 검증 창 전부 · ΔAUC(`auc_boot` 95%) · 모델 − 상수.
- **차트 규칙(사전 고정)**: 주 1 이 «QX4I 통과»면 QX4I 등조, 아니고 부 2 가 «섞은 것 통과»면 섞은 것, 둘 다 통과면 검증 창 Brier 가 낮은 쪽, 둘 다 아니면 현행 HGB 유지.

## 한계 (미리 적음)
- 반사 원리 = 표류 0·연속 경로·일정 σ·정규 증분 가정. 1분 고저는 연속 감시에 가깝지만 점프·두꺼운 꼬리·σ 가 4h 안에서 변하는 몫은 원판에 안 들어간다(등조판이 단조 변환으로만 흡수).

- 1일 블록은 겹침(4h 창이 정시마다 겹침, 자정 넘는 창 3개/일)과 며칠 가는 변동성 국면 상관을 다 못 잡을 수 있다 — CI 가 좁게 나올 수 있다.
- 학습 창 비대칭(QX4 로 적합한 등조 지도를 QX4I 에 적용) · 시험 창 재사용 ≥12회.
