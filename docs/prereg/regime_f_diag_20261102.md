# 사전등록 (진단·보고 전용): ER 상위(큰 움직임) 예측 가능성 + R2 정책 쓰임 (2026-11-02)

**등급: 진단. 승격·배포 근거로 쓰지 않는다**(S0 v1~v3 모두 사전등록 통과 실패, `regime_f_v3_20261102.md` 에서 «최종 중단»을 선언했다). 계산 전 커밋. 스크립트 `research_regime_f_20261102.py` 의 `s2d`.

## 왜
- v3 진단: 오라클 ER 상위 1/3 에서만 R2 를 켜면 검증 +1.46·시험 +1.25bp/결정(보고용 수치; 통과 문턱 2.0 미달, CI 0 포함). 가치 있는 정보는 «횡보냐 추세냐»가 아니라 **«큰 움직임이 오느냐»(ER 상위)**. 이게 변동성·박스 기하 이상으로 예측되는지 + 예측으로 R2 를 켰을 때 오라클의 몇 %가 남는지를 **한 번** 잰다 → 사용자에게 «레짐 모델을 더 만들 값어치가 있나»에 답하는 용도.
- 판정 문턱을 두지 않는다: 숫자를 보고만 한다. 그러므로 통과/불통과 표현을 쓰지 않고, «기준선 대비 증분과 오라클 대비 비율»로만 말한다.

## 규격 (고정)
- 데이터·결정·구간·R2·비용: S0 v2 와 같다. 라벨: y=1 이면 ER_fwd ≥ 학습 2/3 분위수(상위 1/3), 아니면 0(이진, 중간 제외 안 함).
- 학습: 2024-01-15~2025-12-31, 시험 시작 H=48 봉 전까지 purge. 피쳐 24종(설계 §3: RV 비·ER48·ER288·분산비·pos·범위/RV·고저 경과·거래대금 비·테이커 불균형·시간대·BTC ER48·BTC RV 비).
- 모델: M = HGB(max_depth 4, lr .05, 300회, l2 1, min_leaf 200, early_stopping 끔, random_state 0). 기준선 로지스틱: B1 지속(ER48·ER288) · B2 변동성(RV 비 3 + 로그 RV288) · B3 기하(B2 + pos·범위/RV·고저 경과).
- 보고(검증·시험 각각): AUC·Brier(M, B1~B3, 기저율), ΔBrier(M − 해당 구간 최선 기준선) 의 일 블록 부트스트랩 90% 단측 상한; 정책 «p ≥ 0.40(고정, 학습 기저 1/3 보다 약간 높게) 이면 R2, 아니면 쉼» 의 결정당 순 bp, 활성 비율, M·B2·B3 비교, 항상 R2·오라클 상위 대비, 같은 활성 비율 무작위 게이트(1,000회) 분위. p ≥ 0.50 도 같이.
- 임계는 위 두 값만(튜닝 없음).
