# 사전등록: MACD 가 «뜻하는 대로» 움직이는가 — 일반 모멘텀 대비 (2026-11-15)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_macd_meaning_20261115.py`.
사용자 «다음 지표로 넘어가자» — 다음 검증 목록 9번(MACD).

## 왜 (오늘 감사 교훈 반영)
- 11-15 독립 감사: 1분 부호 뒤집기 위약은 모든 자기상관을 지우는 «기억 없음» 귀무라, 구조 돌파 뒤 이어짐 같은 결과가 **지표 고유 의미인지 일반 모멘텀인지** 못 가른다. → 이번엔 **실제 가격에서 «직전 움직임 방향» 그대로 같은 경주를 한 모멘텀 맞춤 대조(P3)**를 주 판정에 넣는다. MACD 교차는 본래 모멘텀 지표라 이 대조가 핵심이다.
- 이전 시행: MACD 단독 검정 없음(09-22 추세 나우캐스트에서 비교 대상으로만). RSI 다이버전스(11-15)는 D1 50.8% 엄격 통과·최근 0.

## 정의 (원 지표 기본값, 봉 마감에 알려짐)
- 15분봉·1시간봉 4코인(ETH·BTC·SOL·XRP), 1분봉 Vision 2022-01~2026-11-13. MACD = EMA12(종가) − EMA26 · 시그널 = MACD 의 EMA9 · 히스토그램 = MACD − 시그널. ATR = 참범위 14봉 평균.
- **M1 시그널 교차**: 봉 t 에 MACD 가 시그널을 위로(아래로) 넘음 → 주장 방향 = 위(아래).
- **M2 0선 교차**: MACD 가 0 을 위로(아래로) 넘음 → 주장 방향 = 위(아래).
- **M3 정규 다이버전스**: 스윙 5봉(p+5 에 알려짐) 새 고점이 직전 60봉 안 스윙 고점보다 높은데 MACD[p] < MACD[q] → 주장 = 아래(반전) · 저점 대칭(RSI 다이버전스 연구와 같은 구조).
- 측정(전 칸 공통) = 사건 봉 종가 기준 100봉 안 주장 방향 1 ATR 이 반대 1 ATR 보다 먼저(`first_hit_race`, 같은 봉 동시 = 주장에 불리).

## 대조
- **P1 기하 위약** 20벌(11-15 와 같은 함수·시드).
- **P3 모멘텀 맞춤(실제 가격)**: M1·M2 = 같은 봉 단위 **모든 봉**에서 주장 방향 = 직전 12봉 수익 부호(EMA12 길이) · 같은 경주. M3 = 같은 «새 고점(저점) 확정» 사건 중 MACD 다이버전스가 **아닌** 것(RSI 연구 P2 와 같은 구조), 주장 방향 = 반전.
  - P3 는 실제 가격의 이어짐·되돌림 성질을 그대로 품는다 → «MACD 라서»인 몫 = 실제 − P3.

## 주 판정 (사전 고정)
칸 = {M1, M2, M3} × {15분, 1시간} = **6칸**, Holm(α .10). 칸마다 «맞음» = 전부:
1. 실제 − P1 단측 90% 하한 > 0 (달력일 군집 + 위약 분산)
2. **실제 − P3 단측 90% 하한 > 0** (달력일 군집 부트스트랩, 두 쪽 날짜 합집합)
3. 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호(실제 − P1)
- 통과 후보 = 1·2 점추정 > 0 + 3. 부호를 뒤집어 넘으면 «거꾸로».
