# 사전등록: 횡보/추세 분별 모델 제로샷 일반화 — 학습에 쓴 적 없는 5개 코인 (2026-11-02)

**등급: 예측 정확도 — 단측 90%, 기준선 대비 증분.** 평가(예측 성과) 전 커밋. 스크립트 `scripts/research_regime_zeroshot_20261102.py`. 사용자 /goal; 선행 `docs/experiments/regime_acc_20261102.md`(4코인 시험 1회 68.7%, 기하 로지스틱 61.8%)의 **독립 재현**.

## 왜
- 선행 결과는 BTC·ETH·SOL·XRP 한 묶음, 시험 1회. 같은 코인·같은 국면이라 «이 4코인에서만 맞는다» 가능성이 남는다. 학습에 한 번도 안 쓴 코인(ADA·AVAX·BNB·DOGE·LINK)에 **동결한 구성**을 그대로 적용해 코인 일반화를 본다(재적합·재선택·임계 조정 없음).
- 유일한 독립 데이터: 5개 코인 5분봉 CSV는 2026-08-26 17:55 UTC 까지. 코인도 시간도 처음 보는 구간 = **2026-06-01 ~ 2026-08-26**(약 87일).

## 규격 (동결)
- 모델: 선행 시험 때와 같은 구성·같은 학습 구간 — 4코인(BTC·ETH·SOL·XRP) 2024-01-15 ~ 2026-05-31(끝에서 4h purge), HGB(depth 3, lr .03, 600회, min_leaf 200, l2 1, early_stopping 끔, seed 0), 27피쳐(레벨 과거이력 제외). 기준선: 같은 구간으로 적합한 기하 로지스틱(GEO 10피쳐), 시험 비율 다수결.
- 라벨·피쳐·레벨: 선행과 같다(라벨 yA48 = 앞으로 4h 종가가 가장 가까운 S/R 띠 이탈; 레벨 = 대시보드 `compute_spliced_levels` 24h 시간별 스냅샷; 피쳐 `frame_for` 공용). 입력 = `data/{ada,avax,bnb,doge,link}_5m_2024_2026.csv`(5분 격자 assert), BTC 교차 피쳐는 BTC 패널을 같은 시각으로 정렬. 임계 0.5.
- 결정: 매 시 정각 마감 봉, 진입 봉 i+1 이후 48봉이 라벨(경계 계약).

## 판정 (주 구간 = 제로샷 코인+시간, 2026-06~08; 5코인 풀링)
통과 = 전부 만족:
1. 정확도 증분(모델 − 기하 로지스틱) 일 블록 부트스트랩 95% CI 하한 > 0 (단측 90% 이상이면 «증분 있음»으로 보고하되 통과 기준은 95%).
2. 5개 코인 중 **4개 이상**에서 모델 정확도 > 기하 로지스틱 정확도.
3. 모델 정확도 > 코인 풀링 다수결(그 구간 실제 비율).
보조(판정 안 씀): 코인별 표, 확신도별 정확도, 시간이 겹치는 2024-01~2026-05 제로샷 코인 결과, AUC.

## 시행 기록
주 판정 1(조건 3개). 동결 구성은 이미 시험에서 1회 쓰였으나 이번 구간·코인은 새 데이터이므로 선택 편향 없음. 불통과면 «4코인에 국한»으로 기록하고 모델을 바꾸지 않는다.
