# 4h 변동성 12라운드 — QX4 + 옵션 내재변동성·옵션 흐름 잔차 보정 (2026-10-25, 채점 전 커밋)

## 왜
- 사용자 목표: 파이프라인별 최고 모델을 문헌 참고로 계속 개선. 변동성은 «정보가 있는» 유일한 축(QX4 가 배포 HGB 이김, 7~11라운드 피쳐·구조 추가 전부 불통과).
- 문헌: Busch·Christensen·Nielsen(2011, J. Econometrics) IV 가 HAR 의 RV 예측에 정보 추가 · Alexander·Deng·Feng·Wan(2021, arXiv 2109.02776) BTC 옵션 순매수 압력·거래량 → 다음 기 RV·IV 유의.
- 앞선 근거: 10-24 VRP 1b 에서 1일 ATM IV 가 HAR 보다 RV 를 훨씬 잘 설명(R² .50 vs .11). QX4 에 옵션 정보를 넣은 적은 없다(7라운드는 펀딩·OI).
- 옵션은 2026 만(사용자 09-29) → 기반 QX4 는 4라운드 동결 예측(학습 2024-25)을 그대로 쓰고, **보정 계수는 검증 2026-01~05 에서만** 맞춘 뒤 시험 2026-06~10-23 에 적용.

## 피쳐(전부 체결 시각 < d)
- x1(IV 격차) = ln(IV²·4/8766) − ŷ_QX4. IV = [d−1h, d) 체결 중 |델타| 0.35~0.65 · 만기까지 1시간~10일인 체결 iv 중앙값(없으면 6시간까지 앞 값, 그래도 없으면 x1 = 0).
- x2 = ln(1+|z|), z = [d−4h, d) 델타 가중 순매수 / 직전 720시간 같은 양의 표준편차.
- x3 = ln([d−4h, d) 거래량 / 직전 720시간 평균).

## 모형
- **QX4I(주)**: ŷ + a + b·x1. **QX4O(보조)**: ŷ + a + b1·x1 + b2·x2 + b3·x3. OLS(y − ŷ), 검증에서만 적합.
- 눈금 c 는 기존 규칙(검증 ln mean exp(y−ŷ)) — 모든 모형 같은 방식.

## 관문(ETH 시험 2026-06-01~10-23, 일 블록 CI = 기존 `day_ci`)
- **G1**: QLIKE(QX4I) − QLIKE(QX4) 평균 < 0 이고 95% CI 상한 < 0.
- **G2**: 검증에서 b > 0(IV 가 높을수록 RV 위로 — 부호 사전 고정).
- 통과 → «QX4I 후보»(배포는 QX4 배포 판단 뒤, 실시간 IV 원천 = 서버 deribit_options 수집기). 불통과 → 옵션 IV 축 닫음.
- 보고만: QX4O, MSE, 상관, lvl 기울기, 월별 ΔQLIKE. 🔴 2026 시험 구간은 4·5·7~11 라운드에서 여러 번 열림(QX4 대비 차이만 판정) — 검정력·재사용 공개.
