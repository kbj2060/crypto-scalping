## 왜 (과거 실패 교훈 반영)
- 레짐 모델 중단 결론: ① ER·레짐 구분은 예측 안 됨(AUC .52~.54) ② **변동성 수준은 예측된다**(미래 |수익| 상위 AUC .657, 양성 대조 통과) ③ 학습만으로 R2(범위 페이드)는 모든 피쳐 분위에서 음수, 고변동·고거래대금에서 더 나쁨 → «변동성이 높을 때 페이드»는 직관과 반대. 그래서 이번엔 **게이트 방향을 가정하지 않고 학습에서 순평균이 양인 변동성 등급만 거래**(검증·시험에서 평가).
- XRP v1/v2: 레벨 돌파 후 즉시 진입은 소음 손절. 이번엔 **꼬리 스윕 후 안쪽 마감**(거절 확인)을 사건으로 하고, 배리어를 레벨이 아니라 **σ 단위**(변동성 비례)로 둬 «기하 = 변동성»(ledger_sr_first_entry_grid, 위약과 동률 교훈)을 설계로 흡수. 위약은 «같은 규칙을 무작위 봉에서» 돌려 레벨 정보만 분리한다.
- 스윕 vs 런 × 거래대금 = 정보 0 (ETH 09-28), 청산맵 S/R 방향 정보 없음 — 선행 확률이 낮다고 알고 시도한다.
- 구간 재사용: 4코인 5분 패널을 이 세션 레짐 연구와 XRP 연구가 이미 썼으나 **이 사건·배리어 조합은 처음**. 2026 은 «준-표본 밖».

## 데이터·시각 규약
- 데이터: `tmp/meta_label_race_20261101/{BTC,ETH,SOL,XRP}USDT_5m.parquet`. 청산맵 레벨 = 대시보드와 같은 `compute_spliced_levels`(24h 창, 5분 쪼개기), **시 정각 t 마다 t 에 닫힌 봉만으로**(XRP v1/v2 와 같은 코드, 4코인 `tmp/levels_4coin_20261102/levels_{COIN}.pkl`), 그 시간 동안 고정. 레벨 = 지지·저항 각 ≤6개.
- 사건(봉 i, 마감 시각 τ): **저항 거절** = 어떤 저항 레벨 R 에 대해 고가 > R ≥ 종가 이고 시가 ≤ R → 숏; **지지 거절** = 저가 < S ≤ 종가 이고 시가 ≥ S → 롱. 여러 레벨이면 가장 가까운 것. 사건 뒤 48봉 쿨다운(한 번에 한 포지션 근사).
- 진입 = 봉 i+1 **시가**. σ = 봉 i 까지 직전 48봉 실현변동성(√Σr²). **SL** = max(진입 ± 0.5σ, 신호 봉 극단 ±0.01%) , **TP** = 진입 ∓ 1.0σ, 시간청산 = i+48 종가(`barrier`: intrabar, 같은 봉이면 SL 먼저). 비용 진입 4bp + (TP 2bp | SL·시간 4bp).
- 변동성 게이트 g = log( σ48 / (RV288/√6) ) (최근 4h 변동성이 24h 평균보다 확장돼 있나).

## 주 판정 (게이트 정책, 4코인 풀링)
정책 = 학습에서 순평균>0 인 g 등급만 거래. **검증·시험 각각** (건수 ≥100 필요): ① 건당 평균 순 bp > 0 이고 **일 블록 99% 양측 CI 하한 > 0** ② 위약(같은 규칙·같은 방향 구성·같은 게이트 등급의 건수, **무작위 봉**에서 1,000회) **99분위 이상**. 둘 다 통과여야 통과. 통과 후보 = 총수익(비용 0) 보고만.
