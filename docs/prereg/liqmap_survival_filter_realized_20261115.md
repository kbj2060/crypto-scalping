# 사전등록: 청산맵 «생존 필터»(지나간 청산가 지우기) 켬 vs 끔 — 실측 청산 위치 일치 (2026-11-15)

**등급: 되돌리기 쉬운 예측(표시) 개선 — 양쪽 방향을 다 묻는 비교라 90% 양측 구간(5·95 분위)으로 판정.** 완화 «통과 후보» 등급 병기.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_eth_liqmap_survival_filter_realized_20261115.py`.

사용자 «검정해줘» (11-15): 우리 180일 지도(생존 필터 켬)와 코인글래스 180일 지도의 위쪽(숏) 누적 차이를 분해하니, 필터만 끄면 코인글래스 모양(위/아래 비율 3.2 vs 4.1)이 나왔다. 어느 쪽이 실제 청산과 더 맞는가.

## 왜 (과거 실패 교훈 반영)
- 10-08 `liqmap_venue_leverage_realized_validation`: 거리 모양만으로도 IC 가 높게 나온다 → 두 지도의 **짝 차이**를 주 판정으로, 시간 섞은 대조(그 시각 고유 정보)는 보조로 같이 낸다.
- 10-08 2차: «직전 24h 실측 청산을 지도에 섞기»가 크게 악화 — «이미 터진 자리는 포지션이 사라진 자리». 이번 가설(필터 끔 = 지나간 자리도 남김)은 이 결과와 같은 방향의 질문이라 «켬이 낫다»가 사전 기대다. 결과가 기대와 반대여도 바꾸지 않는다.
- 10-08: 7·30일 지도는 4h 에서 악화 · 24h 동률 → 180일 지도는 넓은 맥락용이라 **24h 를 주 지평**으로, 4h·7일은 보조.
- 검정력: 10-08 7일 TEST 의 CI 폭 ±.07~.1. 이번엔 약 52일 → 폭 ±.03~.05 예상. 그보다 작은 차이는 «구별 못 함»으로 낸다.
- 같은 구간 재사용 공개: 09-21~10-26 은 10-08·10-28 연구가 **현행 1일 지도**로 이미 봤다(필터 끔·180일 창은 처음). 10-27~11-13 은 처음. 주 판정 2개 → 우연 통과 기대 약 0.2개.

## 데이터·시각 규약
- 봉 = 바이낸스 ETHUSDT 1시간봉(서버 `data/live/liq_tab_k1h_eth.parquet`, 거래량 = 거래대금/종가 근사).
- 기준 시각 i(매 정시) 지도 = 봉 [i−W, i) 만. 생존 필터도 그 안(봉 j 의 청산가가 j 뒤 ~ i−1 봉의 고·저에 닿았나). 기준가 cp = 봉 i−1 종가.
- 실측 = [i, i+H) 바이낸스·OKX(ETH-USDT-SWAP)·Bybit 청산 $. 위치 = 청산 시각 바이낸스 마크(1초, 5초 안 직전값) — OKX·Bybit 가격 필드는 파산가라 안 쓴다(10-08 규약).
- 칸 = cp 대비 0.2% 상대 칸, ±50% 안. 롱 쪽 = 창 최저가~cp 사이 지나간 칸, 숏 쪽 = cp~창 최고가.
- 모델 = 라이브 `compute_tier_profile` 가정(6단 10·20·25·50·75·100배, 롱 = 중간가 진입·숏 = 종가 진입, 유지증거금 0.5%, 가중 = 거래량 × 최근성 × 진입가). 자기 봉 안 5분 쓸림(`_own_bar_alive`)은 넣지 않는다(10-08 틀과 같음).

## 주 판정 (사전에 고정)
지표 = 기준 시각·쪽마다 «지나간 칸 안에서 (지도 값, 실측 청산 $) 스피어만 IC» (칸 ≥4·실측 합 >0·지도 값이 다 같지 않을 때만) → 짝 차이 평균. 일 블록 부트스트랩 2,000회.
1. **B − A** (감쇠 있음에서 필터 끔 − 켬), H = 24h, 세 거래소.
2. **D − C** (감쇠 없음에서 필터 끔 − 켬), H = 24h, 세 거래소.
- 짝은 두 변형 모두 IC 가 정의된 (기준 시각, 쪽)만.
- 판정: 둘 다 5분위 > 0 → «끔이 낫다(엄격 통과)» · 둘 다 95분위 < 0 → «켬이 낫다(엄격 통과)» · 그 밖 = 구별 못 함.
- 통과 후보: 두 점추정 부호가 같고 그중 하나라도 위 구간 조건을 만족.
- 지표는 건수(기준 시각·쪽 수, 일수)와 함께 보고.
