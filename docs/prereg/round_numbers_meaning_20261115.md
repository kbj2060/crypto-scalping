# 사전등록: 라운드 넘버가 «뜻하는 대로» 움직이는가 (2026-11-15)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_round_numbers_meaning_20261115.py`.
사용자 «라운드 넘버 검증 진행해줘» (다음 검증 지표 목록 8번).

## 왜 (문헌·이전 시행)
- 문헌: Osler (2000, 2003 «Currency orders and exchange rate dynamics: an explanation for the predictive success of technical analysis», J. Finance 58(5)) — 외환 주문 장부에서 **익절 주문은 라운드 넘버에 몰려 추세가 거기서 되돌고**, **손절 주문은 라운드 넘버 바로 너머에 몰려 넘으면 가속**한다. 2차 기억(원문 재확인 안 함). 크립토는 미확인 → 두 주장을 그대로 시험한다.
- 이전 시행: 라운드 넘버 단독 검정 없음(09-12 유명 트레이더 전략 6종·09-27 볼린저 터치는 다른 레벨). 11-15 SMC·볼륨 프로파일과 같은 비교 틀(기하 위약 P1 + 같은 간격 비라운드 수준 P2).
- 교훈: 무작위 가격도 가까운 수준엔 잘 닿고 경주 기준선이 50% 가 아니다 → 위약·비라운드 대조 필수.

## 정의 (사전 고정)
- 15분봉 4코인(ETH·BTC·SOL·XRP), 1분봉 Vision 2022-01~2026-11-13, ATR = 15분 참범위 14봉 평균.
- **라운드 간격** = 10^(⌊log10(그 봉 종가)⌋ − 1): ETH 1,000~9,999 → 100 · BTC 10,000~99,999 → 1,000 · SOL 100~999 → 10(10~99 → 1) · XRP 1~9.99 → 0.1(0.1~0.99 → 0.01). 라운드 수준 = 간격의 정수배.
- **비라운드 대조 수준(P2)** = (k + 0.3)·간격, (k + 0.7)·간격.
- 결과는 사건 봉 종가 다음 봉부터, 1분 안 순서 모름 → 같은 봉 동시는 주장에 불리하게(11-15 first_hit_race 규칙).

## 주장과 측정 (3칸)
| # | 주장 | 측정 |
|---|---|---|
| R1 | 라운드 넘버에서 되돈다(익절 몰림) | 수준을 앞 16봉(4시간) 동안 안 닿다가 처음 닿은 봉 → 그 봉 종가 기준 100봉 안 «다가온 반대쪽» 1 ATR 이 «계속 쪽» 1 ATR 보다 먼저 |
| R2 | 라운드 넘버를 넘으면 가속한다(손절 몰림) | 앞 16봉 종가가 모두 한쪽이다가 종가가 수준을 넘은 봉 → 100봉 안 넘은 방향 1 ATR 이 반대 1 ATR 보다 먼저 |
| R3 | 큰 고점·저점이 라운드 넘버에 몰린다 | 15분 큰 스윙(앞뒤 50봉) 고점·저점 가격이 라운드 수준 ±2% 간격 안에 든 비율 |
- 각 칸 P1 = 같은 측정을 기하 위약 20벌(1분 부호 뒤집기, 11-15 와 같은 함수·시드)에서. P2 = 같은 측정을 비라운드 수준(0.3·0.7)에서.

## 주 판정 (11-15 SMC 와 같은 규칙)
칸마다 «의미 맞음» = 전부: 실제 − P1 단측 90% 하한 > 0(달력일 군집 부트스트랩 + 위약 벌 분산) · 3칸 Holm(α .10) · 실제 − P2 단측 90% 하한 > 0 · 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호. 통과 후보 = 점추정 > 0 + 코인·구간. 부호 뒤집어 넘으면 «거꾸로».
