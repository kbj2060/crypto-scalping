- 앞선 시도와 다른 점: 지금까지는 (a) 고정 규칙(추세·VWMA·개장) 또는 (b) 피쳐 → 지도학습(HGB·DL·LLM)이었다. 여기서는 피쳐 학습 없이 **규칙 사이의 온라인 선택**만 배운다. 저장소 메모리에서 «온라인 전문가 가중» 방향 시험은 0건(grep 확인).

## 전문가 묶음(고정, 15개)
k ∈ {1, 3, 7, 14, 28, 56}일 수익률 r_k(d):
- 모멘텀 s = sign(r_k) (6개), 되돌림 s = −sign(r_k) (6개)
- 항상 롱 +1, 항상 숏 −1, 현금 0 (3개)

## 학습기(온라인, 피쳐 학습 없음)
- 전문가 e 의 일 d 성적 p_e(d) = [s_e(d−1)·r(d) − 비용·|s_e(d−1) − s_e(d−2)|] / σ20(d−1). σ20 = 직전 20일 일 수익률 표준편차.
- 점수 S_e(d) = p_e 의 지수 가중 평균(반감기 H일, d 까지 — 일 d 종가에 알 수 있음).
- 신호 s(d) = 점수 상위 m 개 전문가 신호의 평균 ∈ [−1, 1]. 동점은 전문가 번호순.
- 크기: «vol» = s × min(2, σ* / σ20(d)), σ* = 0.5/√365 (연 50% 목표) · «unit» = s.
- 포트폴리오 = 4코인 일 손익 평균.
