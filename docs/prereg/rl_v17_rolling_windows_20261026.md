# RL v17 — v16(TSMOM 위 RL 조정·거울) 을 굴림 3창 + 체크포인트 고정으로 (2026-10-26, 채점 전 커밋)

등급: 돈 걸린 매매 → 사용자 RL 상대 기준.
## 왜
v14·v15·v16 모두 하락장 검증(26-01~05)에서 RL 우위(원형이동 89~99.8분위)·상승장 시험(26-06~09)에서 교사 미달. 체크포인트를 한 국면(검증 5개월)으로 고른 것이 국면 맞춤을 낳음. 판정을 여러 국면으로 넓히고 체크포인트 선택에서 검증 국면을 뺀다.
## 사양(v16 그대로 + 아래만)
- 창(방향 모델 표본 밖 기록 2023-01~ 이용): **R1** 학습 2023-01-01~2023-12-31 · 시험 2024-06-01~2024-10-23 · **R2** 학습 2023-01-01~2024-12-31 · 시험 2025-06-01~2025-10-23 · **R3** 학습 2024-01-01~2025-12-31 · 시험 2026-06-01~2026-09-14. (σ* 와 교사 T2 문턱은 창마다 그 학습 구간으로.)
- **체크포인트 = 마지막(30만 걸음) 고정** — 검증 선택 없음(검증 구간은 보고만: 각 창 시험 직전 1~5월).
- 시드 5개(v14 와 같은 목록) × 3창 = 15학습. 앙상블 = 5시드 평균 명목.
## 관문
- **H1**: 3창 시험 시간 손익 이어 붙인 샤프 RL > T3 TSMOM 그리고 > max(T1, T2).
- **H2**: 3창 각각 RL 샤프 > T3 샤프 인 창 ≥ 2/3.
- **H3**: 조정(RL − T3) 원형이동(창 안에서, 1,000회) 분위 — 3창 이어 붙인 총손익 기준 > 90.
- 통과 = 셋 다 → «후보(상대 기준)» → 전진 기록.
- 장치 검증: R3 에서 심은 신호(ρ .3) 1시드, 마지막 체크포인트로 검증 샤프가 교사보다 크게 높아야.
- 🔴 공개: R3 시험 구간은 v14~v16 에서 세 번 사용 · R1·R2 시험 구간은 RL 에서는 처음(변동성·박스 연구에서는 사용).
