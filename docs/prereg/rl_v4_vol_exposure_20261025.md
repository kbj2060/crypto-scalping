# 사전 등록: RL v4 — 방향 대신 «노출 크기»를 정하는 RL, 1단계 정보 상한 (2026-10-25)

왜: RL v1~v3.1·추세 포트 모두 방향 정보 부족으로 굴림 3창에서 무너졌다. 저장소에서 정보가 확인된 것은 변동성(QX4 가 3창·4코인 통과)뿐이다. RL 이 «규칙에서 시작해 자기 전략»을 만들 여지가 있다면 방향이 아니라 **노출 크기**(변동성 관리) 쪽이다. 결과 전에 커밋한다. 실주문 없음.
문헌: Moreira·Muir 2017(변동성 관리 포트 — 노출 ∝ 1/σ̂² 가 샤프를 올림) · Cederburg 외 2020(표본 밖에선 대부분 실패 — 반론) · Harvey 외 2018(변동성 목표는 주로 꼬리·낙폭을 줄임).

## 1단계(싼 상한 점검, RL 학습 전)
RL 노출 에이전트의 교사 = 변동성 목표 규칙. 교사조차 1배 보유보다 위험 대비 낫지 않으면, 같은 정보로 학습하는 RL 이 이길 근거가 없다(1단계 정보 상한 rl_info_ceiling 과 같은 논리).
- 대상: 4코인 동일 비중 **롱 전용** 바구니(방향 정보 0), 일봉 재조정, 추세 포트 스크립트의 엔진·체결(전날 종가 지정가 1시간 → 테이커)·펀딩 그대로.
- 규칙: 코인 목표 명목 = τ · min(L, (σ*/σ̂)^p) / 4, σ̂ = rv20(5분 실현) · cc20, p ∈ {1(변동성 목표), 2(Moreira·Muir)}, σ* = 그 코인 학습 구간 σ̂ 중앙(학습 구간 평균 노출 ≈ 1배가 되게), L = 2. → 4 규칙.
- 비교: 같은 엔진 1배 보유(τ=1, 노출 고정).
- 창: 추세 5회차·변동성·RL 과 같은 굴림 3창(W1·W2·W3 시험 6~10월, 학습 2년은 σ* 만 정함).
- **통과(RL 2단계로 감)**: 4 규칙 중 하나라도 (i) 3창 이어 붙인 샤프 − 보유 샤프 > 0 이고 일 수익 차의 «변동성 맞춘» 판(규칙 수익을 보유 실현 변동성에 맞춰 축척) 20일 블록 CI 하한 > 0 · (ii) 2022-01~2025-12 연속 구간에서도 샤프 > 보유. Bonferroni 4.
- 불통과면 RL v4 는 만들지 않는다(노출 크기 쪽도 정보 부족으로 기록).
