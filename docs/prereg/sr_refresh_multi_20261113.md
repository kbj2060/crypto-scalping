# 사전등록: 지지·저항 5분 재계산 vs 1시간 — 다방면(버팀·닿음 청산·머묾·수명) (2026-11-13)

**등급: 되돌리기 쉬운 표시 개선 — 단측 90%** + 완화 «통과 후보» 등급 병기.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_sr_refresh_multi_20261113.py`(`--selftest` · `--pilot` · `--run`).
사용자 «지지/저항이 5분마다 업데이트 되는 것이 실제로 지지/저항을 더 효과적으로 잘 반영하고 있는지 분석해줘 … 얼마나 오래 머무는지, 청산이 얼마나 많이 일어나는지 등으로 다방면으로».

## 왜 (과거 교훈 반영)
- 11-09 검정(48ce8287): 다음 60분 청산 $ 위치 몫은 5분이 +0.4%p(불통과) — 그것도 레벨이 6bp 가까워진 몫. **이번엔 «레벨이 지지/저항으로 작동하나»를 직접 잰다**: 닿은 뒤 버팀, 닿는 순간 그 자리 청산, 닿은 뒤 머묾.
- 11-09 교훈 «±40bp 옮긴 평균 위약은 거리 볼록성으로 치우침»: 이번 주 판정은 **닿음에 조건부인 버팀률**이라 거리 영향이 작다. 위약 = 같은 팔 레벨 묶음을 통째로 ±25·±50bp 옮긴 4벌(진짜와 ±0.15% 겹치면 뺌) — 수명·개수 구조를 보존한다.
- 파일럿(ETH 09-21~27, **주 판정에서 뺌**)에서 위약을 먼저 세웠다: ①«거리 섞기» 위약은 5분마다 새 레벨이라 닿음이 진짜의 3배 → 버림 ②옮긴 묶음 위약에서 닿음 순간 청산 $ 진짜 1.16M vs 위약 0.42M(양성 대조 섬) ③«60분 종가 체류»는 위약이 거리 탓에 높아 버리고 «닿은 뒤 30분 머묾»으로 바꿈. 파일럿의 버팀 수치(본 판정 지표)는 7일·73~155건이라 판정 근거로 안 쓴다.
- 11-10 «뚫음 vs 되돌림» 판별 불통과(대칭 ±0.5σ1h, 기저 되돌림 51.3%): 같은 라벨 폭(0.5σ1h)을 쓰되, 이번엔 판별이 아니라 **진짜 레벨 vs 옮긴 레벨의 버팀률 차**다.
- 같은 구간 재사용 공개: 09-28~11-07 은 11-09(청산 몫)·11-10(뚫음/되돌림, 1시간 스냅숏 레벨)·11-12(라인 호가)가 봤다 — 3라운드, 예상 우연 통과 ≈ 0.3. 11-08~11-11 4일만 새 날.

## 팔 (화면 재현 · 11-09 스크립트와 같은 함수)
결정 시각 τ = 매 5분 경계, `cur` = τ 에 닫힌 5분봉 종가, 쪽마다 가까운 순 3개.
- **A1 = 1시간 + 쓸림 필터 + 채우기**(11-09 전 화면): 정시 지도(닫힌 1시간봉 24개) · `[정시, τ)` 5분봉이 지난 레벨 버림 · 모자라면 heatmap_bins 채움.
- **B = 5분 재계산**(11-09 배포, 지금 화면): `compute_spliced_levels(_window_at(τ), cp = cur, 5분봉 < τ)`.

## 데이터·시각 규약
- 1시간·5분·1분봉 = data.binance.vision 일 파일(USDT-M) — 닫힌 봉만. 청산 = 서버 lake `binance/liquidations`(바이낸스 forceOrder, 하한) · 위치 = 청산 자체 가격.
- 사건 = τ 에 보이는 레벨 L 에 (τ, τ+60분] 1분봉이 처음 닿은 분 m(지지 저가 ≤ L · 저항 고가 ≥ L). 같은 닿음(쪽 · m · L 0.15% 칸)을 여러 τ 가 세면 가장 이른 τ 하나.
- 라벨 시작 = m+1 분(닿음은 m 분 끝에야 안다) · 기준가 = L(닿았으니 체결 가능) · 폭 D = 0.5σ1h(τ 까지 288개 5분 수익). 레벨은 τ 까지 닫힌 봉만 본다 → 피쳐 끝 < 라벨 시작.

## 주 판정 (ETH, 사전에 고정)
버팀률 h = 버팀 / (버팀 + 뚫림)(같은 봉 둘 다·60분 끝은 빼고 건수 보고). 팔마다 X = h(진짜) − h(위약 4벌 합).
- **엄격 통과**: ΔX = X_B − X_A1 의 날 블록 부트스트랩(2,000회, 같은 날 뽑기를 두 팔·위약에 공통) **단측 90% 하한 > 0** 이고 **X_B 단측 90% 하한 > 0**(5분 레벨이 실제로 지지·저항으로 작동).
- **통과 후보**: ΔX 단측 90% 하한 > 0 만.
- 지표는 분모·건수(버팀/전체)와 하루 닿음 수로 보고.

## 보조 (판정에 안 씀)
1. 닿음 순간 청산: 닿은 분부터 5분, L ±15bp 안 청산 $ — 닿음당 평균 진짜 vs 위약(배수), 청산 있는 닿음 몫.
2. 머묾: 닿은 뒤 30분 1분 종가가 L ±10bp 안에 있는 몫 — 진짜 vs 위약.
3. 수명: τ 레벨이 15분·60분 뒤에도(같은 쪽 ±0.15%) 보이는 몫 · 연속 표시 길이 중앙(분) · 60분 이상 몫.
4. 거리: 현재가까지 거리 중앙(bp) · 하루 닿음 수.
5. 쪽별(지지/저항) X · 코인별 같은 표(BTC·SOL·XRP·SOXL).
