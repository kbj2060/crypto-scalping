# 사전등록 2라운드: 매크로 국면·4주 편향 — 절편 없는 «부호 × 변화량» 결합 (2026-10-28)

**등급: 되돌리기 쉬운 예측 개선 — 단측 90%.** **계산 전 커밋.** 1라운드 `macro_regime_bias_4w_20261028.md`(불통과, `docs/experiments/macro_regime_bias_20261028.md`)의 후속.
사용자 10-28: «방향을 절편 없는 «부호 × 변화량»(Z91 식) 결합으로 바꾼 2라운드를 새로 사전등록하고, 판정은 2026-06~ 시험 1회와 전진으로만».

## 왜
- 1라운드는 2020–23 강세 평균이 회귀 절편에 남아 예보가 98% 주 «상승» → 방향 정보 0(크기 정보 R²_OS +3.7% 는 있었다). Z91(절편 없음·부호 고정)은 방향에서 견고했다.
- 🔴이 규칙은 1라운드 채점(2024-01~2026-05)을 본 뒤 정했다 → 그 구간은 **판정에 쓰지 않는다**(보고도 «사후 참고»로만). 판정 = 2026-06~ 시험 1회 + 전진.

## 고정 사양 (새 적합 없음)
- 지표·부호: 1라운드 동결 사양 `macro_regime_bias_4w_frozen_20261028.json`(sha256 e4b0cb86…, 2020–23 적합)의 `selected=true` 지표와 sign(r). 자산·모델별(ETH/BTC × B4/A) 그대로.
- 피쳐 x_i,τ: 1라운드와 같다(판정표 변환의 13주 변화, 1주 미룸, 주간 표본 = 판정표 `sample(panel,"W")`).
- 결합: z_i,τ = sign_i · x_i,τ / sd_i,τ, sd_i,τ = x_i 의 τ 까지 104주 표준편차(최소 52주). **Z_τ = 그 시각 값이 있는 z_i 의 평균.** 절편·회귀 계수 없음.
- 방향(B) = sign(Z_B4). 국면(A) = sign(Z_A). 보류 없음(k=0)이 주 판정. 보조: |Z| ≥ 0.5 만 예측.

## 판정
**시험 1회** (2026-06-05 ~, 패널 = 1라운드와 같은 10-27 미러 재생성 + NASDAQ100, 현재 빈티지; 달러지수·STLFSI4 최초 공표값 재채점이 다르면 그쪽이 정답):
- 주(ETH B4): 적중 − «늘 상승»(그 구간 실현 상승 비율). 독립 4주 창 ≈4 라 판정력 없음 — **음수면 실패**로 기록, 0 이상이면 «시험 통과(약)»로 기록.
- 주(ETH A): 국면 적중 − «늘 상승», 같은 규칙.
- 보조: BTC · B8·B13 · corr(Z_A, c13) · Z91 k=0 방향 · |Z|≥0.5.

**전진** (`scripts/live_macro_bias_forward_20261028.py`, 서버 cron 매주 토 10:30 KST): 결정 시각 τ = 직전 금요일(가격 = 바이낸스 현물 1일봉 종가 = 토 00:00 UTC). 그 시각에 받은 FRED API·Yahoo(KOSPI)·바이낸스 값으로 Z 를 계산해 시각과 함께 `data/live/macro_bias_forward.jsonl` 에 남긴다(기록 시각 = 알 수 있던 값). 2026-10-30 결정부터.
- B 판정 시점: ETH 4주 라벨이 확정된 결정 52주(빨라도 2027-11-19).
- B 통과(넷 다): ①전진 적중 − «늘 상승» > 0 의 8주 블록 부트스트랩 2,000회 단측 90% 하한 > 0 ②시험 적중 − «늘 상승» ≥ 0 ③자산 BTC 도 전진 적중 − 늘 상승 ≥ 0 ④원형 이동 위약 1,000회(±8주 제외) 90분위 초과.
