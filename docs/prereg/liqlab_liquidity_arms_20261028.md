# 유동성 전략 전수 조사 + liqlab 사전등록 (2026-10-28)

등급: 매매 팔 T1~T4 = **돈 걸린 매매 신호(엄격: 양측 95%)** · 예측 팔 P1~P3 = **되돌리기 쉬운 예측 개선(단측 90%, 조건부 채택)**.

사용자 지시(10-28): «liquidity 관련 전략을 취할 수 있는 규칙 및 모델을 외부 및 내부에서 전수 조사해서 우리한테 적용시킬 수 있을 게 있는지 가져와주고 리스트업해줘. 바로 테스트하지 말고 테스트 환경을 세세하게 만들어서 완벽하게 불통과/통과를 만들어줘.»

이 문서는 **결과를 보기 전에** 커밋한다. 커밋 뒤에 바뀌는 것은 «사후 변경» 절에 이유와 함께만 적는다.

## 1. 왜 — 과거 실패에서 반영한 것 (playbook_paper_model_tests)

- **비용 산수 먼저**: 1초~5분 유동성 신호는 정보가 실재해도 1~5초 안에 사라져 비용을 못 넘었다(QI IC .44@1s, 5분 IC .03). 그래서 지평을 **1시간 이상** 또는 **메이커 체결 구조 자체**를 시험하는 팔만 골랐다.
- **«깊은 벽»은 정확도 통과·메이커 매매 불통과였다** → 원인 후보인 «체결될 때만 불리» 역선택(Albers 2025)을 하네스의 관통 체결 규칙으로 직접 재현하고(자가 점검 SC6b), T2 팔이 그 메커니즘을 시험한다.
- **가격 그림자**: 유동성 피쳐가 직전 수익·변동성의 재표현이었던 사례가 많다 → 예측 팔은 HAR-RV(+직전 수익) 기준선 위의 **증분**만 잰다. 매매 팔 귀무는 시간대×변동성 3분위를 맞춘다.
- **2022~23 에서만 되는 효과**(횡단면 메타 발견 09-11) → 학습 2024·25, 판정 2026.
- **같은 창 재사용**: 시험창 2026-06-01~10-23 은 다른 연구들도 본 «준-표본 밖»이다. 진짜 표본 밖은 10-24 이후 전진뿐.
- **이항 SE 금지**(사건 군집) → 일 군집 부트스트랩. **0건 스캔엔 양성 대조**(SC6·실데이터 planted).
