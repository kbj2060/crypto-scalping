**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_ob_retest_strategy_20261115.py`.
사용자 «오더블록 재진입 전략» — 의미 검증(`docs/experiments/smc_ict_meaning_20261115.md`)에서 15분 OB «되돌아오면 버팀»이 위약 대비 +3.7pp(N5)·+7.8pp(N50)로 통과한 것을 매매로 옮기면 비용 뒤에 남는가.

## 왜 (과거 교훈 반영)
- 09-16 ICT 3종: **적중 우위는 진짜인데 이긴 판이 작아 손익분기 미달**((2a−1)×b 벽). → 이번엔 적중률이 아니라 **순 bp·손익분기 적중률 대비 여유**로 판정하고, 청산 구조(익절 ATR 배수·손절 여유·시간 정리)를 설계 변수로 넣는다.
- 09-27 CHoCH/BOS 돌파 봉 종가 진입 0/12 — 이번엔 돌파 봉에 들어가지 않고 **존으로 되돌아올 때 지정가**(의미 검증에서 실재한 몫).
- 10-22 전략 설계 절차: 구조 전체 설계 · CPCV + PBO·DSR · 변수 ≤6 · 2026 잠금 1회 · 4코인 같은 규칙. 10-28 liqlab: 메이커 관통 체결이 역선택 ~1.6bp 를 먹는다 → **관통 체결**(가격이 지정가를 넘어야 체결)·체결 분 안 손절 먼저.
- 11-15 켈트너: 남는 몫이 일봉 추세일 수 있음 → 일봉 추세 거르개를 **변수로** 넣고, 모델−롱·모델−숏을 같이 보고.
- **2026 은 깨끗하지 않다**: 의미 검증이 2022-01~2026-11 전체로 OB 버팀률을 쟀다(뒤 구간 2025~26 양수 확인). 2026 잠금은 «매매 설정 1회 채점»으로는 처음이지만 OB 버팀 현상 자체는 이미 본 구간이다. 결과 문서에 적는다.

## 데이터·시각 규약
- 바이낸스 USDT-M 1분봉 ETH·BTC·SOL·XRP(Vision, 2022-01~2026-11-13). 신호는 15분봉(1분 다 찬 봉), 체결·청산은 **1분봉**으로.
- 신호: 의미 검증과 같은 인과 구조(스윙 길이 N, 피벗 p 는 p+N 봉 마감에 알려짐 · 종가가 확정 스윙을 넘으면 돌파 · OB = 스윙 다음 봉 ~ 돌파 직전 봉 중 저가 최저(상방)/고가 최고(하방) 봉의 [저가, 고가]). 돌파 봉 T 마감 시각에 알려진다. BOS·CHoCH 둘 다 씀.
- 상방 OB 만 롱, 하방 OB 만 숏. 돌파 봉 종가가 이미 존 안/반대편이면(롱: c[T] ≤ 존 위) 건너뜀.
- 주문: T 마감 직후부터 **지정가 = 존 가까운 쪽 가장자리**(롱 = 존 위, 숏 = 존 아래). 체결 = 1분봉 저가 < 지정가(숏: 고가 > 지정가), 체결가 = 지정가.
- 취소: (a) 체결 전 15분봉 종가가 존 먼 쪽 밖(존 깨짐) (b) 100봉(25시간) 경과 (c) 같은 코인에 새 신호가 나면 새 존으로 교체. 포지션 보유 중 새 신호는 무시. 코인당 포지션 1개.
- 청산(1분봉, 체결 분 포함):
  - 손절(시장가) = 존 먼 쪽 − sl_buf × ATR(롱). 1분 저가 ≤ 손절가 → 손절가에서 체결(+미끄러짐). 체결 분에도 검사(체결 분 저가가 손절가 이하면 즉시 손절).
  - 익절(지정가) = 지정가 + tp_k × ATR. 1분 고가 > 익절가(관통) → 익절가. **체결 분엔 익절 안 함.** 같은 분에 둘 다면 손절.
  - 시간 정리(시장가) = 체결 뒤 H 개 15분봉 마감 시 1분 종가.
- ATR = 15분 참범위 14봉 단순평균(돌파 봉 T 까지).
- 일봉 추세 거르개(켜면): T 이전 마지막 **마감한** UTC 일봉 종가 > 그 일봉까지 SMA50 이면 롱만, < 면 숏만.
- 크기: 거래당 명목 = 순자산 × 0.25(코인 4개, 레버리지 없음 1배 계산). 손익 = 청산일에 기록.

- 통과 후보: 메이커 경로 0bp, 시장가 경로는 그대로 6bp(10-28 정정 규칙).

## 주 판정 1 — 전략 (사전에 고정, 켈트너와 같은 관문)
S* = 개발 일 샤프 1등 설정(엄격 비용). 등급별로 같은 규칙으로 따로 고른다(후보 등급은 후보 비용으로 S*_c).
**개발 관문 — 엄격**(전부):
1. S* 일 손익 5일 블록 부트스트랩(2,000회) 양측 95% 하한 > 0
2. CPCV(6개월 8묶음 · 2묶음 시험 · 28분할 → 7경로): 경로 샤프 중앙 > 0, 7경로 중 6 이상 > 0
3. PBO(16토막 CSCV) < .2 · DSR(48시행) > .95
4. 연도 ≥ 3/4 양수 · 코인 ≥ 3/4 양수
**잠금 채점 — 엄격**(관문 통과 시 S* 만): 거래 순 bp 평균 달력일 군집 부트스트랩 양측 95% 하한 > 0 · 대조 A·B 95분위 초과 · 1배 낙폭 ≥ −20% · 코인 ≥ 3/4 양수 · 두 쪽 모두 양수.
**통과 후보**: 관문 = 개발 평균 > 0 · CPCV 경로 중앙 > 0 · PBO < .5 · 연도 ≥ 3/4 양수. 넘으면 S*_c 만 2026: 두 쪽 평균 > 0 · 코인 ≥ 2/4 양수 · 대조 A 50분위 이상.
- 관문을 못 넘으면 2026 은 열지 않는다.

## 대조 (S* 에, 개발·잠금 모두 보고)
- **A 바로 옆 가격대**: 같은 신호·같은 규칙인데 존을 존 높이만큼 **가격에서 먼 쪽으로** 한 칸 옮긴 띠(롱: 존 아래 띠). «그 자리라서»인지. 같은 순 bp 비교 + 신호별 짝 차이 달력일 부트스트랩.
- **B 기하 위약**: 1분 로그수익 부호를 무작위로 뒤집은 가짜 가격 20벌(의미 검증의 P1)에 전략 전체를 그대로 — 기대치 ≈ −비용. 실제가 20벌 분포의 몇 분위인지.
- 모델−롱·모델−숏(같은 25% 명목 4코인 보유 대비 일 샤프).
- 손익분기 적중률(평균 손실 / (평균 이익 + 평균 손실)) vs 실제 적중률.

## 주 판정 2 — 내 실원장 적용 (서술형 + 1개 검정)
- 원장: 서버 `data/live/account_round_trips.jsonl` 읽기 사본(닫힌 왕복, ETH·XRP·SOXL). 가격 = 같은 코인 USDT-M 1분봉.
- 각 왕복 진입 시각 직전 **마감한** 15분봉 기준, 진입가가 **살아 있는 같은 방향 OB 존 안**(N5: 생성 뒤 100봉 안 · 그 사이 종가가 먼 쪽 밖으로 안 나감 · 롱은 상방 OB, 숏은 하방 OB)이면 «존 안 정렬», 반대 방향 존 안이면 «존 안 역방향», 나머지 «존 밖».
- 결과: 고정 60·240분 시장 움직임(내 방향, bp)과 실제 순손익($), 건수.
- 검정 1개: **존 안 정렬 왕복의 고정 240분 수익 − 나머지**, 달력일 군집 부트스트랩 양측 95%. N50 은 서술만.

## 점검 (판정 전)
- `selftest`: 손계산 1분·15분 가짜 봉으로 관통 체결(닿기만 하면 미체결)·체결 분 손절·같은 분 둘 다 → 손절·익절 관통·시간 정리·취소 3종·비용.
- **절단 재계산**: 무작위 신호 200개를 봉 T 까지 자른 자료로 다시 계산해 같은 신호·같은 존이 나와야 한다.
- 양성 대조: 같은 진입에 «청산 = 미래 H봉 안 최고가(롱)» 같은 미래참조 가짜 → 큰 양수(하네스가 이득을 볼 수 있는지). 음성: 무작위 방향 ≈ −비용.
