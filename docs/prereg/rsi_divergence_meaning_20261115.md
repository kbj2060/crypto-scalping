# 사전등록: RSI 다이버전스가 «뜻하는 대로» 움직이는가 (2026-11-15)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_rsi_divergence_meaning_20261115.py`.
사용자 «추천 3개 차례로» 중 RSI 다이버전스(다음 검증 지표 목록 7번).

## 왜
- 가장 흔히 쓰는 반전 신호인데 이 저장소에서 단독 검정 없음(09-25 추세 전환 패턴 14종 스크린은 다른 패턴, RSI 는 피쳐로만).
- 11-15 교훈: «스윙이 확정됐다»는 사실만으로도 짧은 되돌림이 생긴다(CHoCH·BOS 뒤 24봉 방향 45~47%). → 다이버전스 몫을 따로 보려면 **같은 구조인데 다이버전스가 아닌 새 고점·저점(P2)** 과 비교해야 한다. 무작위 가격(P1)도 같이.

## 정의 (사전 고정)
- 15분봉 4코인(ETH·BTC·SOL·XRP), 1분봉 Vision 2022-01~2026-11-13. RSI14 = Wilder(RMA α=1/14) · ATR = 15분 참범위 14봉 평균.
- 스윙 = 앞뒤 5봉 최고·최저(피벗 p, **알려지는 시각 p+5**).
- **약세 다이버전스**: 새 스윙 고점 p 의 고가 > 직전 스윙 고점 q(p−q ≤ 60봉)의 고가 **이고** RSI[p] < RSI[q]. **강세**: 새 스윙 저점 저가 < 직전 저점 저가 이고 RSI[p] > RSI[q].
- **P2(다이버전스 아님)**: 같은 «더 높은 고점(더 낮은 저점)»인데 RSI 도 같은 쪽(RSI[p] ≥ RSI[q], 저점은 ≤).
- 결과는 알려진 봉 k = p+5 종가부터. 같은 봉 동시는 주장에 불리하게(first_hit_race).

## 주장과 측정 (주 2칸, 15분봉, 강세·약세 합침)
| # | 측정 |
|---|---|
| D1 | k 종가 기준 100봉 안 반전 쪽 1 ATR 이 반대 1 ATR 보다 먼저 |
| D2 | 24봉 뒤 종가가 반전 쪽에 있음 |
- P1 = 같은 측정을 기하 위약 20벌(1분 부호 뒤집기, 11-15 와 같은 함수·시드)에서. P2 = 다이버전스 아닌 같은 구조 사건.

## 주 판정 (11-15 SMC 규칙)
칸마다 «의미 맞음» = 실제 − P1 단측 90% 하한 > 0(달력일 군집 + 위약 벌 분산) · 2칸 Holm(α .10) · 실제 − P2 단측 90% 하한 > 0 · 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호. 통과 후보 = 점추정 > 0 + 코인·구간. 부호 뒤집어 넘으면 «거꾸로».

## 보조 (판정 안 씀)
1시간봉 D1·D2 · RSI 70 위로/30 아래로 처음 들어감 → 반전 1 ATR 먼저(P1 만) · 숨은 다이버전스(더 높은 저점 + 더 낮은 RSI = 상승 지속, 대칭) → 지속 쪽 1 ATR 먼저(P1 만) · 강세/약세 따로.
