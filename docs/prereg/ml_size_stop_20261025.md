# 사전 등록: 크기·손절 머신러닝 모델 vs 규칙(2배·변동성 + −5%) (2026-10-25)

사용자 2026-10-25: «크기와 손절을 규칙이 아니라 모델링을 해서 머신 러닝 모델로 만들어줘. 규칙은 AI 시대에 맞지 않아»
이 문서는 **결과를 보기 전에** 커밋한다. 사양·관문은 결과 뒤 바꾸지 않는다(바꾸면 «수정 n» 커밋 + 이유).

## 무엇을 배우나
- 방향은 사용자가 정한다. 시장 데이터로 배울 수 있는 것은 «이 진입이 앞으로 얼마나 거꾸로 흔들릴까»(위험)다.
- 모델: 진입 시각 t·방향 s 에서 **다음 24시간 최대 역행폭(MAE)** 의 90% 분위를 예측하는 LightGBM 분위 회귀(log MAE).
  - 24h = 실원장 보유 시간 93% 를 덮는 창(중앙 1.4h · 90% 16h · 95% 30h).
- 손절 ŝ = clip(k·q̂₉₀, 1%, 15%) — k 는 2025 보정 배수(2025 에서 24h 안 ŝ 를 넘는 비율 = 10%).
- 크기 L̂ = min(3, 0.10 / ŝ) — 손절을 맞으면 순자산 약 10% 를 잃게(규칙의 2배 × 5% 와 같은 예산). 규칙의 «변동성 배수»와 «고정 5%» 를 둘 다 모델이 대신한다.
