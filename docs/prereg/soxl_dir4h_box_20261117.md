## 3. 4시간 방향 (배포 `scripts/live_eth_dir4h_20261015.py` B2)
표적 `y_4h` = 봉 τ 종가 → τ+48 종가 로그수익(bp). 모형 = `d4.HGB`(결정적). 결정 = 5분봉 마감.
| 팔 | 학습 | 비고(레시피와 다른 점) |
|---|---|---|
| **E** | 배포 그대로: 매달 1일 ETH 모형(창 [m−4h−365일, m−4h), ETH 행 [::2]) → 그 달 SOXL 피쳐에 | 없음(그 달 배포 ETH 모형과 같은 적합) · 05~11월 7개 |
| **S** | SOXL 행 [05-22, 09-01−4h) [::2] 한 번 적합 → 09-01~ 예측 | **365일 굴림·매달 재학습 불가(이력 6개월)** → 학습 창 = 05-22~08-31 고정 1회, 재학습 없음 |
| **J** | ETH·BTC·SOL·XRP 각 [09-01−4h−365일, 09-01−4h) + SOXL 학습 창, 코인별 행 [::4], y ÷ 그 코인 학습 창 표준편차 → 한 번 적합 | 배포 XRP J 와 같은 쌓기 규약 · 매달 재학습 대신 09-01 고정 1회 |
- 문턱 = 그 팔 자신의 과거 표본 밖 예측 20/80 분위, 달 안 고정(배포 `thresholds()`). **예열만 8,640행(30일) → 2,016행(7일)** — S·J 표본 밖 기록이 09-01 에 시작해서(그래도 10월 문턱은 9월 전체로 만들어진다). E 는 05-15~ 기록이 있다.
- 팔 고르기 = 검증 스피어만 IC 최대.
- **주 판정**(원 연구 `research_btc_sol_xrp_dir4h_20261031` 그대로, 블록만 공통 규칙대로 달력일): 엄격 = IC 부트스트랩(1일 블록 2,000) 10분위 > 0 · IC > 원형 이동 위약 95분위(하루 단위 1~(일수−1)일 전부, ≈46개) · IC > 무작위 위약 95분위(200) · 적중 초과(문턱 밖 부호 적중 − 같은 롱·숏 구성 기저) 10분위 > 0. 후보 = IC > 0 · IC > 원형 90분위 · 적중 초과 > 0.
- 보조: 고르지 않은 팔 · 피어슨 · 5일 블록 판 · 모델 vs 늘 롱 · 늘 숏(신호당 bp) · 월별 IC · 세션별(`clock()` 정규장·프리장·애프터·야간·주말·휴장) IC·적중 · 구간별 상승 비율(기저율).
- 누수: 배포 `build_features` 재사용(행 τ = 봉 τ 종가, 결정 = 봉 τ 마감), 학습 라벨 끝 ≤ 검증 시작(selftest). 고른 팔 시험 IC > .08 이면 한 봉 밀기 트립와이어(같은 모형에 한 봉 묵힌 피쳐) IC 를 같이 적는다.
- 검정력(사전): 시험 47일 × 6 독립 4h ≈ 280 → IC 표준오차 ≈ .06. 참 IC .05 면 엄격 ① 통과 확률 ≈ 33%. **불통과 ≠ 정보 없음**일 수 있다. 4h 방향은 코인에서도 갈렸다(BTC 불통과).

## 4. 박스 유지 30분·1시간 (배포 `dashboard/box_hold.py` HGB · 라벨 `research_eth_range_hold_multiscale_20261016.build`)
라벨: 결정 = 5분봉 마감 분(5분마다), 박스 = 종가 ± ½×지난 W분 고저폭, 유지 = 다음 W분 1분 고가 < 상단 & 저가 > 하단. 특징 27칸(`X.LEAN`) = i 분 마감까지. 4h 척도는 과제 밖(코인 전부 보정 불통과).
| 팔 | 학습 | 비고 |
|---|---|---|
| **E** | 배포 ETH 모형 `dashboard/box_hold_hgb_20261016.joblib` 그대로(ETH 계절표) → SOXL 특징 | 재학습 없음 |
| **S** | SOXL 학습 행(라벨 끝 ≤ 09-01) · `X.hgb()` · 계절표 = SOXL 학습 구간 1분봉(레시피의 «2022~24» 자리) | |
| **J** | ETH 2022~24 행(배포 ETH 계절표) + SOXL 학습 행(SOXL 계절표), 무가중 합동 `X.hgb()` | 코인별 표준화 없음(분류 라벨 · 레시피 그대로) |
- 비교 G = 기하 로지스틱(`log_ds` 하나), SOXL 학습 행 적합.
- 팔 고르기 = 검증 로그손실 최소(순위·보정 둘 다 보는 한 숫자).
- **주 판정**(원 관문 그대로, CI 만 단측 90%): 시험 AUC ≥ .72 · 10분위 보정 최대 차 ≤ 6pp · ΔAUC(팔 − G) 1일 블록 부트스트랩(1,000) 10분위 > 0 → 엄격. 후보 = AUC ≥ .72 · 보정 ≤ 6pp · ΔAUC 점추정 > 0 (원 연구 후보 정의). 95% CI 도 같이 적는다.
- **기저율 흐름 점검**(11-12 레짐 교훈): 라벨은 «지난 W분 폭 대비 다음 W분»이라 30일 굴림 평소 폭에 기대지 않지만, 세션 전환(예: 프리장 끝 → 개장)에서 흐를 수 있다 → 월별·세션×구간 유지율과 고른 팔 평균 예측 vs 실현을 보고. 판정에는 안 쓴다.
- 보조: 고르지 않은 팔 · 세션별 AUC·보정 · 1h 가 통과(엄격 또는 후보)하면 **검증 9월로 한 번 맞춘 Platt** → 시험 ΔBrier(1일 블록 단측 90% 상한). 원 레시피의 굴림 Platt90 은 90일 창이 학습 구간과 겹쳐(S·J 는 표본 안) 이번엔 안 한다.
- 서머타임 공지: 11-01(미국 서머타임 끝) 뒤로 UTC 기준 계절표가 한 시간 어긋난다 — 레시피(UTC 요일×시각) 그대로 두고 세션별 표로만 본다.
- 누수: `X.leak_check`(결정 분 뒤 1분봉을 바꿔도 V·R·Q 불변) · L1(라벨을 `labels()` 독립 재구현으로 다시 계산해 100% 일치 아니면 멈춤) · 학습 라벨 끝 ≤ 09-01.
