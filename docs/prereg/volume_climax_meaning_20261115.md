# 사전등록: 거래량 클라이맥스(거래량 폭증 + 큰 봉) 뒤 반전이 맞는가 (2026-11-15)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_volume_climax_meaning_20261115.py`.
사용자 «다음 지표로» — 다음 검증 목록 12번.

## 왜
- 흔한 주장(와이코프 «셀링/바잉 클라이맥스»): 한 방향으로 달린 끝에 거래량이 폭증한 큰 봉이 나오면 소진 → 반전.
- 오늘 MACD 검정: 실제 가격엔 기본 이어짐(+0.5~1.4pp)이 있어 가짜 가격 대비만으론 지표 고유 몫을 못 가른다 → **같은 큰 봉인데 거래량 폭증이 없는 봉(P3)**과 비교해 «거래량이라서»인 몫을 본다.
- 이전 시행: 09 증거신호 «taker_delta_z_climax»(테이커 델타 z) 메타라벨 — 다른 정의. 11-14 매도자 소진 8검정 불통과(소진 뒤 오히려 더 내림).

## 정의 (사전 고정, 봉 마감에 알려짐)
- 15분봉·1시간봉 4코인(ETH·BTC·SOL·XRP), 1분봉 Vision **2022-01~2026-10-29**(거래량 열이 있는 마지막 날). ATR = 참범위 14봉 평균.
- 직전 흐름 = sign(c[t] − c[t−12]). **큰 봉** = 봉 t 고저폭 ≥ 2 × ATR[t−1]. **거래량 폭증** = 거래량[t] ≥ 3 × 직전 96봉 거래량 중앙값.
- **C1 클라이맥스** = 큰 봉 + 거래량 폭증. 주장 = 직전 흐름 반대(반전).
- **C2 꼬리 클라이맥스** = C1 + 종가가 봉 범위의 반전 쪽 절반에 마감(하락 뒤면 종가가 봉 중간 위).
- 측정 = 봉 t 종가 기준 100봉 안 반전 쪽 1 ATR 이 반대 1 ATR 보다 먼저(`first_hit_race`, 같은 봉 동시 = 불리).

## 대조
- **P1** 기하 위약 20벌(같은 함수·시드 · 거래량은 그 분에 그대로 붙음).
- **P3 거래량 없는 같은 모양(실제 가격)**: C1 ↔ 큰 봉 + 거래량 < 1.5 × 중앙값 · C2 ↔ 그 가운데 같은 꼬리 조건 · 방향 규칙 같음.

## 주 판정 (사전 고정)
칸 = {C1, C2} × {15분, 1시간} = **4칸**, Holm(α .10). «맞음» = 실제 − P1 단측 90% 하한 > 0 · **실제 − P3 단측 90% 하한 > 0** · 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호. 통과 후보 = 점추정 > 0 + 코인·구간. 부호 뒤집어 넘으면 «거꾸로»(= 클라이맥스 뒤 이어짐).
