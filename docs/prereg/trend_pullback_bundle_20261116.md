# 사전등록: 묶음 6 — 추세 속 눌림 3종 (EMA20 터치 · 스토캐스틱 눌림 · 홀리 그레일) (2026-11-16)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_trend_pullback_bundle_20261116.py`.
사용자 «다음 지표로».

## 왜
- 오늘 «되돌림» 주장 가운데 유일하게 9코인에서 맞은 것 = RSI(2) **추세 쪽 짧은 눌림**(A16, `docs/experiments/connors_aroon_soup_bundle_20261116.md`). 극단 되돌림(볼린저·스토캐스틱 70/30·MFI·터틀 수프)은 전부 «이어짐» 쪽. → 같은 «추세 속 눌림» 가족의 대표 규칙 셋을 잰다.
- 오늘 교훈: 4코인 1라운드 통과가 새 코인에서 두 번 무너짐 → **4코인과 새 코인 5종을 같은 사전등록에서 둘 다** 통과해야 «맞음»(ORB 3라운드와 같은 방식).
- P3 는 «같은 추세 쪽 아무 봉» — «눌림이라서» 몫만 본다(A16 과 같은 설계). 홀리 그레일은 «ADX 가 강해서» 몫을 보려고 같은 터치의 ADX ≤ 30 판을 P3 로.

## 공통
- 15분봉·1시간봉(4시간 보조). 그룹 «orig» = BTC·ETH·SOL·XRP 1분 Vision 2022-01~2026-11 · «new» = ADA·AVAX·BNB·DOGE·LINK 5분 CSV 2022-01~2026-08-26(5분 → 15분·1시간 다 찬 봉, 앞 2라운드들과 같은 묶음).
- 측정 = 사건 봉 t 종가 기준 100봉 안 주장 쪽 1 ATR 먼저(`first_hit_race`, 같은 봉 동시·미결 = 불리). P1 = 로그수익 부호 뒤집기 20벌(orig 1분 · new 5분, 시드 SEED+12000+1000·코인+벌 / orig 은 SEED+1000·코인+벌).

## 지표
| 키 | 지표 | 사건·주장 | P3 (실제 가격) |
|---|---|---|---|
| H1 | EMA20 첫 터치 눌림 | EMA20 > EMA50 이고 직전 봉 저가 > EMA20 · 이번 봉 저가 ≤ EMA20 < 종가 → 위 · 대칭 아래 | 표본 봉(15분 4봉마다·1시간 모든 봉) EMA20 vs EMA50 쪽 |
| H2 | 스토캐스틱 추세 눌림 (Raschke) | 종가 > SMA200 이고 %K(14,3) 가 20 위로 넘음 → 위 · 종가 < SMA200 이고 %K 가 80 아래로 → 아래 | 표본 봉 중 %K 30~70 · SMA200 쪽 |
| H3 | 홀리 그레일 (Raschke) | ADX(14) > 30 · 방향 = sign(+DI − −DI) · 그 쪽 EMA20 첫 터치(H1 과 같은 터치 식, EMA50 조건 없음) → 방향 쪽 | 같은 터치인데 ADX ≤ 30 |

## 주 판정 (사전 고정)
그룹마다 칸 = 3 × {15분, 1시간} = 6칸, **Holm(α .10) 지표별 2칸.** 칸마다 «맞음» = 실제 − P1 단측 90% 하한 > 0 · 실제 − P3 하한 > 0 · 코인 ≥ 3/4(orig)·≥ 4/5(new) · 두 구간(2025-01-01 앞뒤) 같은 부호.
**최종 통과 = 같은 칸이 orig·new 둘 다 맞음.** 통과 후보 = 두 그룹 점추정 > 0 + 코인·구간. 둘 다 부호 뒤집어 넘으면 «거꾸로».
