# RL v11 — v10 보상 결함 수정(평균−분산 효용) · 굴림 2창 (2026-10-25, 채점 전 커밋)

## 왜
v10: 미분 샤프는 노출 크기에 불변 → 5시드 모두 상수 m=.5 로 붕괴. v11 은 크기에 민감한 효용으로 바꾼다:
보상 = x − (λ/2)·x², x = (m·r − 비용)/σ_1h (걸음 정규화 순손익). λ = 학습 구간 mean(r/σ_1h) / mean((r/σ_1h)²) — **상수 노출 중 최적이 m=1(보유)** 이 되도록 학습 구간에서만 정함. 그러면 «상수 줄이기»로는 이득이 없고, 상태에 따라 줄일 때만 보상이 오른다(Markowitz 효용 · Kolm·Ritter 2019 «Dynamic Replication and Hedging: A Reinforcement Learning Approach» 의 평균−분산 보상 꼴).
- 학습 구간 평균 수익이 음수면 λ ≤ 0 이 되어 정의가 깨진다 → 그 경우 λ = 1/mean((r/σ_1h)²)·0.01(작은 위험 회피)로 대체하고 보고.

## 기준선
보유(m=1) · **VT**(m = {0,.5,1} 중 min(1, σ_목표/σ̂) 에 가장 가까운 값, σ_목표 = 그 창 학습 구간 σ̂ 중앙값).

## 판정(두 창 시험 일 수익 이어 붙여, 각 1회)
- **G1(주)**: R − 보유 샤프 차 > 0 그리고 5일 블록 부트스트랩 4,000회 95% CI 하한 > 0.
- **G2(RL 몫)**: R − VT 샤프 차 > 0(점추정) — RL 이 단순 규칙보다 나은가.
- **G3(시드)**: 창마다 시드별 R − 보유 샤프 > 0 이 검증·시험 모두인 시드 ≥ 4/5 를 두 창 모두.
- 통과 = G1 ∧ G2 ∧ G3 → «후보». 불통과면 RL 노출 줄이기 축 닫음.
- 보고: 학습된 m 이 상태 분위별로 달라지는가(붕괴 점검) · MDD · 평균 노출 · VT − 보유(참고).
