## Iteration Compact
- Goal: v1~v5 실패가 «데이터에 우위가 없어서»인지 «RL 장치가 못 배워서»인지 가른다. 장치가 못 배우면 합성 세계에서만 고치고(실데이터 과적합 위험 0), 고친 장치를 실데이터에 1회 적용한다.
- 결정: 다음 RL 실데이터 시험을 할지·어떤 장치로 할지.
- Baseline: 교사(추세 규칙 D) · 오라클 규칙(심은 신호 부호를 그대로 따름).
- Unacceptable: 심은 신호가 0인데 RL 이 «배웠다»고 나옴(환각) · 신호가 커도 못 배움(장치 고장).

## 심은 신호 세계(합성)
- 관측 피쳐 13개 중 «D(추세 부호)» 열을 심은 신호로 바꾼다(교사는 원래 D 그대로 따로 계산 · 피쳐 수·구조 불변): s_d = ρ·z_d + √(1−ρ²)·ε_d, z_d = ln(c_d / c_{d−1}) / (σ_d/√365) (그날 실제 종가 대 종가 수익 표준화, ±5 절단), ε ~ N(0,1) 세계마다 고정 시드. **즉 s_d 는 결정일 d 의 수익을 미리 알려 주는 «정답 힌트»**(일 IC ≈ ρ).
- ρ ∈ {0, 0.03, 0.06, 0.12}. 참고: 실제 피쳐의 방향 정보는 손익분기의 40~65%(rl_info_ceiling).
- 학습: W3 학습 구간 30세계(2024-01~2025-12) · 평가: 4코인 2022-06-01~2023-12-31(학습에 없는 기간, 같은 방식으로 신호 심음). 실데이터 시험 기간(2026)은 쓰지 않는다.
- 학습 레시피 = v3.1(TCN · 3행동 · BC 교사 · PPO 초모수 · 30만 걸음 · 5만 저장). 보상 {Z, DD} · ρ마다 시드 3개(secrets): 331161 · 783382 · 713244 (Z) / 835240 · 832343 · 218323 (DD) → 4 × 2 × 3 = 24학습.
- 기준: 교사 · 오라클(매일 sign(s_d) 방향, 같은 실행기) 평가 샤프.

## 판정(장치 검증)
- **L1 배움**: ρ = 0.12 · Z 에서 30만 걸음 평가 샤프 향상(RL − 교사)이 (오라클 − 교사)의 50% 이상인 시드가 3 중 2 이상.
- **L2 환각 없음**: ρ = 0 · Z 에서 30만 걸음 평가 샤프가 교사 + 0.3 이하인 시드 3 중 2 이상.
- **L3 보상 영향**: 같은 ρ 에서 DD 의 향상이 Z 보다 작으면(쉬기 퇴화) F1 확인.
- 보고: ρ별 학습 곡선(체크포인트 0~30만) · 오라클 부호 일치율 · 현금 비율 · 롱 비율.
- L1 실패 → 장치 수정(가치 머리 사전학습 · γ · 학습률 · 걸음 수)을 **합성 세계에서만** 반복. L1·L2 통과 → 실데이터는 «정보 상한이 손익분기 미달»이라 RL 로도 못 넘는다는 결론이 장치 문제와 분리되어 확정.
