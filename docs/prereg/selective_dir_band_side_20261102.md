## 질문
- **A**: 기존 방향 예측(15분·1시간·4시간)의 평균 IC는 .03~.06으로 작다. **확신 상위 일부에서만 말하고 나머지는 보류**하면 그 부분의 적중률이 «항상 한쪽» 기준을 넘는가?
- **C**: 4h 라벨 «띠 이탈»에서 이탈 방향은 동전이었다(가격 경로 E2). 짧은 지평(1h)에서 **띠 안 / 위로 이탈 / 아래로 이탈** 3분류를 하면, 이탈이 일어날 때 방향(위·아래)을 **가까운 가장자리가 먼저 뚫린다는 기하**보다 더 잘 맞히는가?

## 왜 (과거 실패 교훈 반영)
- 방향축은 «항상 예측» 형태로 전부 닫혔다(45/45 음수, 모델은 비용 전 IC .06). **«보류»를 허용한 평가는 아직 없다** — 이것이 새 점. 불통과면 방향은 선택적 예측까지 포함해 닫는다.
- **적중률은 반드시 «그 부분의 다수 방향(롱/숏 상수)» 대비 초과로 본다**(모델−롱·모델−숏 규칙). 하락 국면에서 숏 편향이 적중률을 만드는 것을 막는다.
- 신뢰도 문턱을 검증에서 고르지 않는다: **최근 30일 |예측| 백분위(과거만)**로 고정 q (튜닝 자유도 0).
- 15분·1시간 예측은 «연구 시험 창(2026-06~)에서 고른 팔»이라 승자의 저주가 있다(방향 메모 10-28). **A의 청정 판정은 4시간**(2023-01부터 걸어가며 만든 표본 밖 예측, 검증·2025 확인 가능). 1시간은 같은 규칙의 보조 판정.
- C: 거리만 쓴 기준선이 경고 모델의 거의 전부였던 교훈 → 기준선 G(기하만)를 이기는 증분만 인정. 이탈 방향 동전 전력 → 불통과를 기본 예상으로 사전 인정.
- 구간 재사용 공개: 시험 2026-06~10-23은 이 세션의 띠 이탈·경고·XRP 저거래량·크기 연구와 방향 모델 선정이 모두 사용. 4코인 5분 패널 재사용 다수(이 연구의 라벨·규칙은 새것).

## A 규칙 (모두 고정)
- 코인별 매시 결정마다 신뢰도 u = 직전 최대 30일(최소 7일, 같은 코인·같은 예측 열)의 |예측| 중 현재 |예측|의 백분위(현재 제외).
- **q = 10%**: u ≥ 90% 일 때만 sign(예측)을 발화, 아니면 보류. (보조: q = 5·20·50·100%.)
- 적중 = sign(예측) = sign(수익). 기준 = 발화 부분의 다수 방향 비율 max(상승률, 하락률). **초과 E = 적중률 − 기준.**
- 일 단위 블록 부트스트랩 2,000회(코인 풀링, 같은 날은 한 블록).

## 주 판정 (3개, 전부 단측 90%, Holm m=3: 부트스트랩 p 오름차순 .033/.05/.10)
1. **A-4h** (ETH·SOL·XRP 풀링, 시험): E 의 p = P(E ≤ 0) 가 Holm 문턱 이하, **그리고** 원형 이동 위약(예측을 1~(일수−1)일 밀어 같은 규칙 재적용 200개)의 E 95분위 초과.
2. **A-1h** (4코인 풀링, 시험): 같은 기준. (승자의 저주 주석 달고 보고.)
3. **C-1h** (4코인 풀링, 시험): 이탈이 일어난 행에서 «위로 이탈» 대 «아래로 이탈» 점수 s = P(위)/(P(위)+P(아래))의 AUC 에 대해 **ΔAUC = AUC(M) − AUC(G)** 의 p = P(ΔAUC ≤ 0) 가 Holm 문턱 이하, **그리고** 일 이동 위약(점수를 코인별로 1~(일수−1)일 밀기 200개)의 ΔAUC 95분위 초과.
- 일관성(통과 조건 아님, 보고): A-4h 검증·2025 에서도 E 점추정 > 0 인가 / C 검증 ΔAUC 부호.
- **통과 후보**(엄격 미달 시): 점추정 E > 0 이고 q=10% 적중률 ≥ 55%이며 위약 90분위 초과 / ΔAUC > 0 이고 위약 90분위 초과.
- 분모: 발화 건수·날짜 수·코인별 `적중/건수`를 같이 적는다. 시험 전체 하루당 발화 수도.

## C 모델·기준선 (고정)
