## 무엇을 재나 (용도 정확도)
지지·저항 레벨의 용도는 **«실제 청산이 어디서 터지나»를 짚는 것**이다(09-20 검증: 레벨 ±15bp 분의 청산 확률 0.52 vs 먼 곳 0.28 ·
방향 정보는 없음). 그래서 방향·반등이 아니라 **위치 적중**으로 비교한다.

## 팔 (화면에 보이는 그대로 재현)
결정 시각 τ = 매 5분 경계. 지금가 `cur` = τ 직전에 닫힌 5분봉 종가. 쪽마다 최대 3개(화면과 같음).
- **A0 = 1시간 · 옛 화면**: `hour = floor_hour(τ)`. 레벨 = `compute_spliced_levels(시작 < hour 인 1시간봉 24개, cp = 그 마지막 1시간봉 종가, 5분봉 < hour)`
  (서버 `load_liquidation_map` 와 같음). 화면 필터: `[hour, τ)` 의 닫힌 5분봉이 지난 레벨은 버림(`liqSweepIdx`) · `cur` 의 올바른 쪽만 · 가까운 순 3개.
- **A1 = 1시간 · 지금 화면(11-09 8f80381d)**: A0 + 안 쓸린 레벨이 3개 미만이면 `heatmap_bins` 에서 채움(안 쓸림 · 무게 ≥ 0.05 · `cur` ±5% · 무게 순(같으면 가까운 순) → 가까운 순).
- **B = 5분 재계산**: 레벨 = `compute_spliced_levels(_window_at(1h, 5m, τ, 24), cp = cur, _m5_until(5m, τ))`
  (밀도 이력 5분 열과 같은 창 · 부분봉 포함). 지도가 τ 까지 알므로 쓸림 필터 없음. `cur` 쪽 · 가까운 순 3개.
- 자체점검: 정시 τ 에서 A0 = A1 = B(부분봉 없음·cp 같음) 여야 한다.

## 지표 (분모·건수)
τ 마다, (τ, τ+H] 바이낸스 청산 $ 중 표시 레벨 중 하나의 ±15bp 안에서 터진 몫 `C = 잡힌 $ / 전체 $`. 청산 0건 τ 는 뺀다(건수 보고).
- **위약 P**: 같은 레벨들을 +40bp·−40bp 옮긴 두 판의 C 평균(09-20 «레벨 40bp 옮기기» — 거리·움직임 맥락 보존). **초과 E = C − P** = «그 자리라서» 잡은 몫.
- 날 평균: τ 별 값 → 달력일 평균(UTC) → 날 평균. 부트스트랩 = 달력일 블록 2,000회.

## 주 판정 (사전에 고정, H = 60분, ETH)
1. **엄격 통과**: `ΔE = E_B − E_A1` 날 평균의 단측 90% 하한 > 0 — 5분 재계산이 지금 화면보다 «위치 정보»를 더 준다.
2. **통과 후보**: 엄격은 못 넘고 `ΔC = C_B − C_A1` 단측 90% 하한 > 0 — 잡는 청산은 늘지만 가까워서일 수 있음(거리 효과와 구분 못 함).
- 그 밖은 불통과(5분 재계산 이득 없음 → 지금 1시간 + 채우기 유지).
- 대조 표기: 각 팔의 C·P·E · 표시 레벨 수 평균(쪽별) · `cur` 까지 거리 중앙(bp) · 청산 있는 τ 수·건수·$.
