## 데이터·시각 규약
- Binance USDT 선물 ETHUSDT aggTrades 1초 묶음(2024-01-01 ~ 2026-11-15). 1분봉은 이 묶음에서 만든다.
- **사건**: 분 i 에서 ① 돌파 = 고가(저가)가 직전 look 분 고점(저점) L 을 넘음 ② 접근 = L 의 0.1σ1h 안으로 들어옴. look ∈ {60, 240, 1440}. 각 (look, 종류, 쪽)에서 직전 60분에 같은 사건 없음. L·σ1h 는 분 i 이전 분봉만. 사건 초 a = 그 분에서 문턱을 처음 넘은 초.
- **결정** d = a + 5초. **피쳐** = 초 ≤ d 의 체결 + 분 < i 의 분봉(크기 49 + 부호 38). 기준가 P = d 까지 마지막 체결가(ETH 틱 0.01 ≈ 0.03bp 라 체결가 튐은 배리어 9bp 에 견줘 무시). **라벨** = d+1 초부터.
- **주 라벨 `y_fp15_900`**: 900초 안에 P·e^{±0.15σ1h} 중 사건 쪽을 먼저 닿으면 1, 반대쪽 먼저면 0, 둘 다 못 닿으면 900초 수익의 부호(정확히 0 은 제외). 보조 라벨: 300초 ±0.10σ · 3600초 ±0.25σ.
- 같은 순간이 여러 사건(예: 4시간 접근이자 1시간 돌파)으로 들어갈 수 있다 → 부트스트랩은 달력일 블록.

## 주 판정 — 예측 등급 (시험 구간 · 주 라벨 · 달력일 블록 부트스트랩 2,000회 · 시드 20261118)
1. **방향**: 전체 사건에서 점수의 AUC 단측 90% 하한 > 0.5, 그리고 월 안 라벨 섞기 위약 1,000회의 95분위보다 큼.
2. **집단 차**: 점수가 학습 교차 예측 90분위 이상인 사건과 10분위 이하인 사건의 «사건 쪽 먼저» 비율 차 단측 90% 하한 > 0.
- **통과** = 1·2. **통과 후보** = 검증·시험 모두에서 점 추정이 1(AUC > .5)·2(차 > 0).
- **따로 판정해 같이 보고(통과 조건 아님) — «부호 재료 고유 몫»**: 3. AUC(전체) − AUC(크기만) 단측 90% 하한 > 0 · 4. «월 × 크기만 점수 5분위» 층 안 위약 95분위보다 큼. 그리고 체결 매수 비중 몫 = AUC(크기+체결 매수 비중) − AUC(크기만).
  - 이유: 라벨이 전체 사건에서 정해지므로 1·2 는 «어느 쪽이 먼저인지 동전보다 잘 안다»를 뜻한다(크기 상태로 아는 것도 포함). 3·4 는 그중 «부호 있는 재료가 보탠 몫»을 가른다. 둘을 섞어 말하지 않는다.
- 보고(분모·건수): 구간별 사건 수 · 10분위별 «사건 쪽 먼저» 비율과 평균 수익(bp) · 종류×거리별 AUC · 월별 · 위·아래 · 보조 라벨 같은 표 · 학습 날짜 재추출 10회 시험 AUC.
- 누수 신호: AUC > .60 이면 누수부터 의심.
