# 사전등록: SMC·ICT 지표 의미 검증 2라운드 — 다른 봉 지평 (2026-11-15)

**등급: 되돌리기 쉬운 예측(지표 의미) 검증 — 단측 90%** + 완화 «통과 후보» 병기. 1라운드 `docs/prereg/smc_ict_meaning_20261115.md`(b4a4755b)의 정의·측정·위약·판정을 **그대로** 쓰고 봉 지평만 바꾼다.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_smc_ict_meaning_20261115.py` (환경변수 `SMC_ROUND=2`).
사용자 «이게 지금 5분봉으로 해서 그런걸 수도 있어. 다른 지평으로도 테스트해줘.» — 1라운드 주 판정은 15분·1시간(4시간 보조)이었다. 이번엔 **5분 · 30분 · 4시간 · 1일**.

## 왜
- 1라운드 결론(맞음 5 = OB·FVG 버팀 · 거꾸로 2 · 나머지 위약과 같음)이 «짧은 봉이라 잡음이 많아서»인지 확인한다. SMC 는 흔히 4시간·일봉 구조를 «진짜»로 친다.
- **이미 본 것 공개**: 4시간은 1라운드 보조로 이미 봤다(FVG 버팀 +2.5pp·OB N5 +0.3pp·나머지 0 근처). 4시간 칸은 «재확인»이고 새 증거가 아니다. 5분·30분·1일은 처음.
- 정의·문턱·창(봉 수) 하나도 안 바꾼다 — 결과 보고 고르는 일을 막는다. 창은 봉 수 기준(터치 100봉·메움 50봉·스윕 100봉)이라 지평마다 같은 «봉 개수» 비교가 된다(1일 = 100일).

## 바뀌는 것 (이것뿐)
1. 봉 지평 {5분, 30분, 4시간, 1일}. 1분이 다 찬 봉만(사전 점검: 4코인 전 지평 100% 참).
2. **1일 봉엔 S8(전일 고저) 없음** — 전날 = 직전 봉 하나라 «그날 첫 터치»가 정의되지 않는다.
3. 부트스트랩 블록 = max(1 달력일, 24봉): 5분·15분·30분·1시간은 1일(1라운드와 같음), 4시간 = 4일, 1일 = 24일. 긴 봉에서 사건 결과가 여러 날에 걸쳐 겹치는 것을 일부 반영. (1일 봉 결과창 100일 > 블록 24일이라 1일 신뢰구간은 여전히 좁게 나올 수 있다 — 결과 문서에 적는다.)
4. 출력 `tmp/smc_ict_meaning_20261115_r2/`.

## 칸·판정
- 5분·30분·4시간 각 11칸 + 1일 10칸 = **43칸**, Holm(α .10) 은 43칸 전체에.
- «의미 맞음»·«통과 후보»·«거꾸로» 기준은 1라운드와 같다(실제−P1 단측 90% 하한 > 0 · P2 하한 > 0 · 코인 3/4·두 구간 같은 부호).
- 위약 P1 20벌·P2 정의 동일. 시드 규칙 동일(지평 분 수가 시드에 들어감).

## 지평 비교 요약 (보고 방식 사전 고정)
- 주장별로 5분·15분·30분·1시간·4시간·1일 여섯 지평의 실제−P1(pp)을 한 줄로 놓는다(15분·1시간은 1라운드 값).
- «지평 의존» = 1라운드에서 아니었던 주장이 이번 라운드 어느 지평에서 «맞음»이 되거나, 1라운드 «맞음»이 이번 지평에서 부호가 뒤집힌 경우. 그 밖은 «지평과 무관».
- 긴 지평일수록 사건 수가 적다(1일 N50 스윙은 코인당 몇 건) — 칸마다 건수를 같이 쓴다.
