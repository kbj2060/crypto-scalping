# 사전 등록: RL 2단계 — «우리 규칙으로 시작해 자기 전략을 만드는» 딥러닝 RL 에이전트 (2026-10-25)

사용자 2026-10-25: «수익이 가능하다면 이미 내가 그걸로 했겠지. 내가 바라는건 딥러닝 모델 강화학습 아키텍쳐가 처음엔 우리 규칙으로 시작했다가 학습할 수록 자신만의 매매 전략을 만들어서 매매하는거야.»
결과 전에 커밋한다. 1단계(rl_info_ceiling, bfd469ed)에서 방향 정보가 손익분기의 40~65% 라 통과 기대는 낮다 — 이 시험은 구조를 만들고 정직하게 잰다. 실주문 없음.

## 구조
1. **교사(우리 규칙)** = 복제 자동매매 변형 A(원장 학습 진입 로지스틱 + 청산 위험 함수 τ .065) + 규칙 B(2배·첫 1/3·물타기 2/3·첫 진입가 ∓5%), 1시간 결정으로 옮긴 것.
2. **학생(딥러닝 정책)** = MLP 정책·가치망(128-128, tanh), 관측 23차원 = 시장 16(rl_info_ceiling 과 같은 피쳐, 학습 구간 평균·표준편차로 정규화) + 포지션 7(방향 · 찬 비율 0/⅓/1 · 첫 진입가 대비 미실현 · 최대 이익 · 최대 손실 · log(1+보유 h) · 마지막 청산 뒤 h(상한 48)).
3. **행동 학습(BC)**: 학습 구간에서 교사가 낸 (관측, 행동)을 교차 엔트로피(클래스 역빈도 가중, 상한 20)로 학생에게 먼저 가르친다 → 0단계 정책 = 우리 규칙.
4. **강화학습(PPO, stable-baselines3)**: BC 가중치에서 시작해 보상 = 시간당 log 순자산 변화(수수료·펀딩 포함)로 미세조정 → 학습할수록 교사에서 벗어나 자기 전략으로 간다. 교사와의 행동 일치율을 체크포인트마다 기록.
   - lr 1e-4 · n_steps 4096 · batch 512 · epochs 5 · γ 0.995 · GAE 0.95 · clip 0.1 · 엔트로피 0.001 · 총 300만 걸음 · 에피소드 = 학습 구간 무작위 90일 창.
5. **고정 위험 가드(학습 불가)**: 계좌 명목 ≤ 순자산 2배 · 첫 진입가 ∓5% 손절(5분 고저) · 최대 보유 168h.

## 행동(이산 5) — 매 정시
0 그대로 · 1 롱(없으면 ⅓ 지정가, 숏이면 청산 후) · 2 숏(대칭) · 3 전부 청산(테이커) · 4 남은 ⅔ 추가(테이커).
지정가 = 결정 봉 종가, 다음 1시간 안 1bp 관통이면 메이커 0, 아니면 1시간 끝 종가 테이커 4bp. 청산·추가·손절 테이커 4bp. 실제 펀딩.
