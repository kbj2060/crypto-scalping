## 단계별 판정

### S0 오라클 상한 (모델 없음)
라벨 ER = |c_{i+H}−c_i| / Σ_{k=1..H}|c_{i+k}−c_{i+k−1}| (미래 4h). 오라클 게이트: ER < 학습 중앙값(코인 풀링) → R, 아니면 T. 비교 = max(항상 R, 항상 T)(같은 구간에서 더 좋은 쪽, 보수적).
**통과** = 전체 구간에서 (오라클 게이트 − 최선 고정) 결정당 순 bp: ① 평균 ≥ 2.0bp ② 일 블록 부트스트랩 95% 양측 CI 하한 > 0 ③ 위약(코인별 오라클 라벨 순환이동 ≥7일, 1,000회) 95분위 이상. 미통과 → **중단·보고**(모델 만들 가치 없음).

### S2 F 모델 (S0 통과 시)
- 라벨: y=1 추세 (ER ≥ 학습 상위 1/3 분위수) · y=0 횡보 (ER ≤ 학습 하위 1/3) · 중간 제외. 분위수는 학습 풀링.
- 피쳐(전부 봉 i 마감까지): 로그 변동성 RV12·RV48·RV288·RV2016(√Σr²)와 비 RV12/288·RV48/288·RV288/2016, 과거 ER48·ER288, 과거 분산비(12봉 수익 분산 ÷ 12×1봉 분산, 288봉), pos(24h 범위 내 위치), 로그(범위/가격) − 로그 RV288, 24h 고·저 후 경과 봉 수, 거래대금 12봉합/7일 평균, 테이커 불균형 12·48봉, 시간대 sin/cos, BTC 의 ER48·RV48/288(교차 시장, BTC 자신은 같은 값).
- 모델: M = HistGradientBoosting(max_depth 4, lr .05, 300회, l2 1.0, min_samples_leaf 200, early_stopping=False, 코인 풀링, random_state 0). 기준선(전부 학습 적합 후 같은 평가 구간): B0 기저율 · B1 지속(로지스틱: ER48·ER288) · B2 변동성 단독(로지스틱: RV 비 3개 + 로그 RV288) · B3 기하(로지스틱: B2 + pos·범위/RV·경과 봉).
- **통과**(단측 90%): 검증·시험 **각각** M 의 Brier − 최선 기준선(B1~B3 중 해당 구간에서 가장 낮은 Brier) 의 일 블록 부트스트랩 90% 단측 상한 < 0. 보고: AUC, Brier skill vs B0, 코인별.
- 미통과 → 중단·보고(F 불가, 박스 유지로 충분).

### S3 T 모델 (S2 통과 여부와 무관하게 보고; 판정은 통과 시에만 «전환 경보 가능»)
- 표적: flip = 1(과거 레짐 ≠ 미래 레짐) — 과거 레짐 = ER48(i) ≥ 학습 ER48 중앙값, 미래 레짐 = ER_fwd ≥ 학습 ER_fwd 중앙값.
- 모델: 같은 HGB·피쳐 + 현재 레짐 경과 길이. 기준선: 기저율 · 변동성 단독 로지스틱 · 지속(런 길이) 로지스틱. 경보 = 상위 10% 확률; 정밀도 vs 무작위 경보(같은 비율, 1,000회) 95분위 + 변동성 z 경보.
- **통과**(단측 90%): 검증·시험 각각 ΔBrier vs 최선 기준선 상한 < 0 이고 정밀도가 무작위 경보 95분위 이상.

### S4 쓰임 (S2 통과 시)
- 게이트: M 확률 p ≥ 0.5(학습 균형 라벨의 중립점) → T, 아니면 R. 비교 = max(항상 R, 항상 T)(같은 구간), B3 게이트(기하 로지스틱), 무작위 게이트(같은 비율, 1,000회).
- **통과**(양측 95%): 검증·시험 **각각** (M 게이트 − 최선 고정) 결정당 순 bp 의 일 블록 부트스트랩 95% CI 하한 > 0 이고 M 게이트 > B3 게이트 > 무작위 게이트 95분위. 통과 후보 = 총수익으로 같은 판정.
