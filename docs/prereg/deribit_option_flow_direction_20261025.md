# Deribit ETH 옵션 델타 가중 순매수 → ETH 4h 방향 (2026-10-25, 채점 전 커밋)

## 왜
- 사용자(10-25): «새 원천으로 진행». 방향 μ̂ 새 원천 3번 = 옵션 흐름.
- 문헌: Pan·Poteshman(2006) 개시 매수 풋/콜 비율 → 주식 수익 예측 · Alexander·Deng·Feng·Wan(arXiv 2109.02776, JFM) BTC 옵션: 델타 가중 순매수 압력이 변동성 쪽 예측은 뚜렷, 수익 쪽은 약함(거래량은 다음 기 수익 예측) · Amberdata(2023) Deribit 테이커 방향 표기가 늘 믿을 만하진 않다는 경고.
- 앞선 관련 시험: 10-01 헤지 흔적(옵션 고객 델타 → 1~15분 선물 흐름, 2026) 일관 양수 없음. **4h 가격 방향은 안 봤다.**
- 옵션은 2026 만(사용자 09-29 규칙). 09-30 파일(opt_trades_hist)은 09-30 상장 종목만 담아 1~8월 만기 종목이 빠짐(생존 편향) → 새로 받는다.

## 신호(고정)
- 체결 델타: 블랙-숄즈(r=0), 체결 iv·index_price·행사가·만기(만기일 08:00 UTC). 부호 = 테이커 방향(buy +1).
- 제외: 블록(block_trade_id 있음)·청산 체결. (블록은 보고만.)
- DNB(t) = Σ_{[t−4h, t)} 부호 × 델타 × amount(ETH). z(t) = DNB(t) / 직전 30일(180개 4h 칸) DNB 표준편차(인과).
- 결정 격자 = UTC 00·04·…·20시. 라벨 = log(close[t+4h]/close[t]), close[t] = t 직전 분 종가(피쳐 창 끝 = 라벨 시작 직전).
