## 왜 (과거 실패 교훈 반영)
- 호가 모양·다이버전스는 «이미 움직인 흔적»이라 예측 증분 0이었다 → 점프 검정은 **직전 변동성만 쓴 기준선 대비 증분**으로만 판정(변동성 자체가 점프 AUC .77을 이미 설명, 10-18).
- 청산맵 정보는 10-08에 «크기 증분 0·거리만 .68»로 이미 검정됨 → 이번엔 5분 봉·OI·테이커·롱숏비 증분만 새로 본다. 실측 청산 사건(로컬 31일)·옵션(DVOL 08-04 종료)은 **검정력 부족으로 이번 검정에서 제외**(사유 공개).
- 횡단면은 4h에서 반전 우세(7일 모멘텀 IC −.018)·DL IC .054·리지 .045 → 부호를 **음(반전)으로 사전 고정**, 적합 없는 단순 순위 피쳐만 쓴다(DL 재검정 아님).
- 약한 정확도 피쳐는 모델에 더하면 악화(10-20) → 이번 판정은 «표시해도 되나»이고 모델 편입 아님.
- «독립 표본 수부터»(10-28 매크로): 점프는 **사건이 일 단위 군집으로 15일 미만이면 판정 보류**를 사전 고정.
- 같은 구간 재사용 공개: T3 표본 밖 예측(2026-06-01~)은 10-28 적중 56%/55%로 이미 한 번 열람 · T2 시험 창 2026-06~은 xsec DL 시험과 겹침 · T1 2026-01~05는 변동성 경주에서 사용. 주 판정 7개 × .10 = 우연 통과 기대 0.7개.

## 데이터·시각 규약
- 데이터 = 개발 PC `data/` (서버 REST 금지). **5분봉 종료시각은 `close_time`(ms, UTC)으로 만든다**(`eth_5m_1year.csv`의 `timestamp`는 KST 시프트). 로컬 끝: ETH 5분봉 2026-08-23 11:55 UTC, 알트 2026-08-26 → **시험 창은 2026-06-01 ~ 2026-08-22.**
- 결정 시각 τ = 봉 τ 마감 직후. 피쳐는 τ 마감까지, 라벨은 close[τ] 기준 이후(경계 1봉 이상). 메트릭(OI·롱숏비)은 `create_time` = 버킷 종료라 τ 마감과 같은 행을 조인(한 봉 이내 미래참조 트립와이어: 피쳐를 1봉 앞으로 밀면 AUC가 올라가면 안 됨 — 스크립트가 확인).
- 겹치는 행이므로 모든 CI는 **UTC 달력일 블록 부트스트랩**(B=2000, seed 고정).

## 검정 T1 — 점프(급락) 위험 (ETH)
- 사건 Y = 이후 1시간(τ+1..τ+12 봉) 최저가가 close[τ] 대비 **학습 구간 최저가-낙폭 분포 98분위 이하**(문턱 bp 학습에서 고정).
- 기준선 B = 직전 1h·4h 범위/종가, 24h 실현변동성(로그), 시각 sin/cos. 확장 B+X, X = 1h·4h OI 변화율, 상위트레이더 롱숏비 z, 테이커 매수비 z(1h), 24h 수익률, 거래량 비(1h/24h).
- 모델 = 표준화 로지스틱(L2), C ∈ {0.01, 0.1, 1} 검증 로그손실로 고름(B·B+X 각각).
- **주 판정 1(P1): 시험 ΔAUC(B+X − B) 단측 90% 하한 > 0 AND 시험 로그손실 개선.** 사건이 있는 시험 일수 < 15면 판정 «보류(검정력)»로 사전 고정하고 숫자는 보고만.
- 대조: 같은 B+X를 학습 구간에서 일 단위로 섞은 X(위약 200회) 95분위 위, X를 하루 뒤로 민 지연 위약.

## 검정 T2 — 횡단면 상대 강도 (ETH·BTC·SOL·XRP·ADA·AVAX·BNB·DOGE·LINK, 9코인)
- 4h 격자(UTC 0·4·8…) 결정 τ, 라벨 = close[τ]→close[τ+48봉] 수익의 횡단면 평균 차. 피쳐 = 과거 4h·24h·72h·168h 수익의 횡단면 평균 차(순위).
- 지표 = 시점별 Spearman IC 평균. **사전 가설: 4개 모두 음(반전).**
- **주 판정 4개(P2~P5, Holm): 시험 IC 평균 단측 90% 상한 < 0 AND 학습·검증 평균 IC도 음.** 코인 9개라 IC 잡음이 크다는 점 공개.
- 보조(판정 안 씀): 롱숏 상하위 3 비용 전 평균 bp/4h, 회전율, 기저 대비 — 비용 후 손익분기는 보고만(회전 비용이 DL 때 막혔음). 생존편향(현재 상장 9코인) 공개.

## 검정 T3 — 방향 예측 적중 (ETH 15분·1시간, 표본 밖 예측 41,760봉 중 시험 구간)
- 입력 `data/live/eth_dirshort_oos_seed.parquet`(p15m, p1h; 5시드 표본 밖 예측) · 라벨 = close[τ]→close[τ+3 / +12봉] 부호.
- **문턱 = 과거 확장 20/80 분위(해당 시점까지 예측만, 최소 14일 예열)** — 배포의 표본 전체 분위가 아니라 인과 문턱으로 다시 잰다.
- 상위 20% → «오름», 하위 20% → «내림». 초과 적중 = 해당 방향 적중률 − 그 방향 상시 적중률(기저). 상·하 버킷 평균.
- **주 판정 2개(P6 15분, P7 1시간): 초과 적중 단측 90% 하한 > 0.** 둘 다 모델−롱·모델−숏 따로 보고(롱 기저·숏 기저 각각).
- 건수·분모 `a/b` 병기. 참고: 10-28 열람치 56%/55%(표본 전체 분위·문턱 안쪽 51~52%).
