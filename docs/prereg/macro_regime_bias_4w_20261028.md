## B. 4주 편향 모델 (주)
- 선정(적합 구간, 지표마다): corr(x_i,τ, y_τ) 의 |r| ≥ 0.10 **그리고** 2020–21·2022–23 두 반쪽이 같은 부호.
- 예보: 지표마다 적합 구간 OLS y = a_i + b_i·x_i(고정) → ŷ_i,τ. 결합 ŷ_τ = 그 시각 값이 있는 선정 지표 ŷ_i 의 평균(1/N). 선정 0개면 모델 없음(불통과).
- 방향 = sign(ŷ_τ). 확률 = 적합 구간 로지스틱 P(y>0) ~ ŷ (고정).
- 주 판정(ETH · 4주 · 고정 채점, **넷 다** 만족):
  1. Clark–West(2007) 조정 MSPE 통계(대 **확장 과거평균** — 그 시각까지 적합 시작 이후 실현 y 의 평균, 라벨 끝이 τ 이전인 것만) ≥ **1.282**, Newey–West 지연 3.
  2. R²_OS = 1 − Σ(y−ŷ)² / Σ(y−ȳ_확장)² > 0 (Campbell–Thompson 2008).
  3. 방향 적중률 − «늘 상승» 적중률 > 0, 8주 블록 부트스트랩 2,000회 단측 90% 하한 > 0.
  4. 위약: 결합 ŷ 시계열을 라벨에 대해 원형 이동(±8주 이내 제외) 1,000회 → 실제 R²_OS 가 위약 90분위 초과.
- 보조(판정에 안 씀, 보고만): BTC · 8·13주 · 27지표 전부 평균 · Brier 기술점수(대 확장 기저율) · 기준선 Z91(사양 `liq_dollar_netliq_rule_frozen_20261015.json` 을 주간 결정에 맞춰 k=0 부호·k=1.0) — 🔴Z91 은 2018~26 을 보고 고른 규칙이라 이 구간에서 유리하다 · 코인 자기 13주 모멘텀(Moskowitz·Ooi·Pedersen 2012) · 연도별 표.
- 시험(2026-06~): 같은 지표를 보고한다. 독립 4주 창 ≈4개라 판정력 없음 — R²_OS 부호와 적중률만 기록하고, 고정 채점과 부호가 반대면 «실패»로 본다.

## A. 현재 국면 모델
- 선정: corr(x_i,τ, c_τ) |r| ≥ 0.15 그리고 두 반쪽 같은 부호(적합 구간).
- 예보: 지표마다 OLS c = a_i + b_i·x_i(고정) → 결합 ĉ_τ = 평균(«매크로가 말하는 지금 13주 코인 변화»). 국면 = sign(ĉ_τ), 확률 = 적합 구간 로지스틱 P(c>0) ~ ĉ.
- 주 판정(ETH · 고정 채점, 둘 다): corr(ĉ, c) > 0 의 13주 블록 부트스트랩 단측 90% 하한 > 0 · 국면 적중률 − «늘 상승» > 0 (같은 부트스트랩 하한 > 0).
- 보조: BTC · R²_OS(대 확장 평균) · 다음 4주 실현 변동성이 국면별로 다른가.
- 마르코프 전환 확률은 이번엔 안 한다(모수 추가, 국면 구간 수가 적다) — ponytail: 1차 결과가 통과하면 다음 라운드.
