# 사전등록: ADX 가 «추세 구간 / 횡보 구간»을 가르는가 (2026-11-15)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_adx_meaning_20261115.py`.
사용자 «다음 지표로» — 다음 검증 목록 14번(ADX).

## 왜
- 흔한 주장(와일더 1978): ADX ≥ 25 = 추세가 강해 이어진다 · ADX ≤ 20 = 횡보라 되돈다. 쓰는 법은 «조건 거르개»(추세장에선 추세 추종, 횡보장에선 역추세).
- 오늘 MACD 검정 교훈: 실제 가격엔 기본 이어짐이 있다 → **ADX 조건 없이 같은 방향 규칙을 모든 봉에 쓴 대조(P3)** 와 비교해 «ADX 로 골라서» 생기는 몫만 본다.
- 이전 시행: 11-10 «횡보 vs 추세 판별»(앞 4h 횡보 81.7% 통과 후보 · 추세 판정 62% 한계) · 11-15 추세 거르개 묶음(유의 0). ADX 단독은 미검정.

## 정의 (봉 마감에 알려짐)
- 15분봉·1시간봉 4코인(ETH·BTC·SOL·XRP), 1분봉 Vision 2022-01~2026-11-13. ADX(14) 와일더: +DM/−DM·TR 의 RMA(1/14) → +DI/−DI → DX → ADX = DX 의 RMA(1/14). ATR = 참범위 14봉 평균(경주용).
- 방향 = sign(+DI − −DI).
- **A1 추세 구간**: ADX ≥ 25 인 봉 → 주장 = 방향 쪽(추세 추종).
- **A2 횡보 구간**: ADX ≤ 20 인 봉 → 주장 = 방향 반대(역추세).
- 측정 = 봉 t 종가 기준 100봉 안 주장 쪽 1 ATR 이 반대 1 ATR 보다 먼저(`first_hit_race`, 같은 봉 동시 = 불리).
- 표본: 15분은 4봉마다 한 봉(겹침·계산량), 1시간은 모든 봉. 대조도 같은 표본 봉.

## 대조
- **P1** 기하 위약 20벌(같은 함수·시드) — 같은 규칙.
- **P3 조건 없는 같은 규칙(실제 가격)**: A1 ↔ 모든 표본 봉에서 방향 쪽 · A2 ↔ 모든 표본 봉에서 방향 반대. «ADX 로 골라서» 생기는 몫 = 실제 − P3.

## 주 판정 (사전 고정)
칸 = {A1, A2} × {15분, 1시간} = **4칸**, Holm(α .10). «맞음» = 실제 − P1 단측 90% 하한 > 0 · **실제 − P3 단측 90% 하한 > 0** · 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호. 통과 후보 = 점추정 > 0 + 코인·구간. 부호 뒤집어 넘으면 «거꾸로».

## 보조 (판정 안 씀)
ADX ≥ 40 · ADX 오르는 중만 · 2 ATR 판 · 4시간.
