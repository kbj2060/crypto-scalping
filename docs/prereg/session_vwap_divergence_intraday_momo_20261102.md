## 데이터·시각 규약
- 원천: 서버 `data/live/dirshort_panel/{ETH,BTC,SOL,XRP}USDT.parquet` (바이낸스 vision 5분봉, timestamp = 봉 시작, 시가 = 직전 종가). 사용 열: `timestamp, high, low, close, volume, taker_buy_base`. 열 부재·5분 구멍이 있으면 assert 로 중단(조용히 메우지 않는다).
- 결정 시각 τ = 봉 t 마감. 피쳐는 봉 t 까지만(미래 봉 없음). **체결 = 봉 t+1 시가 = c_t** (이 저장소 시장가 규약), 청산 = 봉 t+6 종가 c_{t+6}(보유 6봉 = 30분). 피쳐 창 끝 = t, 라벨 시작 가격 = c_t, 수익률은 c_t 이후 봉만 쓴다(경계 위반 없음 — 같은 봉의 수익률을 피쳐와 라벨이 공유하지 않는다).
- 세션 = `dashboard/market_ctx.py::market_session` (아시아 09:00 JST · 런던 08:00 · 뉴욕 09:30, 서머타임 반영, 다음 세션이 열리면 넘어감). 세션 VWAP·σ = `session_vwap`(대표가 (고+저+종)/3, 거래량 가중 표준편차, 봉 t 까지).
- 지표 정의(전부 이 문서에서 고정):
  - **H1 세션 VWAP 거리**: z_t = (c_t − VW_t) / VSD_t. 세션 시작 후 12봉(1시간) 미만이면 무효, VSD ≤ 0 이면 무효.
  - **H2 다이버전스**: 창 W = 6봉. Δp = c_t / c_{t−6} − 1 · 델타 d = 2·taker_buy_base − volume(기준자산 수량) · ι = Σd / Σvolume (창 6봉, ∈[−1,1]) · σ_ι = ι 의 직전 288봉(24h, 봉 t 포함) 표준편차 · R = 창 6봉 (최고 고가 − 최저 저가) / c_{t−6}.
    다이버전스 발동 = sign(Δp) ≠ sign(ι) ∧ |ι| ≥ σ_ι ∧ |Δp| ≥ 0.25·R. (σ_ι 는 288봉이 차야 유효.)
    대조군 «정상 정렬» = sign(Δp) = sign(ι) ∧ |ι| ≥ σ_ι ∧ |Δp| ≥ 0.25·R.
  - **H3 세션 모멘텀**: 세션 s 의 첫 30분 수익 F = c[s+5] / c[s−1] − 1(첫 6봉, s−1 = 직전 봉 종가) · 세션 길이 ≥ 24봉(2시간)인 세션만 · 거래 = 세션 마지막 6봉(진입 c[e−6], 청산 c[e], e = 세션 마지막 봉). 세션 길이·종료 시각은 일정표로 사전에 알려진다.

## 방향·보유 (가설마다 사전 고정)
| 가설 | 발동 | 방향(사전 고정) | 보유 |
|---|---|---|---|
| H1 | \|z\| ≥ 2 | **VWAP 쪽으로 되돌림**: z>0 숏 · z<0 롱 | 6봉 |
| H2 | 다이버전스 발동 | **가격 방향 지속**(흡수 해석): Δp>0 롱 · Δp<0 숏 | 6봉 |
| H3 | 세션 | **첫 30분 방향 지속**: F>0 롱 · F<0 숏 | 마지막 6봉 |
- 결과가 **반대 부호로 유의**하면 «반대 방향 발견»으로 보고하되 판정은 불통과다. 반대 방향 거래는 **새 사전등록**이 필요하다(결과를 보고 방향을 뒤집어 통과시키지 않는다).
- 겹침 제거: H1·H2 는 코인마다 한 번 발동하면 이후 5봉(30분 보유가 끝날 때까지) 발동을 버린다(탐욕적, 시간순). H3 는 세션당 1건.

## 비용
- **엄격**: 시장가 진입 + 시장가 청산, 편도 테이커 5bp → **왕복 10bp**(우대·프로모션 가정 금지). 펀딩 무시(30분 보유, 보고서에 명시).
- **통과 후보(완화)**: 왕복 5bp (진입 메이커 0 · 청산 테이커 5). 지정가 체결 모델이 없어 **낙관적**이다 — 통과 후보 등급은 이 가정 아래서만 읽는다.

## 주 판정 (가설마다 시험 구간, 전부 만족)
1. **엄격 비용 반영 평균 수익 > 0** 이고 4코인 풀링 사건에 대해, 달력일(UTC 날짜) 군집 부트스트랩 2,000회 **양측 95% CI 하한 > 0**.
2. **원형 밀기 위약**: 발동 신호 배열만 288봉의 정수배(1~30일)로 무작위 밀고(가격은 그대로, 코인 간 같은 밀기), 같은 판정 구간·같은 겹침 제거로 평균을 다시 구해 200회 분포의 **95분위 초과**.
3. **다리별 대조(모델−롱 · 모델−숏)**: 롱 다리 평균 수익 − 같은 구간 모든 봉의 6봉 무조건 평균 수익 > 0, 숏 다리 평균(−r6) − 같은 구간 무조건 평균(−r6) > 0 — 둘 다 만족(잔존 베타 배제).
4. **방향 일관성**: 검증 구간에서 통과 후보 비용 평균 > 0, 시험에서 총 수익(비용 전) 평균이 > 0 인 코인 ≥ 3/4.
- 가설 3개의 단측 p(부트스트랩 평균 ≤ 0 비율)에 **Holm 보정**(α = 0.05)을 적용하고, 보정 후에도 기각되어야 «통과». 보정 전 숫자도 같이 낸다.
- 지표는 분모·건수(`a/b`)·bp 단위로 보고한다. 평균은 «상위 3일 제외 평균»을 같이 낸다.

**통과 후보(완화)**: 통과 후보 비용(왕복 5bp)으로 검증·시험 평균 둘 다 + · 시험에서 코인 4개 중 2개 이상 + · 원형 밀기 분위 ≥ 50.

## 보조 (판정에 안 씀)
- H1 문턱 \|z\| ∈ {1.5, 2.5}, 지평 3·12봉. H2 문턱·창 변주, 강세/약세 다이버전스 분리, **다이버전스 − 정상 정렬 증분**(같은 \|Δp\| 분위 안에서). H3 첫 30분 대신 첫 60분, 세션별(아시아·유럽·미국) 분리.
- 코인별 표, 월별 부호 표, 비용 민감도(왕복 3·5·7·10·15bp).
- OI(패널 `sum_open_interest`, 한 봉 지연) 조건부 분할은 이번 범위 밖 — 보고서에 «하지 않음»으로 명시.
