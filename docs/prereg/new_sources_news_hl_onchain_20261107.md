## N1 · 뉴스 건수 → 다음 1시간 변동성 (등급: 예측 칸 — 단측 90%)
- 왜: 변동성은 원천이 먹히는 축이다. 10-22 는 LLM impact·15분이라 건수·1시간은 안 쟀다. 느린 피쳐 교훈 → 지연 위약을 주 판정에 넣는다.
- 데이터: 서버 `news_rss.sqlite` `items`(backfill=0) `first_seen_ms`, ETH 5분 패널. 2026-10-05 ~ 패널 끝.
- 표적: 시간 H 끝에 결정, log(H+1 시간 안 5분 r² 합).
- A = log RV(1h) · log 평균 RV(24h) · log 평균 RV(168h) · 같은 시각 직전 14일 평균 log RV. B = A + log1p(H 시간 안 뉴스 건수).
- 확장 OLS, 표적 끝난 행만, 최소 14×24행. 평가 ΔMSE(B − A).
- 통과: 일 블록(B = 2,000) 단측 90% 상한 < 0 **그리고** 뉴스를 1~9일 과거로 민 9판 ΔMSE 평균보다 낮은 수 ≥ 8/9.
- 보조: LLM `impact` 합(10-27 정지 전까지) · BTC · 앞/뒤 절반. 한계: 31일, 독립 일수 31.

## N2 · Binance → HL 추종 매매 (등급: 돈 — 양측 95%)
- 데이터: 서버 `binance_tape.sqlite` 1초(가격 칸 가중평균, ETH 칸 $0.1) · `hl_ctx.sqlite` ETH `mid_px`(약 1초, 수신 시각). 같은 서버 시계. 최근 전 구간.

- 매매: 사건 방향, 진입 = 사건 초 끝 + 2초 뒤 첫 HL mid, 청산 = 진입 + 30초 첫 HL mid.
- 비용: HL 테이커 4.5bp × 2 = 9bp(엄격), 스프레드 별도 미반영. 후보: 메이커 진입 가정은 재지 않는다(추종은 시장가).
- 통과: 순 평균 달력일 군집 양측 95% 하한 > 0. 위약: 사건 방향 뒤집기 대조를 함께 보고.
- 보조: 지연 0·1·5초, 보유 10·60초, 비용 전 평균, BTC.
- 양성 대조: 사건 초 **이전** HL mid 로 진입한 판은 비용 전 평균이 뛰어야 한다(장치가 추종분을 잡는다).

## 수정 1 (2026-11-07, 독립 누수 검토 반영 · 채점 전)
**N1**: A 에 주말 더미 추가, `seas` 를 표적 시각의 직전 14일 평균(행 H 기준 H−23 까지)으로 정정. 위약은 k 마다 실제 판을 같은 시작점으로 잘라 비교하고, 요일 위상이 같은 **k=7 승리를 필수**로 한다(≥ 8/9 + k=7). LLM impact 보조는 판정 정지 시각까지만. 실제 평가 표본은 약 18일·431시간이다(본문 «31일»은 수집 기간).

BTC 는 HL 기록 공백으로 사실상 표본 없음.
