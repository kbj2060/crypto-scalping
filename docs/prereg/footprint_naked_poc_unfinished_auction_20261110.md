## 왜 (과거 실패 교훈 반영)
- 이 저장소에서 맨 POC·미완 경매를 직접 잰 적은 없다(docs·메모리 검색 0건 · 08-15 AMT 문서는 «정의만»). 흡수·소진·다이버전스 «패턴 글자»는 09-30 방향 0 으로 뺐다 → 이번엔 방향이 아니라 **«그 가격으로 돌아오나»**(표시 선의 쓸모)만 잰다.
- 🔴11-09 지지·저항 5분 vs 1시간: «±40bp 옮긴 레벨 평균» 위약은 거리 볼록성으로 무효였다 → 위약은 **거리를 정확히 맞춘다**. 같은 거리 반대쪽(거울)은 «되돌림 vs 추세» 차이를 섞으므로 주 위약은 **같은 거리 · 같은 «직전 움직임 기준 쪽»** 을 다른 날 같은 시각에 놓은 시간 이동 위약으로 한다(일반 되돌림을 빼고 «그 레벨이라서»만 남김). 거울은 통과 후보 등급용.
- 0건/양성 결과를 장치 탓이 아닌지 보려고 양성·음성 대조를 넣는다([[feedback-clean-scan-result-needs-positive-control]]).
- 같은 구간 재사용: tape lake 09-15~ 구간은 흡수선(09-29)·지지저항(11-09) 연구가 이미 봤다(2~3회). 이번 판정 2개 → 예상 우연 통과 ≈ 0.2.

## 데이터·시각 규약
- 원천: 바이낸스 USDⓈ-M ETHUSDT 체결 tape lake(1초 × $0.1 칸 buy_qty/sell_qty, 서버 `/mnt/data2/lake/binance/tape/coin=ETH` 55일 2026-09-15~11-08 복사본). 행 = $0.5(대시보드 FOOTPRINT_BUCKET).
- 5분봉 b = [t, t+300). 봉의 행별 거래량 = 그 봉 안 체결 합. POC = 거래량 최대 행(동률은 봉 종가에 가까운 행).
- 결정 시각 τ = 봉 b+1 마감(= b 마감 + 5분). 기준가 P = τ 직전 마지막 체결가(체결 가능). 결과 창 = (τ, τ+H] 초 단위 — 피쳐(레벨·조건)는 τ 이전 체결만 쓴다.
- 닿음: 레벨 L 이 P 위면 창 안 최고 체결가 ≥ L − $0.25(행 아래 끝), 아래면 최저 ≤ L + $0.25.
- 결측: 결과 창 또는 [b 시작, τ] 안에 체결 없는 초가 연속 120초 넘게 있으면 그 사건 제외.

## 사건 정의 (고정)
- **맨 POC(5분)**: 봉 b 의 POC 행이 봉 b+1 의 [최저 행, 최고 행] 밖 = b+1 동안 안 지나감. L = POC 행 가운데.
- **미완 경매(5분)**: 봉 b 최고 행에서 buy_qty>0 이고 sell_qty>0 (양쪽 체결 = 경매가 안 끝남, ATAS·Dalton 관례 정의) 이고 봉 b+1 최고가가 그 행 아래 → L = b 최고 행. 최저 행도 같은 규칙(대칭). 
  (지시문은 «한쪽 0»으로 적었지만 그건 관례상 «끝난 경매»다 — 끝난 경매는 보조 비교 팔로 같이 잰다.)
- 지평 H: 주 1시간 · 보조 4시간.

## 위약 (사전 고정)
- **주 위약 = 시간 이동·쪽 맞춤**: 사건 e 의 상대 거리 d=|L−P|/P, 쪽 s=sign(L−P), 직전 움직임 m=sign(P − 봉 b 시가)(0 이면 사건 제외), 상대 쪽 r=s·m. 같은 시각 ±1·±2·±3일(데이터 안·결측 없는 것만) 각 τ' 에서 m'=sign(P' − τ'−10분 시가)(0 이면 그 τ' 버림), L' = P'·(1 + r·m'·d). 같은 닿음 규칙 · 위약 닿음률 = 쓸 수 있는 τ' 평균.
- **거울 위약(통과 후보용)**: 같은 τ, L_m = P·(1 − s·d).

## 주 판정 (사전에 고정, 각 팔 독립)
팔 A = 맨 POC 5분 · H=1h, 팔 B = 미완 경매 5분 · H=1h.
1. Δ = 사건 닿음률 − 주 위약 닿음률(사건 짝 차 평균). 일(τ 의 UTC 날짜) 블록 부트 5,000회, P(Δ≤0) — Holm 2팔(α=.10: 작은 p ≤ .05, 큰 p ≤ .10) → **통과**.
2. **통과 후보**: 주 판정 불통과지만 거울 위약 대비 Δ_m 이 같은 Holm 기준 통과.
3. 장치 대조(판정 전 확인, 실패면 판정 보류): 양성 = 레벨을 τ+30분 체결가로 바꾼 가짜 사건(같은 위약 절차) → Δ ≥ +0.3 이고 P(Δ≤0) < .01 · 음성 = 주 위약끼리(+1일 위약 vs −1일 위약) → 90% CI 가 0 포함.
- 보고: 사건 수·일수·닿음 건수(`a/b`)·하루 몇 건·거리 분포(중앙값 bp).
