## 체결 규칙
결정 t 에 코인별 변경분 Δw 만 주문한다.
- 지정가 = p0, 봉 t 부터 **K = 12봉(1시간)** 유효. 매수는 저가 < p0, 매도는 고가 > p0 면 p0 에 체결, 수수료 메이커.
- 끝까지 미체결이면 K 번째 봉 종가에 시장가, 수수료 테이커.
- 손익 = Σ w_old × (c_end/p0 − 1) + Σ Δw × (c_end/p_fill − 1) − 수수료. 봉 결측이면 p0 시장가로 처리하고 건수를 보고한다.
