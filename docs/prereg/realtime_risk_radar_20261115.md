# 사전등록: 실시간 위험 레이더 — 1분마다 갱신되는 다음 15분 폭 · 급변 경보 · 국면 (2026-11-15)

**등급: 되돌리기 쉬운 예측 개선 — 단측 90%.** 매매 신호 아님(크기·손절 거리·경보용). 완화 «통과 후보»는 4코인 중 ETH 만 충족해도 기록.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_realtime_risk_radar_20261115.py`.
사용자 «바로바로 시장의 반응에 즉각적으로 반응할 수 있는 모델» → 고른 것: «다음 15분 폭·급변 경보» + «지금 국면 판정».

## 왜
- 방향(5분~1시간)은 반복 불통과, 변동성은 모델이 실제로 이긴다(4h QX4, SOXL 세션 HAR-S 15분 QLIKE 1.176 → .445). 그러나 화면의 크립토 15분 σ 는 아직 «직전 7일 1시간 수익 표준편차 × √(15/60)» 고정값(B0)이라 시장이 갑자기 격해져도 그대로다.
- 이번엔 **매 1분** 갱신(결정 τ = 매 분 마감)으로 «즉각 반응»을 직접 잰다. 직전 1·5분 변동성을 넣어 급변 직후 바로 커지는지를 본다.
- 10-25 7라운드 교훈: 레버리지·OI 재료는 넣지 않는다(악화). 09-23: 거래량 지표는 HAR 에 먹힘 → 넣지 않는다.
- 11-10 국면 교훈: «지금 횡보/추세»는 서술일 뿐(미래 절반 섞어도 같은 정확도) → 서술 규칙은 판정하지 않고, **«앞으로 1시간 조용/격함»만 예측으로 판정**한다.
- 같은 구간 재사용 공개: 2026-06~10 은 4h 변동성(QX4·QG) 등에서 여러 번 썼다. 1분 격자 15분 지평은 처음.

## 자료·시각
- `data/binance_vision/klines1m/{ETH,BTC,SOL,XRP}USDT-1m-YYYY-MM.parquet` + `klines1m_daily`(2026-10). 선물 1분봉.
- 결정 τ = 분 t 마감. 피쳐 = 분 ≤ t 의 1분 로그수익 r. 표적 RV15 = √Σ r²_{t+1..t+15}(바닥 1e-4 × √15 아래는 바닥). 빈 분이 표적·피쳐 창에 있으면 그 τ 제외.
- 피쳐(고정): 로그 RV 1·5·15·60·240분·1일·7일(√Σr²) · UTC 시각(24) × 주말 여부 더미 48칸.

## 모델
- **HAR-1m**: log RV15 를 위 피쳐에 OLS(코인별). 예측 분산 F² = c · exp(2·ŷ), c = 학습 평균(RV15² / exp(2ŷ)).
- **B0 현행**: 직전 완결 168개 1시간봉 로그수익 표준편차 × √(15/60), 같은 c 규칙.
- **B1 지속성**: 직전 60분 RV × √(15/60), 같은 c 규칙.

## 주 판정 (전부 시험 구간, 일 단위 블록 부트 2,000회 시드 20261115)
1. **현행 대비**: QLIKE(HAR-1m) − QLIKE(B0) 단측 90% 상한 < 0 — ETH 필수, 4코인 중 3 이상.
2. **지속성 대비**: QLIKE(HAR-1m) − QLIKE(B1) 상한 < 0 — ETH 필수.
3. **급변 경보**: 경보 = τ 의 1분 |r| ≥ 4 × (τ−1 에 낸 HAR-1m 15분 예측 ÷ √15) 또는 직전 5분 RV ≥ 3 × (τ−5 예측 × √(5/15)). 같은 분 30분 안 중복은 첫 것만.
   - (a) 경보 뒤 15분 RV ÷ 같은 코인·UTC 시각 학습 중앙값 의 평균 ≥ 1.5, 그 비율의 단측 90% 하한 > 1.2.
   - (b) 경보 직후(τ) HAR-1m 예측의 눈금: 평균(RV15² / F²) 이 [0.8, 1.25] — 모델이 경보 순간 이미 따라 올라갔는가.
4. **앞 1시간 조용/격함**: 같은 모델 사양을 지평 60분으로 적합(HAR-1m-60). «평소» = 직전 30일 1시간 RV 중앙값.
   - 판정 «조용» = 예측 ÷ 평소 ≤ 0.7 · «격함» = ≥ 1.5. 맞음 = 실제 다음 1시간 RV 가 평소보다 작음/큼.
   - 통과: ETH 시험에서 두 판정 정확도 ≥ 75% · 판정 비율(전체 시간 대비) 함께 보고 · 같은 문턱의 B0 판정보다 정확도 높음(단측 90%).

## 서술(판정 안 함)
- «지금 국면» = 지난 4시간 순이동 |log(c_t/c_{t−240})| ≥ 1.5 × 직전 30일 4시간 순이동 중앙값 → 추세, 아니면 횡보. 11-10 단순 규칙(사후 참고 정답 70.3%). 매 분 갱신. 비율·바뀜 횟수만 보고.
- 15분 «폭 띠»: 시험에서 |15분 안 최대 이동| ÷ F 의 80·95% 분위(화면 «15분 안 ±x% 안에 머물 확률»).
