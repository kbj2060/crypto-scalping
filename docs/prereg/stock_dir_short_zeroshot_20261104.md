# 사전등록: 주식(SNDK·SOXL) 15분·1시간 방향 — ETH 65열 모형 재학습 없이 적용 (2026-11-04)

**등급: 되돌리기 쉬운 화면 표시용 예측 — 단측 90%.** 매매 신호·크기가 아니다(통과해도 «표본 짧음» 표시만). **이 문서는 계산 전에 커밋한다.**
스크립트: `scripts/research_stock_dir_short_zeroshot_20261104.py`. 사용자 «있는 피쳐로만 해보는건 어때?» (주식에 예측이 없다는 11-04 질문 뒤).

## 왜 (과거 실패·교훈 반영)
- 데이터 가용성 정정: 11-04 답변에서 «주식은 OI 패널이 없다»고 했으나 Binance Vision 에 SNDK(klines 5m 2026-04~ · metrics 일별 210일 · 펀딩)·SOXL(klines 05~ · metrics 172일)의 5분 메트릭이 있다 → 65열 피쳐를 **같은 식으로** 만들 수 있다. «있는 피쳐로만» = 빈 피쳐는 NaN 으로 두고(LightGBM 결측 처리) 온전한 피쳐가 90%(≥59/65) 미만인 행은 쓰지 않는다.
- 이력이 짧아(SNDK ~210일·SOXL ~172일) 주식 자체 학습·검증 분할은 못 쓴다 → **학습 없이 적용**(코인 이식 BTC·SOL·XRP 1시간 선례, 10-31).
- 교훈: 제로샷 이식은 «학습 시점과 시험 시점이 겹치면» 시장 공통 충격을 학습한 모형이 이득을 본다 → 시험 이전에 끝나는 **동결 모형**(학습 경계 2026-06-01, 5월 말까지)을 쓴다(배포 모형은 09-30까지라 시험 창과 겹친다).
- 교훈: 효과가 약해(적중 +3~5%p) 검정력이 문제 → 독립 일수·분모를 먼저 보고. 약한 정확도 신호는 매매 근거 아님(비용 산수).
- 교훈: 문턱은 인과(표본 전체 분위 금지) · 라벨은 결정 시각 이후 실제 봉만(주식 5분봉은 결측일이 있다) · **양성 대조**(이미 통과한 코인으로 같은 파이프라인).
- 같은 구간 재사용 공개: SNDK·SOXL 시험은 처음. 대조(SOL)는 10-31 시험 창과 겹침(재사용·판정 아님).

## 데이터·시각 규약
- 주식 패널 = Binance Vision 일별 klines 5m + metrics(CDN 정적 파일, REST 아님)를 `build_binance_vision_panel_20260915.day` 로 받아 vision 패널 형식으로. 코인 패널 = 서버 패널 사본 `data/live/dirshort_panel`(2026-11-01 23:55까지).
- 대상 코인을 «ETH 자리»에 두는 기존 방식(`frames_for`) · 결정 시각 τ = 봉 마감(`dataset` 의 t) · 라벨 = 결정가(직전 봉 종가)→h봉 뒤 종가, **그 사이 봉이 전부 실제 봉**인 행만(결측일 앞뒤 1시간 제외).
- 모형 = `live_eth_dir_short_20261028.train(…, None, month=2026-06-01)` 로 ETH 65열판을 새로 학습(학습 경계 2026-05-31, 15분·1시간, 표적 4종×시드 5) → 동결, 재학습·튜닝 없음. 서빙 모형(09-30 경계)은 쓰지 않는다.

## 판정
- 예측 = 동결 모형 5시드 평균(`L.predict`). 신호 = 그 주식의 **자기 예측 과거 확장 20/80 분위**(당일 0시 이전 예측만, 최소 14일): 상위 20% → «오름», 하위 20% → «내림».
- 지표 = 평균 초과 적중 = ½[(상위 오름 적중률 − 기저 오름률) + (하위 내림 적중률 − 기저 내림률)], 일 블록 부트스트랩 B=2000.
- **주 판정 4개: SNDK·SOXL × 15분·1시간, 각각 단측 90% 하한 > 0, Holm(α=.10, 부트 p = 초과 ≤ 0 비율).** 통과 = 화면에 «표본 짧음» 표시로 올릴 수 있음. 불통과·판정 불가 = 비움.
- 중단 조건: 온전 행(≥59/65 피쳐) 비율 < 50% 이면 «같은 모형이 아니다» 로 보고 판정 보류.
- 지표는 분모·건수(`a/b`)·일 수 병기. 독립 일수 < 30 이면 «판정 불가(검정력)».

## 대조 (판정 안 씀, 먼저 통과해야 해석)
1. **양성 대조 = SOL**(ETH 모형 1시간 이식이 10-31 시험을 통과): 같은 파이프라인 SOL 1시간 평균 초과 > 0 이 아니면 주식 결과는 해석 불가.
2. 위약 = 예측을 하루(288봉) 밀어 같은 지표 — 0 근처여야 한다.
3. 한 봉 밀기 트립와이어 = 결정 시각 피쳐를 한 봉 과거/미래로 민 ΔAUC 가 누수 지문이 아님을 확인(11-03 감사 반영).
