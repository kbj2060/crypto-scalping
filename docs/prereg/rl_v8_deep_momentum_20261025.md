## 장치(자유 선택은 하나씩만, 모두 고정)
- **입력** = v7 와 같은 20일 × 13 정규화 일 피쳐(R3.window 의 시장 부분, F[d] 는 이미 d−1 종가까지). **포지션 상태 없음**(DMN 은 상태 없음).
- **구조 = 저장소 인과 TCN**(R3 Seq: Conv1d 13→32 k3 · 32→32 k3 dil2, 왼쪽만 채움, 마지막 시점) → 드롭아웃 0.3 → Linear(32→1) → tanh. 논문 최고는 LSTM(63일 궤적) 이지만 TCN 을 고른 이유: v6 D1 에서 같은 관측·TCN 이 심은 힌트를 완전히 표현함이 확인됐고(오라클 BC 3.09·3.17), v7 과 피쳐 추출기를 같게 두어야 «학습 방식(PPO→샤프 직접)» 하나만 바뀐다. 드롭아웃 0.3 = 논문 격자 {0.1…0.5} 가운데.
- **손실** = 식 (16) 음의 샤프(√365), 수익은 식 (35) 꼴: R_{i,d} = X_{i,d}·L_{i,d}·r_{i,d} − c·|X_{i,d}·L_{i,d} − X_{i,d−1}·L_{i,d−1}|.
  - r_{i,d} = c_d / c_{d−1} − 1 (결정일 d 의 종가 대 종가 수익 = 실행기에서 그날 포지션이 버는 수익, 피쳐는 d−1 까지).
  - L_{i,d} = min(2, 0.25/σ_{i,d}) — 논문 σ_tgt/σ_t 를 실행기 슬리브 크기(목표 25%·상한 2배)와 똑같이. σ = 60일 EWM(논문과 같은 span, 이미 d−1).
  - c = 10bp (논문 §VII-A 의 c = 10bps · v3~v7 κ 와 같음).
- **학습**: Adam lr 1e-3 · 최대 기울기 노름 1.0 · 미니배치 = 63일 연속 궤적 8개(≈ 504 표본, 논문 격자 512 근처 · 궤적 길이 63 = 논문 LSTM 궤적) · 궤적 첫날의 전날 포지션도 망으로 계산해 비용 항에 씀 · 최대 100 에폭 · **조기 멈춤**: 창의 검증 구간 4코인(실제 세계)에서 같은 손실(비용 포함 샤프)이 25 에폭 개선 없으면 멈추고 최선 에폭 가중치로 되돌림(논문: 100 에폭·인내 25). 하이퍼파라미터 탐색 없음(논문은 무작위 탐색 50회 — 과적합 자유도를 없애려고 안 함).
