# 사전등록: 앵커드 VWAP(스윙 고저에서 시작한 거래량 가중 평균가)이 지지·저항으로 버티는가 (2026-11-15)

**등급: 되돌리기 쉬운 지표 의미 검증 — 단측 90%** + 완화 «통과 후보». 수익 안 봄.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_anchored_vwap_meaning_20261115.py`.
사용자 «다음 지표로» — 남은 목록 중 앵커드 VWAP.

## 왜
- 흔한 주장(Shannon 2008 «Anchored VWAP»): 의미 있는 스윙 고점·저점에서 시작한 AVWAP 은 «그 뒤 산 사람들의 평균 단가»라 가격이 다가오면 버틴다(되튕김).
- 이전 시행: 세션 VWAP 규칙 3라운드(10-29) · 볼륨 프로파일 0/5 · 라운드 넘버 0/3 — 대부분 «수준에서 되튕김»은 가짜 수준과 같았다. 맞은 것은 OB·FVG «되돌아오면 버팀»뿐.
- 오늘 교훈(MACD·ADX·ORB): 실제 가격 고유 성질과 섞이지 않게 **같은 실제 가격에서 수준만 옮긴 대조(P3)** 를 주 판정에.

## 정의 (봉 마감에 알려짐)
- 15분봉·1시간봉 4코인(ETH·BTC·SOL·XRP), 1분봉 Vision 2022-01~**2026-10-29**(거래량 열 있는 마지막 날). ATR = 참범위 14봉 평균.
- 스윙 = 앞뒤 20봉 최고(최저) 봉 p, **알려지는 시각 p+20**. 앵커는 가장 최근에 알려진 스윙 고점(H)·스윙 저점(L) 각각 하나.
- AVWAP[t] = Σ(전형가×거래량, p..t) / Σ(거래량, p..t), 전형가 = (고+저+종)/3.
- **다가옴 사건**: 봉 t−1 종가가 AVWAP 에서 한쪽(s)으로 0.5 ATR 이상 떨어져 있고, 봉 t 종가가 AVWAP ±0.25 ATR 안. 주장 = s 쪽으로 되튕김.
- 측정 = 봉 t 종가 기준 100봉 안 s 쪽 1 ATR 이 반대 1 ATR 보다 먼저(`first_hit_race`, 같은 봉 동시·미결 = 불리 — 양쪽 같은 폭이라 시간대 오염 없음).

## 대조
- **P1** 기하 위약 20벌(같은 함수·시드 · 거래량은 그 분에 붙은 채).
- **P3 옮긴 수준(실제 가격)**: 같은 앵커의 AVWAP 을 앵커 확정 시각 ATR 의 ±1 배만큼 평행 이동한 두 선에 같은 다가옴 규칙.

## 주 판정 (사전 고정)
칸 = {H 앵커, L 앵커} × {15분, 1시간} = **4칸**, Holm(α .10). «맞음» = 실제 − P1 단측 90% 하한 > 0 · **실제 − P3 단측 90% 하한 > 0** · 코인 ≥ 3/4 · 두 구간(2022-24 / 2025-26) 같은 부호. 통과 후보 = 점추정 > 0 + 코인·구간. 부호 뒤집어 넘으면 «거꾸로»(= 뚫고 감).

## 보조 (판정 안 씀)
