## 전략 (고정)
- **R2 범위 페이드**: pos(24h 범위 내 위치) ≥ 0.8 → 숏, ≤ 0.2 → 롱. **TP = 24h 범위 중점**, **SL = 범위 극단 ± 0.5×ATR48**(숏은 위, 롱은 아래). 진입가가 이미 SL/TP 를 넘었으면 무효(0).
- **T2 돌파 추종**: 종가가 직전 288봉 고가(봉 i 제외)를 넘으면 롱, 저가 아래면 숏. **TP = 진입 ± 3×ATR48, SL = 진입 ∓ 1.5×ATR48**.
- 공통: 진입 i+1 시가, TP/SL 은 i+1 봉부터 intrabar, 같은 봉에 둘 다면 SL 먼저, 시간청산 i+H 종가(H=48). 비용: 진입 4bp + (TP 2bp | SL·시간 4bp). 결정당 평균 = 거래 순손익 합 ÷ 결정 수(쉼 0).
