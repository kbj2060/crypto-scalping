## 왜
- 크립토에서 널리 믿는 «CME 선물이 주말에 쉬는 동안 생긴 갭은 결국 메워진다». 11-15 FVG 메움이 90% 로 높아 보였지만 무작위 가격도 90%(기하 착시)였다 → 같은 위험: 가까운 수준엔 무작위 가격도 잘 닿는다.
- 그래서 **같은 거리 반대편 거울 수준**을 대조로 둔다 — 갭 쪽(금요일 종가)이 반대편 같은 거리보다 더 잘 닿아야 «메워진다»가 뜻을 가진다.
- 이전 시행: CME 갭 검정 없음(CME 관련 메모는 옵션·감마뿐).

## 정의 (사전 고정)
- 자료: 바이낸스 USDT-M **BTCUSDT 1분봉**(Vision) 2022-01~2026-11-13. ETH 는 보조(CME 이더 선물도 같은 시간표).
- **대리 갭**(실제 CME 가격 아님 — 베이시스·휴장일 무시를 결과 문서에 공개):
  - 금요일 마감 = 금요일 16:00 America/Chicago(서머타임 반영, zoneinfo) 직전 1분봉 종가 P_fri.
  - 일요일 개장 = 일요일 17:00 America/Chicago 직전 1분봉 종가 P_sun(시가 열이 없어 직전 종가로 대신).
  - 갭 = P_sun − P_fri, 갭% = 갭 / P_fri.
- **메움**: 일요일 17:00(시카고) 이후 1분봉에서 가격이 P_fri 에 닿음(위 갭: 저가 ≤ P_fri, 아래 갭: 고가 ≥ P_fri). 지평 H 일 안.
- **P2 거울 수준** M = 2·P_sun − P_fri(개장가 반대편 같은 거리) — 같은 지평 안에 닿는 비율.
- **P1 기하 위약**: 1분 로그수익 부호 무작위 20벌(11-15 SM.placebo, 같은 시드 규칙) 위에서 같은 시각·같은 문턱으로 갭을 다시 만들고 같은 측정.

## 판정 (사전 고정)
칸마다 «의미 맞음» = 전부:
1. 실제 − P1(20벌 평균) 단측 90% 하한 > 0 (주말 단위 부트스트랩 2,000회 분산 + 위약 벌 분산/20) · 2칸 Holm(α .10).
2. 실제 − P2(거울) 단측 90% 하한 > 0 (같은 주말 짝 차이 부트스트랩).
3. 두 구간(2022-24 / 2025-26) 모두 실제 − P1 > 0 · 실제 − P2 > 0.
- 통과 후보: 1·2 점추정 > 0 + 3. 부호를 뒤집어 넘으면 «거꾸로».
