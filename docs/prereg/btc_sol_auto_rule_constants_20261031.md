# 사전등록: 자동 규칙 상수(2배·첫 1/3·∓0.75% 물타기·∓5% 손절)를 BTC·SOL 에 그대로 써도 되나 (2026-10-31)

**등급: 돈 걸린 크기·손절 — 양측 95%** + 완화 «통과 후보» 병기.
**이 문서는 계산 전에 커밋한다.** 스크립트: `scripts/research_xrp_auto_rule_constants_20261031.py` 를 `--coin` 인자로 일반화(기본 XRPUSDT).
사용자 «일부러 그대로 둔 것들도 모두 각각 코인에 맞게 재학습 및 최적화 진행해줘».

## 왜 (과거 교훈 반영)
- 선례 = XRP 판(`docs/prereg/xrp_auto_rule_constants_20261031.md` 수정 1 포함 · 결과 `docs/experiments/xrp_auto_rule_constants_20261031.md`). 규칙·데이터 규약·진입 과정 E1/E2·구간·M1·M2·M4·질문 1·2·대조·자체 점검 S1~S3 를 **그대로** 쓴다. 바뀌는 건 코인과 아래 M3 뿐.
- 🔴XRP 판 M3(실력 0 1년 −20% 낙폭 확률)은 두 코인 모두 100% 포화 — 무작위 진입은 왕복당 −7~−13bp(비용)라 1년 865건이면 반드시 −20% 를 넘는다. 이번엔 **원장 실력 보정 수익분포**로 고친 M3′ 를 판정에 쓴다(아래).
- 상수 후보 격자 금지(과적합 교훈) — 코인 판은 사전에 정한 식 하나(변동성 비 r 환산)뿐.
- 같은 구간 재사용 공개: 2026 검증·시험은 ETH 원장 연구들과 XRP 판(같은 질문의 ETH 쪽 무작위 진입 경로)이 이미 봤다(준-표본 밖). BTC·SOL 1분 경로로 이 질문을 본 연구는 없음. 이번 라운드 주 판정 = 코인 2 × 질문 2.
- BTC 는 r < 1 일 가능성이 높다 → C_X 가 상한을 **키운다**(2/r). 크기를 키우는 쪽은 갭 꼬리가 커지므로 2022-23 갭 꼬리 조건을 변경 권고에 붙인다(아래).

## 규칙·데이터·진입 과정 (XRP 판과 동일)
- 상한 L × 순자산 · 첫 진입 = 상한 1/3 · 물타기 2/3 = 첫 진입가 ∓d 지정가 · 손절 = 첫 진입가 ∓s 거래소 스탑 · 익절 없음. C_E = (2, 0.75%, 5%).
- 코인 판 C_X: r = 학습(2024-01~2025-12) 매일 00 UTC 직전 24h 1분 로그수익 표준편차 비(코인/ETH)의 중앙값 · **d_X = 0.75%×r · s_X = 5%×r · L_X = 2/r** (손절 손실 L×s = 순자산 10% 유지). r 은 학습에서 한 번만.
- 데이터: 바이낸스 USDT 무기한 1분봉 ETHUSDT·BTCUSDT·SOLUSDT 2022-01-01 ~ **2026-10-27**(vision 10-28 없음, XRP 판 수정 1 과 같음). 로컬 `data/binance_vision/klines1m` + `klines1m_daily`(vision 덤프와 값 동일 확인: ETH 10-05 1,440행 h·l·c·t 완전 일치).
- 진입 = 직전 분 종가 · 물타기 엄격 관통 · 손절 체결 기본(손절가, 분 전체 갭이면 그 분 고가) / 스트레스(그 분 저가) · 메이커 2bp · 테이커 5bp · 펀딩 생략.
- E1 실력 0 = 구간마다 무작위 결정 분 20,000(코인 공통 시각·방향 롱 60%·보유 = ETH 원장 225왕복 복원 추출) · E2 = ETH 원장 이식(보조).
- 구간: 학습 2024-01~2025-12(r 만) · 검증 2026-01~05 · 시험 2026-06~10-27(1회) · 스트레스 2022-01~2023-12(보조 + 변경 권고 조건).

## 지표
- M1 손절률 · M2 스트레스 손절 손실 > 순자산 10% 비율(전체 대비) · M4 최악 왕복 — XRP 판과 같다.
- XRP 판 M3(실력 0)은 재현용으로 그대로 계산·보고하되 **판정에 안 쓴다**.
- **M3′ 실력 보정 1년 −20% 낙폭 확률**: 실력을 «가격 단위 우위 κ × 보유 명목»으로 더한다. 왕복 i 의 보정 손익 = 원 손익 + κ × N_i, N_i = L/3 × (1 + 2 × 물타기 체결?)(순자산 단위 명목). κ 는 구간마다 **ETH·C_E E1 의 보정 평균 = μ_led** 가 되게 한 번 정하고(κ = (μ_led − 평균 r_ETH) / 평균 N_ETH), 같은 κ 를 코인 팔(C_E·C_X)에 그대로 쓴다. μ_led = ETH 실원장 이식(E2, C_E, 기본 체결) 왕복 평균 손익(XRP 판 212왕복 합 +24.0%p → 약 +11.3bp/왕복; 이번 실행 값 그대로). 이후 XRP 판 M3 과 같은 경로 생성(하루 Poisson 2.37건 · 같은 날 묶음 재표집 · 365일 복리 · 4,000경로 · 두 팔 같은 추첨) → MDD ≤ −20% 비율, 차의 양측 95%(쌍 이항 정규근사). 기본·스트레스 체결 둘 다, 판정은 기본.
  - ponytail 한계: 상수 κ 가산은 손절된 왕복에도 더해지는 근사(실력이 손절 경로를 바꾸는 효과는 못 봄). 원장 μ_led 는 2026-08~10 구간에서 잰 값이라 시험 구간과 겹친다(선택이 아닌 보정 상수 하나).
  - **포화 방지(사전 고정)**: 어떤 구간에서 ETH·C_E 의 M3′ 이 5% 미만 또는 95% 초과면 그 구간 M3′ 은 «변별 불능»으로 판정에서 빼고 M1·M2 로만 판정한다(결과에 명시).

## 주 판정 (코인마다, 사전에 고정)
**질문 1 — ETH 상수의 위험이 코인에서 다른가**: C_E 로 코인 vs ETH, 검증·시험 각각, M1·M2·M3′ 차(코인 − ETH)의 양측 95%(M1·M2 = 5일 블록 부트스트랩 2,000회).
- «더 위험» = 어떤 지표든 CI 하한 > 0 · «더 안전» = 어떤 지표든 CI 상한 < 0(나머지는 «더 위험» 없음). 검증·시험 둘 다 같은 방향이면 **확정**.
**질문 2 — 코인 판 C_X 가 ETH 수준 위험으로 맞추는가**: C_X 로 코인 vs C_E 로 ETH.
- **엄격 통과**: 검증·시험 모두 M1 차 CI 상한 ≤ +1%p · M2 차 CI 상한 ≤ +0.5%p · M3′ 차 CI 상한 ≤ +5%p.
- **통과 후보**: 검증·시험 모두 세 지표 점추정 차가 위 한계 이하.
**상수 변경 권고 = 셋 다**: ① 질문 1 확정(어느 방향이든 — 현행 상수가 그 코인에 안 맞음이 두 구간에서 유의) ② 질문 2 엄격 통과 ③ 2022-23 스트레스 구간 C_X 코인 vs C_E ETH 의 M2 차 점추정 ≤ +0.5%p(갭 꼬리 조건). 하나라도 빠지면 **현행 유지**(통과 후보는 기록만).
- 대조: 손절 없음(M4) · ETH 끼리 7일 원형 이동 위약(M1·M2 차 ≈ 0 이어야 부트스트랩 정상).

## 양성 대조 (채점 전 필수)

- 자체 점검 S1~S3 그대로 + **S4**: M3′ 보정 후 ETH·C_E E1 평균 = μ_led (1e-12).
