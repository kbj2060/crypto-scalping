## 0. 결론 먼저

**우려 한 문장**: 방향 축은 이 저장소에서 여섯 계열(HGB·GBM·TCN·TabPFN v3·단일피쳐·지도 45D)이 OOS .50~.55 로 닫혀 있고, 직접매매 RL(DSAC)도 09-12 에 개입 3종 뒤 «항상 숏」 대조군을 못 넘었다. 사용자 결정으로 방향을 다시 연다. 그러면 이 설계는 **아직 안 해본 정식화**여야 하고, 그 값은 사전등록한 대조군·킬게이트가 정한다.

1. **09-12 DSAC 와 다른 점 다섯.** ① 매 봉 연속 노출이 아니라 **빈 슬롯에서만 결정하는 semi-MDP**(행동 {롱, 숏, 관망}) — 진입하면 배포 스택(MAE 분위 크기·planning_hold 지평·손절 3%·예산 사다리)이 청산까지 관리하고 에이전트는 다시 빈 뒤에야 결정한다. 회전율이 **구조적으로** ≤ 1거래/지평. DSAC 를 죽인 «비용×거래량」이 행동공간에서 사라진다. ② 보상은 청산 시 **실현 순손익 한 항**(정형화 항 0). ③ 입력은 이진 발동 플래그가 아니라 **연속 재료 41열**(09-12 사용자 지시). ④ 관망이 정당한 행동(기권 벌점 0) — «엣지 < 비용」이면 관망을 배우는 게 정답이고, 엣지 > 비용인 부분집합이 있으면 거기서만 베팅한다(학습된 선택적 예측). ⑤ 학습 가격은 탈드리프트, 평가는 실제 가격.
2. **피쳐 분석은 학습 뒤가 아니라 게이트다.** 순열 중요도 상위군의 단변량 분위 효과가 평평한데 모델이 2~3피쳐 규칙을 5pp 이상 이기면 상호작용이 아니라 **누수**부터 의심한다(CLAUDE.md 탐지 신호). 피쳐군 절제(재료·레짐·변동성·BTC 교차·시간대)를 매 실행 자동으로 낸다.
3. **RL 이 지도학습 쌍둥이를 못 이기면 RL 은 없다.** 같은 피쳐·같은 창에서 «손익 회귀 + 임계 기권」(09-12 판)을 대조군으로 둔다. 보상이 청산 시 한 번 관측되므로 이 문제는 지연 보상 컨텍스추얼 밴딧에 가깝고, 순차 결합은 «슬롯 점유의 기회비용」과 «복리」뿐이다. 그 둘을 가치함수가 실제로 잡는지가 RL 의 존재 이유다.
4. **아키텍처는 둘 중 하나를 컨펌받는다(§8).** A) 표형 상태 MLP 2×64 + PPO(권고, 먼저) · B) 재료 시퀀스 소형 Transformer 인코더 + 같은 헤드(A 통과 시 또는 병행 양성대조 팔로). 원시 OHLCV 시퀀스 TCN 은 09-13 양성대조로 닫혔으므로 B 의 입력은 원시 봉이 아니라 **재료 시퀀스**다.
5. **정직한 사전 예상**: 킬게이트 G2(3창 중 2창 순 bp > 0, 블록평균 t ≥ 2)를 못 넘을 확률이 높다. 이 설계를 돌리는 값은 «방향 RL 정식화」라는 마지막 미시험 칸을 닫거나, 넘으면 처음으로 방향 축에 생존자를 두는 것이다. 어느 쪽이든 결과는 기록된다.

## 4. MDP 정식화

- **행동공간은 {롱, 숏, 홀드} 셋뿐이다**(사용자 확정 09-14: *"롱숏홀드의 행동만 갖고 진입 및 청산 로직을 따르며 학습"*). 빈 슬롯에서 홀드 = 관망. **보유 중에는 홀드만 유효**(마스크) — 청산은 배포 로직(손절·사다리·만기)만 한다. 보유 중 반대 측면 행동으로 «뒤집기 = 조기 청산」을 허용하면 닫힌 청산 축이 뒷문으로 들어오므로 허용하지 않는다.
- **결정점**: 슬롯이 빈 봉 t(결정 간격 5/15분). 관측 s_t = §3.1(봉 t 종가까지). 행동 a_t ∈ {롱, 숏, 홀드}.
- **관망**: 다음 결정점으로. 보상 0.
- **진입**: 측면 a_t 로 배포 스택이 L_t·H_t 를 정하고 체결(진입 2.95bp). 이후 청산까지 결정 없음(semi-MDP 옵션). 청산 봉 τ 에서 보상 `r = L_t · (a_t·(exit/entry − 1) − cost/1e4) − funding(τ−t)`, cost 는 청산 유형별(peg/손절 테이커). 다음 결정점은 τ+1.
- **드리프트**: 학습 테이프는 탈드리프트. 추가로 액터 손실에 `direction_reg`(mean(a)² 계열) 0.20 — DSAC 정정에서 «한 곳에」 원칙. 환경 보상엔 정형화 항 없음.
- **에피소드**: 학습 창(2024-01~2025-08, 확장판이면 2021-12~)에서 90일 창 무작위 표집. γ = 1(옵션 단위 할인 없음). 종단 없음.
- **판정 지표**(보상과 별개): 거래당 순 bp(블록 = 지평, **블록 평균** t) · 시간적분 노출당 로그성장 · 거래 수/창 · 측면 비중 · MDD.

## 5. 알고리즘

- **1차: PPO(이산 3행동, 마스크 없음 — 결정점에서만 호출)**, 액터·크리틱 MLP 2×64, 엔트로피 계수는 관망 붕괴/편향 붕괴 두 방향 모두를 감시하며 스윕. 이유: 시뮬레이터가 있으므로 온라인이 정당하고, 옵션 단위 semi-MDP 는 «다음 결정점까지의 가치」 하나로 크리틱이 단순하다. DSAC 코드는 재사용하지 않는다(차원·붕괴·조용한 0회 학습 이력).
- **지도학습 쌍둥이(필수 대조군)**: 같은 피쳐·같은 창·같은 비용으로 «부호 있는 순손익 bp 회귀 + |예측| > c 기권」(09-12 `research_eth_pnl_objective_direction_20260912` 판). RL 이 이 팔을 ≥2/3 창에서 못 이기면 **RL 은 탐색 분산만 더한 것**이다.
- **양성대조(하네스 검증)**: 같은 상태·같은 루프로 **변동성확장 타깃**(보상 = 앞으로 H 봉 실현변동성 상위 1/3 이면 +1)을 학습해 OOS AUC ≥ .65 가 나와야 한다. 안 나오면 방향 결과를 읽기 전에 하네스를 고친다.

## 9. 부록 — v1: 방향 없는 크기·지평 제어 에이전트 (보류)

사용자 정정으로 보류. 요지: 방향을 주입 정확도 a 로 외생 처리하고 숨긴 채, 신념 상태(Beta 사후)·낙폭·변동성 국면을 상태로 L·H 를 정하는 제약 MDP. 사다리 L0 래퍼 → L1 오라클 → L2 닫힌형 대조군(베이즈 분수 켈리 + MDD 브레이크) → L3 표형 DP → L4 CEM → L5 PPO. 이 축은 v2 가 G2 를 넘든 못 넘든 **독립**이고, v2 가 넘으면 그 정책의 확신도를 L 에 연결하는 자리에서 다시 만난다. 상세는 이 파일 v1(git 이력) 참고.

## 10. 제로샷 모델 (문헌, 2026-09-14 확인)
