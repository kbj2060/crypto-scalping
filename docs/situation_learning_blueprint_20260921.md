# «상황 읽기 · 30분» 학습 설계도 (2026-09-21)

전체 문서(층 지도·표·단계): https://claude.ai/artifact/21sAaNffyj7713fKRuZaDm — 이 파일은 저장소용 요약이다. 코드는 이 설계가 합의된 뒤 P0 부터 쓴다.

## 결론
- 첫 판은 강화학습이 아니라 **온라인 확률 예측**. 카드는 예보를 낼 뿐 시장을 바꾸지 않으므로 보상은 적절 채점 규칙(로그 점수)으로 정의된다.
- **RL 의 첫 걸음은 밴딧**: 행동 = {A/B/C 를 1순위로 부른다, 보류}. 보상 = 로그 점수(+ 모의 손익은 둘째 축).
- **진화의 정의**: 주 단위 프리퀀셜(test-then-train) 로그 점수가 고정 규칙표(SCORES)를 일-블록 CI 밖에서 이길 때만 화면이 학습값으로 바뀐다. 그 전에는 «규칙 | 학습 | 차이» 병기.

## 층 지도
| 층 | 내용 | 지금 상태 |
|---|---|---|
| L0 데이터 계약 | 결정 시점 t · 피쳐 ≤ t · 라벨 (t, t+30m] · **채점 기하 수정**(A 목표가 중앙 1bp vs B·C 51·48bp → 최근접 81% 승) · 1분봉 해결 · none 클래스 · 라벨 두 벌(Y_geo 트레이더 의미 / Y_sym 대칭 ±k×창폭) · 연속 타깃(30분 수익·MFE·MAE) | 장부·해결은 있음, 기하 수정 필요 |
| L1 피쳐 | 규칙 엔진의 `evidence` dict 가 그대로 피쳐(이진 규칙 + 30일 롤링 분위 수치). 이력이 4.7년인 군(이동·OI·거래량·BTC·시각)과 며칠짜리 군(고래/리테일·호가·청산맵·펀딩·베이시스)을 구분 | 재료 있음 |
| L2 온라인 모델 | 4클래스 다항 로지스틱. **초기 가중치 = SCORES, 정규화 중심 = SCORES**(사전 쪽 L2) · 감쇠 학습률 · 망각 계수(반감기 ~30일) · 온라인 보정층 · **두 탑**: 기저(4.7년 패널 오프라인, fresh-forward) + 잔차(온라인, 기저 로짓을 피쳐로 스태킹) | 없음 |
| L3 밴딧 | 행동 {A,B,C,보류} · 컨텍스트 = L2 확률 + 사후 분산 + 뒤집기 신호 수 + 활발 · 톰슨 샘플링 · 보상 로그점수(모의손익: 1순위 방향 진입·목표=TP·반대=SL·USDC 왕복 1.4bp·30분 시간청산은 둘째 축) | 없음 |
| L4 평가·승격 | 프리퀀셜만 · 기준선 3개(균등 / 롤링 7일 기저율 / 고정 규칙표) · 일-블록 부트스트랩 + 에피소드 가중 · 하이퍼 3개(η₀, λ, γ)×후보 ≤3, 선정 1주 → 고정 1주 · 게이트 5항목(≥7일 · CI 0배제 · 일 부호일치 ≥5/7 · 롤링 기저율도 이김 · 보정 이탈 ≤10pp) | 장부 적중률 표시만 |
| L5 진화·안전 | 가중치 버전 파일 append-only(`data/live/situation_model/`) · 주간 드리프트 감시 · 2주 연속 지면 자동 롤백 · 사람 개입 = SCORES 편집(=사전 갱신, 기록) · 레짐 라우터 금지(세션을 피쳐로) · 학습 표본 파일 동결(재현) | 없음 |

## 표본과 시간
중복 정리 예측 ~1,080/8h · 에피소드 ~157/8h(≈470/일) · 1순위 적중 5pp 개선 검출에 독립 사건 ≈1,300 → 자기상관 감안 1~2주 · 선형 잔차 탑 2~3주 · 작은 GBDT 잔차는 2~3개월(사전등록 실험으로만).

## 단계 (확인 항목이 완료 정의)
- **P0** 채점 기하 수정 + 1분봉 해결 + none + 두 라벨 → 거리 비슷한 부분집합과 전체의 A 비율 차이 10pp 안, 경계 감사 통과
- **P1** 학습 표본 파일 기록 시작(학습 없음) → 하루 표본·에피소드·판정불가 비율 카드 표시, 1주 축적
- **P2** 기저 탑 오프라인(4.7년, Y_sym) → 표본외에서 롤링 기저율을 로그점수로 이김(못 이기면 기저 탑 없이)
- **P3** 잔차 탑 온라인 섀도우 + «규칙|학습|차이» 병기 → 하이퍼 선정 1주·고정 1주·게이트 5항목
- **P4** 밴딧(보류) → 부른 것의 적중 > P3, 보류 ≤50%
- **P5** 화면 전환 + 월간 기저 재학습 + 자동 롤백 → 4주 연속 통과 뒤에야 «포지션을 드는 RL» 문서를 연다

## 함정(저장소가 밟은 것)
최근접 목표 채점 · 사건 라벨 경계 · bp→정확도 환산 금지 · 임계값 분위 · 확신↑=체결가↓(모의손익 보상) · 조건부 하위통계 · AUC 동률≠경제성 · 시드 다양성 · 표본외 열어놓고 고르기 · 상태의 진실은 파일 · 레짐 라우터.
