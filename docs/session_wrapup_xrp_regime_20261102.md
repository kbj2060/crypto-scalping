## 한 줄 결론
매매 규칙은 사전등록 기준을 통과한 것이 **0건**이었고, **횡보/추세 분별 모델 1건**이 두 번 독립 검증을 통과해 대시보드 ⑤ 예측 줄(`7일 예측` 자리)에 배포됐다. 정확도(시험 68.7%, 미학습 5코인 제로샷 66.6%)의 큰 몫은 «띠 폭÷변동성» 기하이고, 모델의 새 정보 몫은 +6.9%p / +3.1%p 다. 전진 성능은 서버 기록기로 앞으로 쌓인다.

## 흐름
1. 사용자 «XRP 원장 분석» → 서버 원장(읽기 전용 job)으로 XRP 14건 분석: 최근 3일 10건 9승 +$163, 9월 3건 −$122, 크기 $2k→$9k(배수 1.9→7.1), 하락 국면 숏 편승.
2. 사용자 재량 규칙(저거래량 돌파→반대 진입, TP 청산맵·SL 돌파점) 기계화 검정 2회 불통과 → 레짐 모델 설계(`docs/design/regime_model_design_20261102.md`) → 오라클 상한 3회 불통과(ER 라벨은 예측 불가) → 레벨×변동성 불통과 → 크기 감사·시뮬.
3. 사용자 «수익은 내가 낼 것, 분별 정확도만» → 라벨을 «가장 가까운 지지~저항 띠 4h 이탈»로 바꿔 사전등록 → 시험 1회 통과 → 미학습 5코인 제로샷 통과.
4. 서빙 모듈·패리티 테스트·전진 기록기·크론 래퍼 → 사용자 «풋프린트 카드 7일 예측 칸을 이번 모델로» → API·화면·배포·서빙 바이트 확인 → 서브 에이전트 2개 독립 검증 통과.

## 한계 · 남은 일
1. **전진 증거 없음**: 배포 모델은 2026-10-23 까지 in-sample. 전진 판정 제안(사전등록 필요): 4주, 정확도 ≥ 기하 기준선(61.8%) + 3%p 이고 확신 0.6↑ 정확도 ≥ 80%.
2. 정확도는 «띠 이탈» 라벨에 대한 값이고 수익이 아니다. 이 판별로 만든 매매 규칙은 검정 통과 못 했다.
3. 기존 «박스 유지 확률»(AUC ~.79)과 같은 라벨 비교 미실시. 화면에 둘 다 있으면 헷갈릴 수 있다.
4. 개선 후보: 레벨 결측 행 라벨 NaN 처리 · API 응답의 NaN 방어 · 툴팁에 «0.8↑는 약 3%뿐» 추가 · 4코인 스냅샷 생산 스크립트를 저장소에 포함.
5. 이 세션 대화 중 정정: «0.8↑ 95%를 전체 시간의 16%»라고 한 것은 오류(0.8↑ 약 3%, 0.6↑ 약 16%).

## 정정 2 (2026-11-02, 사용자 지적 «차트를 보니 파랑이 오히려 추세 같다»)
- 칸 이름 «횡보·추세»가 실제 의미와 어긋났다. 모델이 맞히는 것은 «앞으로 4시간 안에 가장 가까운 지지~저항 띠를 종가로 벗어나느냐»이고, 방향성/추세의 곧음이 아니다.
- 근거(시험 4코인 13,908건, 판정 뒤 4시간): 횡보 판정 순변동 56bp·범위 104bp·효율비 0.13 · 애매 72·132·0.14 · 추세 판정 101·183·0.14 → **방향성(효율비)은 판정과 무관**(p 와 효율비 상관 0.03), 이탈 판정 뒤에는 움직임의 크기만 크다. 그림의 이틀(XRP, 확정 29건)은 횡보 판정이 오히려 더 크고 곧게 움직였다(순변동 69 vs 58bp, 효율비 0.14 vs 0.10; 표본 작음).
- 이유: 띠가 변동성에 비해 넓으면 한 방향으로 꾸준히 올라도 «띠 안»(예: 10-23 06~15시 KST 약 +2%), 좁으면 흔들리기만 해도 «띠 이탈». 방향성 라벨(ER)은 처음 시도했고 예측 불가였다(AUC .52~.54).
- 조치: 칸 이름 **«띠 안·이탈»**, 판정 «띠 안 / 띠 이탈 / 애매», 툴팁에 «방향도 추세의 곧음도 말하지 않는다» + 위 수치. 모델·정확도는 그대로. (PR: claude/regime-card-rename)
