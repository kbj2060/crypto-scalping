Odyssey4 라이브 딥러닝 모델 — 3-Head BatchEnsemble TabM

h48qual·zig075 두 컴포넌트가 공유하는 단일 신경망 아키텍처를, 실제 순전파(forward) 순서를 따라 5단계로 나눠 그렸다. 학습 절차·데이터 파이프라인은 다루지 않고 구조만 다룬다.

k=8 (BatchEnsemble) hidden=192 layers=3 → 잔차블록 2개 dropout=0.08 활성화=SiLU 파라미터 118,552개 헤드 3개

개요

입력 한 개의 벡터가 5단계를 거쳐 세 갈래(direction / quality / exit)의 확률로 나온다. 아래 5개 상자가 이 문서 하단 Stage 1–5와 그대로 대응한다.

이 모델이 시스템에서 차지하는 위치

아래 순전파 5단계는 이 신경망 하나의 내부다. 그런데 라이브에는 이 신경망의 독립적으로 학습된 인스턴스가 6개 존재한다 — h48qual(품질 임계값 0.50)·zig075(0.75) 두 컴포넌트가 각각 bull/bear/chop 레짐별로 별도 가중치를 갖기 때문이다. 레짐 라우터는 신경망이 아니라 손수 구현한 sticky Gaussian HMM이며, 현재 bar가 어느 레짐인지에 따라 두 컴포넌트가 각자 보유한 3개 인스턴스 중 하나씩만 활성화한다.

모델 내부 — 순전파 5단계

STAGE 1

입력 & BatchEnsemble 아핀 변환

115차원 입력 하나를 k=8개의 학습된 원소별 scale·bias로 복제·변형해 8개의 서로 다른 "관측"을 만든다. 이게 이 모델이 8개의 독립 네트워크 없이 앙상블 다양성을 얻는 지점이다 (TabM 논문 arXiv:2410.24210의 BatchEnsemble 수식 중 R 항에 해당, S·B는 미구현).

xk = x.unsqueeze(1) * self.input_scale.unsqueeze(0) + self.input_bias.unsqueeze(0)
STAGE 2

입력 프로젝션 + 정규화

8개 멤버 전부 같은 가중치의 Linear(115→192)를 통과한다 — 다양성은 이미 Stage 1에서 주입됐고, 여기서부터는 가중치를 공유한다. 뒤이은 LayerNorm·SiLU·Dropout도 마찬가지로 8개 멤버가 같은 파라미터를 공유한다.

STAGE 3

잔차 인코더 블록

블록마다 다시 한번 원소별 스케일(expert_scale)로 8개 멤버를 갈라놓고, 공유 Linear(192→192) → Norm·SiLU·Dropout을 거친 뒤 블록 입력과 항등 스킵(residual add)한다.

↻ ×2 반복 — 블록 0 → 블록 1, 각 블록의 파라미터는 서로 독립
STAGE 4

헤드 3분기

잔차 블록을 다 통과한 은닉 상태 h 하나가 서로 독립적인 3개의 선형 헤드로 동시에 들어간다. 세 헤드 모두 같은 h를 보되, 헤드끼리 가중치나 표현을 공유하지 않는다.

{"direction": direction_head(h), "quality": quality_head(h), "exit": exit_head(h)}
STAGE 5

앙상블 평균

각 헤드의 로짓을 클래스 축으로 softmax한 뒤, k=8 멤버 축으로 평균낸다. 이 순간 8개의 "다른 관점"이 하나의 확률로 합쳐진다 — 개별 멤버 가중치를 따로 두지 않고도 앙상블 효과를 내는 BatchEnsemble의 핵심이다.

torch.softmax(out["direction"], dim=-1).mean(dim=1) # quality/exit도 동일

스펙 요약

앙상블 방식TabM 스타일 BatchEnsemble — 논문(arXiv:2410.24210)의 R(사전 곱)만 구현, S·B(사후 스케일·바이어스)와 piecewise-linear 수치형 임베딩은 미구현
k (앙상블 멤버 수)8
hidden192
layers3 → in_proj 1개 + 잔차 블록 2개
활성화SiLU
정규화LayerNorm(192), Dropout 0.08
입력 차원115 = base 102(기술적·오더플로우·OU 96 + 레짐3-current HMM 확률/신뢰도 6) + position-state 13
direction_headLinear(192→3) — cash / long / short
quality_headLinear(192→3) — action별 신뢰도, 진입 게이트로 사용
exit_headLinear(192→2) — hold / exit, 임계값 0.95에서 청산
총 파라미터118,552
독립 인스턴스6개 = 컴포넌트(h48qual·zig075) × 레짐(bull·bear·chop), 가중치 공유 없음

이 구조(R-only, 임베딩 없음, residual 있음, k=8)는 논문대로 S·B·수치형 임베딩까지 완성하거나 residual을 제거하거나 k=32로 키우는 N≥5 시드 재검증에서 전부 현재 구조를 이기지 못해 2026-08-16 최종 종결됐다 (docs/experiments/eth_candidate_faithful_tabm_batchensemble_20260816.md).
