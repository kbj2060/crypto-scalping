## F0 — 준비 게이트: **PASS**

- 모델 로드 성공 (GPU 사용), lookback=400시간·pred_len=20시간 단일 윈도우 추론에서
  NaN/Inf 0건.
- 예측 종가가 실제값과 비슷한 스케일(예측 ~4300, 실제 ~4350~4400) — 발산 없음.
- **사전학습 오염 조사**: 저장소 README/문서에 명시적 학습 데이터 컷오프 날짜를
  찾지 못함. 논문(arXiv 2508.02739)이 2025-08에 최초 게시된 점으로 미루어 사전학습
  데이터는 우리 val 구간(2025-09~) 이전일 가능성이 높으나, **이는 추정이지 확인된
  사실이 아니다** — camera-ready 체크포인트가 이후 데이터로 갱신됐을 가능성 배제 못 함.
  → `pretrain_overlap` 판정은 "불확실, 중간 신뢰도"로 기록.

## F1 — Zero-shot Sanity: **KILL 게이트 발동, 트랙 종료**

25개 롤링 윈도우(탐색 구간 내 균등 분산, lookback=400h, pred_len=5h, 윈도우당 5회 샘플링):

| 지표 | 값 |
|---|---|
| Kronos 방향 정확도 | **56.0%** |
| 모멘텀 벤치마크(직전 6시간 부호) 정확도 | **60.0%** |
| 동전 던지기 | 50.0% |
| 불확실성(q10-q90 폭) vs 실현 전방 이동폭 스피어만 상관 | **0.025** |

**판정 기준 (설계 문서 F1 kill gate)**: "방향 정확도가 모멘텀 벤치마크 이하 **이고**
불확실성 상관 |ρ|<0.2 → 전체 트랙 종료." 두 조건 모두 충족:
- Kronos(56.0%) < 모멘텀(60.0%) — 방향성에서 단순 모멘텀보다 못함.
- 불확실성 폭이 실제 변동폭과 사실상 무상관(ρ=0.025) — 신뢰구간이 보정되어 있지 않음.

## 최종 판정: **WS-F 트랙 종료 (F2 진행 안 함)**

설계 문서가 예상한 대로다: LOBCAST/TLOB 문헌이 보고한 "모델이 새 데이터·자산에서
일반화 실패"라는 결론과 정확히 일치하는 결과. Kronos 파운데이션 모델은 이 프로젝트의
ETH 1h 시계열에서 (a) 방향성 예측이 단순 모멘텀보다 나쁘고, (b) 불확실성 추정이
실제 변동성과 무관하다 — 두 가지 잠재적 가치(방향 신호, 보정된 불확실성) 모두 부재.

**기존 스택(Sigma6/Omega4.6.1)에 피처로 추가할 근거 없음. F2(피처 기여 테스트),
파인튜닝 시도 모두 불필요 — 낮은 사전 기대치가 실측으로 확인됐으므로 재시도 우선순위
최하.**

## 한계 및 참고

- pred_len=5h(F1)로 짧게 잡았음 — 설계 문서가 언급한 "장기 호라이즌에서 TLOB류가
  상대적으로 강점"이라는 방향과는 다른 조건. 그러나 F1은애초에 "저비용 kill 게이트"이므로
  이 정도 조건에서 이미 탈락한 것 자체가 유효한 결론(design 문서 F1 취지: 값싸게
  빨리 걸러내기).
- Kronos-small(경량)만 테스트, Kronos-base는 미시도 — 하지만 F1의 실패 폭
  (모멘텀보다 4%p 낮음 + 불확실성 무상관)이 크지 않아 더 큰 모델로 뒤집힐 근거는 약함.
  재시도 우선순위는 여전히 낮게 유지.
- 25개 윈도우는 통계적으로 크지 않은 표본 — 그러나 kill 게이트 자체가 "저비용/보수적
  기각"을 의도한 설계이므로 이 표본 크기로 종료 판정하는 것은 설계 의도에 부합.
