# 실행 결과 종합 요약 (2026-07-19 01:45~02:30 KST 실행)

6개 워크스트림 전부 실제 라이브 DuckDB/거래소 데이터로 실행 완료. 설계도만 만들고
끝낸 게 아니라, 각 테스트를 끝까지 돌리면서 발견한 버그를 그 자리에서 고치고
재실행했다. 아래는 최종 판정과 실행 중 발견한 실제 이슈들의 종합.

## 실행 중 실제로 고친 버그 (설계도만으론 안 보였을 것들)

1. **WS-A**: 변동성 분위수 계산이 1분봉 절대수익률의 0값 과다로 붕괴 → 30분 롤링으로 교체.
   `microstructure_1m.mark_price`가 최근 9시간치만 채워진 것을 발견 (스키마 신규 추가,
   조용히 발생 — WS-D 감시 대상에 편입).
2. **WS-C**: q95 분위수 정의가 청산 이벤트의 극심한 zero-inflation(99.98%)으로 퇴화 →
   이벤트 지시자로 교체. 가격 소스도 mark_price 갭 때문에 kline 아카이브로 교체.
3. **WS-D**: `shadow_pnl` 컬럼 매칭이 `pnl` 문자열만 찾아 5개 DB 전부 실패 → `net_return`
   포함하도록 수정. 이후 "0인데 왜 0인지" 자동판별 로직 추가 중 con.close() 순서 버그도
   즉시 발견/수정.
4. **WS-B**: theta(체결확률 임계값)를 val이 아니라 test에서 뽑는 설계 결함을 작성 중
   스스로 발견해 val-only 그리드서치로 교정.
5. **DuckDB 락 경합**: 라이브 봇이 쓰기 중인 파일이라 모든 스크립트에 재시도 백오프 추가.
