# 단·중·장기 흐름 예측 가능성 스크린 — 2026-09-10

> 사용자: *"대시보드에 있는 재료들이 모두 5분봉 단기 정보들인데 이걸 중기·장기로 만들 수 있나? 단·중·장기 흐름을 예측하고 싶어."*
> 스크립트 `scripts/research_eth_multi_horizon_screen_20260910.py` · 산출 `tmp/eth_multi_horizon_20260910/report.json`.
> 선행 결정: 포지션 청산 감시자(§8 시리즈)는 사용자 판단으로 **배포 중단**(2026-09-10, "의미 없어 보임").

## 0. 결론

1. **재료를 중장기로 올리는 것 자체는 된다.** 증거신호 코드는 봉 수 기반이라 1h·4h 봉에서 그대로 돌고 발동률도 같다(봉당 14~16%).
   5분 발동을 일 단위로 집계하는 것도 된다. **그러나 그렇게 올린 재료는 어느 지평에서도 방향을 말해주지 않는다**(AUC 0.47~0.56, 전부 CI에 0.5 포함).
2. **방향(흐름의 부호)은 단·중·장기 어디서도 예측되지 않았다.** 일 앵커 1/3/7/14/30일, 4h 앵커 1/3/7일 전부 CI가 0.5를 품는다.
   장기(14·30일)에서 단변량 최대가 0.67~0.81까지 뜨지만 **독립 관측이 25·11개**라 검정력이 없고, 테스트 창(2025-09~2026-09)이
   하락 레짐 하나여서 OI 수준·90일 고점거리 같은 **추세 자체를 되읊는 변수**가 높게 나온 것이다(수준 변수의 in-sample 착시).
3. **변동성 레짐은 지평이 길수록 더 잘 예측된다.** 앞 RV/뒤 RV > 1.2 라벨: 1일 0.70~0.75 · 3일 0.70~0.78 · 7일 0.73~0.74 ·
   14일 0.81~0.83 · 30일 0.90~0.96. 기여는 가격·RV·DVOL·OI·롱숏비이고 증거신호 집계는 거의 0. 이것이 "중장기 흐름" 중
   **정직하게 만들 수 있는 유일한 층**이다 — 방향 없는 흐름, 즉 "앞으로 1~2주 장이 커지는가/조용해지는가".
4. 이 저장소가 가진 유일한 **중기 방향 리드**는 5분 재료가 아니라 별개 프로그램이다: 무기한 60종 횡단면 상위트레이더 롱숏비
   수준 페이드(일 보유, 표본외 +37bp/일 p=0.001, 다만 손익 94%가 꼬리). ETH 단일 자산 방향과는 다른 질문이다.

## 4. 만들 수 있는 것 / 없는 것

| 층 | 가능? | 근거 | 형태 |
|---|---|---|---|
| 단기 방향(≤2h) | ✗ | 09-08 방향축 종결, 09-10 청산모델 .535 | 이미 종결 |
| 중기 방향(1~14일) | ✗ | 본 스크린 CI 전부 0.5 포함 | 없음 |
| 장기 방향(30일+) | 판정 불가 | 독립 관측 11개, 레짐 1개 | 데이터 부족 — 2.7년으로는 못 잰다 |
| 단기 변동성(24h) | ✓ 배포됨 | AUC .836 | 「위험도」 카드 |
| **중기 변동성 레짐(7·14일)** | **✓ 새로 가능** | 0.73~0.83, CI 하한 0.64~0.70 | 24h 카드의 지평 확장. HAR-RV + DVOL·VRP + OI·롱숏비 |
| 장기 변동성(30일) | △ | 0.90+ 이나 n=11 | 표시 가능하나 정밀도 주장은 불가 |
| 중기 방향(횡단면) | △ 별개 프로그램 | 쏠림 페이드 +37bp/일, 꼬리 의존 | ETH 단일 카드가 아니라 60종 롱숏 포트폴리오 |

**권고**: "중장기 흐름 예측"을 **변동성 레짐 전망(7일·14일)** 으로 정의하면 만들 수 있고, 지금 카드(24h)의 지평 확장이라 비용이 작다
(같은 피쳐 모듈, 라벨 지평만 추가). 방향은 어느 지평에서도 근거가 없으니 화면에 "상승/하락 전망"으로 내보내면 안 된다.
방향을 정말 원하면 ETH 단일 자산이 아니라 횡단면 프로그램이 유일한 실측 리드다.
