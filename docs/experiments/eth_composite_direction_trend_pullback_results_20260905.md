## 2. C1 방향 — 다중신호 합의 (multi-signal consensus)

R은 같은 봉·같은 측면에서 여러 신호가 동시에 발동해도 한 건으로 뭉갠다. 그 **다중도**를 살렸다.
`m_same` = 과거 W봉(0/3/12, 미래 금지) 안 같은 측면 첫발동 **서로 다른 신호 개수**.

| 창 | W=3 다중도별 행 평균 bp (m=1 → m≥5) |
|---|---|
| TRAIN | **+1.15 → +5.79 → +8.55 → +10.57 → +12.96** (완벽한 단조) |
| VAL | +4.68 → +2.86 → +2.66 → −0.22 → +12.06 (단조 아님) |
| OOS | +4.25 → +10.23 → +12.95 → −1.58 → +8.76 (단조 아님) |

**TRAIN의 아름다운 단조성이 두 확인 창에서 전혀 재현되지 않는다.** W=0/W=12도 같다(TRAIN 단조, VAL/OOS 붕괴).
팔로 만들면 전부 R에 진다 — `m_same≥2`(W0): VAL −14.6 [−33.0, +3.4] / OOS **−28.8 [−48.6, −10.3]**.
건당 기대값은 오르는데(OOS `m≥3` +20.8bp/건) 건수가 1/10로 줄어 자본 대비 일손익이 무너진다 —
§5.27의 "cap1 붕괴 = 뭉침" 패턴과 같다. 사이징 형태(`w ∝ m_same`)만 두 창 양수(VAL +1.8 / OOS +2.3)이나 CI 0 포함.
`filter_regime_ok`(레짐 상충 제외) VAL −2.4 / OOS +2.1, `filter_b2_aligned`(retail_shift 정렬) VAL −8.0 / OOS −20.3 — 둘 다 기각.

> ⚠️**이건 "TRAIN만 보면 대발견처럼 보이는" 사례다.** n=12,813에 5구간 단조 그래디언트가 나오고
> 경제적 해석("여러 독립 감지기가 동시에 발동 = 진짜 큰 움직임")도 그럴듯한데, 확인 창에서 흔적도 없다.

## 4. C3 되돌림 지정가 — 역선택이 가격 이득을 압도 (그리고 그게 메커니즘 증거다)

`limit = open[i+1] − sign·k·ATR`, 유효 N봉, 체결 시 **다음 봉부터** 관리(체결 이전 고가/저가 크레딧 금지 —

**되돌림이 오는 거래가 곧 실패하는 거래다.** 역선택 손실(일별 짝비교 −26 ~ −62bp/일, 12셀 전부 CI 음수)이

메이커 7.8bp를 써도(P7.8 = +3.4~+5.9) 건수 감소를 못 메운다.

> 이건 실패이면서 동시에 **§5.23 메커니즘의 독립 확증**이다. 발동 봉이 반전 시점이라면 되돌림 진입이
> 이득이어야 하는데 정확히 반대다 — 엣지는 **되돌아오지 않는 움직임**에 있다.

(§5: 손절을 조이면 지속 쪽도 단조 악화).
