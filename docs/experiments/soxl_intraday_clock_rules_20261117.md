1. **593일에서 t −3.6 · 다중 보정 통과 · 위약 0분위였던 탐색 결과가 다음 126일에 부호까지 뒤집혔다.** 탐색 때 이미 «2024 는 0, 2025~26 만»이라는 해별 불안정이 보였다 — 그게 경고였다. 해마다 부호·크기가 갈리는 효과는 t 가 커도 확인 전엔 믿지 않는다.
2. **SOXL 은 폭이 커서 «같은 적중률이면 비용을 넘는다»는 산수는 맞지만, 폭이 큰 만큼 확인에 필요한 표본도 커진다.** 하루 한 번 거래에 표준편차 480bp 면 20~40bp 효과는 수천 일이 있어야 보인다. 장중 시계 규칙처럼 하루 한 건짜리는 이 종목에서 사실상 검증 불가다.
