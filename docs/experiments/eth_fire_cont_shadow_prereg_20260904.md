## 2. 가설과 판정 기준

- **H1(주 가설)**: 마감 트레이드의 순차 포트폴리오 평균 순손익(10bp) > 0. 백테스트 VAL +4.44 [0.7, 8.1] / OOS +6.78 [2.6, 11.4]bp.
- **H2**: 바닥 발동→숏 ≥ 천장 발동→롱 (세 창 모두 숏이 주력이었고 천장→롱은 하락장 두 창 ~0).
- **H3(2차)**: 레짐 방향 일치 필터(R2: 바닥∧bull, 천장∧bear 제외)가 건당 기대값을 올린다(백테스트 +0.3~+1.9bp).
- **H4(2차)**: ATR 하한(atr_pct ≥ 22.6bp)이 건당 기대값을 올린다(백테스트 +2.0~+2.3bp) — 비용/ATR 기계관계.

**판정 절차** (섀도우 원장만 사용, 재최적화 없음):
1. **30일 점검**(계측 무결성 위주): 진입 지연 중앙값 ≤ 30초, 슬리피지 평균 |·| ≤ 3bp, 첫발동 빈도 백테스트(24/일)의 ±30%, 놓친 봉 비율 < 2%,
   재구성 파리티(원장 진입가·ATR로 `sim_exit` 재계산 시 청산봉·손익 일치 ≥ 95%). 하나라도 어긋나면 **성과 판단 전에 러너를 고친다.**
2. **90일 판정**(독립 일수 ≈ 90, 건수 ≈ 2,000 예상, 건당 σ≈85bp → SE ≈ 2bp 명목, 일군집으로 ~3bp):
   - 마감+시가평가 평균 순손익의 일군집 CI 하한 > 0 → **사이징·실행(메이커) 설계 단계로 진행**(실주문은 별도 결정).
   - CI 상한 < 0 → **폐기**. 그 사이 → 90일 연장 1회, 그래도 애매하면 폐기.
3. **킬 스위치**: 어느 시점이든 최근 30일 평균 < −10bp이고 일군집 CI 상한 < 0이면 즉시 정지·보고.
4. 측면별로 따로 보고한다. 천장→롱이 90일에 CI 상한 < 0이면 **숏 전용 변형을 새로 사전등록**한다(사후 선택으로 흡수하지 않음).

## 3. 무엇이 이 규칙을 반증하는가
- 섀도우 평균이 백테스트 CI 밖으로 낮다(계측이 맞다는 전제에서) → 진입 규약(다음 봉 시가 vs 마크) 또는 레짐 변화.
- 슬리피지·지연이 체계적으로 불리(>3bp) → 얇은 엣지(백테스트 비용 15bp면 0)라 실행 설계 없이는 무의미.
- 첫발동 빈도가 백테스트와 30% 이상 어긋남 → 라이브 발동 정의/창 길이 불일치(L1이 못 본 것).

## 5. 사이징 제안 (섀도우는 단위 명목, 실행 시 적용 — 저장소 선물 사이징 계약 형식)
- 건당 위험 r = 0.4% equity. 손절 거리 = 5×atr_pct(중앙 28bp → 1.4%). **notional = r / (5·atr_pct)** (중앙 0.29 equity), 건당 상한 0.5 equity.
- 레버리지 3 고정 → margin_fraction = notional / 3 (중앙 0.095). 동시 5 → 총 notional 상한 1.5 equity(크로스심볼 캡 A4의 1.5와 정합).
- 예상 낙폭(단위 명목 백테스트 × 0.29): OOS −2,364bp → **−6.9% equity**, VAL −4,648bp → **−13.5%**. 손익비 0.35·승률 75%의 음의 왜도 —
  연속손실 13(F0 유사 구조) 가정 시 −5.2%. 볼타깃(atr_pct 역수) 대안은 H4 결과 후 결정.
