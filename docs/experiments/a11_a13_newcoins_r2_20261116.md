3. **A11 화면 오더블록(큰 스윙 N50)의 «옆 띠 64.9%보다 높은 68.9%» 주장은 새 코인에서 무너졌다.** 존에 되돌아오면 버티는 비율(66%)은 무작위 가격(61%)보다 높지만, 같은 높이로 위·아래 옮긴 가격대도 66% 버틴다. 즉 «최근 가격대로 되돌아오면 반응이 있다»이지 «오더블록 상자가 특별하다»가 아니다. 단기 스윙(N5) OB·FVG 는 옆 띠보다 1.5~2pp 나은 게 재현됐다(작음).
