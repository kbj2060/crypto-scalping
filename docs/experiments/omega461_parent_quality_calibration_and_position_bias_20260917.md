## 0. 한 줄

보정은 **base 에만 듣는다**(+3.80 → **+5.56bp**, 배포본 +4.94 를 넘는다). 그런데 **7/7 모델
전부 숏 다리가 롱 다리보다 낫고, 「모델−항상숏」 초과는 0/7 이 0 을 배제한다.** 보정이
헤드라인을 올리는 방식조차 **롱 다리를 먼저 자르는 것**이라 같은 이야기다.

## 1. ① 품질 보정 — 통과율을 낮추면 따라잡히는가

두 갈래였다: **(A) 순위는 멀쩡한데 보정만 헐겁다** → 임계값만 올리면 된다 ·
**(B) 순위 자체가 나쁘다** → 통과율을 맞춰도 못 따라잡는다.

보정은 두 방식으로 냈다. **온도 보정**은 TRAIN 꼬리(내부검증)에서 온도 T 와 임계값 q* 를
정하고 VAL 에 그대로 적용한다 — **VAL 을 안 보므로 이쪽이 정직한 숫자**다. 「통과율 맞춤」은
VAL 에서 고른 지점이라 선택편향이 있어 참고용이다.

| 모델 | q=0.75 기본 | 통과율 3.5% 맞춤 ⚠️ | ⭐온도보정(VAL 미사용) |
|---|---|---|---|
| **배포본** | 3.5% · **+4.94bp** | — (이미 3.5%) | — |
| **deep** (3시드 평균) | 8.3% · +0.42bp | 3.6% · +0.21bp | T≈1.28 · 5.4% · **+0.11bp** |
| **base** (3시드 평균) | 7.7% · +3.80bp | 3.7% · +5.31bp | T≈1.30 · 2.7% · **+5.56bp** |

⭐**deep 은 (B) 다.** 통과율을 반으로 줄여도 +0.21bp, 온도보정해도 +0.11bp — 보정 문제가
아니라 **순위 자체가 나쁘다**. 5.6배 데이터로 라벨은 더 잘 맞추는데(bacc 0.5803) 그
순위가 돈으로 정렬되지 않는다.

⭐**base 는 (A) 다.** 보정이 실제로 듣고 **배포본을 넘는다**(+5.56 vs +4.94).
🔴단 시드별 CI 하한은 **+0.53 / −0.07 / −2.38** — **1/3 만 0 을 배제**한다. 독립일 122 에서
이 차이를 유의하게 만들 검정력이 없다.
⚠️온도 T 는 1.25~1.35 로 미미하다. 실제로 듣는 건 온도가 아니라 **분위 기준 임계값 재설정**
이다 — 즉 "보정"이라기보다 **"덜 쏘게 만든 것"**이다.

### 읽기

⭐**① 숏 다리가 롱 다리보다 낫다 — 7/7, 보정 전후 모두.** 예외 없다. deep 은 롱 쪽이
3시드 전부 음수고, 보정하면 **−4.81bp** 까지 내려간다.

🔴**② 「모델−항상숏」 초과는 0/7 이 0 을 배제한다.** 보정 전 +1.01~+2.20, 보정 후
+0.66~+2.24 — 전부 CI 가 0 을 품는다. **「숏 편향을 넘는 실력」을 주장할 수 없다.**
대조적으로 「모델−항상롱」은 배포본·base 일부가 0 을 배제한다(+8.88 [+0.35,+18.40]) —
당연하다, 롱은 이 창에서 지는 쪽이었다. **모델−롱만 보면 실력처럼 보이고 모델−숏을
보면 사라진다.**

🔴**③ 편향이 시드마다 요동친다.** 롱 비중이 base 는 **16.1%~47.1%**, deep 은 44.1%~71.5% 로
시드 하나에 3배 가까이 흔들린다(라벨은 45/47 로 균형). **모델이 고른 편향이 아니라
잡음이다.** 시드가 정하는 값을 전략이라 부를 수 없다.

🔴**④ 보정이 듣는 방식이 곧 편향이다.** base 를 조이면 롱 비중이 31.7→25.1 · 22.3→16.1 로
**롱 다리가 먼저 잘린다.** 헤드라인 +3.80→+5.56 의 정체는 "더 잘 고르게 됐다"가 아니라
**"지는 다리를 덜 쏘게 됐다"** 다. 그래서 모델−숏은 그대로다(+1.35 → +1.32 등).

## 3. 결론

- **보정 자체는 실재하는 레버다** — base 는 +3.80 → +5.56bp 로 배포본을 넘는다. deep 은
  못 살린다(순위 문제).
- **그런데 그 이득이 「숏 편향」과 분리되지 않는다.** 모델−숏 0/7, 롱비중 시드폭 3배.
  이 창(2026-03~06)에서 잘 나온 모든 수치는 **숏 쪽에 서 있었다**로 설명 가능하다.
- ⭐이건 [[direction_4h_top5_gross_edge_candidate_20260915]]("모델 실력 아니라 고변동 꼬리의
  **롱** 편향")의 **거울상**이다. 같은 함정에 부호만 반대로 다시 걸렸다.
- **부모 교체 근거는 여전히 없다.** 보정된 base 가 헤드라인으로는 앞서지만, 유의하지 않고
  (CI 1/3) 편향과 분리되지 않으며(0/7) 시드에 흔들린다.
- 다음에 이 축을 다시 열려면 **검정력부터**다. 독립일 122 로는 모델−숏 ±2bp 를 가릴 수 없다.
  그리고 **모델−롱이 아니라 모델−숏을 1급 지표로** 봐야 한다 — 어느 쪽이 「쉬운 다리」인지
  창마다 바뀌므로, **양쪽 초과를 항상 같이** 낸다.
