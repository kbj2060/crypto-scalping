# B2(롱숏비 급변) 청산 없는 경로 방향 측정 — 방향 정보 없음 (2026-09-07)

## 왜 다시 쟀나

B2의 유일한 근거는 09-04 경제 축 스크린의 `(R∪B2)−R` 일손익(+3.3/+6.1/+7.4bp/일, **CI는 0 포함**)이었는데,
그 측정이 결함 트레일링(`sim_exit` 5.0/1.5/0.1) 위에서 이뤄졌고 09-07 수정으로 무효가 됐다.
게다가 판정 기준선인 R 자체가 −10bp로 무너져 **증분을 잴 대조군이 사라졌다.**

그래서 09-06에 지속 규칙에 적용했던 것과 같은 방법 — **청산·비용·배리어를 전부 빼고 가격 경로만으로**
규칙이 고른 방향이 실제로 더 멀리 뻗는지 — 를 B2 모집단에 그대로 적용했다.

## 방법 (자유도 0, 라이브 규칙 그대로)

`count_long_short_ratio`(metrics 덤프) → `d6 = ratio − ratio.shift(6)` → `z = (d6−mean288)/std288`(min_periods 144)
→ **lag1**(봉 T 결정은 T−5분 행까지) → `|z| ≥ 2.2616` 발동, 같은 측면 직전 12행 안 발동 없을 때만(GAP12).
방향 = **−부호**(z ≤ −T → 롱, z ≥ +T → 숏).

발동 봉 종가 `c0` 기준 이후 H봉의 최대 유리/불리 이탈폭을 재고 **규칙 방향이 더 멀리 뻗었는가**(우세 빈도)를 본다.
일군집 부트스트랩 CI. 귀무는 **같은 발동 봉·같은 롱숏 비율로 측면 무작위 배정**(B=200) — 구간 드리프트를 상쇄한다.

발동 2,213건(TRAIN 1,572 / VAL 346 / OOS 295), 665일. HOLDOUT 미접촉.

**두 창이 동시에 0.5를 유의하게 넘는 지평이 하나도 없다.**

- **규칙이 실제로 쓰는 지평(200봉 = 배포 셀의 시간청산)에서 VAL·OOS 둘 다 CI가 0.5를 포함한다.**
- 유일하게 VAL이 CI로 0.5를 넘긴 H12는 **OOS에서 부호가 뒤집힌다**(0.5549 → 0.4610, 귀무 백분위 98 → 8).
  전형적인 VAL/OOS 부호 반전이며, 짧은 지평일수록 강해 보이는 건 규칙 설계와도 어긋난다.
- 귀무 평균이 전 지평 ≈0.500이라 이 구간의 시장 드리프트는 대칭이었다 — 비교가 깨끗하다.
- `ALL` 열이 H48에서 0.5183 [0.5000, 0.5374]로 하한이 정확히 0.5인데, ALL의 71%가 TRAIN(발견 집합)이라 증거가 아니다.
