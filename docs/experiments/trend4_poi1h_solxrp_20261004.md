## 1. 사전등록 (결과를 보기 전에 고정, 2026-10-04)

### 정의 — 엔진(`scripts/rl_1s_agent.py`)과 같게
- **trend4**: 매일 00:00 UTC, 완결 일봉 종가로 `sig = mean(sign(c[-1] − c[-1−L]), L∈{7,14,21,28})`. 목표 = sign(sig)(1배), sig=0 이면 관망. 그날 하루 보유.
- **trend4_vs**: 같은 방향 × `k = |clip(sig·0.5/σ20, ±2)|`(σ20 = 직전 20개 일 로그수익 표준편차×√365). **엔진 그대로 k 는 새 진입(목표≠현재 포지션) 때만 바꾸고 보유 중엔 고정.**
  원 연구판(매일 크기 재조정, 신호 분수 그대로)은 ETH 재현용으로만 따로 낸다.
- **poi1h**: 정시 H 마다 직전 1시간 로그수익(5분 수익 12개 합) ≤ POI_DOWN_BP(코인 자기 4.7년 25분위)이면 ΔOI 1시간(5분 OI 변화율 12개 합) < 0 → 롱, > 0 → 숏, 다음 정시까지 1시간 보유. 아니면 관망.
  - 진입 = 정시 봉 종가(엔진과 같음). 판정 코드는 엔진 `ArmPolicy("poi1h")` 를 직접 돌려 벡터 구현과 포지션이 일치하는지 assert.
- 일봉·5분봉 원천 = `data/binance_vision/panel/{SYM}.parquet`(2022-01-01 ~ 2026-09-14, 세 코인 같은 원천·같은 격자). 펀딩 = data.binance.vision 월별 fundingRate. ETH 현물 재현 = data.binance.vision 현물 1d 월별.
- 🔴**OI 스탬프**: metrics 원천마다 규약을 먼저 잰다(코인별 «ΔOI ↔ 같은 봉/직전 봉 수익» 상관, 전환 전후). 기본값: 2024-03-04 이후 행 t = t+5분 스냅샷, 그 전 행 t = t 스냅샷 ⇒ 봉 마감 OI 로 정렬. 트립와이어: OI 를 한 봉 더 늦춰도 결론이 유지되는지.
