## 숫자를 그대로 믿으면 안 되는 부분
1. **SOXL·나머지의 «+5pp»는 대조가 약해서 커 보인다.** 검증(9월)에서 고른 기준선 «따라가기»가 시험에서 48.7% 로 뒤집혔다. 같은 확신 행에서 네 기준선을 전부 보면 거스르기 51.3% · **늘 내림 52.4%** · 따라가기 48.7% · 늘 오름 47.6% 다. 가장 좋은 단순 규칙(늘 내림) 대비 모델의 몫은 **+1.4pp** 다. 판정은 사전등록대로 «통과»지만 실질 우위는 그 정도다.
2. **SOXL·나머지의 우위는 숏 신호에만 있다.** 롱 신호 932/1,803 = 51.7%·평균 −0.7bp, 숏 신호 1,411/2,555 = 55.2%·평균 +4.7bp. 시험 구간(10~11월)은 SOXL 이 내린 기간이다(15분 오름 비율 48.1%) — 방향 실력과 하락 국면이 섞여 있다.
3. **맞힌 비율이 돈으로 거의 안 바뀐다.** 확신 행의 방향 맞춘 평균 수익(비용 전): ETH·활발 +0.6bp · ETH·나머지 −0.1bp · SOXL·나머지 +2.5bp · SOXL·활발 −4.0bp. ETH 는 맞힐 때 폭이 틀릴 때 폭보다 작다. SOXL·나머지는 이긴·진 폭이 같고(평일 64 대 65bp, 주말 22 대 23bp) 정확도 몫만큼만 남는다 — 왕복 비용(메이커 진입 0~2bp + 테이커 청산 5bp)보다 작다.
4. **ETH 모델은 사실상 «직전 15분 거스르기»다.** 모델 신호가 거스르기 규칙과 같은 비율: ETH·나머지 81% · ETH·활발 70% · SOXL·나머지 60%. 지표 45개를 넣어도 단순 되돌림 규칙에 +0.65~+2.1pp 를 더할 뿐이다.
