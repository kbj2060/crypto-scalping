## 배경 / 가설

`eth_h48qual_zig075_quality_label_base_rate_direction_check_20260811.md`에서 "숏 쏠림이 학습
라벨 자체의 base rate 불균형 때문"이라는 가설을 직접 반증했다(h48qual 학습 라벨은 균형,
zig075는 오히려 롱 쪽 쏠림). 그 문서 말미에 남겨둔 미검증 대안 가설이 이것이다:

> `quality_head`가 실제로는 독립적인 "품질" 신호를 추가하는 게 아니라, `direction_head` 자체의
> confidence를 그대로 반영/증폭하는 것 아닌가? 그리고 그 confidence가 하락장(VAL/OOS) 레짐에서
> 방향별로 비대칭적으로 커지는 것 아닌가?

이 문서는 이 가설을 4단계로 직접 검증한 결과다. 재사용 데이터: 오늘 다른 진단에서 이미 쓴
저장된 예측 CSV(`train/validation/oos_predictions_q050.csv`, `q075.csv`) 그대로, 재학습 없음.

## 방법: 공식 검증부터

가정하지 않고 소스에서 직접 확인(3개 독립 코드 경로에서 오차 0으로 일치):
- `dir_confidence = max(dir_p_cash, dir_p_long, dir_p_short)` (`trading_bot_modules/omega4_6_1_live.py:200`, `scripts/build_fixed_seed_prediction_ensemble_20260729.py:100`)
- `dir_action = argmax(...)`이므로, 액티브(non-cash) bar에서 `dir_confidence`는 정확히 "이긴 클래스의 확률"과 동일함을 행 단위로 검증(오차 0) — 이게 이 문서에서 쓰는 `winning_dir_prob`.
- 게이트 공식: `quality_for_action = quality[dir_action]`; `final_action = dir_action if (dir_action≠cash and quality_for_action≥threshold) else cash` — 기존 문서와 정확히 일치(불일치 0건).
- train/validation 파일은 `_oof` 접미사, oos 파일은 접미사 없음(`prediction_export_q045_q050_20260630.json` 계약으로 확인) — 이 차이를 몰랐다면 컬럼을 잘못 짚었을 것.

**기존 문서 대비 재현성 검증**: 게이트 전/후 숏비중·게이트통과율 12개 숫자 전부 기존
h48qual/zig075 추세편향 문서와 정확 일치 또는 반올림 오차 수준으로 일치 — 파일/컬럼을 올바르게
짚었다는 강한 근거.

## 해석: 부분 지지 — "증폭" 메커니즘은 맞고, "레짐 유발"은 틀렸다

1. **확인됨 — direction_head confidence는 방향별로 비대칭이다**(숏이 롱보다 확률 3~5pp 높음,
   두 번들 다, 압도적 유의).
2. **반증됨 — 레짐(하락장) 때문에 생기는 현상이 아니다.** 다양한 레짐이 섞인 학습 구간에서
   이미(오히려 더 크게) 나타나고, 하락장인 VAL/OOS에서는 약간 줄어든다. "최근 하락장이라
   direction_head가 숏에 더 확신을 갖게 됐다"는 서사는 성립하지 않는다 — **학습 시점에 이미
   박혀 있는, 모델의 지속적인 보정(calibration) 특성**으로 보인다.
3. **확인됨 — confidence 단독 필터가 실제 게이트 결과 대부분을 재현한다**(6건 모두 4.3~6.5pp
   이내). `quality_head`를 거치지 않고 "direction_head가 가장 확신하는 bar만 고른다"만 해도
   게이트 후 숏 쏠림과 거의 같은 숫자가 나온다 — "게이트가 실질적으로 confidence 필터 역할을
   하고 있다"는 프레이밍의 가장 강력한 근거.
4. **"quality_head가 아무 것도 안 더한다"는 아님 — 혼재된 결과**: zig075의 ρ≈0.95는 라벨
   설계상 구조적으로 예상된 결과라 독립적 증거가 못 된다. h48qual은 ρ 0.18~0.43로 confidence
   단독 설명보다 분산이 크다 — 다만 기존에 이미 닫힌 진단(순위상관·회귀전환·앙상블-disagreement)
   에서 이 독립 분산이 실현 수익률과 상관없다는 게 확인돼 있으므로, "신호"라기보다 "노이즈"에
   가깝다.

**수정된 메커니즘**: direction_head 자체가 (레짐과 무관하게) 숏 콜에 더 높은 confidence를
부여하도록 학습되어 있고, `quality_head`의 게이트는 이 기존 confidence 패턴을 대체로 그대로
통과시킨다(일부는 완충, 한 경우만 소폭 증폭). 즉 문제의 근원은 `quality_head`가 아니라
**direction_head의 confidence 보정 자체**에 더 가깝다 — 다만 direction_head의 argmax 픽 자체는
이미 균형(53~59%)인 것으로 확인돼 있으므로, "무엇을 고르는가"는 괜찮은데 "얼마나 확신하는가"가
방향별로 비대칭이라는, 더 좁혀진 문제다.

## 왜 이런 비대칭이 학습 시점부터 있는지는 아직 미확인 (추측)

`eth_zig075_quality_trend_bias_control_20260811.md`에서 OOS 구간 한정으로 확인했던 "숏 스윙이
더 뚜렷하다(wave_return/path_edge 측면에서)"는 관찰과 방향은 같지만, 그건 OOS 국소 현상으로
확인됐던 반면 이번 confidence 비대칭은 학습 구간부터 일관되다. 가능한 설명(검증 안 됨,
추측 수준): 암호화폐/주식 시장에서 흔히 관찰되는 "하락은 상승보다 빠르고 가파르다"는
비대칭(레버리지 효과, 패닉 청산 등) 때문에 zigzag/배리어 라벨의 숏 스윙이 롱 스윙보다
평균적으로 더 "교과서적"이라 모델이 더 쉽게, 더 확신 있게 학습했을 가능성. **이건 이번
진단 범위 밖이며, 확정하려면 방향별 스윙의 가격 패턴(변동성, 지속시간, 각도) 자체를 학습
구간 전체에서 직접 비교해야 한다.**

## 결론 (요약)

"quality_head가 direction_head의 confidence를 증폭시키는 것 아니냐"는 가설은 **부분적으로만
