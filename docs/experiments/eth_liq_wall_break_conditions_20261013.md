# 향하는 쪽 가까운 청산벽을 «뚫는» 조건 — ETH 4.7년 + 실측 청산 (2026-10-13)

사용자: «현재 가격이 향하는 방향으로 가까운 청산벽을 뚫는 조건들을 4년치 데이터로 분석해서 실시간 데이터와 정리된 피쳐들을 가지고 연구해줘»

스크립트 `scripts/research_eth_liq_wall_break_conditions_20261013.py` (`--build` · `--test` · `--rt` · `--selftest`) ·
산출 `tmp/liq_wall_break_20261013/{events.parquet, report.json, conditions.csv, wall_specific.csv, report_rt.json}`.

## 한 줄 결론
**뚫을지 튕길지는 «지금 가격이 벽 안 어디쯤 있나»(거리비)가 거의 다 정한다.** 거리비 하나로 정확도 65~66%·AUC .71~.73이 나오고,
피쳐 57개(모멘텀·체결·OI·포지션·호가·BTC·벽 질량)를 모두 더해도 ΔAUC는 +.001~+.003이며 CI가 0을 포함합니다.
2022~24년에는 «거래량·체결이 터지며 닿으면 청산벽에서만 더 뚫린다»(+5~7pp, 위약 0)가 실제로 있었지만, 2025년 이후에는 1/2~1/3로 약해져 판정 기준을 통과하지 못했습니다.

## 정의 (사전등록, 스크립트 docstring)
- **벽**: 대시보드 풋프린트에 «보이는» 청산 띠(liqBandEdges 임계 0.25). 10-12 `edges_long` 캐시를 썼고, 행 t는 5분봉 끝에 알 수 있는 값입니다.
- **사건**: 5분봉 k가 직전 봉 끝 지도의 위(아래) 가장자리 E를 닿고, 직전 종가는 벽 밖에 있을 것. 방향 = 닿은 쪽 = 가격이 향하는 쪽. 같은 쪽은 1시간 쿨다운.
- **라벨**: 봉 k가 끝난 다음 1분부터 4시간 동안 1분 고·저가로 판정. **뚫음** = 띠 끝 F + 0.1%에 먼저 닿음, **튕김** = E에서 같은 거리만큼 반대로 먼저 닿음.
- **기하 기준선** p0 = (종가 − 튕김선)/(뚫음선 − 튕김선). 드리프트가 없을 때의 뚫음 확률입니다. 모든 조건은 잔차 (y − p0)로 읽습니다.
- **위약 벽**: 7일 전 같은 봉의 «가장자리·띠 끝까지 상대 거리»를 지금 가격에 얹은 선입니다. 사건·라벨·피쳐는 같습니다.
- **구간**: DEV 2022~24 · VAL 2025 · TEST 2026-01~10-10. **주 판정은 RECENT(2025~)**입니다.
- **조건 통과 기준**: DEV 5분위 경계로 나눈 Q5−Q1 잔차 차가 RECENT 일 블록 95% CI에서 0을 제외하고, DEV와 부호가 같고, 크기가 2pp 이상일 것.
- 실제 벽 27,839건, 위약 29,387건. 그중 15.2%는 닿은 그 5분봉 안에서 이미 결정(종가가 배리어 밖)됐고(위약 12.7%), 14.7%는 4시간 안에 결론이 나지 않아 제외했습니다.

## 4. 실시간 데이터 — 실측 청산(바이낸스 forceOrder, 07-19~10-10, 80일)
«밀리는 쪽 청산이 터짐» = 닿은 봉에서 향하는 쪽으로 밀리는 포지션의 청산(위 벽이면 숏 청산)이 직전 7일 90분위 이상인 경우.
- 실제 벽 사건의 71%가 «터짐»이고, 위약 선은 40%입니다. 청산맵이 실제 청산이 나는 «위치»는 맞춘다는 09-20 결과와 같습니다.
- 터짐 vs 안 터짐 잔차 차: 실제 **+9.0pp [+1.5, +17.6]** (614건) · 위약 +2.0 [−3.0, +8.2].
- 🔴**결과를 본 뒤 통제**: 닿은 봉 거래량·폭·델타·15분/1h 모멘텀을 함께 넣으면 계수 .26(p .24)로 사라집니다. 기간 반분은 +2.3pp / +15.8pp로 흔들리고, 거래량 3분위 안에서는 +6.9 / −0.3 / +3.8pp입니다.
  ⇒ 대부분 «닿은 봉 거래량»이 대신 설명하는 몫이고, 80일로는 따로 떼어 낼 수 없습니다. 후보 수준입니다.

## 쓸 곳
- 화면의 «뚫을까?»는 **거리비 b/(a+b)**로 이미 거의 정확합니다(10-10 «먼저 닿음 = 기하» 결과와 같음). 별도 신호는 필요 없습니다.
- 남은 후보 두 가지(벽 쪽 호가가 얇음, 밀리는 쪽 청산 터짐)는 둘 다 «벽 특이» 방향으로 맞지만 다중검정 수준입니다. 쓰려면 전진 사전등록이 필요하고,
  청산 쪽은 거래량을 통제한 판정이어야 합니다. 판정 가능 시점은 대략 사건 1,500건 이상(지금 속도로 약 6개월 뒤)입니다.
