## G4/G5/G6 정의

- **G4 완전 하모닉(XABCD)**: 최근 5개 교대피벗의 4구간 비율을 Gartley/Bat/Butterfly/Crab

- **G5a Elliott 5파동 완성**: 최근 6피벗이 교과서 규칙 2개(파동2 미돌파, 파동3 비최단) 동시충족.
- **G5b ABC 조정 완성**: 3구간 조정에서 C파동 길이가 A파동의 0.618~1.618배.
- **G6 Gann 부채꼴 터치**: 가장 최근 확정피벗에서 투영한 0.5/1.0/2.0×ATR/bar 기울기 라인에
  가격이 0.25×ATR 이내로 접근.

## 표본 문제 — 풀링창(VAL+OOS)에서는 진짜 테스트 불가

기존 관례대로 VAL+OOS 풀링창(48,853봉)에서 먼저 실행 → **G4/G5a/G5b 전부 n=0**(복합조건이라
4.5개월로는 안 걸림), G6도 n=1(무의미). 이건 "기각"이 아니라 "표본 자체가 없어 테스트가
성립 안 함" — 임계값을 낮췄으면 더 자주 걸렸겠지만 그건 튜닝이므로 안 함. 대신 **신호 정의는
그대로 두고 평가창만 정직하게 확장**(전체 가격프레임 커버리지 2024-01~2026-02, zigzag_action
2024년 라벨 추가 로드 — 새 컬럼/파생 없음, 순수 창 확장).
