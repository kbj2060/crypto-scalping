## 1. 가설
H. 대시보드 4분할 기계(핑퐁 페이드 진입)에서, «가격이 15분 동안 내 반대로 σ15 이상 움직이는데 OI 가 급증(zOI15 ≥ +2)»하면 바로 정리하는 규칙은,
같은 거래들을 같은 보유시간 분포로 시간 청산한 것보다 크기 가중 건당 손익이 높다(«신호가 보유 길이 이상의 정보를 준다»).

## 2. 고정 정의 (코드 = 위 스크립트, 바꾸려면 새 사전등록)
- **데이터**
  - ETHUSDT USDT-M 1분봉(data.binance.vision 일별, 이전 사전등록 `prereg_eth_pingpong_vol_sizing_fwd_20261007.load_all`).
  - 5분 패널(`data/binance_vision/panel/ETHUSDT.parquet`) + 그 뒤 날짜는 같은 빌더 함수(`build_binance_vision_panel_20260915.day`)로 일별 5분 klines·metrics. 바이낸스 REST 는 쓰지 않는다.
- **후보**: 이전 사전등록 `candidates()` 그대로(인과 지그재그 0.5% · 다리 ≥ 40bp · 극값 10bp 안 · 5분 마감 · 같은 다리 첫 건). 진입 = 다리 반대, 다음 1분 종가.
- **기계(대시보드 규칙)**
  - 첫 진입 + 첫 진입가 대비 44·88·132bp 역행에 1단위씩(균등 4분할, 지정가 0bp).
  - 손절 = 첫 진입가 ∓ 3·σ24. σ24 = √(Σ 직전 288개 완결 5분봉 로그수익(bp)²), 결정 직전 마감 봉까지.
  - 익절 없음(대시보드 브래킷과 같음) · 최대 24h · 손절/시간/신호 청산 테이커 5bp(체결 단위당).
  - 크기 = 대시보드 «크기 ∝ σ» 배수 size_mult(σ24/√6) = clip(σ24/√6/157.394, 0.25, 3)/0.76576.
  - 후보마다 독립으로 매긴다(겹침 허용, 일 단위로 묶어 재표집).
- **X4 신호**: 5분봉 마감에 15분 수익이 포지션 반대로 ≥ σ15(= σ24/√96) **그리고** zOI15 ≥ +2.
  - zOI15 = ln OI 15분 변화의 강건 z(직전 2016봉의 중앙값·IQR/1.349, 그 봉 제외). OI 는 스탬프 규약 보수로 1봉 지연.
  - 신호 봉 마지막 분 마감에 알고, 다음 1분 종가로 정리.
- **비교선(주)**: 같은 거래들의 X4 보유시간(분)을 거래끼리 섞어 시간 청산(신호 없음), 시드 20261008 로 20번 평균.
- **보조 1**: X4 − 무신호(손절/24h만) 크기 가중 건당 손익 > 0(부호만).

- 통계 = 크기 가중 건당 (X4 − 비교선) 평균. z = 평균 / SE, SE 는 UTC 일 재표집 부트스트랩 5,000회 표준편차.
- **확정**: z ≥ 문턱 **그리고** 보조 1 > 0.
- **기각**: 어느 점검이든 z < 0 이면 중단한다. 최종에서 z < 1.98 이어도 기각이다.
- 보고 전용: X4·비교선·무신호 각각의 크기 가중 건당 손익, 신호 청산 비율, 손절 비율.
