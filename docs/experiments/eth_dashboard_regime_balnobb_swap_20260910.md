# 대시보드 레짐 분류기 S12_K3 → balnobb 교체 (2026-09-10)

사용자 지시: *"모델 파일이 서버 쪽에 있나봐. balnobb으로 대시보드도 교체해줘."*

## 0. 사실 확인 — 두 분류기는 완전히 달랐다

질문의 출발점은 "대시보드 레짐 분류기와 오메가4.6.1 balnobb 이 같은가"였다. **아니다.**
같은 것은 **모델급(GBM3_HP)과 136 feature_cols/medians** 뿐이고 라벨·학습창·debounce 가 다르다.

| | 대시보드 (교체 전) | 오메가4.6.1 `balnobb` |
|---|---|---|
| 라벨 | scale-parameterized RegimeEngine — **효율비** er_12/er_24 | `balancedish_adx16_slope15` **− BB 덮어쓰기** |
| 임계 | T1 er12 .2875 / T2 er24 .2253 | adx≥16 · slope≥1.5e-4 · adx<12 chop |
| debounce | 라벨에 **K=3** 확인 | **K=0** |
| 학습창 | 2024-01-01 ~ **2026-06-30** | **≤2025-09-30** (`cut2509`) |
| TRAIN 배분 | bull .228 / bear .214 / chop **.558** | bull .273 / bear .262 / chop **.464** |

두 라벨의 상호일치는 **69~71%**, κ **0.43~0.47**(`omega461_regime_label_ab_balgbm_vs_s12k3_20260909.md`).

서빙 경로: `dashboard/server.py:128` 이 `live_regime_gbm3_signal_20260826` 을
`compute_regime_wide24_signal` **옛 이름 알리아스**로 임포트한다 — 엔드포인트 이름이
`regime-wide24` 라 HMM 처럼 보이지만 실제 서빙은 GBM 이다. **표시 전용**(리본 + 청산맵 오버레이),
트레이딩 경로는 소비하지 않는다(s12k3 트레이너 docstring 에서 확인·기록됨).

## 2. 왜 오메가 아티팩트를 그대로 얹지 않았나
`cut2509`(≤2025-09-30) 컷오프는 **오메가 라인의 VAL(2025-10~12)/OOS(2026-01~02) 보호용**이다.
대시보드는 그 제약이 없고 현행 s12k3 는 2026-06-30 까지 학습돼 있다 — 그대로 얹으면 **11개월
낡은 모델로 후퇴**한다. 그래서 **라벨만 가져오고 학습창은 대시보드 것**을 썼다.
트레이너 `scripts/train_eth_regime_balnobb_dashboard_20260910.py` 는 s12k3 트레이너의 near-copy로,
**바뀌는 것은 학습 타깃 하나뿐**이다(HP·피쳐·SEED·아티팩트 스키마 동일 → 라이브는 한 줄 변경).

## 3. ⚠️사전 우려가 실측으로 뒤집혔다 — debounce 불필요

s12k3 가 채택된 근거 자체가 **리본 떨림을 절반으로 줄인 것**이었다(예측 flip .0965 vs .1803,
"visibly flickery" 민원이 GBM2 프로젝트를 낳았다). balnobb 은 K=0 이라 그 축을 되돌릴 것으로
예상했고, 계약에도 "OOS 전환 1,674회 · 상태의 48% 가 5봉 이내"가 적혀 있었다. **틀렸다.**

평가창 2026-07-01~08-19 (14,400봉, **두 모델 모두 미학습**), 예측 라벨 기준:

| 안 | flip | 중앙지속 | 전환수 | ≤5봉 비율 | 추세비중 |
|---|---|---|---|---|---|
| 배포본 s12k3 (라벨 K=3) | 0.0965 | 7.0 | 1,389 | 0.433 | 0.439 |
| **balnobb K=0 (채택)** | **0.0781** | 7.0 | **1,124** | 0.430 | 0.373 |
| balnobb + 후처리 K=3 | 0.0553 | 10.0 | 796 | 0.235 | 0.373 |
| balnobb + 후처리 K=6 | 0.0344 | 18.0 | 495 | 0.002 | 0.371 |

⭐**balnobb K=0 이 배포본보다 오히려 안정적이다**(flip −19%, 전환 −265회). 계약의 1,674회는
**cut2509 모델을 오메가 OOS(2026-01~02)에서** 잰 값이라 이 창·이 모델에 그대로 적용되지 않았다.
⭐교훈: 다른 창·다른 학습컷으로 잰 안정성 수치를 그대로 이식해 판단하면 안 된다.
   **서빙 debounce 는 걸지 않는다(K=0).** 필요해지면 예측 위 후처리 한 줄로 되돌릴 수 있다.

예측 일치율 80.3%. 추세비중은 오히려 낮다(.373 vs .439) — 라벨은 추세가 더 많은데(chop .464 vs
.558) 모델 예측은 더 보수적이다.
