## 버그 수정 (실행 중 발견)

OI 원본에 0값 오염치 208개 존재 → `oi_chg = (oi-oi_prev)/oi_prev` 나누기 0 → inf가
7일 트레일링 z-score 롤링 통계를 오염시켜 `oi_z`의 94.5%가 NaN이 되는 버그 발견·수정
(oi≤0을 NaN 처리, z-score 계산에서 NaN 보존/스킵). 수정 전 캡츄레이션 이벤트 4개,
수정 후 165개(롱128/숏37) — 수정 없이는 사실상 무발생 판정이 나올 뻔했다.

2. **그러나 평균 vs 중앙값 괴리로 착시 확인**: 롱 50건 평균 **+58.0bp, 중앙값 -43.6bp**.
   상위 5건(최대 +1,213bp, TP 도달은 50건 중 4건뿐)이 평균을 견인 — 실제 거래 절반 이상은

   "평균≠중앙값=이상치 driven" 패턴의 재현.

4. **가장 최근 구간(2026, OOS 성격) 붕괴**: n=9, 승률 **11%**, 순손실.
5. **숏 사이드 자체 손실**: n=13, 평균 -55.5bp — 대칭 메커니즘이 반대 방향에서 작동 안 함.

## 결론

**REJECTED.** strict(사용자 설명 원문)는 gross부터 음수. loose는 1차 부트스트랩 확증은
통과했지만, 평균≠중앙값 괴리·연도 집중·OOS 붕괴·숏 실패를 모두 겹쳐보면 지속 가능한
인과 엣지가 아니라 2023-2024 단일 강세장 구간의 소수 대박 트레이드가 만든 통계적 우연으로
판정한다. 재현: `scripts/research_eth_capitulation_oi_stoch_reversal_backtest_20260824.py`
(bootstrap 확증 로직 포함), `data/research/eth_capitulation_oi_stoch_reversal_backtest_20260824.json`.

**How to apply**: 유사 "이벤트 조건부 + 느슨한 트리거"류 재제안 시 이 문서의 확증 체크리스트
