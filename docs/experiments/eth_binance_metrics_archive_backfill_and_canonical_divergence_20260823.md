# Binance metrics 아카이브 백필 + 캐노니컬 2026 OI/롱숏비 불일치 발견 (2026-08-23)

## 경위

"무료 데이터에서 신호를 만들 수 없나"라는 질문에서 출발 → data.binance.vision의
`futures/um/daily/metrics` 아카이브(5분 간격 OI/톱트레이더 롱숏비/글로벌 롱숏비/테이커
롱숏 볼륨비, **2021-12-01~전일, 무료**)를 확인 → 백필 착수 전 사용자 지시("이미 피쳐에
있는지 먼저 점검")로 기존 데이터를 전수 점검하다가 **캐노니컬 2026 파일의 데이터 무결성
문제를 발견**했다.

다만 방향상 "다음 버킷" 값이라 **해당 산발 행들은 미세한 1-bar lookahead**다(2024년 파일
~5%, ETH 2024/2025에도 0.2% 수준 동종 잔여 존재). 영향은 무시 가능 수준으로 평가하되,
차세대 재구축 시 캐시 vintage를 통일하면 자연 해소된다.
