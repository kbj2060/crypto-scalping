## 설정
- 기준 = B2 확정판(레이더 HAR-1m + 1분봉 거래대금 5창), 식·표적·분할·QLIKE 는 `angry-wilson-bbf351` 의 `research_realtime_risk_radar_20261115.py` 를 그대로 import.
- 재료 O = log(|Δ log OI| + 1e-4), 창 5·15·60·240분 · OI = Binance Vision metrics `sum_open_interest`(계약 수, 5분) · 스탬프 T 의 값은 **T+5분에 안다**(2024-03-04 이후 스탬프 t 값 = t+5분 스냅숏, 메모 binance-metrics-oi-stamp-switch-20240304) · 15분 넘게 낡거나 사이 스냅숏이 빠지면 NaN(시험 덮임 99.7%).
- 위약 = O 의 하루 전 값. 모든 팔은 같은 행으로 학습·채점. 시험 2026-06-01~10-27(ETH 127일·나머지 149일, 칸당 18~21만 분).
- 판정: 엄격 = 4코인 합동 날짜 블록 단측 90% 상한 < 0 · 코인 Holm ≥ 3/4 · 위약보다 나음 / 실용 = 엄격 + 상대 개선 ≤ −0.5%.

## 민감도: 스탬프를 «즉시 안다»고 두면(낙관, 잘못된 처리)
15분 −1.88% · 1시간 −0.63%, 엄격 통과처럼 나온다. 그러나
- 몫이 지평에 반비례해 준다(5분 미래 ÷ 15분 창 ≈ 1/3 → 1시간 창 ≈ 1/12) = 5분 미래참조 모양.
- 직접 확인: 스탬프 T 의 |ΔOI(T−5→T)| 와 가격 변동 5분 창의 순위 상관이 창 끝 T+5분에서 가장 크다(ETH .436 vs 창 끝 T .341 · BTC .457 vs .363 · SOL .383 vs .299 · XRP .407 vs .328) → 스탬프 T 값은 T+5분 스냅숏. 기존 메모와 같은 결론.
→ 이 −1.9% 는 누수다. 본판(T+5분에 앎)만 유효.
