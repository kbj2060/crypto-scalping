## 1. 손익 집중도 — 「한두 건 운」은 base 가 아니라 **배포본**에 맞는다

의심: "데이터 많은 deep 이 시드 분산이 적어야 하는데 오히려 돈이 더 흔들린다. base 는 운으로
한두 번 크게 번 것 아닌가." ⚠️1h 전방수익은 5분봉에서 12봉씩 겹치므로 **일 단위를 1급**으로 본다.

| 모델 | 총bp | **중앙 건당bp** | 양수일 | 최고1일 제거 | 최고1일 지분 | 상위3일 지분 | 상위1%건 지분 |
|---|---|---|---|---|---|---|---|

⭐**집중도가 가장 낮은 건 base 다.** "드물게 크게 번다"는 배포본의 모양이다(최고 1일이 27%,
상위 3일이 67%, 상위 1% 건이 51%, 양수일 45.1%).
🔴**deep 은 중앙 건당 bp 가 3시드 전부 음수다**(−2.91/−1.81/−1.34). 거래 절반 이상이 지고
평균을 0 근처로 올리는 건 꼬리뿐이다.

⭐**그래서 deep 의 시드 분산이 큰 것이 설명된다.** 데이터가 많아져 **결정은 실제로 안정됐다**
(롱비중 폭 0.255 < base 0.293 · 통과율 폭 0.014 < 0.034). 그런데 **수익 분포의 중심이 0 아래**라
평균이 「어느 꼬리를 잡았나」로 정해지고 그건 시드마다 다르다. **결정이 안정돼도 페이오프가
꼬리 지배면 평균은 안 안정된다.** 시드 겹침도 같다 — base 3시드는 상위10일 중 **5일 공유**
(쌍별 Jaccard 전부 0.429), deep 은 3일 공유에 한 쌍은 0.176.
⚠️deep 의 「지분」 지표는 분모가 0 근처라 무의미한 값(486%, −5.6e16)이 나온다. 표시 인공물이다.

## 2. 편향 제거 재학습

### 편향의 출처 (학습 단계)
기존 가중치는 `w = compute_sample_weight("balanced", y_전체) * route_prob[:, expert]` 로
**클래스 균형을 전체 라벨에서 잡고 라우팅 확률을 나중에 곱한다.** 그래서 bull 전문가가 보는
분포는 LONG 이 과대표집돼 있다(bull 레짐 ↔ LONG 라벨 상관). **전문가별 측면 사전확률이 여기서
생긴다.**
**고침(new)**: 라우팅 가중을 먼저 적용하고 **그 분포 위에서** 클래스 균형을 잡는다 —
`s_c = Σ_{y_i=c} route_w_i`, `w_i = route_w_i · (Σs)/(3·s_{y_i})`.

분산은 **무작위 5시드 앙상블**로 죽인다(613042·27851·904377·155690·488213, 고정간격 아님).
결정 단계에는 **측면 대칭 게이트**(롱/숏 임계값을 TRAIN 꼬리에서 각각 잡아 양쪽 1.75%씩 통과).

### 결과 (VAL 2026-03~06 · 독립일 122)

|---|---|---|---|---|---|---|

⭐**① 학습단 편향 제거는 의도대로 작동한다.** 게이트 전 롱비중 시드폭 old 0.194 → new **0.137**,
평균 0.457 → 0.444. **결정적 증거: new 에서는 대칭 게이트가 무의미해진다** — 롱/숏 임계값이
0.767 로 **같게** 나오고 롱비중도 46.7 vs 46.5 다. 학습에서 이미 균형이 잡혀 게이트가 고칠 게 없다.

🔴**② 그런데 돈은 떨어진다**(+6.93 → +4.29). 반면 old 에 **대칭 게이트만** 씌우면 롱비중이
26.6 → **50.8%** 로 균형이 되면서 **총bp 가 오르고**(+7.84) **모델−숏이 +1.49 → +5.33 으로
3배 이상 커진다.**
⇒ **편향을 빼도 엣지가 남는다. 09-17 오전의 "성과의 정체는 숏 편향" 은 3시드 개별 모델
기준이었고, 5시드 앙상블 + 측면 대칭에서는 그 설명이 성립하지 않는다.**
읽히는 이유: 라우팅 가중 뒤의 클래스 불균형은 **정보였다.** bull 전문가가 롱 사전확률을 갖는
건 bull 레짐에서만 발화하니 당연하고, 지우면 실제 신호가 같이 지워진다. 결정 단계 대칭화는
「각 측면에서 얼마나 깐깐할지」만 맞추므로 신호를 안 건드린다.

🔴**③ deep 은 편향을 빼도 살아나지 않는다**(최고 +3.98, 중앙 −1.63~+1.00).
🔴**④ 8판 전부 모델−숏 CI 가 0 을 포함한다.**

## 3. 라벨 설계 3종

제안: 「봉 하나에 1 찍히는 라벨 대신 ① 1 부근을 모두 1로 ② 회귀로 0.9 근처」.
**전제 두 가지가 실제와 달랐다.**

**① 라벨은 봉 하나가 아니라 구간 전체다.** 2024 실측: LONG 918구간·길이 중앙 **34봉**(2시간50분)
·평균 55·최대 441 · SHORT 925구간·29봉 · CASH 1,844구간·**5봉**. 「1 부근을 모두 1로」는 이미
그렇고, 남은 손잡이는 피벗 주변 CASH 버퍼(`transition_buffer`, 현행 2)를 줄이는 것이다.

**② soft 라벨이 이미 있는데 학습에 안 쓰인다.** 생성기가 `zigzag_soft_{cash,long,short}` 를
내놓고 LONG 봉의 `soft_long` 은 평균 **0.7395** · 분위 [.19, .54, .84, .99, 1.0] 로 **이미 연속**
이다(`mae_penalty` 1.25 · `softmax_temperature` 1.75 위험조정). 쓰이는 곳은
`_quality_target_hard_rule` 의 `side_soft >= 0.70` **이진 임계 한 줄**뿐이고 그건 h48qual 전용 —
**zig075 는 `same_as_direction` 이라 soft 를 아예 안 본다.** 현 부모의 방향 손실은 순수 hard CE 다.

### 결과 (base · 5시드 앙상블 · 대칭게이트 고정 · 라벨만 교체)

⚠️bacc 는 라벨 정의가 바뀌면 비교가 안 되므로 **전 판 공통으로 현행(버퍼2) 라벨 기준**으로 쟀다.

| 판 | CASH% | 롱% | 총bp | 중앙 | 양수일 | bacc | 모델−숏 |
|---|---|---|---|---|---|---|---|
| **L0 버퍼2/hard**(현행) | 11.8% | 50.8% | **7.84** | +2.55 | 54.2% | 0.5631 | +5.33 |
| **L2 버퍼2/smoothing .1** | 11.8% | 52.4% | **7.84** | **+2.64** | 53.4% | **0.5636** | **+5.96** |
| L1 버퍼2/**soft** | 11.8% | 35.1% | 7.21 | +1.09 | **60.4%** | 0.5501 | +3.71 |
| L4 버퍼0/**soft** | 1.7% | 25.1% | 6.56 | +2.03 | 52.5% | 0.5207 | +0.79 |
| 🔴**L3 버퍼0/hard** | 1.7% | 56.4% | **3.15** | **−2.51** | 44.3% | 0.5146 | −0.84 |

⭐L0 이 §2 의 `base/old/대칭게이트` 와 **정확히 같은 +7.84/+2.55** 로 재현됐다(같은 시드·구성)
— 내부 정합성 확인.

🔴**① 버퍼 축소는 명확히 해롭다.** CASH 11.8% → **1.7%** 로 활성 라벨을 최대화하면
**중앙 건당 bp 가 +2.55 → −2.51 로 부호가 뒤집힌다**(양수일 54.2 → 44.3%). 그 5봉 버퍼는
**피벗에서 방향이 뒤집히는 구간**이고, 거기에 확신 있는 라벨을 붙이면 「곧 반대로 갈 봉」을
롱이라 가르치는 셈이다. 학습량은 늘고 가르치는 내용이 틀린다.

**② soft 는 현행 버퍼에선 중립~약간 나쁨이지만 「라벨이 더러울 때의 보험」으로 작동한다.**
현행(L1)은 +7.84→+7.21·중앙 +2.55→+1.09 로 약간 나쁘나 **양수일이 60.4% 로 5판 중 최고**고
진입이 909→707 건으로 준다. ⭐**버퍼0 에서는 soft 가 구해낸다**: L3 +3.15/중앙 −2.51 →
L4 **+6.56/중앙 +2.03**. 라벨이 피벗 잡음을 머금으면 hard 는 무너지는데 soft 는 그 불확실성을
타깃에 흡수한다(활성 평균 0.983 → 0.719).

**③ label smoothing ε=0.1 은 사실상 동률**(총bp 동일, 중앙·bacc·모델−숏 소수점 개선). 공짜지만
효과도 거의 없다.

⇒ **현행 라벨 설계(버퍼 2 + hard)가 이미 거의 최적이다.**

## 4. 🔴가장 중요한 유보 — 선택편향

§2 의 8판 + §3 의 5판 = **13개 구성을 같은 VAL(독립일 122)에서 비교하고 그 중 최고를 인용하고
있다.** 시드/구성 잡음이 ±2~3bp 인데 13개 중 최대를 뽑으면 그만큼 부풀려진다. 이 저장소가
이미 기록한 함정이다 — [[feedback_selection_is_the_thing_to_walk_forward_20260915]]
("워크포워드해야 하는 건 모델이 아니라 **규칙 선택**이다").

**+7.84bp 를 기대값으로 읽으면 안 된다.** 그리고 13판 전부 모델−숏 CI 가 0 을 포함한다.
이 축을 다시 열려면 **새 창에서 이 한 구성만** 검정해야 하고, 예약된 single-touch
OOS(2026-07-01~09-30)가 그 자리다. 이번 작업은 **그 창을 건드리지 않았다.**
