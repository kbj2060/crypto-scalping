## 3. 동결 규칙 (결과를 본 뒤 하나씩 고정 · 전진에서 바꾸지 않음)
- **R1(아이디어 1)**: 15분(900초 배수 UTC)마다 리밸런스한다. 5코인 z 최댓값을 롱, 최솟값을 숏하고, 롱 z ≥ 0.6 이고 숏 z ≤ −0.6 일 때만 들어간다(아니면 무포지션). 실행은 s+1 mid, 명목은 각 1, 비용은 다리 변화마다 편도 0.705bp(메이커 줄)와 4bp(테이커 줄)다. 원 방향만 등록한다.
- **R2(아이디어 2)**: 코인별로 초마다 |z| ≥ 0.6 이면 진입하고, 최소 300초 보유한 뒤 z 가 0을 넘어가면 청산, ≤ −0.6 이면 반전한다. 실행 지연은 30초, 메이커 줄로 계산한다. 5코인 일 손익을 평균한다. 원 방향만 등록한다.
- **R3(아이디어 3)**: ho3 매매 규칙에 «QI 내 쪽» 진입 게이트를 단다. 매수 진입은 직전 초 bt_qi_mean > 0 일 때만, 매도 진입은 < 0 일 때만 주문을 건다. 체결 모델은 그대로다.
- **R4(아이디어 4)**: 사용자 ETH 진입+추가 주문을 체결 직전 초 z 로 «일치 / 중립 / 반대»로 나누고, 60분 방향 드리프트를 본다.
- 방향 근거(메커니즘): 깊은 벽 원 방향은 네 창 연속 양수였고, 인과 풀링에서도 5코인 모두 양수였다. 탐색의 반대 방향은 아이디어 1~3 전부에서 총수익이 음수였다. 그래서 모든 가설을 **원 방향 하나로만** 등록한다. 반대 방향은 등록하지 않는다.

## 4. 전진 가설과 판정 기준
- 전진 창: **2026-10-04T00:00Z 이후**. 문턱(z) 예열에만 직전 24시간을 쓴다.
- 판정 단위는 UTC 일 클러스터, 통계는 일 평균 ± SE다.
- 다중비교: 주 가설 4개(H1~H4)와 보조 2개(F0a·F0b)가 있다. 주 가설 «통과»는 **t ≥ 2.33**(한쪽 α = 0.05/5)이다. 2.0 ≤ t < 2.33 은 «약한 지지»로만 적는다.
- 필요 일수 = (2.33 · 일 SD / 기대 효과)². 기대 효과는 탐색 점추정의 **절반**으로 잡는다(승자의 저주 보정). 판정일은 lake 가 그날까지 봉인된 다음 날이다.
