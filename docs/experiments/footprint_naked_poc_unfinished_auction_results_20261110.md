## 🔴 판정을 읽을 때 (효과는 작고, «그 레벨이라서»라는 증거는 약하다)
1. **크기**: 기저 닿음률이 65~70% 라 «대부분 돌아온다»는 레벨 고유 성질이 아니다. 레벨 몫은 그 위 +2~2.6%p — 선 100개 그리면 2~3개 더 닿는 정도.
2. **거리별로 갈린다**(1시간, 맨 POC): ≤10bp 85.0% vs 위약 86.7%(**레벨이 더 못함**) · 10~30bp 66.7 vs 64.6 · >30bp 45.0 vs 33.5(+11.5). 이득이 먼 레벨에 몰렸는데, 거울 대비로는 >30bp 가 45.0 vs 47.1(오히려 못함). → 시간 이동 위약은 «방금 움직인 직후(변동성 큼)» 사건 시각과 «다른 날 같은 시각» 변동성이 안 맞아 먼 거리에서 위약이 낮게 나온 몫이 섞였을 가능성이 크다(사후 해석, 판정 바꾸지 않음).
3. **«미완»이라서가 아니다**: 끝난 경매(극값 행 한쪽 0, 1,169건)도 시간 이동 위약 대비 +3.4%p(p .042)로 똑같이 넘는다. 거울 대비는 +0.7%p(p .37) 불통과. 미완−끝난 원 닿음률 차 +5.4%p 는 거리 분포가 달라(중앙 14.7 vs 18.1bp) 비교 불가. 즉 효과는 «아직 안 돌아간 봉 극값·POC» 일반이지 양쪽 체결 여부가 아니다.
4. 4시간 지평(보조): A +1.7%p(p .030) · B +2.6%p(p .003) — 1시간과 같은 방향.

## 사전등록과 다른 점
- 기준가 P = «τ 직전 마지막 체결가» 대신 **직전 체결 초의 VWAP**(lake 에 초 안 체결 순서가 없다 · 차이 수 센트).
- 지시문의 «한쪽 0 = 미완»은 관례상 «끝난 경매»라 사전등록에서 관례 정의(양쪽 체결)를 주 팔로, 한쪽 0 을 보조 팔로 둠.
- 일 POC 보조는 돌리지 않음(55일 = 사건 ≤54건, 검정력 없음).
