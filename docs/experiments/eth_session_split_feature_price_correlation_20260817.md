# ETH 5m 세션 분할 피처-가격 상관 분석 (2026-08-17)

## 목적

pooled 상태에서 엣지가 안 보이는 ETH 5m 데이터를 거래 세션(us / europe / asia / none)으로
분할했을 때, 피처-가격 상관이 세션별로 갈라지는지 측정한다. 즉 **"세션 split 자체가 엣지를
만드는가"** 를 검증한다.

## 결론 (요약)

1. **사용자가 제안한 us / europe / asia 3분할은 엣지를 만들지 못한다.** 3분할 중 어느 것도
   사전 등록 기준 3개를 모두 통과한 셀이 사실상 없다 (us 0개, asia 0개, europe 1개 / 각 600셀).
2. **엣지는 버려질 뻔한 `none` 버킷에 있다** (600셀 중 8개 통과). 거래소 캘린더 세션 경계가
   진짜 경계를 가로질러 자르고 있었다.
3. 진짜 경계는 **평일 20:00–23:59 UTC** (미국 현물 마감 직전 1시간 + 애프터아워). 이 구간에서
   `rsi` / `mtf_trend_4h` / `cvp_volume_imbalance` 가 TRAIN·VAL·OOS 3개 split 모두에서 일관되게
   **음의 IC (평균회귀)** 를 보이고, 호라이즌이 길어질수록 커진다 (최대 -0.28).
4. `us` 버킷이 무너진 이유는 내부에 부호가 반대인 두 구간이 섞여 있기 때문이다:
   13–14 UTC 는 음(평균회귀), **15–16 UTC 는 양(모멘텀)**.
5. **아시아 세션(01–07 UTC)은 노이즈**다. 어떤 피처도 3-split 부호 일관성을 못 지킨다.

정리하면, 분할 축을 "거래소 세션"이 아니라 **"미국 현물 마감 기준 시각"** 으로 바꿔야 한다.

### 판정 기준 (사전 등록)

forward return 이 서로 겹치므로(overlapping) 순진한 p-value 는 과대신뢰가 된다. p-value 대신
다음 3개를 **모두** 통과해야 후보로 인정한다.

1. **부호 일관성** — TRAIN / VAL / OOS IC 부호가 모두 동일
2. **rotation null** — VAL 과 OOS 각각에서 |z| ≥ 2. 귀무분포는 세션 라벨 시계열을 1~23시간
   원형 회전시켜 만든다 (버킷 크기와 블록 구조는 보존, 진짜 정렬만 파괴). 회전 귀무분포의
   표준편차가 1/√n 로 스케일되므로 **z 는 표본 크기 차이를 자동 보정한다**
3. **pooled 초과** — VAL·OOS 모두에서 |IC| 가 pooled |IC| 보다 커야 함 (= split 이 실제로
   무언가를 더했는가)

다중비교 규모: 102 feature × 6 horizon × 4 session ≈ 2,406 셀/split.

## 한계 (중요)

1. **20–23 UTC 는 사후 분할이다 (forking paths).** 사전 등록된 것은 4-way 세션 분할까지였고,
   `none` 분해와 시간대별 쪼개기는 결과를 본 뒤 수행했다. 이 구간은 **자체 사전 등록 확인
   테스트가 따로 필요하다.** 현 시점 증거 등급은 CONFIRMED 가 아니라 가설이다.
2. **IC 는 거래 가능한 엣지가 아니다.** 이 레포 이력상 lift-positive 신호가 실제 TP/SL 비용
   게이트에서 죽은 사례가 반복됐다 (Dalton Rule 2: lift 양수 → 6/6 윈도우 cost-gate 실패).
   IC -0.1 을 bp 단위 breakeven cost 로 환산해 검증해야 한다.
3. **3개 피처는 독립 발견이 아니다.** `rsi` / `mtf_trend_4h` / `cvp_volume_imbalance` 는 모두
   추세·모멘텀 계열로 서로 상관이 높다. 사실상 1~2개의 독립 신호로 봐야 한다.
   `oi_change_rate` / `smart_money_flow` 는 위에서 밝혔듯 아예 같은 컬럼(=1개).
4. **OOS 가 2개월(2026-01-01 ~ 02-28)뿐이다.** 21–24 UTC 버킷은 OOS 에서 1,473 bar.
   IC 가 TRAIN < VAL < OOS 로 **커지는** 방향인 것은 과적합 징후는 아니지만 레짐 드리프트일
   수 있다 — 2개월로는 구분 불가.
5. rotation null 의 원형 회전은 5m 바가 연속임을 가정한다. 실제 데이터에 소량의 결측 바가
   있다 (TRAIN 78,568 vs 이론치 78,624). 귀무분포 용도로는 무시 가능한 수준.
6. **fresh-forward 검증이 아니다.** 이 분석은 상관 스크리닝이며, CLAUDE.md 의 Fresh-Forward
   규칙이 적용되는 승격 근거가 아니다. 승격을 주장하려면 bar-by-bar causal walk-forward 로
   다시 돌려야 한다.

## 결과 4 — 세션별 비지도 피처 군집 (추가 분석)

질문: 세션으로 나눈 뒤 피처를 비지도로 묶으면 세션마다 다르게 분류되는 피처가 있는가?

방법: 거리 = 1 − |Spearman(f_i, f_j)| 로 세션별 상관행렬을 각각 만들고 average-linkage 계층군집
(k=10). 세션 간 일치도는 Adjusted Rand Index.

**귀무 대조가 핵심이다.** 표본 노이즈만으로도 군집은 흔들리므로, 같은 세션의 바를 하루 블록
단위로 A/B 반쪽으로 나눠 within-session ARI 를 baseline 으로 잡았다. 이때 **within 과 cross 가
반드시 같은 표본 크기여야 한다** — 처음엔 cross 를 전체 n, within 을 n/2 로 재서 baseline 이
인위적으로 낮아졌고 "차이 없음"이라는 반대 결론이 나왔다. 모든 세션을 최소 세션 크기
(TRAIN+VAL 11,285 / OOS 1,509)로 맞춰 재계산했다.

### 4-1. 전역 군집 구조

| split | 피처 | within (baseline) | cross | gap |
|---|---|---|---|---|
| TRAIN+VAL | 전체 102 | 0.783 | 0.556 | **+0.226** |
| TRAIN+VAL | 시각 인코딩 제외 | 0.693 | 0.632 | **+0.061** |
| OOS | 전체 102 | 0.651 | 0.434 | **+0.217** |
| OOS | 시각 인코딩 제외 | 0.647 | 0.399 | **+0.248** |

세션은 시각으로 정의되므로 `hour_sin` / `hour_cos` / `minute_sin` / `minute_cos` /
`is_hour_open` 의 상관 프로파일이 세션마다 달라지는 건 **동어반복이지 발견이 아니다**
(cross agreement 가 -0.09 까지 내려간다). 이 5개를 빼면:

- **TRAIN+VAL(표본 크고 신뢰도 높음)에서 gap 이 +0.226 → +0.061 로 붕괴한다.** 즉 전역
  군집 구조 차이의 대부분은 시각 인코딩 동어반복이었다.
- OOS 에서는 gap 이 유지되지만(+0.248), OOS 반쪽이 754 bar 뿐이라 군집 자체가 매우 불안정하다
  (within baseline 도 0.647 로 낮다).

**전역 수준 결론: 세션별로 피처 군집 구조가 근본적으로 달라진다는 증거는 약하다.**

### 4-2. 피처 단위 — 실제로 세션마다 다르게 분류되는 피처

피처별로 '다른 피처들과의 상관 벡터'(상관 프로파일)가 세션 간에 얼마나 바뀌는지를
`gap = within_null − cross_session` 로 측정. 시각 인코딩 5개 제외 후, **TRAIN+VAL 과 OOS
양쪽에서 모두 상위 20위에 든** 피처:

| feature | gap (TRAIN+VAL) | gap (OOS) | 계열 |
|---|---|---|---|
| `sig_volume_confirm` | 0.161 | 0.166 | 거래량 확인 |
| `svps` | 0.136 | 0.158 | 거래량/유동성 |
| `regime3_..._margin` | 0.085 | 0.208 | 레짐 분류기 확신도 |
| `regime3_..._confidence` | 0.081 | 0.201 | 레짐 분류기 확신도 |
| `regime3_..._entropy` | 0.067 | 0.192 | 레짐 분류기 확신도 |
| `whale_conviction` | 0.059 | 0.049 | 대형주문 흐름 |
| `mta_funding` | 0.045 | 0.148 | 펀딩 (※ 신뢰도 낮음) |
| `liquidity_vacuum` | 0.037 | 0.074 | 유동성 |
| `bb_width_z` | 0.024 | 0.051 | 변동성 |

일관된 계열이 나온다: **유동성·거래량 미시구조 + 레짐 분류기 확신도**. 반대로 `rsi`, `macd_hist`,
`hurst_*` 같은 순수 가격·추세 피처는 세션 간 프로파일이 안정적이다 (전체 평균 cross 0.863 vs
null 0.902, gap 0.040).

해석: 세션마다 실제로 바뀌는 것은 **유동성 환경**이고, 가격 구조 자체가 아니다.

### 4-3. 이 결과의 한계

- 상위 20위 중 9개 중복은 우연 기대값(20×20/97 ≈ 4.1)의 **약 2배**다. 방향은 맞지만 압도적이진
  않다.
- `mta_funding` 은 cross 와 null 이 **둘 다 낮다** (TRAIN+VAL 0.248 / 0.327). 세션 의존이 아니라
  그냥 노이즈 피처일 가능성이 크므로 신뢰하지 말 것. (`funding_abs` 는 OOS 에서
  cross=-0.001 / null=0.166 으로 같은 패턴이라 교집합에서 탈락했다.)
- k=10 고정 컷은 임의 선택이다. k 민감도는 확인하지 않았다.
- 여기서 나온 "세션 의존 피처"는 **비지도 구조 발견일 뿐 예측력과 무관하다.** 결과 1–3 의
  IC 분석에서 살아남은 피처(`rsi`, `mtf_trend_4h`, `cvp_volume_imbalance`)와 이 목록은
  **겹치지 않는다.**

## 결과 5 — 20–23 UTC breakeven cost 환산 (**비용 게이트 실패**)

결과 3 의 IC 를 실제 진입 규칙으로 바꿔 per-trade gross return 을 bp 로 환산했다.

**기준선**: 이 레포의 검증된 taker 비용 **one-way 5.0 bp**
(`scripts/research_ws_b_fill_probability_20260719.py:228`, WS-A 캘리브레이션) →
**round-trip 10.0 bp**. breakeven < 10bp 이면 비용을 못 넘는다.

### 규칙

- 유니버스: 평일 20:00–23:55 UTC 바
- 임계값은 **TRAIN 구간에서만 적합한 empirical CDF** (lookahead 차단), VAL/OOS 에 그대로 적용
- IC 음수이므로 percentile > 0.8 → SHORT, < 0.2 → LONG
- **진입 지연 1 bar** (신호 t, 진입 t+1 종가), 보유 h bar 후 종가 청산
- overlapping / non-overlapping 둘 다 계산

### 최고 성적 config (composite, 보유 1h, non-overlap, lag=1)

| split | n_trades | breakeven (bp) | t_stat |
|---|---|---|---|
| TRAIN | 472 | **-1.56** | -0.40 |
| VAL | 132 | +15.47 | +2.35 |
| OOS | 83 | +19.84 | +2.17 |

**TRAIN 이 음수다.** 표본이 가장 큰 구간에서 신호가 없다. 결과 3 의 IC 가 TRAIN 에서
가장 약했던 것(-0.05)과 일관되지만, 거래 수익 수준에서는 아예 0 이하로 떨어진다.

### 방향 편향 검증 (통과)

레포 관행상 `max(always_long, always_short)` 벤치마크가 필수다.

| split | LONG 비중 | LONG gross | SHORT gross | max(always) | **증분** |
|---|---|---|---|---|---|
| TRAIN | 51.3% | +0.10 | -3.30 | +4.94 | **-6.50** |
| VAL | 60.6% | +17.66 | +12.11 | +1.32 | **+14.16** |
| OOS | 44.6% | +27.01 | +14.08 | +0.36 | **+19.49** |

롱/숏이 균형 잡혀 있고 VAL/OOS 는 **양쪽 모두 수익**이다. 단순 숏 바이어스가 아니다.
이 축에서는 통과했다.

### 월별 집중도 — 결정적 실패 지점

| split | 월별 gross (bp, 거래수) |
|---|---|
| TRAIN | 01:+1.5(60) 02:+6.5(58) 03:+12.5(43) 04:+4.3(54) **05:-11.8(48) 06:-34.8(56)** 07:+1.1(55) 08:+3.8(55) 09:+6.3(43) |
| VAL | 10:-5.7(47) **11:+37.8(45)** 12:+15.2(40) |
| OOS | 01:+4.0(42) **02:+36.1(41)** |

거래는 서로 독립이 아니다 (같은 달 안에서 같은 레짐을 공유). 유효 표본은 거래 수가 아니라
**월 수**다. 14개월 클러스터 기준:

| 지표 | 값 |
|---|---|
| 월 단순평균 | **+5.49 bp** |
| 거래수 가중평균 | +4.30 bp |
| 월간 표준편차 | 18.01 bp |
| SE | 4.81 bp |
| **t-stat** | **+1.14** |
| 양수 월 | 11 / 14 |
| **round-trip 10bp 기준 net** | **-4.51 bp** |
| 상위 2개월 제외 시 | +0.24 bp |

- **breakeven 5.49 bp < 필요 10.0 bp → 비용 게이트 실패**
- t=1.14 로 0 과 구분되지 않는다
- 상위 2개월(2025-11, 2026-02)을 빼면 +0.24bp 로 사실상 0. **14개월 중 2개월이 전부를 만든다**
- 짧은 보유(15m/30m)의 breakeven 은 1~8bp 로 10bp 에 더 크게 미달한다

### 선택 편향 경고

위 config 는 **4 signal × 3 hold × 2 lag × 2 overlap = 48개 조합 중 최고**를 고른 것이다.
48개 중 최고를 골라도 월 클러스터 t=1.14 라는 점이 오히려 이 결론을 강화한다.

### 판정

**20–23 UTC 평균회귀 가설은 비용 게이트를 통과하지 못한다.** 레포의 기존 패턴을 그대로
반복했다 — IC/lift 는 양수인데 실제 TP/SL 비용에서 죽는다 (선례: Dalton Rule 2, breakeven
0–1.6bp, 0/6 윈도우).

다만 "죽었다"기보다 **"입증되지 않았다"** 가 정확하다: 11/14 월이 양수이고 방향 편향 검증은
통과했다. 막는 것은 신호의 부재가 아니라 **per-trade 엣지가 taker round-trip 비용보다 작다**는
점이다.

### 판정을 뒤집을 수 있는 유일한 경로

이 신호는 **되돌림을 페이드하는(fade) 성격**이라 지정가 주문에 구조적으로 적합하다. 움직임을
쫓아가는 게 아니라 반대편에 물량을 걸어두는 것이므로 maker 체결 가능성이 있다. maker 로
one-way 비용이 5bp → 1~2bp 로 내려가면 round-trip 2~4bp 가 되어 breakeven 5.49bp 를 넘는다.
이 레포에 이미 체결 확률 연구가 있다 (`scripts/research_ws_b_fill_probability_20260719.py`).
**다만 이건 제안이지 결과가 아니다** — 체결 확률과 adverse selection 을 실제로 측정해야 한다.

## 결과 6 — 비지도 패턴 탐색 (매매 결정 없음)

질문: 바(sample)를 비지도로 묶으면 실제로 패턴(군집)이 존재하는가? 그 구조가 세션과
관련이 있는가? **진입/청산 규칙이나 수익 계산을 일절 하지 않는다.**

### 피처 처리

102개 중 22개를 뺀 **80개** 사용:
- **시각 인코딩 5개 제외** (`hour_sin/cos`, `minute_sin/cos`, `is_hour_open`) — 세션이
  시각으로 정의되므로 포함하면 동어반복 (결과 4에서 확인)
- **close 레벨 오염 16개 제외** — 포함하면 군집이 시장 상태가 아니라 '몇 월인가'(가격 에폭)로
  수렴한다
- **`smart_money_flow` 제외** — `oi_change_rate` 와 완전 동일 컬럼

rank-gauss 변환 후 PCA → **33개 주성분으로 분산 90%** (PC1 14.4%, PC2 11.2%).
33차원으로 90%가 필요하다는 것 자체가 저차원 잠재구조가 없다는 신호다.

### 6-1. 군집이 존재하는가 → **사실상 없다**

| k | gap | s_k | split-half ARI | silhouette |
|---|---|---|---|---|
| 2 | 1.7077 | 0.0060 | 0.945 | **0.1135** |
| 3 | 1.7128 | 0.0010 | 0.776 | 0.1027 |
| 5 | 1.7341 | 0.0004 | 0.922 | 0.0798 |
| 8 | 1.7665 | 0.0005 | 0.666 | 0.0637 |
| 12 | 1.7976 | 0.0011 | 0.444 | 0.0659 |

**gap 이 k 에 대해 단조증가한다 (1.708 → 1.798).** 이것이 교과서적인 "군집 없음" 신호다.
Tibshirani 기준이 k=3 을 elbow 로 찍지만 s_k 가 0.001 로 극히 작아서 생긴 수치 artifact다.

**결정적 검정 — 동일 공분산 가우시안 귀무 대비 실루엣.** 가우시안 단일 덩어리는 정의상
군집이 없는데도 k-means 를 돌리면 실루엣이 나온다. 실제 데이터가 이걸 못 넘으면 군집이 없다.

| k | 실제 silhouette | 가우시안 귀무 | 차이 |
|---|---|---|---|
| 2 | 0.1137 | 0.0930 ± 0.0008 | **+0.0207** |
| 3 | 0.1049 | 0.0739 ± 0.0010 | +0.0310 |
| 5 | 0.0792 | 0.0550 ± 0.0003 | +0.0241 |
| 8 | 0.0636 | 0.0478 ± 0.0008 | +0.0158 |

구조 없는 상관 덩어리가 이미 실루엣 0.093 을 만든다. 실제 데이터는 **0.114 로 겨우 넘는다**.
관측된 "군집성"의 약 82% 가 구조 없는 덩어리로 설명된다.

split-half ARI 가 0.945 로 높은 것은 **모순이 아니다.** 하나의 연속 덩어리를 지배적 축을
따라 자르면 그 절단면은 재현 가능하다. 높은 안정성 + 가우시안 수준 실루엣 =
**"재현 가능한 임의 절단"이지 "분리된 군집"이 아니다.**

### 6-2. k=2 분할의 정체 → 군집이 아니라 추세 축

| feature | c0 (26.7%) | c1 (73.3%) | 차이 |
|---|---|---|---|
| `regime3_..._bear_prob` | +1.287 | -0.415 | -1.702 |
| `mtf_trend_4h` | -1.128 | +0.410 | +1.538 |
| `cvp_volume_imbalance` | -0.993 | +0.446 | +1.439 |
| `rsi` | -1.034 | +0.376 | +1.410 |
| `breakout_strength` | -0.994 | +0.361 | +1.355 |
| `regime3_..._bull_prob` | -0.944 | +0.371 | +1.315 |
| `mean_reversion_z` | +0.952 | -0.346 | -1.298 |

c0 = **하락추세 + 과매도** 상태, c1 = 그 반대. 즉 k=2 는 **PC1(추세 방향)이라는 연속 변수를
반으로 자른 것**이다. 발견된 이산 패턴이 아니다.

### 6-3. 세션과의 연관 → 실재하지만 미미. 단, 하나의 예외

세션-군집 NMI 를 rotation null(세션 라벨 1~23시간 원형 회전)과 비교:

| k | NMI | null 평균 | null 최대 | z |
|---|---|---|---|---|
| 3 | 0.0482 | 0.0223 | 0.0424 | +2.42 |
| 5 | 0.0243 | 0.0121 | 0.0218 | +2.45 |
| 8 | 0.0387 | 0.0175 | 0.0326 | +2.59 |

z 는 일관되게 +2.4~2.6 이지만 **NMI 0.048 은 절대값으로 무시할 수준**이고, 관측값이 23회
회전 귀무의 **최대값(0.0424)을 겨우 넘는다**.

**단 하나 뚜렷한 것: US 세션이 c0(하락/과매도)에 과대표현된다.**

| 분기 | 전체 c0 비율 | us lift | europe | asia | none |
|---|---|---|---|---|---|
| 2025Q1 | 0.295 | **1.62** | 0.94 | 0.87 | 0.83 |

`none`(오프세션)은 반대로 일관되게 0.64~0.84 로 과소표현된다. europe/asia 는 1.0 근처로 무의미.

### 6-4. 세션별로 따로 군집하면 구조가 더 뚜렷한가 → 아니다

| session | n | 실제 silhouette | 가우시안 귀무 | 차이 |
|---|---|---|---|---|
| us | 19,342 | 0.1264 | 0.1224 | +0.0040 |
| europe | 19,610 | 0.0897 | 0.0918 | **-0.0022** |
| asia | 16,036 | 0.1045 | 0.0964 | +0.0081 |

세션 안에서 따로 군집해도 전부 가우시안 귀무 수준이다. europe 은 오히려 귀무보다 **낮다**.
`none` 만 약간의 초과분(+0.025)을 보이는데, 이는 결과 1–3 에서 `none` 이 유일하게 살아남은
것과 방향이 일치한다.

### 6-5. OOS 재현

k=2 모델을 OOS 에 적용 vs OOS 자체 군집: **ARI 0.836**. 군집 점유율도 안정
(TRAIN+VAL 0.267/0.733 → OOS 0.288/0.712). 절단면 자체는 재현되지만, 위에서 봤듯
그것이 "군집이 있다"는 뜻은 아니다.

### 결론

1. **이 피처 공간에 이산적 패턴(군집)은 없다.** 하나의 연속된 상관 덩어리이고, 지배적 축은
   추세 방향이다. gap 단조증가 + 실루엣이 가우시안 귀무를 겨우 초과.
2. **세션은 이산 군집을 만들지 않는다.** 하지만 그 연속 축 **위에서의 위치 분포를 체계적으로
   바꾼다** — US 세션은 하락/과매도 쪽에 1.5~1.9x 몰리고, 오프세션은 0.64~0.84x 로 반대다.
   5분기 연속 + OOS 재현.
3. 이 사실은 결과 1–3 과 정합적이다. 세션은 "다른 종류의 시장"을 만드는 게 아니라
   **같은 축 위의 다른 지점에 시간을 더 많이 보내게 한다**.

### 한계

- k-means/PCA 는 구형 군집을 가정한다. 밀도 기반(HDBSCAN) 이나 비선형 임베딩(UMAP)에서는
  다른 결과가 나올 수 있다. **이 분석은 "선형 부분공간에서의 구형 군집"만 배제했다.**
- 오염 16개 제외는 판단이 들어간 선택이다. 포함하면 군집이 가격 에폭으로 수렴하는 것을
  확인했지만, 그 경계선(|Spearman| ≥ 0.5)은 임의다.
- 6-3 의 US lift 는 **관측된 연관일 뿐 인과나 예측력이 아니다.** 왜 US 시간대가 하락/과매도
  상태에 더 오래 머무는지는 이 분석이 답하지 않는다.

## 결과 7 — HDBSCAN / UMAP (밀도 기반 + 비선형)

결과 6은 "선형 부분공간의 구형 군집"만 배제했다. 남은 가능성을 검증한다.
데이터는 결과 6과 동일(80피처 → rank-gauss → PCA 33차원), n=30,000 부분추출.

**귀무 대조 3종.** UMAP 은 구조가 전혀 없는 데이터에서도 시각적으로 선명한 덩어리를
만들어내는 것으로 잘 알려져 있다. 따라서 동일 파이프라인을 통과한 귀무와 비교해야 한다.

| 귀무 | 보존하는 것 | 파괴하는 것 |
|---|---|---|
| NULL-A (iid 가우시안) | 공분산 | 자기상관, 주변분포, 고차 의존성 |
| NULL-B (위상 무작위화) | 공분산 + **자기상관**(파워 스펙트럼) | 비선형/비가우시안 구조 |
| NULL-C (주성분별 셔플) | **주변분포 정확히** | 모든 의존성 |

### 7-1. HDBSCAN을 33차원 PCA 공간에 직접 → **군집 0개**

| min_cluster_size | REAL | NULL-A | NULL-B |
|---|---|---|---|
| 150 | 0개, noise 100% | 0개, noise 100% | 0개, noise 100% |
| 500 | 0개, noise 100% | 0개, noise 100% | 0개, noise 100% |
| 1500 | 0개, noise 100% | 0개, noise 100% | 0개, noise 100% |

원 공간에는 밀도 구조가 전혀 없다. (단, 33차원은 밀도 추정 자체가 어려운 차원이라
이 결과는 HDBSCAN 의 한계이기도 하다.)

### 7-2. UMAP → HDBSCAN → **지표가 귀무에 대해 일관되지 않는다**

| mcs | 지표 | REAL | NULL-A | NULL-B | NULL-C |
|---|---|---|---|---|---|
| 150 | clusters | 7~11 | 7 | 3 | 4 |
| 150 | noise | 0.016~0.033 | 0.692 | 0.265 | 0.240 |
| 150 | **DBCV** | 0.069~0.179 | 0.008 | **0.407** | **0.650** |
| 500 | clusters | 9 | 4 | 3 | 2 |
| 500 | noise | 0.054~0.066 | 0.736 | 0.684 | **0.000** |
| 500 | DBCV | 0.151~0.338 | 0.129 | 0.109 | 0.016 |
| 1500 | clusters | 2~3 | 3 | 2 | 2 |
| 1500 | noise | 0.000 | 0.730 | 0.702 | 0.083 |
| 1500 | DBCV | 0.260~0.514 | 0.000 | 0.000 | 0.000 |

처음에는 REAL 이 이겨 보인다 — noise 비율이 3~7% 로 NULL-A/B 의 27~74% 보다 훨씬 낮다.
그러나 귀무를 하나 더 걸면 무너진다.

- **DBCV 에서 NULL-B(0.407)와 NULL-C(0.650)가 REAL(0.069~0.179)을 크게 앞선다.** 구조가
  전혀 없는 데이터가 실제 데이터보다 "더 좋은 밀도 군집"을 만든다.
- **noise 비율에서 NULL-C(mcs=500)는 0.000 으로 REAL(0.054)보다도 낮다.** 판별 방향이 뒤집힌다.
- **REAL 자신의 지표가 재현되지 않는다.** 부분추출 30,000개를 다시 뽑기만 해도 mcs=500
  DBCV 가 **0.338 → 0.151** 로, mcs=150 군집 수가 **7 → 11** 로 바뀐다.
- split-half ARI = **0.5688** (결과 6의 k-means 0.945보다 훨씬 낮다).

지표가 귀무 종류에 따라 부호를 바꾸고 실제 데이터 자체도 재현되지 않는다 —
**구조가 없을 때 나타나는 전형적 양상이다.**

### 7-3. 그래도 나온 군집은 에폭인가 상태인가 → 에폭은 아니다

혹시 군집이 실재한다면 무엇인지 확인했다. UMAP→HDBSCAN(mcs=500) 9개 군집의 월별 분포:

| 군집 | 최대 월 비중 | 2% 이상 출현 월수 | 크기 |
|---|---|---|---|
| 0 | 0.125 | 11 | 5,517 |
| 1 | 0.160 | 11 | 2,833 |
| 2 | 0.156 | 11 | 5,000 |
| 3 | 0.120 | 11 | 7,176 |
| 5 | **0.351** | 11 | 1,828 |
| 8 | 0.267 | 12 | 1,237 |

12개월 균등이면 최대월 비중 0.083. 대부분 0.12~0.16 (1.4~1.9배)으로 **특정 달에 갇혀 있지
않고 11~12개월 전부에 재출현한다.** 달력 에폭이 아니다. 다만 군집 5는 0.351 로 한 달
(2025-07)에 몰려 있고, 실제로 2025-07 은 전체 구성이 다른 달과 확연히 다른 이상 월이다.

연속 런 길이 중앙값 2.0 bar (28% 부분추출 기준, 시간 무관이면 ~1.1) — 시간적 지속성은 있다.
다만 이는 매끄러운 다양체를 시간축으로 훑을 때 자연히 나오는 성질이라 군집의 증거는 아니다.

### 7-4. 세션 연관 → 결과 6보다 **더 약하다**

세션-군집 NMI = **0.0089** (z=+18.21). z 는 크지만 귀무 분산이 극히 작아서 생긴 값이고,
**절대 효과 크기는 결과 6의 k-means NMI 0.048보다 한 자릿수 작다.**

군집별 세션 lift 에서 눈에 띄는 것은 결과 6과 같은 방향 하나뿐이다:
**US 세션이 noise 영역(-1)에 lift 2.24, 소수 군집(7, 827개)에 1.74 로 과대표현.**
나머지 군집은 전부 0.66~1.24 로 무의미하다.

### 결론

**HDBSCAN 과 UMAP 도 이산 패턴의 증거를 주지 못한다.** 결과 6(k-means/PCA)과 같은 결론이다.

- 원 33차원 공간: 밀도 군집 0개
- UMAP 압축 후: 군집이 나오지만 지표가 귀무에 대해 일관되지 않고 실제 데이터 자체도
  부분추출을 바꾸면 재현되지 않는다
- 구조가 **UMAP 의 비선형 압축 이후에만** 나타난다는 점 자체가 경고 신호다 —
  바로 그 지점이 artifact 가 가장 잘 생기는 곳이다
- 세션 연관은 결과 6보다 더 약하고, 유일하게 반복되는 것은 **US 세션이 공간의 특이 영역에
  몰린다**는 결과 6과 동일한 관찰이다

### 한계

- HDBSCAN 은 33차원에서 밀도 추정이 원리적으로 어렵다. 7-1 의 "0개"는 데이터의 성질이자
  방법의 한계다.
- UMAP 하이퍼파라미터는 `n_neighbors=50, min_dist=0.0` 하나만 시도했다. 다른 설정에서
  다른 그림이 나올 수 있지만, **귀무도 같이 움직이므로 결론이 바뀔 가능성은 낮다.**
- n=30,000 부분추출이다 (전체 105,064). 부분추출 민감도가 실제로 컸다는 점은 7-2에 기록했다.
