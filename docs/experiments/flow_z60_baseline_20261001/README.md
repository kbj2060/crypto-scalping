## 결론
- **방향성: 64개 후보 전부 동률.** 그룹 IC 는 ±0.005 안에서 같다(ETH 리테일 TRAIN −0.058~−0.061). 맞대결 bp 가 달라 보이는 것은
  척도가 바뀌면 |z|≥0.5 의 발동 빈도가 1.3~3.9회/일로 달라지기 때문이다. 빈도를 현행과 맞추면(사후 점검) TRAIN 에서 현행을 이기는 후보가 없고,
  TEST 에서 현행 대비 짝지은 차이의 CI 는 거의 모두 0 을 포함한다.
- **표시 공정성: 같은 시간대 기준선(hod·dow)이 결정적으로 낫다.** 시간대별 |z|≥1 비율의 표준편차가 현행 7.1pp → 0.4pp 이고,
  한산/붐빔 비율은 0.51 → 1.00 이다. KST 02~06시(UTC 17~21) |z|≥1 비율은 현행 25% vs 미국장 41% 에서 37% vs 37% 로 바뀐다.
- 비율판(순매수÷거래량)을 후행창에 쓰면 반대로 한산한 시간이 과장된다(q/b 1.6~1.8).
- 사전 고정 규칙의 결과: ETH 승자는 `dow4|mad|net|none`(TRAIN 에서 최고 후보와 동률 20개 중 시간대 std 최소)이다.
  TEST 맞대결 +5.29bp [+1.7,+8.5] 3.68회/일로 확인됐고, 현행 대비 −1.16 [−3.9,+1.7] 로 동률이다.
  hod14|mad 는 모든 지표에서 이와 동률(시간대 std 0.36 vs 0.35pp)이고 이력은 절반만 필요하다.
- BTC: 방향은 동률로 재현됐다(TRAIN 2024 한 해뿐이라 모두 CI 가 넓다). 공정성 개선(7.8 → 0.5~0.8pp)도 재현됐다.

다중 비교: 64후보 × 3그룹, 선택 지표 1개(TRAIN 맞대결). 빈도를 맞춘 점검은 1차 결과를 본 뒤 추가한 것이라 선택에는 쓰지 않았다.
