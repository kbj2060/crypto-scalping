## 무엇을 재측정했나

Phase 1은 **"전환 시점의 방향 예측력"** 을 쟀고 전 스케일에서 무의미했다. Phase 2는 목적함수를
바꿔 **"레짐이 증거신호가 잘 먹히는 때를 알려주는가"** 를 잰다.

라벨은 **모델 예측이 아니라 ground truth**로 계산했다. 의도적인 순서다 — 라벨 정의 자체에 조건부
가치가 없으면 어떤 분류기도 만들어낼 수 없다. (⚠️따라서 2026-08-27 연구의 +29~37%와 직접 비교
불가 — 그건 GBM3의 *예측* 레짐을 썼고 반전 계열 일부만 보고했다. 이 문서의 `REF_deployed` 행이
이 스크립트 자신의 사과-대-사과 기준선이다.)

**GBM3 기반**: 3-class bull/bear/chop, 기준은 raw(무디바운스) — GBM2 계보 import 없음.

## 대조군 — 순환 이동(circular shift) 귀무분포

세그먼트로 조건화하면 신호의 정밀도와 세그먼트 자신의 피벗 기준선이 **둘 다** 바뀌므로
"조건부 lift > 전체 lift"는 그 자체로 증거가 아니다. 그런데 **무작위 산포 표본은 레짐의 올바른
귀무가 아니다** — 레짐은 자기상관이 강한 연속 블록이다. 그래서 레짐 마스크를 **무작위 오프셋으로
순환 이동**(B=200)시켜 블록 구조와 duty cycle은 정확히 보존하고 가격과의 정렬만 파괴했다.
이 저장소 microstructure 패널 스크린이 쓴 것과 같은 구성이다.

창은 **VAL(2025-09-01~12-31)/OOS(2026-01-01~02-17)를 분리 보고**한다 — 같은 날 §5.15에서
풀링 생존자 7개가 정확히 이 분리로 전멸했다.

## 후보 라벨 정의

```
S = 12 (1시간), K = 3 (15분 확인)
er_12  = |close − close[−12]| / Σ|diff|(12)
er_24  = |close − close[−24]| / Σ|diff|(24)
net_24 = close − close[−24]
slope_12 = EMA(close, 12).pct_change()
trend  = (er_12 ≥ T1) | (er_24 ≥ T2)      T1/T2는 TRAIN에서 배포 라벨 발동률에 백분위 매칭
bull = trend & net_24>0 & slope_12>0  /  bear = 대칭  /  chop = 나머지
→ _debounce(K=3)
```

배포 라벨 대비: 방향 앵커가 **4시간 → 2시간**, 최단 창이 **2시간 → 1시간**으로 짧아졌고,
동시에 flip_rate는 **0.2014 → 0.0718**, run median은 **3봉 → 10봉**(Phase 1 측정)으로 안정적이다.
**"작은 범위인데 더 안정적이고 더 잘 조건화한다"** — Phase 1의 긴장이 디바운스로 해소된 형태.

## ⭐순환 오염 사전점검 — 실행 완료, 결과는 "추가 제외 불필요"

Phase 3에 들어가기 전에 새 라벨의 4개 원재료를 136피처 전체와 Spearman 대조했다(66,528행).

| 원재료 | 최대 \|rho\| 상위 | ≥0.80 프록시 |
|---|---|---|
| `er_12` (추세/횡보 판별) | chop_index 0.584, bb_width_z 0.369 | **없음** |
| `er_24` (추세/횡보 판별) | bb_width_pct_rank_288 0.394, state7_range_compression 0.380 | **없음** |
| `net_24` (방향 앵커) | mtf_trend_4h 0.829, rsi 0.815 | 2개 |
| `slope_12` (방향 확인) | vwap_dist_24 0.908, kalman_velocity 0.886, rsi 0.875 | 5개 |

**해석 — 두 종류의 상관을 구분해야 한다.**

2026-08-26에 실제로 문제였던 것은 `state7_trend_efficiency_48 = clip(er_48, 0, 1)` 같은
**리터럴/단조 변환의 재투입**이었다(정답 공식을 그대로 피처로 준 것, rho≈1.0). 반면 여기서 나온
0.80~0.91은 **서로 다른 공식이 같은 경제적 실체를 재는** 정상적 상관이다 — RSI·VWAP 이격·칼만
속도가 단기 기울기와 높게 상관하는 건 당연하고, 이걸 배제하면 레짐 분류기에서 모멘텀 정보를
통째로 빼는 것이 된다.

**결정적 사실 두 가지**:
1. **`slope_12`는 `mtf_trend_1h`와 정의가 완전히 동일**(둘 다 `EMA(close,12).pct_change()`)한데,
   `mtf_trend_1h`는 **이미 GBM3의 제외 5개 목록에 있다**(확인: `'mtf_trend_1h' in feature_cols
   → False`). 즉 유일한 리터럴 원재료는 이미 빠져 있다.
2. **조건부 가치를 만드는 부분은 `chop` 클래스**이고, 그 판별을 담당하는 `er_12`/`er_24`에는
   **≥0.80 프록시가 하나도 없다**(최대 0.584). Phase 2가 측정한 것이 정확히 chop 조건화이므로,
   그 결과는 순환으로 설명되지 않는다.

**결론: 새 라벨은 GBM3가 이미 제외하는 것 외에 추가 제외가 필요 없다.** 배포 모델도 정확히 같은
상황(방향 프록시는 존재, 리터럴 원재료만 제외)을 이미 수용하고 있다.
