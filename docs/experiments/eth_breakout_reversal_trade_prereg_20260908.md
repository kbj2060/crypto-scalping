## 개정 2 — 배리어를 ATR 상대로, 매매 규칙 보류 (2026-09-08, 사용자 선택 A)

**라벨의 배리어를 절대 ±0.25% → `±0.8×ATR` 로 바꿨다.** 새 규칙 ID
`breakout_reversal_ff075_atr08_h1h_20260908`.

### 왜 바꿨나
절대 배리어는 ATR 구간마다 **질문의 난이도가 딴판**이었다:

| ATR 구간 | 배리어/ATR | 시간청산 | 돌파율 | 정확도 | 귀무 | 초과 |
|---|---|---|---|---|---|---|
| 0.000~0.155% | 2.33× | 25.3% | 0.515 | 55.1% | 48.5% | +6.6pp |
| ≥0.404% | 0.46× | 0.0% | **0.334** | 68.2% | **66.0%** | **+2.2pp** |

⭐고ATR 의 "정확도 68.2%"는 대부분 **클래스 불균형**이었다. 반대로 저ATR 은 정확도가 낮아
보이지만 초과분은 최고였다. 그리고 저ATR 에서는 `강` 등급이 하루 0.2건뿐이라
**2026-09 같은 저변동성 구간에서 카드가 사실상 죽어 있었다**(실측 ATR 0.156% = 학습 중앙의 58%).

### 0.8× 로 바꾼 결과 (시드 20개 · B=32 셔플)
| | 절대 0.25% | **ATR상대 0.8×** |
|---|---|---|
| 커버100 초과 (V/O/H) | +2.91 / +3.49 / +5.59 | +2.72 / **+4.44** / +5.11 |
| 시드 판정 | OK 0 · FLAG 3 · FAIL 0 | **OK 2 · FLAG 1 · FAIL 0** |
| 시드 sd (커버100) | .0074~.0084 | **.0044~.0054** |
| 세 창 동시 | 20/20 | **20/20** |
| 시간청산율 | 9.5% | **3.2%** |
| 저ATR `강` | 0.2건/일 | **1.3건/일** |
| 돌파율 구간 격차 | 0.181 | **0.011** |

전 구간 돌파율이 0.46~0.47 로 균등해졌고 확신도가 불균형이 아니라 실력을 반영한다.

### 🔴대가: 매매 규칙 보류
브라켓 격자를 다시 돌리자 **0/196 통과**(절대 배리어는 10/196, 최선 +2.53bp).
배리어 중앙이 0.25%→0.212% 로 좁아져 최적 TP 가 20→15bp 로 내려갔고,
**TP 15bp 에서는 비용 10bp 가 수익의 67%** 다. 최선칸조차 −2.95bp/건이다.

**사용자 선택 A**: 참고 지표를 살리고 매매는 보류한다. 근거 --
(1) 게이트를 이미 제거해 매매 규칙을 쓰지 않고 있었다,
(2) 통과 10칸이 전부 한 이웃이라 견고성이 얇았다,
(3) 저변동성인 현 구간에서는 게이트 통과가 4.2%뿐이라 사실상 휴면이었다.

`meta.strategy.status = "suspended"`. 종이거래 기록은 계속하되 **판정 근거로 쓰지 않는다.**
직전 규칙은 `meta.strategy.superseded` 에 보존했다.
