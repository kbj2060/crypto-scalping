## 최종 규칙 명세 (통과 후보 — 전진 확인 전 실주문 금지)
1. 4h 방향 모델(대시보드 배포 HGB, `scripts/live_eth_dir4h_20261015.py`) 예측을 5분봉 마감마다 받는다.
2. 8위상: 봉 번호 % 48 ∈ {0, 6, …, 42} 인 봉 마감마다 그 위상이 결정 — 예측 ≥ 그 달 문턱 hi(달 시작 전 모든 표본 밖 예측의 80분위) 면 롱, ≤ lo(20분위) 면 숏, 사이면 평평. 위상당 명목 1/8.
3. 목표가 바뀌면 다음 봉 시가에 시장가 청산. 같은 방향이면 그대로 보유.
4. 평평하고 목표가 있으면 매 봉 마감에 **EMA20(5분 종가) 지정가**를 다시 건다(롱이면 EMA20 < 현재가일 때만). 목표가 선 뒤 24봉(2시간) 안에 못 채우면 시장가.
5. 손절·익절 없음. 펀딩 미반영(보유가 길어 실제 손익에 영향).
라이브에 필요한 것: 위상별 지정가 재호가 집행기(USDC peg 집행 경로와 겹침 — 취소 확인 없는 재호가 금지 메모 참고), 4h 예측의 5분마다 기록, 전진 판정 코드(미작성).

## 교훈 (playbook 에 추가)
- 5분 EMA/VWAP «정렬 상태»는 세 번째 확인으로도 방향 정보 0 — 지정가로 비용을 0 으로 만들어도 회전(코인당 하루 18회) × 테이커 청산·역선택이 다 먹는다. EMA/VWAP 은 **체결 위치**로만 쓸 것.
- 승률 기저가 낮은 메타 라벨에 확률 문턱 .5~.6 을 사전 고정하면 거래 0 → «아무것도 안 함»이 검증 1등이 된다. 문턱은 학습 예측 분위로, 거래 0 팔은 고르기에서 뺀다.
- 겹치는 다봉 표적(48봉)을 행마다 넣고 적합하면 GBM 이 외운다(학습 IC .55 → 검증 .005). 강한 기존 모델이 있으면 새로 적합하지 말고 저장된 걸어가기 예측을 재료로 쓴다.
- 강한 방향 신호 위에 «동의 필터»를 얹으면 신호의 큰 몫(추세 반대편 진입)을 잘라 손해(21/21).
