# zig075 학습형 SHORT 진입거부 (TCN, 딥러닝) — Odyssey4 실행 로그 #2 (2026-08-14)

상태: **`REJECTED_SIGN_MISMATCH`** — VAL 게이트는 strict 통과했으나 OOS-Q1+OOS-Q2 단일터치에서
OOS-Q1이 파국적으로 반전(with_gate 67.25% → **−12.70%**, MDD −15.48% → −28.43%)해 탈락.
strict/relaxed 동일 판정. **규칙 기반 veto(Odyssey4 베이스라인, CONFIRMED)가 유효한 해로
유지된다.** 이 실험은 동시에, 30번째 entry-side 학습 시도로서 "정보 부족(모델 용량 문제가
아님)" 가설을 지금까지 중 가장 강한 형태로 재확인했다 — 모델 예측이 전혀 개입하지 않는 순수
가격 경로 라벨(연 10만 bar 밀집)로도 연도 밖 판별력이 없다(2026 AUC 0.477, 역방향).

## 배경 — 과제 지시

사용자 지시(2026-08-14): "고정 규칙 기반 필터 말고 강화학습이나 딥러닝으로 학습해서 문제를
해결해줬으면 좋겠어." 규칙 veto(Odyssey4)와 같은 슬롯에서, 학습된 모델이 거부 결정을 내리는
버전을 만들고 같은 게이트로 심사했다.

## 정식화 — 왜 "방향 학습"이 아니라 "거부 게이트 학습"인가

Odyssey1이 확정한 벽(direction 스킬은 이 피처 우주에서 학습 불가, N≥5 × 7개 모델 계열) 때문에
방향을 다시 학습하지 않는다. 대신:

- **라벨**: zig075 SHORT의 거래 템플릿은 상수(TP 7.5%/SL 4.0% price move, ATR floor 포화)이므로
  **매 bar의 반사실 결과를 모델 없이 계산 가능**: "이 bar에서 템플릿 숏을 열면 SL이 TP보다
  먼저 오는가"(replay와 동일한 슬리피지·TP우선 규칙). 연 10만 bar 밀집 라벨.
- **RL 등가성**: 고정 템플릿의 진입/스킵은 1-step contextual bandit이고, Q(state, enter) =
  E[거래손익|state]는 위 barrier 확률과 등가다. 반사실 라벨이 전 bar에 존재하므로 희소 보상
  policy gradient(창당 거래 13~35건, 선례: Gittins Deep RL exit 부정 결과)보다 잘 정식화된
  같은 문제의 supervised 해다.
- **배포**: p(SL-first) ≥ p\*이면 zig075 SHORT 진입 거부. 이미 검증된 veto replay 슬롯
  (`greedy_replay_entry_veto`의 `short_entry_veto_mask`)에 마스크만 교체.

## 사전 등록 규율 (전부 실행 전에 고정)

1. **학습 = 2024년만** (`training_features_2024.csv`, Omega4.6.1 계보 전체가 사용한 적 없는
   연도) → 2025 전체(Q1/Q2/Q3/VAL)와 2026(OOS)이 진짜 홀드아웃. Q3는 구조적으로 학습 배제.
2. 라벨은 2024 가격 내에서만 해소 — 연말 미해소는 검열 폐기 → 2024/2025 경계 누수 자동 차단.
3. **HP 탐색 없음, 조기종료 없음**: 레포에서 검증된 TCN 아키텍처(B9,
   `verify_eth_h48qual_tcn_sequence_model_20260812`) 재사용, 고정 12 epoch. 어떤 결과에도
   선택이 걸리지 않음.
4. **임계값은 자유변수가 아님**: p\* = (TP − 왕복수수료)/(TP+SL) = **0.6435** — 페이오프
   구조의 손익분기("E[손익]<0이면 거부")에서 유도.
5. 시드 5개 사전 등록([733421, 90817, 428003, 615229, 187561]), 배포 점수 = 5시드 앙상블 평균,
   시드별 마스크는 Q3/VAL 부호 일치 확인용.
6. 판정: G0(베이스라인 재현) → 앙상블 마스크 6창 fresh-forward → VAL 게이트 →
   OOS-Q1+OOS-Q2 단일터치(Odyssey3 무개입 베이스라인 대비). 규칙 veto 수치는 참고 비교 행.

피처(12채널, 전부 causal): 다중 스케일 후행 로그수익률(1/12/96/288/1008/2016 bar),
ETH−BTC 상대 2016-bar 수익률, dual_momentum(raw), 실현변동성(96/2016), chop_index,
regime_persistence. 손 규칙의 rolling-fraction 집계는 **의도적으로 입력에서 제외**(모델이
스스로 집계를 학습해야 "학습형"이므로). 윈도우 288 bar(1일), 표준화는 2024 통계만.

학습: 서버 GPU(handoff.sh), 85,509 샘플. 2024-11+ 홀드아웃 AUC 0.57~0.58(진단 전용).
2024 월별 SL-first 비율은 0.48(7월)~0.96(11월)로 레짐 의존성이 라벨에 실재함을 확인.

### 메커니즘 — 판별이 아니라 기저율 효과였다

앙상블 AUC(진단 전용, 반사실 라벨 대비):

| 구간 | AUC | SL-first 기저율 |
|---|---|---|
| 2025-Q1 | 0.587 | 0.570 |
| 2025-Q2 | 0.524 | 0.746 |
| **2025-Q3** | **0.498 (무작위)** | 0.726 |
| 2025-Q4(VAL) | 0.544 | 0.541 |
| **2026** | **0.477 (역방향)** | 0.550 |

- mask 발동률이 전 구간 36~58% — 레짐 탐지기(규칙 veto: 5~12%)가 아니라 **bar의 절반을
  무차별 거부하는 광역 필터**로 수렴했다.
- 2025 내 성과 개선(VAL +122% 포함)은 판별력이 아니라 기저율 효과다: SL-first 비율이 높은
  구간에서 숏 절반을 지우면 스킬 없이도 개선처럼 보인다. Q3 개선(+4.08)조차 AUC 0.498에서
  나왔다 — 규칙 veto(+20.17)에 크게 미달하면서 메커니즘도 다르다(우연한 절반 제거 vs 정확한
  레짐 조준).
- 2026에서는 AUC가 0.5 아래로 뒤집혀(0.477) 승리 숏을 골라서 거부하는 역선택이 됐다.
- **시드 5/5 일치의 교훈**: 일치한 것은 신호가 아니라 기저율 효과였다 — 시드 일치는 신호의
  필요조건이지 충분조건이 아니며, 다중구간 단일터치 게이트가 정확히 이 함정을 잡았다
  (VAL +122% 신기루 = Odyssey1 미해결 이슈 12 "VAL 신뢰성"의 재확인이기도 하다).

### 이 부정 결과가 확인해주는 것

30번째 entry-side 학습 시도. 이전 29건과 달리 이번엔 (a) 모델 비개입 순수 가격 경로 라벨,
(b) 연 10만 밀집 샘플, (c) 완전 홀드아웃 연도 분리, (d) HP/임계값 선택 편향 원천 차단이었는데도
연도 밖 판별력이 없다. **"h48qual/zig075 계열 피처 우주에서 진입 방향/타이밍의 미래 결과는
학습 불가능하다(정보 부족)"는 Odyssey1 결론이 라벨 정의와 무관하게 성립함을 가장 깨끗한
조건에서 재확인**했다. 학습이 실패한 자리에서 규칙 veto가 성공하는 이유도 대칭적으로
명확해진다: 규칙은 "예측"하지 않고 이미 실현된 1주 추세의 지속성만 측정한다(측정 vs 예측).

## 준수 확인

`fresh_forward_bar_by_bar=true`(마스크는 causal 피처만의 함수, replay는 단방향 pass),
`trade_ledgers_used_as_input=false`, `saved_parent_exit_timestamps_used=false`,
`future_rows_used_for_entry=false`. 반사실 라벨은 미래 참조가 맞으나 (i) 2024 학습과
(ii) 홀드아웃 진단 AUC 보고에만 쓰였고 어떤 의사결정 경로에도 들어가지 않는다.
G0 베이스라인 재현 6창 전부 일치. 라이브 파일/서버 섀도우 무변경, 기존 모듈 임포트만.
Seed-Diversity Gate: N=5 사전 등록 랜덤 시드, 시드별 결과 전부 보고(위). 학습은 서버
GPU(handoff.sh job `zig075_learned_veto_train`), 평가는 dev CPU.
