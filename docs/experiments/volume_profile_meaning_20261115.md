## 무엇을 뜻하나
1. **POC 끌림은 «시가 근처 되돌아옴»의 재표현**: 실제 가격은 무작위보다 시가 근처 수준을 자주 다시 찍는다(하루 안 평균회귀). POC 자리든 반대편 같은 거리 아무 자리든 비슷하다(68.8% vs 67.7%).
2. **80% 규칙은 반대로 읽어야 한다**: 시가가 가치영역 밖에서 출발해 다시 안으로 들어와도, 반대 끝까지 가는 비율 44% < 무작위 50%. 들어온 쪽 가장자리 근처에 머물거나 원래 쪽으로 돌아가는 경향(09-30 실측 44/34% 와 같은 방향).
3. VAH·VAL 은 되밀지 않고(48.9% = 위약), 손 안 탄 POC 는 «언젠가 채워진다»는 끌림이 없고(반대편 거울 수준이 더 잘 닿음), LVN 에서 더 빨리 움직이지도 않는다(1.013 vs 1.017 ATR).
4. 대시보드 표시는 **«어디서 많이 거래됐나» 지도**로만 쓰고, 지지·저항·목표로 읽지 않는다 — `dashboard/market_ctx.py` docstring 의 09-30 결론과 같다.
