# 일리아스 — 레짐 직결 노출(RDE) 정책: 시드-안정 방향원 아키텍처 검증 (2026-08-22)

## 배경과 가설

사용자 과제: "논문 축은 전부 막혔다. 일리아스 프로젝트에서 가진 무기로 **시드 검증에서
백테스트 PnL을 양수로** 만들 새 무기를 만들라."

기존 확정 사실(이 실험의 출발점):
- 3라벨(zigzag/h48qual/cusum) TabM의 방향 정보량은 정보이론적으로 0
  (BCE=절편전용 이론하한, `ilias_eth_label_fusion_combined_model_research_20260821.md` §8).
- 시드검증 실패의 실제 원인은 시드별 우연한 롱/숏 편향 × 구간 추세
  (long_frac↔PnL 상관 0.888~0.918, 계약서 "일리아스 라벨로직 후보축" 절).
- 이 프로젝트에서 Seed-Diversity Gate(N=5)를 실제 통과한 유일한 자산 = wide24 HMM 레짐
  분류기(states=24/sticky=0.90, OOS std≈0.0001).

**가설**: PnL을 결정하는 방향 판단을 시드-불안정한 TabM에서 시드-안정한 HMM 레짐 확률로
직결(bull→LONG, bear→SHORT, 신뢰저하→청산)하면, (1) 시드간 부호 일치는 구조적으로 확보되고
(2) 레짐 nowcast의 지속성이 비용을 이겨 양수 PnL이 가능하다.
