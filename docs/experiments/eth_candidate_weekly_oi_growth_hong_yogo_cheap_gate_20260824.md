## 가설 (Hong & Yogo 2012, JFE, doi:10.1016/j.jfineco.2012.04.005 이식)

상품선물에서 OI 증가율은 월간 수익률을 양(+)으로 예측(리스크프리미엄/헤징수요 메커니즘,
가격 모멘텀보다 강함). 크립토 직접 검증 문헌은 부재(이번 검색 기준) — 이식 가설:
**ETH 무기한선물의 4주 OI(계약수) 증가율이 다음 1주 수익률을 양(+)으로 예측한다.**
부호는 사전고정(+, Hong-Yogo). 크라우딩 역가설(−)은 채택하지 않고 결과만 양방향 보고.

## 설계 (데이터 접촉 전 고정)

- **데이터**: `data/TOTAL_ETHUSDT_metrics_2024_2026.csv`의 `sum_open_interest`(**계약수 기준**
  — `sum_open_interest_value`는 가격×수량이라 기계적 가격오염, 사용 금지),
  `binance_data/klines/ETHUSDT/ETHUSDT-5m-api.csv` close. 둘 다 UTC-naive, 08-23 무결성
  대수술 검증 참조본. 신선도 가드: 두 소스 max ≥ 2026-08-18 미달 시 abort.
- **주간 그리드**: 월요일 00:00 UTC 경계. 경계 t의 피쳐 = log(OI_t / OI_{t−4주}) (primary),
  log(OI_t / OI_{t−1주}) (secondary, 보고용 — 선택에 사용 금지). 타깃 = log(close_{t+1주}/close_t).
  OI_t는 경계 직전 30분 내 마지막 5m 버킷값(bucket-end 라벨, causal).
- **표본**: 2024-01 시작 + 4주 룩백 → 유효 ~134주. 반분 경계 2025-05-05(월).
- **통계**: 전표본 Spearman IC + circular-shift 순열 z(N=2000, 최소 shift 8주) + 양반분
  부호일치. 오염 게이트: |spearman(피쳐, close)| ≥ 0.5면 배제.
- **경제성**: 피쳐의 후행 26주 z(min_periods=24 — 92%, min_periods=window 금지 규칙 준수),
  |z|≥1일 때 포지션 = sign(z)(부호 사전고정 + 방향 그대로: OI성장 상위→롱), 아니면 플랫.
  주간 재평가, 비용 5bp/leg × |Δpos|(플립=2leg=10bp). 벤치마크 = max(always-long,
  always-short)(자체 진입비용 차감). **수수료 우대 시나리오 없음 — 10bp 왕복 표준만.**
- **판정(사전등록)**: PASS = ① 전표본 IC>0 그리고 |순열z|≥2, ② 양반분 모두 IC>0,
  ③ 경제성 증분(전략 순PnL − 벤치) > 0 양반분 모두. 하나라도 실패 시 REJECTED.
- **교차자산(보고용)**: BTC/SOL 동일 파이프라인(`TOTAL_{BTC,SOL}USDT_metrics`) — 판정에
  사용하지 않고 교차자산 정합성만 기록(Bieganowski-Ślepaczuk 2026의 교차자산 안정성 동기).
- 변형 탐색 금지: 룩백 2종(4주 primary/1주 secondary) 외 그리드 없음, 단일 실행.
