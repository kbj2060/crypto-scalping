## 2. 극점 탐지기 · V자 급등란 — 거리 교란

같은 봉·같은 콜 건수·중립 성과로 정면 비교했다(공통 표본외 2026-04-01~09-08 · 46,351봉 · 160일).
자카드 16~24% 로 **서로의 사본이 아니다** — 그래서 「중복이니 하나 자른다」는 논거는 성립하지 않았다.
무너뜨린 건 **거리**다.

- 극점 콜의 **98%(231/235)가 거리 최상위 십분위**에 몰려 있다(콜 평균 3.48 ATR vs 무작위 봉 0.52).
- 거리 ±5% 최근접 매칭: 극점 71.1% vs 거리기대 64.8% = **1.10x**(p=0.048) · V자 66.8 vs 63.7 = 1.05x(p=0.34).
- **평탄한 3.0×ATR 스톱이 더 짧은 거리에서 같은 생존율**을 낸다(3.00 ATR→70.6% vs 극점선 3.48 ATR→71.1%).
- 모델 없이 「가장 넓은 봉」만 골라도 **77.0%** — 극점보다 높다(선이 더 머니까).
- 12봉 수익은 6개 팔 전부 일군집 CI 가 0 을 포함한다.

🔴**아티팩트 자신의 meta 에 적힌 「리프트 3.62x」도 같은 교란을 안고 있다** — 기저 18.7% 는
모든 거리를 섞은 값이다. 이 라벨을 다시 쓸 때는 거리 층화가 필수다.

## 3. ⭐변동성 수준 — 화면이 자기 모델의 가장 좋은 출력을 버리고 있었다

카드가 오래 「🔴 곧 커진다는 못 맞힙니다(확장 AUC .46~.52 = 동전)」라고 적어 왔다.
**채점 오류였다.** 확장은 «비율» 질문인데 모델의 «수준»으로 채점했다(수준은 스케일을 갖고
비율은 안 갖는다). 올바른 점수는 `예측 ÷ 직전 4시간`이다.

| 점수 | AUC (확대 ≥1.3배, 기저 26.8%) |
|---|---|
| 모델 **수준** (카드가 쓴 방식) | 0.5157 ← 카드의 ".46~.52" 재현 |
| rv48 단독 (평균회귀) | 0.6831 |
| HAR 이탈 | ~0.65 |
| **모델 이탈 (예측÷직전)** | **0.8237** |

분모 공유(rv48 이 점수와 라벨 양쪽에) 를 의심해 rv48 십분위 안에서 재측정: **평균 0.7865 ·
10/10 셀 0.69 이상** · 축소 쪽 대칭 0.8015 · 분기 5/5 (0.729~0.791) ·
일블록 부트스트랩 95% CI **[0.754, 0.822]** 로 0.5 배제.

크기도 편향이 없다: `log(실제배수) = −0.0091 + 1.0365·log(예측배수)`.
예측 십분위별 실제 중앙값 0.55 → 1.78 단조, P(≥1.3배) 2.3% → 82.5%.
⚠️단 잔차 SD 0.34 — 예측 1.5배일 때 실제 68% 구간이 [1.07, 2.12]배다. **점이 아니라 중심값**이다.

변동성은 4시간 안에 실제로 많이 움직인다: 1.3배 이상 변하는 경우 56.5%, 2배 이상 13.5%.

**화면 반영**: `1.36배 · 확대 56%`. 확률 = `sigmoid(-1.6560 + 6.1834·ln(배수))`,
TRAIN(≤2025-08-31, 385,453행) 적합 · OOS 109,267행 Brier 0.1388(상수예측 0.1961) · 십분위 보정오차 ≤4pp.
