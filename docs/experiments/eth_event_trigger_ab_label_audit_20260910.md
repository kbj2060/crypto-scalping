## 질문 — 라벨이 **들어갈 수 없는 가격**을 기준으로 채점하는가

돌파/되돌림은 라벨 탐색이 트리거 봉 **안**에서 시작해 39%가 진입 전에 끝났다.
나머지 트리거는 탐색창이 `i+1` 부터라 봉을 공유하지 않는다. 대신 다른 형태로 같은 병이 있다 —
**기준가가 트리거 봉의 저가/고가**다. 장중 극점은 사후에만 아는 값이고 그 가격에 살 수 없다.
결정 시점에 실제로 잡을 수 있는 값은 **그 봉의 종가**다.

| | A라벨 (현행) | B라벨 (체결가능) |
|---|---|---|
| 기준가 | `low[i]`(바닥) / `high[i]`(천장) | `close[i]` |
| 탐색창 | `i+1 …` (동일) | `i+1 …` (동일) |

행·피쳐(38)·모델(HGB 5시드)을 전부 고정하고 **기준가만** 바꿨다. 절대 AUC 는 배포 수치가 아니다
(배포는 TabPFN·다른 피쳐) — 읽어야 할 것은 **A와 B의 격차**다.
극점 A라벨은 배포 라벨을 **파리티 0.999971** 로 재현한 뒤 비교했다.

### 극점 — 실력은 있으나 광고의 절반, 그리고 **배포 모델은 그대로 못 쓴다**

무관용 B라벨("종가로 사서 한 틱도 안 내려간다")은 양성률 1.2%(양성 46~106건)로 퇴화하므로
판정 근거로 쓰지 않는다. 실제 손절 여유를 준 팔이 답이다: **0.54~0.60**.
0.70 → 0.54~0.60, 즉 **AUC 의 0.13~0.16 이 기준가 특혜**였다.

🔴더 중요한 것: **A학습 모델을 B라벨에 그대로 쓰면 AUC 0.477~0.485 로 기저 이하**다.
세 창 전부 0.5 아래이고 방향이 일관된다 — 우연이 아니라 **역상관**이다.
메커니즘은 단순하다. A라벨은 «장중 극점이 안 깨졌다»를 요구하므로 **꼬리가 긴 봉**을 선호한다.
그런데 꼬리가 길수록 종가는 저점에서 멀고, 그래서 종가 기준 라벨은 더 자주 실패한다.
지금 화면의 극점 확률은 «진입 타이밍»으로 읽으면 **거꾸로 읽는 것**이다.
(카드 자체는 "매매 트리거가 아닙니다"라고 이미 밝히고 있다 — 이 결과는 그 문구를 뒷받침한다.)

## 추가 (사용자 질문) — «딱 그 한 봉 말고 3봉쯤 오차를 주면?»

두 가지로 갈린다. **인과적 형태**는 «종가에 들어가서 첫 g봉은 무조건 견딘다»(판정창을
`i+1+g … i+W+g` 로 통째로 민다 — 창을 줄이면 쉬워져서 양성률 상승이 grace 효과처럼 보인다).
«그 g봉 중 최저 종가에 산다»는 결정 시점에 어느 봉인지 모르므로 **오라클**이고, 상한으로만 읽는다.

### B재학습 AUC (VAL / OOS / 최근)

| | 시간 여유 g=0 | g=1 | g=2 | **g=3** |
|---|---|---|---|---|
| 가격 여유 τ=0.5ATR | **.542 / .573 / .546** | .512 / .547 / .523 | .509 / .540 / .535 | .507 / .540 / .539 |
| 가격 여유 τ=1.0ATR | **.556 / .602 / .576** | — | — | .528 / .568 / .554 |
| 오라클(3봉 최저종가) | — | — | — | .512 / .554 / .535 |

🔴**시간 오차를 줄수록 내려간다.** τ=0.5 에서 .542→.507(VAL), τ=1.0 에서 .556→.528.
두 τ 에서 방향이 같고 g=1 에서 이미 떨어진다 — 잡음이 아니다.
**오라클조차 g=0 보다 낮다**(.512/.554/.535 vs .542/.573/.546). 즉 «몇 봉 빗나갔을 뿐»이 아니다 —
3봉 안에서 어느 봉이 최선인지 미리 알려줘도 모델의 순위는 나아지지 않는다.

⭐**가격 여유는 도움이 되고 시간 여유는 안 된다.** τ 0.5→1.0 은 g=0 에서 +.014~+.030,
g=3 에서 +.021~+.028 로 두 줄 다 오른다. 이 신호의 제약은 «언제»가 아니라 «얼마나 견디느냐»다.

🔴**배포 모델(A학습)의 역상관은 어느 오차에서도 안 뒤집힌다**: g=0 .477~.485 → g=3 .486~.493,
오라클 .491~.495. 0.5 로 다가가긴 하나 세 창 어디에서도 넘지 않는다.
