## 판정: 사전등록 글자대로는 통과 — 그러나 «강도로 방향(이어짐/되돌림)을 안다»는 성립하지 않는다 → 배포 대기에 올리지 않음
- 사전등록 네 조건은 시험 구간에서 전부 넘었다(아래 표).
- 그런데 독립 검토가 낸 분해를 돌려 보니, 방향 점수는 **«얼마나 격한 돌파인가(크기)»의 거울**이었다. 크기 재료만 쓴 모델과 견주면 방향 판별력이 늘지 않는다(시험 +.007 · 하한 −.009, 검증 −.011).
- 사전등록의 조건 2·3·4 는 «방향 정보가 전혀 없는 피쳐»로도 통과할 수 있는 꼴이었다(아래 모의). 판정 기준을 잘못 짠 것이다. 그래서 이 결과를 «돌파/되돌림을 맞히는 모델»로 보고하지 않는다.
- 남는 것: **«60초 안에 크게 움직이느냐»는 잘 맞힌다**(AUC C .70 · R .78 · 로그손실 −0.128). 이것은 크기(변동성 계열) 예측이다.

## 사전등록 표 (시험 2026-06-01 ~ 11-15 · 단측 90%)

## 왜 «방향»이 아닌가 (독립 검토의 분해 · 재구성 스크립트로 직접 실행)
결판 난 사건의 C 대 R AUC 를 재료 묶음별로 다시 냈다.
| 모델 | 시험 | 검증 |
|---|---|---|
| 사전등록 기준선(평소 변동성·시각·24시간 여부) | .526 | .573 |
| **크기 재료만**(부호 없는 거래량·체결 수·변동성 계열) | **.575** | **.596** |
| 부호 있는 재료만(돌파 쪽 매수 비중·흐름·방향) | .558 | .567 |
| 전체(사전등록 모델) | .582 | .585 |
| 전체 − 크기만 | +.007 (하한 −.009) | −.011 (하한 −.028) |
- «큰 움직임이 날 확률» 하나만으로도 방향 AUC 가 시험 .579 · 검증 .631 이다. 방향 점수와 큰 움직임 확률의 순위상관은 −.73 · −.77.
- 위약을 «월 × 큰 움직임 확률 층» 안에서 섞으면(크기를 고정) 위약 평균이 .5 가 아니라 시험 .552 · 검증 .589 다. 실제는 시험 .582(위약이 실제 이상인 비율 5.4%) · 검증 .585(58.9%).
- **모의**: 방향을 모르고 변동성만 아는 피쳐에, 돌파 쪽으로 일정한 쏠림(기저 C 비율 58.6%)만 주면 — 결판 조건부 방향 AUC 평균 .560(5~95% .513~.603) · 모델 몫 +.062 · 상위−하위 C 비율 차 +21.8pp. 실자료의 통과 수치와 같은 크기다. 쏠림 0 이면 .500.
- 원리: 조용한 돌파는 큰 움직임 자체가 드물고(10%), 났을 때는 평균 쏠림(이어짐)이 그대로 보인다. 격한 돌파는 양쪽으로 다 튀어 50:50 에 가깝다. «결판 난 것만» 보면 크기를 아는 것만으로 C 비율이 갈린다.
- 전체 사건 기준 확률로 보면 «이어짐 쪽» 집단이 오히려 C 가 가장 드물다: 시험 상위 집단 P(C) 7.9% · P(R) 2.6% / 하위 집단 P(C) 35.5% · P(R) 40.4%.
- 진짜 방향 몫 후보: 돌파 전 10초 매수 비중(`pre_imb10`)은 세 구간 모두 같은 방향의 C 비율 차를 보였다(검토 보고). 크기를 떼고 난 몫은 아직 재지 않았다 → 2라운드에서 본다.

4. **(채점 뒤 · 독립 검토) 판정 기준 자체의 결함**: 조건 2·3·4 가 크기만으로 통과 가능(위). 조건 1 은 거의 자명하다(강도는 크기를 맞힌다).
