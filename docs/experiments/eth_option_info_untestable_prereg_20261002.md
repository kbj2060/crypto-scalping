## 가설과 판정 기준(동결)
1. **ATM 호가 폭** — 카드 주장: «넓으면 마켓메이커가 위험을 피한다(급변 경계)».
   - 주 검정: 다음 24h ln 실현변동성 ~ 호가 폭 + ln DVOL + ln 지난 24h 실현변동성, 순위 표준화 β.
   - 지지 = β > 0 이고 CI 가 0 배제. 반대 = β < 0 이고 CI 0 배제. 그 외 = 근거 없음(필요 일수 병기).
   - 보조(판정 미사용): 다음 24h |ΔlogDVOL|.
2. **옵션 선도 − 지수** — 카드 주장: «대개 ±3bp, 그 정도는 잡음» + 툴팁이 보류한 해석 «콜 수요면 +».
   - 잡음 주장: 10분 변화 SD 와 수준 5~95% 분위를 보고(기술, 판정 아님).
   - 주 검정: ρ(선도−지수, 7일 25Δ 리스크 리버설) 시간별, 지지 = ρ > 0 이고 CI 0 배제.
   - 방향 무관 확인: 다음 1h·24h 수익률 부호 β — CI 가 0 포함이어야 «방향 신호 아님»과 부합.
3. 판정 뒤 처리: 근거 없음/반대면 대시보드에서 줄을 뺀다(사용자 10-02 방침과 동일). 지지면 툴팁을 «✅검증»으로 바꾼다.
