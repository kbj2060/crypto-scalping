## 무엇을 뜻하나
1. **차트에서 «맞아 보이는» 비율 대부분은 기하가 만든다.** 방향 기억이 없는 가짜 가격에서도 FVG 는 90% 메워지고, 같은 고점은 83% 스윕되고, OB 는 59~61% 버틴다. 실제 값(90% · 84% · 63~69%)만 보면 «잘 맞는다»처럼 보이지만 비교 기준이 50% 가 아니다.
2. **추세 전환(CHoCH)은 동전 던지기**: CHoCH 뒤 새 방향으로 한 번 더 구조가 깨질 확률 50% = 위약 50%. 보조(24봉 뒤 방향)에선 CHoCH·BOS 둘 다 신호 방향 적중이 45~47%로 위약(50%)보다 **낮다** — 구조 돌파 뒤엔 짧게 되돌아온다. 15분 내부 BOS 의 «지속»이 거꾸로 나온 것도 같은 현상.
3. **존(OB·FVG)이 되돌아온 가격을 받치는 효과는 실재하지만 작다**: 무작위 대비 +1~+8pp, 바로 옆 띠 대비 +1~+4pp. 15분 스윙(N50) OB 가 가장 크다(68.9% vs 61.1%). 단, 구조 돌파 뒤 짧은 되돌림(2번) 성질이 같이 작용하므로 «그 자리라서»인 몫은 P2 차이(+1~+4pp) 쪽으로 읽는다.
4. **유동성 이야기는 절반만 맞다**: 같은 고점·저점은 «거리가 같은 평범한 스윙»보다 +2~4pp 더 잘 스윕되지만, 무작위 가격 대비로는 거의 차이가 없고 코인마다 엇갈린다. 스윕 뒤 반전(«유동성 사냥»)은 없다(47~48% ≈ 위약). 스윕 봉 거래량(직전 100봉 중앙 대비)도 같은 고점 1.9~2.1배 < 평범한 스윙 2.2배 — «손절이 쌓여 있다가 터진다»는 거래량 흔적이 없다.
5. **전일 고저(핵심 가격대)는 되밀기보다 뚫고 가는 쪽**: 첫 터치 뒤 반대 1 ATR 먼저 46.6%(15분) < 위약 48.7%. 11-14 «24시간 고저 돌파 뒤 이어짐»과 같은 방향.
6. FVG 는 15분에서 하루 18개, **봉의 77~84% 에 살아 있는 갭이 있다** — 거의 늘 «FVG 안»이라 구간 자체로는 정보가 적다.

## 보조
- 사후 그림 효과: 스윙을 피벗 봉에서 바로 안다고 쳐도(뒤 N봉 미리 봄) CHoCH·BOS 의 «다음 돌파 같은 쪽» 비율은 인과판과 0~1.4pp 차이(실제 46~51%) — 이 측정에선 미래참조가 부풀리지 않았다. 패키지의 «나중에 뚫린 것만 표시»는 차트의 인상을 바꾸지만 이 비율과는 무관.
