## 결론
1. «횡보/추세 구분» 모델의 쓰임 근거가 없다. 미래 레짐을 완벽히 알아도 이 전략군에서 이득은 문턱 미만이고, 실제 예측은 AUC .52~.54 로 기준선과 구별되지 않는다.
2. 사용자의 직관과 다른 점: 페이드가 이기는 날은 «횡보»가 아니라 **큰 반전이 오는 날**이고, 그건 인과 피쳐로 예측되지 않는다. 조용한 날의 페이드는 소음 손절로 진다.
3. 전환 T 는 F 가 이 단계에서 막혀 사전등록대로 진행하지 않았다(T 는 F 보다 어렵다는 선행 결과와 일치).
4. 한계: ER·4h·R2/T2 라는 하나의 라벨·전략 정의 안에서의 결론이다. 다른 지평·전략(예: 레벨 기반 TP, 사용자의 재량 청산)은 검정하지 않았다. 시행 4회(S0 3 + 진단 1), 전부 기록.
5. 사후 탐색(위 학습 4분위 표)은 추가 검정 없이 해석용으로만 썼고, 더 이상의 변형은 같은 데이터의 정의 탐색이 되어 만들지 않는다.
