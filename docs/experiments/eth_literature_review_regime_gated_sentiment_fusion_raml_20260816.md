# 논문 리뷰 — RAML(Regime-Aware Multi-Modal Learning): Reddit 감성 + 레짐게이트 BTC 방향 예측, 우리 모델 적용 가능성 검토 (2026-08-16)

상태: **완료. 신규 서브프로젝트 착수는 권장하지 않음.**

## 요청과 한 일

사용자가 `arXiv:2607.23370v1` 링크를 주고 우리 모델에 적용 가능한지 조사해달라고 요청했다.
WebFetch의 HTML 변환이 PDF를 바이너리로 잘못 읽어 실패했기 때문에, `pypdf`로 직접 텍스트를
추출해(19페이지, 62KB) 전문을 읽었다. 논문의 아키텍처·데이터·결과·저자 자신이 밝힌 한계를
정리한 뒤, 저장소의 `docs/model_contracts/research_line_registry.json`(종료된 21개 리서치
라인), 최근 h48qual 데이터소스 조사 문서, 그리고 이미 CONFIRMED 상태로 배포된 zig075 레짐
거부권 메커니즘과 대조해 적용 가능성을 평가했다.

## 논문 요약

- **저자**: Muhammad Abdullah Haroon, FAST-NUCES(파키스탄) 학부생 단독 저자. 동료심사 없는
  arXiv preprint(2026-07-25 게재).
- **대상**: BTC-USD, **시간봉**(우리는 ETH 5분봉), 3시간/6시간 앞 방향 이진분류
  (`y=1 if close[t+h] > close[t]`).
- **데이터**: yfinance OHLCV(시간봉, 730일 제한) + Reddit r/Bitcoin FinBERT 감성 점수
  (Kaggle 사전계산 데이터셋, PRAW로 수집) inner join → 3,491시간(2024-07~2025-09, 14.5개월).
  train 2,146행(2024-07~2025-06) / test 1,345행(2025-07~2025-09), 단일 시간순 분할.
- **아키텍처**: 가격 브랜치(OHLCV+r_t+σ_t+RSI+MA7+MA30=10피쳐, 24시간 윈도우, 2-layer
  BiLSTM d=64)와 감성 브랜치(FinBERT composite/bullish/bearish/strength+post count=5피쳐,
  동일 구조)를 각각 32차원 임베딩으로 인코딩. 이진 변동성 레짐(24h 롤링 vol > 전체 중앙값)에
  조건화된 **단일 스칼라** 시그모이드 게이트 `w_t = σ(θ_r · r_t)`로 두 임베딩을 가중합
  (`e_fused = w_t·e_sent + (1-w_t)·e_price`) 후 2-layer FF 분류기(BCE loss). 총 파라미터
  ~218K, 게이트는 θ_r 단 1개 추가 파라미터.
- **핵심 주장**: RAML이 3h/6h 모두 F1 최고(0.5474 / 0.5513), 3h AUC 최고(0.5084). 3-variant
  ablation(감성 브랜치 제거 / 레짐게이트 제거 / 융합을 concat으로 대체)에서 셋 다 제거 시
  성능이 저하되어 "세 요소 모두 필요"하다고 주장.
- **저자 스스로 인정한 한계**: 절대 성능은 무작위에 가깝고("modest"), train 2,146행이 작다,
  이진 레짐이 단순하다, BTC 단일 자산만 검증했다, 시간 단위 감성 집계가 시간 내 순서를
  버린다, 매크로 이벤트 피쳐가 없다.

## 통계적 엄밀성 비판 (우리 기준으로 재검증)

1. **"최고 AUC"가 통계적으로 무작위와 구분되지 않는다.** Hanley–McNeil SE 근사
   `SE = sqrt((n1+n2+1)/(12·n1·n2))`, test set n1=659(Down)/n2=686(Up)로 계산하면
   SE≈0.0158. 3h AUC 0.5084는 z≈0.53(양측 p≈0.6, 완전히 비유의). 6h AUC는 오히려 0.4902로
   무작위 이하(z≈-0.62, 방향도 틀림). "4개 모델 중 최고"라는 상대적 우위가 절대적으로
   무작위와 구분된다는 뜻은 아니다.
2. **시드 다양성 전무.** 7개 모델 변형(baseline 4 + ablation 3)을 각각 "1회" 학습·평가한다.
   다중 시드, 반복, 분산 보고가 어디에도 없다. 저장소의 Seed-Diversity Ensemble Promotion
   Gate(N≥5 진짜 다양한 시드) 기준에 크게 못 미친다. `tabm_hp_low_signal_pattern` 메모에서
   이미 확인했듯 이 스케일(ΔAUC 0.008)의 차이는 시드 노이즈 범위 안일 가능성이 높다.
3. **Ablation이 내적으로 모순적이다.** 레짐게이트를 제거한 A2가 오히려 3h F1을
   0.5474→0.6180으로 "개선"시키는데, 저자 스스로 이것이 recall 0.58→0.79로 폭증하는
   다수클래스 편향 때문이라고 인정한다. 즉 "게이트가 필요하다"는 주장은 F1이 아니라 유의하지
   않은 AUC 차이 하나에 의존한다.
4. **train/test 경계에 purge/embargo가 없다.** 6시간 라벨은 미래를 보는데 분할 경계
   (2025-06→2025-07) 부근 행에 대한 embargo 언급이 전혀 없다. 저장소의 Fresh-Forward
   Validation/OOS/Test Rule 대비 약하다.
5. **OOS가 3개월 단일 연속 구간이다.** 우리가 요구하는 멀티윈도우 게이트(독립된 여러 구간에서
   방향 일치 확인)가 없다. 단일 구간 결과가 재현 안 되는 패턴은 이 저장소에서 반복적으로
   확인된 리스크와 정확히 같다.
6. **거래 전략 평가가 전혀 없다.** 순수 분류 지표(Acc/Prec/Rec/F1/AUC)만 있고 TP/SL, 레버리지,
   비용, 슬리피지를 반영한 PnL 백테스트가 없다. 분류 지표상의 근소한 우위가 실제 트레이딩
   가치로 이어지는지 검증되지 않았다.

## 우리 프로젝트와의 대조

- `research_line_registry.json`의 종료된 21개 라인 중 "소셜/텍스트 감성" 계열은 없다 — 순수
  신규 축은 맞다.
- 단, `docs/experiments/eth_h48qual_quality_new_data_source_research_20260811.md`(항목 8)에서
  이미 확인됐듯 저장소 전역에 텍스트 뉴스/소셜 감성 데이터가 **전혀 존재하지 않는다**.
  `news_shock_guard.py`는 이름과 달리 마이크로구조+청산 테일리스크+예측시장 신호의 합성일
  뿐 텍스트 인풋이 전무하다("존재하지 않음 — 완전 신규 구축 필요"). 이 논문을 실제로
  적용하려면 라이브 Reddit/Twitter/뉴스 수집기 + FinBERT류 스코어링 파이프라인을 처음부터
  구축해야 하고, 자산(BTC→ETH)과 시간프레임(시간봉→5분봉) 전환도 별도 작업이다.
- 아키텍처 아이디어(이진 레짐에 조건화된 단일 스칼라 시그모이드 게이트) 자체는 새롭지 않다.
  우리는 이미 zig075 레짐(추세방향) 조건부 진입 거부권 메커니즘을 CONFIRMED 상태로 실제
  라이브에 배포했다(SHORT/업트렌드, LONG/다운트렌드 양쪽 모두). 차이는 RAML이 "거부권"이
  아니라 "두 임베딩의 연속 가중합"이라는 점인데, 이는 신호 강도에 따른 연속 가중 결합 계열과
  개념이 겹친다 — 그 계열(evidence-signal 주입 축)은 발화 bar가 매칭된 랜덤 bar와 exit
  결정에서 구분 불가능함이 확인돼(6/6 윈도우) 이미 닫혔다.
- 감성 신호 자체가 신규 정보를 담고 있는지는 이 논문만으로는 미지수다. 우리가 표준으로 쓰는
  raw-feature 오염 체크(`spearmanr(feature, price)`)에 해당하는 것도, 실제 미래 수익률과의
  rank correlation(우리 IC 사전선별 기준)도 이 논문에 없다 — `mean_finbert`가 가격 레벨과
  r≈+0.08이라는 것만 보고할 뿐이다.

## 결론

**신규 서브프로젝트로 착수하는 것은 권장하지 않는다.**

이유:
1. 논문의 헤드라인 결과 자체가 통계적으로 무작위와 구분되지 않는다(AUC z<0.6, 6h는 방향도
   틀림) + 시드/멀티윈도우 검증이 전무하다.
2. 감성 데이터 자체가 우리 저장소에 존재하지 않아 착수 비용이 크다(라이브 수집기+NLP
   파이프라인 신규 구축, 자산·시간프레임 전환 포함).
3. 유사한 "레짐조건부 연속가중 융합" 메커니즘 계열은 이미 저장소에서 실패로 닫혔다
   (evidence-signal 주입 축).
4. 이미 CONFIRMED 상태로 배포된 zig075 레짐 거부권이 개념적으로 이 논문의 핵심 기여를
   이미 흡수하고 있다.

나중에 재검토한다면 선행 조건: 감성 데이터(Reddit/Twitter/뉴스) 라이브 수집기부터 구축 →
방향 라벨과의 rank correlation(IC) 사전선별로 free-benchmark 대비 증분 확인 → 통과할 때만
게이트/융합 아키텍처를 검토. 현재는 1단계(데이터 자체)조차 없는 상태다.
