## B. 금리 발작 → ETH 5분봉 — «요즘 반대로 같이 움직인다»는 체감은 맞다, 단 나스닥을 거쳐서
- 정의(사전 고정): 30년물 5분 수익이 직전 20거래일 표준편차의 4배 이상인 봉입니다.
- 비교 기준: 같은 요일·같은 5분 칸의 평소 봉
- 아래 표의 «금리↑ 방향 ETH»는 금리 오르는 쪽을 +로 맞춘 값이라, 음수면 금리가 오를 때 ETH가 내렸다는 뜻입니다.

| | 예전 2024-01~2026-06 | **요즘 2026-07~10-11** |
|---|---|---|
| 발작 횟수 | 748 (월 25) | 92 (월 28) — 더 잦아지지는 않았다 |
| 같은 봉 ETH 크기 / 평소 | 40.5 / 17.9bp = **2.3배** [2.1, 2.5] | 29.4 / 17.8bp = **1.7배** [1.3, 2.1] |
| 같은 봉 금리↑ 방향 ETH | −8.8bp [−14.6, −2.7] | **−21.6bp [−30.9, −14.0]** (중앙값 −15.7) |
| 금리 반대로 움직인 비율 | 59% | **76%** |
| 같은 봉 나스닥(금리↑ 방향) | −2.6bp | **−17.4bp** |
| 이후 1시간 / 2시간 ETH | +7.7 / +10.6 (되돌림 쪽, CI 0 포함) | −12.7 / **−21.2 [−46, −1.9]** (이어짐 쪽) |
| ETH ~ 나스닥 + 채권 회귀 | 채권 t = 5.1 (나스닥 빼고도 남음) | **채권 t = 0.4** (나스닥이 전부) |

- 문턱을 3배로 낮춰도 같은 그림입니다. 요즘 같은 봉 −15.9bp [−19.7, −12.1], 74%이고, 예전은 −1.8bp(0 포함)입니다.
- 발작 시각은 08:30 ET(지표 발표)가 가장 많고, 10:00·18:00(선물 재개장)·13:00(입찰) 순입니다.

해석:
1. **«요즘 금리 발작 = ETH 급변»은 방향 면에서 맞습니다.** 예전엔 금리가 튀어도 ETH 방향이 반반(59%)이었고, 요즘은 76%가 반대로 움직이며 평균 이동도 2.5배입니다.
2. 크기 자체는 «평소의 2배 안팎»으로 예전과 비슷합니다(오히려 예전이 2.3배). 예전 발작은 지표 발표 순간의 양방향 흔들림이 많았고, 요즘은 한 방향(금리↑ = ETH↓)으로 정렬된 것이 차이입니다.
3. **전달 경로는 나스닥입니다.** 요즘 발작 봉에서 나스닥이 −17bp로 같이 빠지고, 나스닥을 통제하면 채권 몫이 사라집니다(t 0.4). 앞의 일간 분석(나스닥↔10년 이동 상관 −0.39~−0.59, 2022년 이후 최강)과 같은 현상입니다. 금리가 주식을 흔들고, 주식이 ETH를 흔듭니다.
4. 발작 뒤 2시간 이어짐(−21bp)은 약한 결과입니다. 50일 중 음수인 날이 52%뿐이고, 발작 9번이 몰린 10-01 같은 며칠이 평균을 끌었습니다. 예전엔 반대(+10.6)였습니다. 매매 규칙으로 쓰려면 전진 사전등록이 필요합니다.
