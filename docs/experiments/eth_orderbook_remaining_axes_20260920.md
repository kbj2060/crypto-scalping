# 호가 프로파일 — 남은 두 축을 닫는다 (ETH, 2026-09-20)

「이 피드에서 아직 안 잰 것」이 둘 남아 있었다. 둘 다 쟀고 **둘 다 화면에 넣지 않는다.**
이유가 서로 다르므로 각각 적는다.

## 1. 깊이 기울기 — 독립적이지만 «이미 그려져 있고» 예측력이 없다

기울기 = `ln( 먼 쪽 누적깊이 / 가까운 쪽 누적깊이 )`, near ≤0.25% · far 0.25~1.0%,
닿는 쪽만. 사건 집합은 지지·저항 테스트와 **같다**(71,357건).

### 화면이 이미 그리는 축과 겹치나 — 안 겹친다

| 상대 | Spearman rho |
|---|---|
| 불균형(OBI) | +0.026 |
| 지속률 | +0.041 |
| 가장 가까운 벽 거리 | +0.031 |
| 닿는 벽 크기 | −0.302 |

### 뭔가를 예측하나 — 아니다

반등률: 0.513 / 0.505 / 0.509 / 0.508 (기울기 사분위, ±0.007).
크기 사분위 안에서 기울기 상위−하위 합산 **−0.003, z = −1.25**.

### 그래서 왜 안 넣나

「다른 스칼라와 독립」과 「화면에 없다」는 다른 말이다. **막대 자체가 거리별 깊이**이고
기울기는 그 막대들의 기울기다 -- OBI 처럼 `abs()` 에 지워지는 축이 아니라, 눈으로 읽는
바로 그 모양이다. 거기에 예측력도 없다. 숫자를 하나 더 얹을 이유가 없다.

## 2. 초 단위 취소 vs 체결 — 사건에선 살아나는데 화면 단위에서 다시 죽는다

행별 흡수/이탈은 앞서 기각됐다(15분 창에서 체결량이 감소량을 압도해 「거래가 있었나」의
재표현이 됐다 -- 체결 있던 행 이탈 전 분위 0.00). 포화 원인이 **집계 폭**이라면 초 단위로
맞대면 갈릴 것이다 -- 그 가설을 쟀다.

맞댄 것: 래스터(1초 × $0.5) ↔ `trade_tape_1s`(1초 × $0.1, 5칸씩 접음). 방향은 테이커
매도↔매수호가 / 테이커 매수↔매도호가. 겹치는 구간 4.6일.

### 사건 단위 — 포화가 풀린다 (가설 맞음)

- 감소 사건 **11,253,587건**, 그중 같은 초에 체결이 있던 것 **188,262 (2%)**.
- 체결이 있던 초만: 이탈비율 p10/25/50/75/90 = **0.0 / 0.659 / 0.942 / 0.992 / 0.999**.
  완전이탈 48% · 완전흡수 14% · **중간 38%**.

15분판의 「전 분위 0.00」과 비교하면 확실히 갈린다.

### 화면 단위 — 다시 죽는다 (그래서 안 넣는다)

1시간 창 × 행별 흡수율 `Σmin(drop,fill)/Σdrop` (n=22,009 행-창):

p10~p90 = **0.0 / 0.0 / 0.0 / 0.0 / 0.004** · **0 에 붙은 행 99%** · 가운데 1%.

행 단위 총감소는 «체결 없는 초»가 지배하므로 비율이 전부 0 으로 눌린다. 상수는 축이 아니다.

## 남은 진짜 소득 하나

**호가 감소의 98%는 그 초에 체결이 전혀 없다.** 즉 화면의 「이탈」이 말하는 바 --
사라지는 유동성의 대부분은 먹혀서가 아니라 그냥 빠지는 것 -- 이 훨씬 촘촘한 해상도에서도
그대로다. 먼 벽을 장벽으로 믿지 말라는 화면의 경고에 근거가 하나 더 붙었다.

## 그래서 이 피드의 미탐색은 0 이다

남은 것은 전부 **원리적 불가**다: 큐 위치 · 아이스버그 · 개별 주문 수명(바이낸스 선물 WS 는
레벨별 총량만 주고 주문 ID 가 없다) · 다른 코인(래스터가 ETH 전용이고 호가는 소급 불가).

# 덧붙임 — 그래서 호가창은 무엇에 쓰나 (같은 날)

「벽이 지지·저항이 아니면 이 화면은 뭘 말하나」에 답하려고, **화면에 있는 축 전부**에
같은 잣대를 댔다. 60초마다 한 표본, 5.8일, **7,676개 · 독립 일수 7**, 일자 블록 부트스트랩.

## 방향 — 없다

| 축 | 300초 | 900초 |
|---|---|---|
| 불균형(OBI) | +0.033 (CI 0 포함) | +0.001 (0 포함) |
| 60초 Δ | +0.004 (0 포함) | +0.014 (0 포함) |

벽 크기·지속·기울기가 반등/돌파를 못 가른 것과 같은 결론이다. **호가창은 어느 쪽으로
갈지 말하지 않는다.**

## 크기 — 있다

|수익률|(움직임의 크기)과의 Spearman, 괄호는 **직전 300초 실현변동을 통제한 부분상관**:

| 축 | 300초 | 900초 |
|---|---|---|
| 재깔림 | +0.165 → **(+0.139)** | +0.177 → **(+0.156)** |
| 블록 크기 | +0.124 → (+0.093) | +0.158 → (+0.135) |
| 지속률 | −0.111 → (−0.076) | −0.122 → (−0.099) |

전부 일자 블록 CI 가 0 을 배제한다. 통제 전후로 크게 줄지 않는다 --
`rho(직전변동, |300초|) = +0.161` 이니 **재깔림은 최근 실현변동과 비슷한 정도로 말하고,
그 위에 얹힌다.**

부호도 뜻이 통한다: 자꾸 다시 깔리는 책·큰 덩어리가 오가는 책은 곧 크게 움직이고,
**가만히 있는 책은 조용하다**(지속률이 음수).

## 그래서 이 화면의 쓰임

**「어디서 멈출까」가 아니라 「얼마나 흔들릴까」다.** 진입 방향을 고르는 도구가 아니라
**크기·손절폭·대기 여부**를 정하는 도구다. 벽을 목표가로 쓰지 말고, 재깔림이 높은 국면에서
평소 크기로 들어가지 않는 식으로 쓴다.
