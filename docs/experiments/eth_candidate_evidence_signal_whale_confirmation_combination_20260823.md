# ETH — 증거신호×모델지표 조합 방향가설: 고래포지션 컨펌 (사전등록, 2026-08-23)

## 정정 먼저

이 세션 앞부분에서 "trading_bot이 모델지표 이력을 저장하지 않는다"고 여러 번 단언했는데
**틀렸다** — `dashboard_state.json`(대시보드가 읽는 파일)만 최신값뿐이었고, 별도 경로
(`data/live/microstructure.duckdb::microstructure_1m`, `data/live/tail_risk.duckdb::tail_risk_1m`)에
분단위 이력이 이미 쌓이고 있었다. 서버 실측: 145,646~145,732행, 2026-05-03 17:36 ~
**2026-08-23 18:14(현재)**, 계속 갱신 중. 이 덕분에 몇 주 대기 없이 지금 바로 cheap-gate가
가능해졌다.

**데이터 결함 이월 확인**: `tail_risk_1m.shadow_aftershock_prob`는 5~6월 100%, 7월 72%가 0 —
[[eth_liquidation_feed_epoch_defect_20260817]]에서 이미 진단된 청산피드 결함(07-18 15:03 UTC
이전 무음)과 같은 패턴(aftershock_prob가 그 청산스트림에서 파생되므로 당연한 전파). 이
축은 `microstructure_1m`(obi/nif_whale/whale_position_score/eai — 결함 없음, 5월부터
건강)만 쓰므로 이 결함의 영향 밖이다.

## 가설

증거신호(가격위치/오더플로우 계열, 2026-08-14 검증)의 반전 콜이 **모델지표의 고래포지션
컨펌**(다른 정보계열 — 오더북 심도/고래전용 대형체결)과 동시에 발생하면, 컨펌 없는 콜보다
순방향 수익률이 크다. 근거: 이 저장소에서 서로 다른 정보계열 결합이 유일하게 검증된 성공
사례(orthogonal_combo = 오실레이터+테이커플로우, +54% 리프트)를 **아직 안 써본 계열
페어**(오더북/고래)로 확장하는 것 — 새 조합을 무작정 찾는 게 아니라 이미 검증된 패턴을
원칙적으로 넓히는 것.

## 조작적 정의 (데이터 보기 전 고정)

- **증거콜**: `bottom_votes≥1`(바텀) 또는 `top_votes≥1`(탑) — 08-14 연구·이 세션 발동률
  실측과 동일 정의 재사용, 새 정의 없음.
- **고래컨펌**: 증거콜 봉 시각에 가장 가까운(≤5분) `microstructure_1m.whale_position_score`가
  바텀콜엔 `> 0.2`, 탑콜엔 `< -0.2` — 대시보드 기존 `whalePosTone` 임계값 재사용(데이터 보고
  새로 고른 임계값 아님).
- **타겟**: h=3(15분) forward return, 콜 방향으로 부호 정렬(바텀콜=원시 수익률,
  탑콜=수익률×-1) → "signed_fwd_ret". 양수=콜이 맞은 방향.
- **왜 whale_position_score만(6개 다 아님)**: 다중비교 희석 방지. obi는 후보축으로 기록만
  해두고(탐색적, 저가중), 이번 1차 가설은 whale_position_score 단일.

## 분할 (사전등록)

데이터가 2026-05-03부터라 이 저장소의 표준 TRAIN(2024-01~)에 안 맞음 — 이 축 전용 분할:

| 구간 | 기간 | 용도 |
|---|---|---|
| TRAIN | 2026-05-03~07-31 | IC스캔/순열귀무 |
| VAL | 2026-08-01~08-16 | 부호일관성·판정 |
| OOS | 2026-08-17~(현재) | **예약, 오늘 미평가**, 추후 단일터치 |

전체 창이 ~16주뿐이라 OOS를 지금 쪼개 쓰면 표본이 지나치게 얇아진다(이 저장소가 반복 경고한
함정) — 시간이 더 쌓인 뒤 재평가. 오늘은 TRAIN+VAL만.

## 사전등록 판정 기준 (5개, 결과 보기 전 고정)

1. **부호일관성**: 컨펌subset 평균 signed_fwd_ret > 비컨펌subset 평균, TRAIN·VAL 둘 다.
2. **순열귀무**: 컨펌 라벨을 N=2000회 셔플(주변 컨펌비율 보존), 실제 갭의 |z|≥2 (VAL 기준).
3. **절대수익**: 컨펌subset 평균 signed_fwd_ret이 그 자체로 양수(상대적으로 나은 정도가
   아니라 실제 방향이 맞아야 함).
4. **비용게이트**: 컨펌subset 평균이 taker 10bp(리포 표준) 이상.
5. **최소표본**: VAL 컨펌subset N≥30. 미달 시 "표본부족"으로만 기술, 방향 주장 금지.

5개 중 하나라도 실패하면 표본 크기와 무관하게 기각. 결과 확인 후 이 기준을 바꾸지 않는다.

## 결과 (같은 날 실행, TRAIN+VAL만)

스크립트: `scripts/research_eth_evidence_whale_confirmation_cheap_gate_20260823.py`.
(참고: 스크립트의 "N/M calls matched" 진단 출력은 klines 전체(2023-12~2026-08) 기준이라
낮아 보이는데, 이는 모델지표 데이터가 2026-05-03부터만 있어서 그 이전 구간 콜은 애초에
매칭 대상이 아니기 때문 — 아래 TRAIN/VAL 표본은 분할 창으로 걸러진 실제 사용치.)

| | TRAIN(05-03~07-31) | VAL(08-01~08-16) |
|---|---:|---:|
| 콜 수(매칭됨) | 690 | 643 |
| 컨펌subset N | 310 | 306 |
| 컨펌 평균 | **−0.49bp** | +1.58bp |
| 비컨펌 평균 | +0.96bp | +1.49bp |
| 갭 | **−1.45bp** | +0.09bp |
| 순열 z | −0.67 | **0.059** |

**판정 기준 5개 전부 실패**:
1. 부호일관성 — TRAIN 갭이 **음수**(가설과 반대 방향), VAL은 거의 0. 불일치.
2. 순열 |z|≥2 — VAL z=0.059, 순수 노이즈와 구분 안 됨.
3. 절대수익 양수 — VAL만 기술상 참(+1.58bp)이나 무의미한 수준.
4. 10bp 비용게이트 — 미달(자릿수 자체가 다름).
5. 최소표본 N≥30 — **충족**(TRAIN 310/VAL 306) → 표본부족 때문에 기각된 게 아니라
   통계적 검정력은 충분한데 효과 자체가 없다는 뜻.

**REJECTED.** orthogonal_combo 패턴(오실레이터+테이커플로우 결합이 +54% 리프트)을 새
계열 페어(오더북/고래)로 확장한다는 원칙적 근거가 있었지만, 실측은 그 확장이 안 먹힌다는
걸 보여준다. 표본 부족이 아니라 진짜 무효과(z≈0)라는 게 핵심 — 이 저장소의 지배적 메타
발견(약한 신호끼리 조합해도 새 축이 안 열림)이 여기서도 재확인됐다.

**OOS(08-17~)는 계획대로 오늘 안 봤다** — 판정이 이미 TRAIN+VAL에서 결정적으로 갈려서
볼 이유가 없다(사전등록 규율: 5개 중 하나라도 실패하면 표본 크기 무관 기각).

## ⚠️ 같은 날 정정 2건 — 타임존 버그 + 컬럼 epoch 발견 (재실행 완료, 판정 불변)

**1. 타임존 버그**: 위 "결과" 절의 1차 실행은 join이 9시간 어긋나 있었다 — klines CSV는
UTC-naive(Binance API 실측 대조로 확정: CSV 2026-08-18 17:35 행이 API의 UTC 봉과 정확히
일치), duckdb ts는 KST tz-aware인데 `tz_localize(None)`으로 KST 벽시계를 그대로 벗겨
UTC-naive와 비교했다. 즉 모든 콜에 **9시간 전의 고래점수**가 조인됐다. 1차 수치(TRAIN
갭 −1.45bp 등)는 가설 검정이 아니라 버그 검정이었으므로 무효.

**2. 수정 후 재실행 (동일 사전등록 설계, join만 수정)**:

| | TRAIN | VAL |
|---|---:|---:|
| 매칭 콜 / 컨펌 N | 706 / 200 | 608 / 160 |
| 컨펌 평균 | +2.03bp | +0.70bp |
| 갭 | **+2.06bp** | **−1.75bp** |
| 순열 z | +0.93 | −1.00 |

**판정 불변 — REJECTED**: 부호가 TRAIN/VAL 간 뒤집히고(+2.06 vs −1.75), 어느 쪽도
유의(|z|≥2) 근처에 못 가며, 10bp 비용게이트는 자릿수부터 미달.

**3. 컬럼 epoch 발견 (전 컬럼 감사로 확인)**: `whale_position_score`는 **2026-07-18
23:58 UTC부터만 기록**(5월/6월 100% NULL, 7월 40.8%) — 낮은 매칭률(~23%)의 진짜 원인.
따라서 이 실험의 "TRAIN 05-03~07-31"은 실질적으로 **07-18~07-31의 13일**이었다. 사전등록
기준(최소 N=30)은 여전히 충족(200/160)돼 판정 자체는 유효하나, 설계 의도(90일 TRAIN)보다
훨씬 얇은 창이었음을 명시한다. 나머지 9개 지표 컬럼(obi/taker_buy_ratio/spoofing/nif_*/
eai/oi_delta/toxicity/queue_collapse)은 05-03부터 전 기간 99.4~100% 건강 — 후속 실험
(h=12/48 패널 게이트)은 이쪽을 쓴다.
