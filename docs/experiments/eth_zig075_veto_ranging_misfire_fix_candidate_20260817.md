# zig075 SHORT 베토 — 레인지 오작동 수정 후보 (2026-08-17)

## 배경

[[eth_zig075_short_veto_paired_onoff_causal_test_20260817]]에서 zig075 SHORT/지속상승장
진입거부(CONFIRMED, `docs/experiments/eth_omega461_zig075_short_entry_veto_sustained_uptrend_20260814.md`)
가 판정 데이터에서 유의한 양의 효과를 낸 적이 없고, 진짜 레인지 구간(2025-05-12~07-07)에서
real_g0 자신에게 −20.18%p, N=20 무작위 방향 전부(20/20)에서 유사한 규모의 손해(평균
−19.22pp, t=−26.58)를 인과적으로 확인했다. 사용자 요청으로 오작동을 수정하는 후보를 설계·검증한다.

## 설계 원칙 (원 탐지기와 동일 규율 적용)

원 탐지기(`score = rolling(2016bar/1주).mean(dual_momentum>0) > p90(2025 Q1+Q2만 보정)`)가
CONFIRMED 지위를 얻은 핵심 이유는 **신규 자유변수 0개**였다(WEEK_BARS=2016은 dual_momentum
자체의 기존 룩백 재사용, DETECTOR_PERCENTILE=0.90은 "표준 십분위 관행, 결과에 맞춰 스윕 안 함").
이번 수정 후보도 같은 규율을 적용한다.

**오작동 가설**: dual_momentum의 "지난 1주 중 양(+)이었던 비율" 점수는, 가격이 기존 레인지
안에서 국지적으로 반등할 때도(1주 전 저점 대비 지금이 높기만 하면) 높게 유지될 수 있다 —
진짜 지속 상승장과 달리 **가격이 신고점을 갱신하지 않는다**는 차이가 있다.

## 시도 1 (v2) — 정확히 신고점 조건: 기각

`close_t >= rolling_max(close, 2016)_t` ("이 bar가 1주 신고점")를 기존 모멘텀 조건에 AND로
결합. WEEK_BARS 재사용, 신규 임계값 없음.

**결과**: 레인지 구간의 손해는 완전히 없앴다(real_g0 −17.59%→+2.59%, no-veto와 동일). 그러나
**활성화율이 모든 윈도우에서 60~1000배 붕괴**(Q3: 43.0%→0.70%)했고, **Q3 자체의 이득도 완전히
사라졌다**(+20.17%→−15.86%, no-veto와 동일, veto_bars 19→0). "1주 안에서 정확히 최고가"라는
조건은 추세든 레인지든 극히 드물게만 참이 되는 사건이라, 베토를 고치는 게 아니라 사실상
꺼버린 것과 같다. **기각.**

## 시도 2 (v3) — 주간 평균 초과 조건: 부분 성공

더 느슨한 조건으로 교체: `close_t >= rolling_mean(close, 2016)_t` ("이 bar가 자신의 1주
평균가 이상"). 같은 WEEK_BARS 재사용, "평균"도 "최댓값"과 마찬가지로 임계값이 필요 없다 —
신규 자유변수 여전히 0개.

### 판정 — 핵심 목표 성공, 한 곳은 못 고침

1. **주 목표(레인지1) 사실상 완전 해결**: t=−26.58(사실상 결정론적 해악) → **t=−0.10**
   (귀무와 구분 불가). real_g0 자신도 −17.59%→+0.97%로 no-veto 기준(+2.59%)에 거의 근접.
2. **Q3(원래 존재 이유) 보존, 오히려 소폭 개선**: +20.17%→**+21.41%**. 활성화율이
   43.0%→32.2%로 줄었지만 veto_bars는 19→18로 거의 그대로 — Q3의 진짜 신호는 대부분
   "가격이 평균 위"라는 조건도 함께 만족했다는 뜻.
3. **VAL/OOS-Q1/레인지2-A/레인지2-B**: 전부 무해 유지 또는 개선(OOS-Q1의 미미한 +0.62pp
   양의 편향도 사라졌지만 애초에 무유의였음).
4. **OOS-Q2는 전혀 못 고쳤다** — random 평균delta·t-stat이 v1과 **소수점까지 완전히 동일**
   (−5.31pp, t=−2.64). 활성화율은 8.19%→3.82%로 줄었는데도 무작위 시드들의 실제 손해가
   조금도 안 바뀌었다 — 이 윈도우에서 해로운 베토 발동은 "가격이 평균 위"라는 조건도
   함께 만족하는 bar에서 일어난다는 뜻, 즉 v3의 필터가 여기서는 변별력이 없다. OOS-Q2는
   전반적 하락추세 속 국지적 반등이라 레인지1(순수 초이스)과 다른 메커니즘일 가능성 —
   원인 미해명, 후속 과제.

## 결론

v3는 **정직하게 부분 성공**이다 — 가장 극적이었던 실패 사례(레인지1, 거의 결정론적 −20pp급
손해)를 신규 자유변수 없이 해결했고 원래의 이득(Q3)을 해치지 않았지만, 두 번째로 컸던 실패
사례(OOS-Q2)는 전혀 건드리지 못했다. "베토를 고쳤다"고 전면 선언할 수 없고, "레인지 국지반등
오작동은 고쳤지만 하락추세 내 국지반등 오작동은 별개 문제로 남아있다"가 정확한 요약이다.

**이건 연구 결과이지 배포 결정이 아니다.** 이 리포의 승격 절차(사전등록 게이트, Red Team,
N≥5 시드 등)를 거치지 않았고, `trading_bot.py`/섀도우 프로세스 어느 것도 이 세션에서
건드리지 않았다 — 실제 배포하려면 별도의 정식 검증 라운드가 필요하다.

## 추가: h48qual 레짐인지 exit 가드는 같은 오작동을 공유하지 않음 (2026-08-17)

### 배경

zig075 SHORT 진입베토와 h48qual 레짐인지 exit 가드는 **같은 탐지기**(v1: 모멘텀만)를 쓰지만
**다른 메커니즘**이다 — 전자는 진입을 아예 막고, 후자는 이미 열린 h48qual 포지션의 exit
판단을 원본(느린) exit head로 전환할 뿐 진입은 건드리지 않는다. Ilias 서브프로젝트
계약(`docs/model_contracts/ilias_eth_human_direction_risk_management_contract_20260817.md`)의
Layer Contracts 표는 진입베토는 스코프 밖(결정 #2)으로 제외했지만 이 exit 가드는
"상속(무변경)"으로 명시했다 — 즉 사람이 아직 검증 안 된 v1 탐지기를 그대로 물려받는다.
사용자 질문("일리아스에 쓸만한가?")에 답하기 위해, 같은 v1 vs v3 페어드 방법론을 exit
가드에도 적용해 같은 레인지 취약점을 공유하는지 확인했다.

### 방법

zig075 베토는 이 테스트 내내 완전히 제거(격리)하여, PnL 차이가 오직 h48qual exit 가드
메커니즘에서만 나오도록 했다. 같은 6개 창(VAL/OOS-Q1/OOS-Q2/레인지1/레인지2-A/레인지2-B) +
Q3(가드의 원래 존재 이유 컨텍스트)에서, 가드 마스크를 NONE(가드 항상 꺼짐)/V1(원본
모멘텀만)/V3(모멘텀 AND 주간평균가 이상, zig075 수정과 동일 마스크 재사용)로 교체하며
real_g0(실제 모델 방향) + N=20 무작위 방향 시드(paired on/off 테스트와 동일 시드,
직접 비교 가능)를 돌렸다. 재현: `scripts/research_eth_odyssey4_h48qual_exit_guard_ranging_misfire_test_20260817.py`.

### 핵심 발견 3가지

1. **real_g0(실제 모델 방향)은 6개 창 전부에서 가드 유무·버전과 무관하게 PnL이 소수점까지
   완전히 동일하다** — 4개 창에서 활성bar가 1000개 이상(Q3는 6053개)인데도 실제 모델의
   실거래 경로에서는 가드가 exit 판단을 단 한 번도 뒤집지 못했다. zig075 베토는 정반대로
   real_g0 자신의 PnL을 레인지1에서 −17.59% vs +2.59%로 직접 파괴했었다 — 근본적으로 다른
   인과 프로파일.
2. **무작위 20시드에서도 6개 창 중 어디에서도 유의한 음성 효과가 없다** — 레인지1(zig075의
   가장 극적인 실패 창)에서조차 t=−1.70으로 무유의(zig075는 같은 창에서 t=−26.58,
   20/20 시드 전부 손해). 오히려 레인지2-B에서는 t=+2.88로 **유의한 양의 효과**(가드가
   도움이 됨).
3. **v1과 v3 사이 차이가 사실상 없다** — 활성화율(가드가 발동한 bar 수)은 창마다 크게
   다른데(OOS-Q1: 1029→0, 레인지2-B: 1029→0) 무작위 시드 PnL 델타는 소수점 한 자리까지
   거의 동일하다. zig075에서는 같은 마스크 교체가 레인지1을 t=−26.58→−0.10으로 완전히
   바꿨던 것과 대조적 — exit 가드에서는 v3 "수정"이 사실상 무의미하다(고칠 문제가 딱히
   없었기 때문).

### 결론

**"exit 가드가 zig075 진입베토와 같은 레인지 오작동을 공유한다"는 가설은 기각된다.** 같은
탐지기를 쓰지만, exit 가드는 (a) 실제 모델 경로에서 사실상 관성적(inert)이고 (b) 무작위
방향 강건성 테스트에서도 어느 창에서도 유의한 해악을 보이지 않는다 — 진입을 막는 것과
이미 확정된 포지션의 exit head를 바꾸는 것은 리스크 노출이 다르다는 뜻으로 해석된다. Q3
컨텍스트 체크는 가드가 zig075 없이도 여전히 원래 목적(−18.87%→−15.86%)을 수행함을 확인했다.

**남는 캐비어트**: (a) 레인지 창은 3개뿐이라 결론이 두껍지 않다, (b) 6개 창에 대한 다중비교
보정을 하지 않았다(레인지2-B의 t=+2.88 단독으론 약한 신호), (c) real_g0가 모든 창에서
완전 무반응이라는 게 "가드가 잘 보정됐다"인지 "원래 영향력이 낮은 메커니즘이라 위험도
낮지만 효용도 낮다"인지는 이 테스트만으론 구분 안 된다 — 이 역시 연구 결과일 뿐 배포
판단이나 Ilias 계약 수정 근거로 그대로 쓰면 안 된다.

**Ilias에 대한 실질적 답**: 계약의 "exit 가드 상속(무변경)" 결정은 이 특정 축(레인지 오작동)
에서는 지금까지 확인된 범위 안에서 안전해 보인다 — 단, 이는 Ilias 세션의 판단이며 이
발견은 참고용으로 전달할 뿐 해당 계약 문서를 이 세션에서 직접 수정하지 않는다.
