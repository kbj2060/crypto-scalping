## 전략별 판정

**① 킬존 + 피벗 — CLOSED.** 킬존 단독은 문자 그대로 0(−0.12pp). 피벗 되찾기는 적중 우위가
진짜지만(+2.8~+5.8pp) 전부 손익분기 미달이고, S1 매수는 유의하게 **음수**다. 킬존을 피벗에
곱하면 건수만 1/3 로 줄고(1.5→0.5건/일) 여유pp 는 **더 나빠진다**(−1.9 → −0.2, 천장은 −1.6 → −2.9).
= "컨펌 쌓기는 희석하거나 무효" 4번째 실측 사례.

**② FVG — CLOSED, 그리고 방향이 반대다.** 적중 우위가 **음수**(−0.6 ~ −2.3pp)이고
갭이 클수록 더 나빠진다(0 → 0.5ATR → 1.0ATR 단조 악화). 08-24 의 0.88x 를 4.8년에서 재현.
⭐**발동 75.7건/일 = 전체 봉의 27%** — OB 가 29% 였던 것과 같은 병리다. 존이 차트를 뒤덮으면
"존 터치"는 신호가 아니라 배경이다.

**③ Equal Highs/Lows — CLOSED, plain sweep 대비 개선 없음.** 설계상 EQH/EQL ⊂ sweep 이라
직접 비교가 된다. 터치 2회 이상으로 조이면 건수 7.07→1.60건/일(4.4배 축소)인데 적중 우위는
+3.02 → +2.71pp 로 **오히려 내려가고**, 3회로 더 조이면 +4.11pp 로 올라가지만 손익분기적중이
57.7→59.3% 로 **더 빨리 올라가** 여유는 −3.0 → −4.9pp 로 악화된다. 09-14 의 터치수 축 기각과 동일 결론.

**④ 세 개를 겹치면(릴스의 실제 주장) — 최악.** 4.8년에 60/38건(0.03건/일)뿐이고
gross **−44 / −49bp**. 원인이 분해로 보인다: 평균이익이 101→**67bp** 로 줄고 평균손실이
128→**178bp** 로 늘어 손익분기적중이 **75%** 가 된다. ICT 합류는 "가격이 이미 크게 뻗은 뒤"에만
성립하므로, 겹칠수록 **역행폭이 큰 자리만 골라 잡는다**.

**결론: ICT 축은 이것으로 4.8년 창에서 재확인 종결.** 살아 있는 것은 "직전 스윙 레벨에서
방향이 조금 맞는다"뿐이고 그 조금은 +3~5pp 로 측정되며, 비용이 아니라 **이긴 판의 크기**가
그것을 무효로 만든다.
