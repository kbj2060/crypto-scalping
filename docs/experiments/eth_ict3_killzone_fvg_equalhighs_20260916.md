09-11(`eth_entry_exit_axes_closed_by_oracle_upper_bound`)과 09-13(`eth_entry_oracle_exit_excess_is_volatility`)
둘 다 같은 이유로 무효였다: **오라클 청산 = MFE = 창 안 최댓값 = 레인지(변동성) 측정**이라
방향을 못 잰다. 09-13 에는 "MFE 회귀 상위1% 초과 +47.7bp"가 나왔는데 롱 146.4 / 숏 154.8 로

> **점유율 = MFE / (MFE + MAE) = 내 쪽으로 간 전방 레인지의 비율**

(1) [0,1] 유계 (2) 레인지로 나눠서 변동성 수준에 무관 (3) ⭐**역방향 대조군이 정확히 1−점유율**
이라 09-13 의 함정이 **구조적으로 불가능**하다. 09-13 의 합/차 판별식도 여기서는 자동이다
(합 ≡ 레인지, 차 ≡ (2·점유율−1)·레인지). 귀무는 09-13 이 지적한 대로 **전방 레인지 20분위 매칭**
(100분위로도 재확인 — 레인지 차 0.0~0.5bp, 매칭은 사실상 완전하다).

오라클 정의: 롱 진입 `open[i+1]`, 창 `[i+1, i+H]` 의 **고가 최대**에 청산(resting TP 체결 관례).
