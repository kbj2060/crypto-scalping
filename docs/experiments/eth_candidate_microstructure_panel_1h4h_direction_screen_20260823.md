# ETH — microstructure_1m 패널의 1h/4h 방향 스크린 (방식2, 사전등록, 2026-08-23)

## 배경 — 왜 이건 금지된 재시도가 아닌가

사용자 요청: "방식2(5분봉 유지, 더 먼 미래 예측)로 1시간/4시간 방향 연구." 기존 클로저와의
경계를 실행 전에 확정한다:

- `microstructure_1m`은 엔트리 알파로 **4회 기각**됐으나 전부 **"1m 단독 알파"**였다
  (`docs/duckdb_live_data_utilization_design_20260719.md` 전제 #1: contrarian flow t=−7.6이나
  0.3~2bp<비용, 금지조항도 "새 1m 진입 모델"). **h=12/48(1h/4h)은 이 데이터로 검증된 적 없음.**
- 캘린더 리샘플 스크린(150피쳐)·분포회귀(158피쳐)는 h=12/48을 다뤘지만 **캐노니컬
  2024~ 분할** 기준 — 2026-05-03부터만 존재하는 이 테이블은 물리적으로 포함 불가능했다.
- L2 요약 게이트는 다른 테이블(`orderbook_decision_snapshots`, 5m 스냅샷)의 h=1 중심.
- microstructure veto 라인(판정보류, 재개 ≥09-30)은 **거부/게이트 질문 + OOS-Q2 소진** —
  본 실험은 방향 IC 질문이고 OOS-Q2를 건드리지 않는다(자체 분할, OOS 예약).

**정직한 사전확률 — 낮음**: 미시구조 정보는 이론상 분 단위 반감기가 정설이라 1~4시간
예측력은 이론에 반하는 베팅이다. 다만 패널에 느리게 움직이는 상태변수(OI 누적, 스푸핑/
독성 레짐)가 있고, 이 조합(이 원천×이 호라이즌)은 진짜 미검증이므로 cheap-gate 1회는
정당하다. 결과가 음성이면 이 축도 닫힌다.

## 설계

- 타겟: 5분봉 close→close forward return, **h ∈ {12(1h), 48(4h)}** — 9피쳐×2지평 = 18셀.
- 통계: Spearman IC + **circular-shift 순열귀무 N=2000**(iid 셔플이 아니라 시프트 —
  겹치는 forward 윈도우의 자기상관을 귀무분포에 보존, 유의성 과대평가 방지).
- 분할: TRAIN 2026-05-03~07-31 / VAL 08-01~08-16 / **OOS 08-17~ 예약(오늘 미평가)**.

## 사전등록 판정 기준 (결과 보기 전 고정)

1. **오염 체크**: |spearman(피쳐, close)| ≥ 0.5면 그 피쳐 제외(판정 아님, 배제).
2. **부호일관성**: TRAIN·VAL IC 동일 부호.
3. **유의성**: circular-shift 순열 |z| ≥ 2, **TRAIN과 VAL 둘 다**.
4. **경제성**: 2·3 통과 셀에 한해 TRAIN-IC부호 고정 임계규칙(트레일링 288봉 z ≥ |1|일 때
   IC부호 방향 진입, h봉 비중첩 보유, 왕복 10bp) 순수익 증분이 max(always_long,
   always_short) 대비 **TRAIN·VAL 둘 다 양수**.
5. **고립생존자 규칙**: 18셀 중 1~2셀만 통과하고 피쳐 패밀리 정합성이 없으면 이 저장소
   반복 패턴(비단조 과적합)에 따라 "미확인"으로만 기술, 통과 주장 금지.

하나라도 실패하면 그 셀 기각. 실행 후 기준 변경 금지.

## 결과 (같은 날 실행, TRAIN+VAL만 — OOS 미접촉)

조인 프레임 33,121봉(커버리지 78.3%). 18셀 전체 결과는 스크립트 출력 참조. 요약:

**통계 생존자 3/18 — 전부 taker-flow 패밀리 (정합적, 고립 아님)**:

| 셀 | contam | IC_tr / z_tr | IC_val / z_val |
|---|---:|---:|---:|
| taker_buy_ratio h=12 | −0.011 | +0.0274 / **3.72** | +0.0662 / **3.19** |
| nif_retail h=12 | −0.008 | +0.0301 / **3.61** | +0.0713 / **3.19** |
| taker_buy_ratio h=48 | −0.011 | +0.0165 / 2.04 | +0.0459 / 2.17 |

- 부호는 **양(+)** — 테이커 순매수 우세가 이후 1~4시간 **지속**(모멘텀)을 예측. 이 저장소가
  아는 단기 5~15분 리버설(lag1_ret 음의 IC)과 방향이 반대인 별개 시간구조.
- nif_retail과 taker_buy_ratio는 같은 aggTrade 흐름의 파생(retail=비고래 잔여)이라 사실상
  **한 개의 신호 패밀리**다. nif_whale(고래만)은 통과 못 함(z 1.3~2.3 사이) — 정보가
  "고래"가 아니라 **전체 테이커 흐름**에 있다.
- circular-shift 순열(겹침 자기상관 보존) 기준으로 TRAIN·VAL 양쪽 |z|≥3은 이 저장소 IC
  스캔들에서 드문 수준 — 통계적으로는 진짜다.
- 맥락: 캘린더 리샘플 스크린(150피쳐, OHLCV 파생)에서는 1h에서 통계 신호가 죽었는데
  (OOS AUC 0.494), 이 패널(1분 해상도 테이커흐름)에서는 1h 신호가 살아있다 — 원천/해상도가
  다르면 결과가 다르다는 드문 실증. 단 시대도 다름(2024~26Q1 vs 2026-05~08)에 유의.

구조적으로 손실이고, |z|≥1 발동률(~30%/봉)의 비용 복리 + 추세장에서 벤치마크(always-long)

지배 패턴의 가장 선명한 재현 사례 중 하나(통계 z 3.7짜리도 비용 벽을 못 넘는다).
