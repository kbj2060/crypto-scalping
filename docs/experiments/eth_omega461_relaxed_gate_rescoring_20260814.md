# Odyssey2 — 완화된 사전등록 기준으로 기각 실험 재채점 (2026-08-14)

## 배경

사용자가 지금까지 기각된 실험들(레짐별 quality_threshold 2종, GBDT/TCN exit_head)을 더
관대한 기준으로 재평가해달라고 요청했다. **사후선택 편향(결과를 보고 그걸 통과시키는
기준을 고르는 것)을 피하기 위해, 구체적인 결과를 다시 들여다보기 전에 새 기준을 먼저
확정**했고, 그 뒤 기계적으로 전부 재채점했다.

## 새 기준 (결과 확인 전 확정)

`replay_omega4_6_1_greedy_router_20260706.py` 원문 주석이 duration-gate 적용 버전을
`"HONEST final number"`라고 명시한다(2026-07-06부터 있던 문구, 오늘 밤 신규 아님) — 이를
근거로 with_gate를 주된 판단 기준으로 승격했다.

1. **주 기준**: 포트폴리오 with_gate PnL이 baseline보다 개선(필수).
2. **리스크 제약**: with_gate MDD는 3%p 이내 악화까지 허용(개선 필수 아님) — 소표본 노이즈
   감안.
3. **가드레일**(exit_head 모델 자체를 바꾸는 실험에만 적용): 컴포넌트(h48qual 단독) PnL이
   부호반전하거나 baseline 대비 50% 넘게 상대 악화하면 안 됨 — GBDT/TCN이 보인 "컴포넌트
   경제성을 회전율로 가리는" 패턴을 막기 위함.
4. no_gate는 진단용으로만 참고, 판정에서 제외.

## 방법

GBDT/TCN exit_head 실험은 with_gate를 애초에 계산하지 않았다(포트폴리오 레벨이 no_gate만).
저장된 거래원장 CSV(`portfolio_ledger_*.csv`)에 `research_eth_omega461_live_sltp_mfe_width_
20260813._duration_gated`(기존 검증된 헬퍼, 신규 코드 없음)를 그대로 적용해 사후에
with_gate를 계산했다 — 재학습·재시뮬레이션 없음, 이미 확정된 거래 목록의 사후 집계만 다시 함.

## 결론

**새 기준으로도 어떤 실험도 뒤집히지 않는다.** 두 가지가 특히 눈에 띈다:

1. **GBDT/TCN의 with_gate 포트폴리오 숫자는 원래(no_gate) 기준보다 훨씬 더 극적으로
   좋아 보인다**(GBDT +101.27%→+120.20%, TCN +60.24%→+84.87%) — 그런데 이건 개선이 아니라
   경고 신호다: with_gate가 좋아질수록 컴포넌트 단독 경제성은 그만큼 더 나빠져 있었다(TCN은
   손실 전환). 포트폴리오 지표만 보고 판단했다면 GBDT/TCN을 오히려 원래보다 더 강하게
   채택하고 싶어졌을 것 — 가드레일이 정확히 이걸 막기 위해 필요했다.
2. **대기압력 OOS는 with_gate로 다시 봐도 반전 자체는 그대로**(-44% 상대하락) — 관대한
   렌즈로 봐도 없어지지 않는 진짜 반전이라는 뜻.

원래 "4개 지표 전부 비악화" 기준이 자의적으로 과했던 게 아니라, 실제로 문제가 있는
후보들을 정확히 걸러내고 있었다는 근거가 됐다 — 원 기각 판정들의 신뢰도가 오히려
강화됐다.
