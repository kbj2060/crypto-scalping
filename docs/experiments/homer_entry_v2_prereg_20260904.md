# 호메로스 진입 모델 v2 — 사전등록 (2026-09-04, 결과 보기 전 작성)

사용자 지시: "오메가 모델은 다 지워라, 엣지 없다. 호메로스의 증거신호와 레짐 분류기가 더 유망하다.
이걸로 진입 모델을 재구축하고, ETH 층별 재구성 게이트를 같이 구성해 버그가 없게 하라."

## 0. 출발점 — 호메로스 계보에서 지금 살아 있는 것 하나

호메로스 계보의 진입 축 시도는 대부분 죽었다(§5.16 앵커 미래참조, §5.17 역선택, §5.20 8축 종결,
진입모델 v1 라벨결함). **살아남은 것은 하나**: V자반등 **경제라벨** 모델
(`live_eth_v_rebound_econ_autotrade_signal_20260902.py`, 문서 `docs/homer/v_rebound_open_issues_20260901.md` §20).

- 모집단 = **매 5분봉 × 양방향**(트리거 게이트 없음 → 앵커 선택 문제 A가 구조적으로 없음)
- 라벨 = **"open[i+1] 진입 → 트레일링(SL 5.0·ARM 1.5·Trail 0.1 ATR, 200봉) → 10bp 차감 > 0"**
  (모양이 아니라 결과. 소진·방향·비용이 라벨에 내장)
- 피쳐 = Tier0 23(klines 전용), 학습기 = TabPFN 5시드 컨텍스트 앙상블(18k행), 선정 = VAL 상위 5%
- 성과 = VAL +3.63 / OOS +7.98 / **HOLDOUT +6.09bp**(n 1,987, 1회) 순차 포트폴리오(동시보유 5)
- 09-04 룩어헤드 감사 A~D 전부 무혐의, 섀도우 러너 봉 고가/저가 파리티 300/300, 09-04 재기동 가동 중

**v2 = 이 모델을 F0(기준선)으로 두고, 사용자가 지목한 두 재료를 얹는다**: ① 레짐 분류기
(ETH S12_K3 · BTC S24_K3, OOF) ② 증거신호 8종 메타라벨 재료(OOF `_pct`/`_age`/방향).
질문은 "레짐·증거신호가 경제라벨 진입 모델의 표본외 기대값을 올리는가"다.

## 1. 층 구조와 게이트 (층 출력이 바뀔 때 그 층 게이트를 다시 돈다)

| 층 | 내용 | 게이트 |
|---|---|---|
| L4 결정 시각 | 봉 τ 마감 후 결정, 진입 open[τ+1] (`fi=pos+1`, `btf=1`) | L4 known_ts 계약 |
| L1 발동 | 모집단은 전체 봉(트리거 없음). 재료가 쓰는 증거신호 발동은 raw 단일봉 | L1 인과성(재료 발동에 대해) |
| L2 라벨 | `sim_exit` 원문(비관 순서: 불리→best→무장→트레일), 비용 10bp, 명목 1 | L2 1분 재구성(5% 표본) |
| L2P 채점 | 백테스트 `sim_exit` ↔ 섀도우 러너 `manage()` | L2P 합성 경로 300 |
| L3 피쳐 | Tier0 23 + 레짐 one-hot(OOF) + 재료(OOF) + `log_return`(조인시점용) | L3 단일AUC/모델AUC/OOF출처/조인시점 |
| 평가 | 대조군 + DSR/PBO | T1 너무 완전 · T2 수치 취약성 |

**FAIL 층 위의 결과는 provisional**. 게이트 러너: `scripts/gate_eth_entry_layers_20260903.py --pipeline tmp/homer_entry_v2_20260904`.

## 4. 선정·평가 (모든 팔 동일, 팔당 OOS 1회)

1. VAL에서 팔별 앙상블 확률 상위 5% 분위 → 임계값(팔 간 **호출 빈도 일치**).
2. 같은 봉 양방향 동시 호출 → 확률 높은 쪽만, 동률 스킵(라이브 규격 T5).
3. 순차 포트폴리오: 진입봉 순, 동시보유 5, `pnl_bp = net_bp`(10bp 차감).
4. 지표: 기대값 bp/건(주지표, n 무관), 총bp, 승률, 손익비, 최대DD, 월별.
5. 대조군: **방향뒤집기**(같은 호출, 반대쪽 행의 net_bp) · **랜덤 부분표집 귀무**(같은 n, B=200, 백분위) ·
   **일 단위 군집 부트스트랩** CI(B=1000; 팔 자체와 F0 대비 Δ 페어드) · **5시드 부호일치**(시드별 자기 VAL 분위 → OOS).
6. 다중검정: 팔 4개를 trial로 DSR(승자=VAL 기대값 최고 팔, OOS 일별 수익률), PBO(CSCV, 일별 × 4팔).
7. 층 게이트 전부 실행(L4/L1/L2/L2P/L3/T1/T2).

**F0 하네스 점검**: F0의 VAL/OOS 기대값이 경제라벨 모델(+3.63/+7.98, TRAIN 시작이 2024-01이라 완전 동일은
아님)과 부호·크기 급이 다르면 하네스 버그로 간주하고 멈춘다.

## 5. 판정 (사전등록)

팔 X(F1/F2/F3)를 **섀도우 승격 후보**로 인정하는 조건(전부 충족):
- VAL·OOS 기대값 > 0, 뒤집기보다 큼, 랜덤 귀무 백분위 ≥ 95 (양 창)
- **F0 대비 Δ**: VAL 일군집 CI 하한 > 0 이고 OOS Δ > 0
- 5시드 중 ≥ 4 시드에서 OOS 기대값 > 0
- L1/L2/L2P/L3 PASS, T1 FLAG 아님(또는 L1/L2 PASS로 해소), T2 부호반전 없음
- DSR ≥ 0.95(4 trial) 이거나, 미달 시 "provisional"로 표기

**어느 팔도 못 넘으면**: "레짐·증거신호 재료는 경제라벨 진입 모델에 표본외 증분을 주지 않는다"로 종결.
그 경우 진입 모델은 F0(이미 섀도우 가동)이고, 다음 레버는 피쳐가 아니라 **전진 섀도우 판정·사이징(음의 왜도)·
레짐 편중 모니터링**이다. 새 팔을 더 만들어 격자를 늘리지 않는다(§5.20 "96셀 통과수 무의미").

## 6. 알고 시작하는 위험

- 검정력: 독립 일수 VAL 122일/OOS 90일. 팔 간 Δ 수 bp는 CI가 넓다. 그래서 판정을 "Δ CI 하한 > 0"로 못 박는다.
- 09-03 재료 실험의 선례: OOF 누수 제거 후 "원시 signed 합 이상은 없다". F2/F3가 지는 것이 기본 예상이다.

## 9. 판정 (사전등록 §5 기준)

**어느 팔도 통과하지 못했다.** 레짐(F1)은 양 창에서 F0보다 낮고(유의하지 않음), 재료(F2)와 둘 다(F3)는 OOS에서 F0 대비 Δ의 일 단위
군집 CI 상한이 0 아래 → **유의하게 해롭다**. 재료 팔은 OOS 기대값 자체가 음수이고 랜덤 귀무 백분위 1~8%다.

⇒ **레짐 분류기와 증거신호 재료는 경제라벨 진입 모델에 표본외 증분을 주지 않는다. 진입 모델은 F0(V자반등 경제라벨)이고,
이미 섀도우로 가동 중이다.** 격자를 더 늘리지 않는다(§5.20). 다음 레버는 피쳐가 아니라 전진 섀도우 판정·사이징·레짐 편중
모니터링이다. 09-03 재료 실험("OOF 누수 제거 후 원시 signed 합 이상 없음")과 Phase 0 exit 킬게이트("재료 세 번째 0")에 이어
**재료의 매매 기여는 네 번째 0**이다.

T2 해석: `y`와 `y_recon`은 행의 0.1%에서만 1bp 넘게 다른데 회귀 프록시의 꼬리 선별 평균은 그 섭동과 dtype에 부호까지 흔들린다.
데이터 층(L1~L3)의 문제가 아니라 **이 표본 크기에서 상위 5% 꼬리 기대값 추정치가 수치적으로 취약하다**는 뜻이다. TabPFN 앙상블
증거(F0 OOS 시드 4/5 양수, 일CI 하한 +0.15)와 모순되진 않지만, **F0의 +8bp류 수치를 기대값으로 인용하지 말 것** — 전진 섀도우가
심판이라는 결론을 강화한다. 사전등록대로 이 FAIL 위에 승격을 쌓지 않는다(승격 후보 자체가 없다).

## 11. 교훈

1. 게이트가 실제로 버그를 잡았다 — 단 파이프라인이 아니라 **게이트 자신의 가정**(트레일링 규약)이었다. "저장소 표준"이 둘 이상인
   함수는 설정으로 선언받아야 한다. [[feedback_trailing_stop_anchor_convention_gate_must_declare_20260904]].
2. 재료·레짐은 다시 0. 이번엔 앵커·누수·라벨결함이 전부 게이트로 배제된 상태에서의 0이라, "버그 때문에 못 봤다"는 여지가 없다.
3. 검정력: 일 단위 CI 폭이 ±8~10bp. 팔 간 수 bp 차이는 원리적으로 못 가른다. 그래서 Δ CI가 0 아래로 내려간 F2/F3만 "해롭다"고 말할
   수 있고, F1은 "낫지 않다"까지다.
