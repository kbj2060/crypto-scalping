## ③ 15분~4시간 방향 예측 입력 후보: 계산식과 시각 규약

**위 결과로는 15분~4시간 지평의 예측력을 주장할 수 없다.** 아래는 «넣어 보고 IC로 검증할 후보»이고, 검증된 피쳐가 아니다. 공표 시각은 일반적인 관행이며, 실제 사용 전 ALFRED 빈티지나 발표 일정표로 확인해야 한다.

**A. 레짐·맥락 피쳐 (일·주 단위, 느리게 변함)** — 지평과 무관하게 «현재 어떤 매크로 상태인가»를 주는 용도.

| 피쳐 | 계산식 | 알려지는 시각(규약) |
|---|---|---|
| `usd13` | 100·ln(DTWEXBGS_w / DTWEXBGS_{w−13}), w = 공표가 끝난 마지막 주 금요일 값 | H.10 광의 달러지수는 주 단위(보통 월요일 오후 ET)에 지난주 일별치가 공표된다. **결정 시각 τ에서는 직전 공표분까지만** 쓴다. 이 세션 분석은 1주 시차를 뒀다 |
| `usd13_bucket` | 위 값을 **확장 윈도** 3분위로 분류(최소 104주, 미래 분위 금지) | 같음 |
| `real13_bp` | 100·(DFII10_d − DFII10_{d−13주}) | H.15/FRED 일별치는 다음 영업일에 공표된다. τ 기준 **전 영업일까지** |
| `be10_d`, `real10_d` | T10YIE·DFII10 일간 Δbp | 같음(다음 영업일) |
| `vix_d` | 100·Δln(VIXCLS) | CBOE 마감 직후(≈20:15/21:15 UTC)에 확정된다. 장중에는 실시간 VIX가 필요하다 |
| `hy_oas_d` | ΔBAMLH0A0HYM2 (bp) | ICE/FRED는 다음 영업일. FRED에는 2023-10 이후만 있다 |
| `spx_d` | 100·Δln(^GSPC 종가) | 미국 마감(20:00/21:00 UTC) 이후 |
| `stables_4w` | 100·ln(Σ공급_t / Σ공급_{t−4주}) | 온체인 값이라 실시간에 가깝다. 단, **BTC를 뒤따르는 변수**라 방향 피쳐로는 의심된다 |

**쓰지 말 것**:
- NFCI와 NFCI 하위지수: 개정·평활된 현재 빈티지라 누수다. 쓰려면 ALFRED 실시간 빈티지가 필요하다.
- M2·순유동성의 "N주 선행" 시차 피쳐: 시차를 골라 맞춘 것이다.
- 수준(level) 피쳐: 추세 공유로 가짜 상관이 생긴다.
- **Yahoo 미러 BTC/ETH `Close`**: 2025~26년이 오염돼 있다. Open[D+1]을 써야 한다.

## ④ 실데이터로 못 돌린 것과 필요한 데이터

1. **분 단위 리드-래그**(`scripts/research_macro_crypto_intraday_leadlag_20261027.py`): 합성 셀프테스트와 적대적 테스트 6종만 통과했다.
   - **필요한 것**: 서버에서 `pip install yfinance`를 하고, Yahoo(5m 59일, 1m 약 28일)·바이낸스 fapi/api·Hyperliquid에 네트워크로 접근할 수 있어야 한다. 실행 명령은 원 보고서 §10b에 있다.
   - **현재 측정 범위**: 시차는 5m에서 ±6봉(30분), 1m에서 ±15봉까지다. 대상은 BTC/ETH 선물이다.
   - **1~4시간 지평에 쓰려면**: 15m·1h로 집계하고 시차를 ±16봉(4h)까지 늘리는 확장이 필요하다. 대상도 ETH 15m/1h/4h 미래수익으로 바꿔야 한다.
2. **글로벌 M2**(ECB·BOJ·PBoC), **현물 ETF 일별 자금흐름**(Farside 등), **MOVE 지수**, **DXY 원지수**, **나스닥 일봉**, **공포탐욕지수**, **펀딩·OI 장기 이력**: 이 클라우드 세션의 네트워크 정책 때문에 받지 못했다. 서버에서는 FRED 직접 접근이 가능하다(`scripts/research_eth_rates_correlation_20261013.py`가 사용 중).
3. **ETH 리드-래그·레짐·표본외**: BTC만 실행했다. 파이프라인의 대상을 ETH로 바꾸면 그대로 재실행할 수 있다.
