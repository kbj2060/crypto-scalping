- BTC 는 V1~V5 가 모두 ✓ 라 **통과**다. 배포 HGB 의 월별 치우침은 21개월 중 16개월이 + 이고 평균 +1.0pp 다. 굴림층이 이것을 −0.1pp 로 당긴다. 이득은 ETH(−.0002~−.0004) 정도이고, XRP(−.0008)의 약 1/4 이다.
