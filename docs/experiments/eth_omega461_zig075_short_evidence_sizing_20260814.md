# zig075 증거신호 사이징 (macro veto 위 계층) — Odyssey4 실행 로그 #3 (2026-08-14)

상태: **`REJECTED`** — VAL 게이트 strict 탈락(`with_gate_pnl_nonworse=False`). OOS-Q1/Q2 단일터치는
열리지 못했다. **v2(마스터 랭킹 상위 5개 신호로 정제, 배율 불변)로 재검증했으나 오히려 더
악화**(VAL with_gate 77.31%→43.71%, 목표였던 2025-Q3조차 베이스라인보다 나쁨) — 축 종결.
**오디세이4의 macro 진입거부(실행 로그 #1)는 이 결과와 무관하게 유효한 해로 유지된다.**

## 배경 — 왜 이 실험을 했는가

실행 로그 #1(zig075 SHORT 진입거부, CONFIRMED) 이후 사용자가 근본적 개선 방향을 요청했고, 그
논의 중 별도 서브 프로젝트 문서(`docs/experiments/eth_evidence_signal_ranking_stability_
mar_jul_2026_20260814.md`)를 검토했다. 이 문서는 OHLCV+taker_buy_base만으로 계산되는 "증거
신호"(오실레이터+오더플로우 조합, 유동성 스윕, 거래량+꼬리 클라이맥스, VWAP 극단, 다이버전스
등)가 **완전히 다른 두 레짐(2025-09~2026-02 하락장 vs 2026-03~07 조용한 구간)에서 순위가
거의 그대로 유지된다**(Spearman 0.976/0.924)는 걸 독립적으로 검증했고, zig075 학습에 전혀
쓰이지 않은 외부 신호라 A1~A9(내부 신뢰도 기반 게이팅, 전부 실패)와 순환 논리 문제가 없다.

동일 저장소에 이미 이 신호를 라이브 모델에 주입하는 설계 문서(`docs/experiments/
eth_omega461_evidence_signal_injection_research_20260814.md`, 상태: "리서치 완료 — 설계만")가
있었고, entry-side(quality gate/거부) 주입은 **선례 근거로 명시적 no-go**, post-entry 인접
사이징/exit 오버레이(Tier 1)만 허용한다고 결론 내려져 있었다. 세션 중 소규모 사전 확인(zig075
SHORT 필드 렛저에 TOP 증거신호 유무를 교차, 표본 n=3~13)에서 Q1/Q2는 증거확인 시 승률이
크게 높았고(Q1: 100% vs 57.1%, Q2: 66.7% vs 30.8%) Q3에서는 구분력이 없었다(12.5% vs
11.1%) — macro veto(주간 스케일)와 이 신호(시간 스케일)가 서로 다른 것을 측정하므로
상호보완적일 것이라는 가설을 세우고, 설계문서의 Tier 1(사이징, 재학습 없음)에 맞춰 이 실험을
설계했다.

## 개입 정의 (사전 등록)

macro veto(오디세이4)가 이미 거부하지 않은 zig075 SHORT 진입에 한해:
- TOP 증거신호(오실레이터+오더플로우/taker_buy_climax/거래량꼬리클라이맥스/VWAP극단/다이버전스/
  볼린저%b극단/유동성스윕, A5 BTC선행 제외 — 라이브 미가용) 중 하나라도 신호 bar에 활성 →
  `margin_fraction` 그대로.
- 어느 것도 활성 아님 → `margin_fraction × 0.5`(SIZE_MULT_UNCONFIRMED, 결과를 보기 전에 고정,
  스윕 없음).

거부가 아니라 사이징만 바꾸므로 **어떤 거래가 발생하는지는 절대 안 바뀐다**(TP/SL은 가격
이동 트리거라 notional과 무관) — 이 구조적 안전성을 코드에서 거래 identity 체크로 직접 검증.

데이터 소스: 증거신호 원본 스크립트는 `data/eth_5m_1year.csv`(2026-02-17까지)를 쓰지만 OOS
전체를 커버 못해, 이미 파이프라인이 쓰는 `sweep.BASE_2025`/`BASE_2026`(2026-07-20까지,
`taker_buy_base` 보유 확인)에서 **동일 함수를 그대로 재사용**해 계산 — 6창 전부 커버.

### 원인 — 승률로 판단한 게 오판이었다

증거확인 비율이 신호 bar의 **2~13%에 불과**해, 규칙이 사실상 "zig075 SHORT 대부분을 절반
크기로"로 퇴화했다. 사전 소규모 체크는 승률만 비교했는데(Q1 미확인 버킷 57.1% 승률), 승률
57%는 여전히 **양의 기대값**(평균 +0.0458)을 뜻한다 — 이미 순이익인 버킷을 절반으로 줄이면
나쁜 거래를 거르는 게 아니라 잘 작동하던 수익을 깎는다. 둘 다 이미 음수였던 Q3에서만 사이징이
무해했다(+1.24pp). 표본 n=3~8짜리 사전 체크는 확인율이 이렇게 낮다는 걸 드러내지 못했고,
승률 대신 기대값을 봤어야 했다.

## 결론

이 특정 사이징 규칙은 부정 결과다. **배율을 재조정하는 사후 튜닝은 하지 않는다** — 그 자체가
오늘 하루 지킨 "목표 결과를 본 뒤 숫자를 고르지 않는다" 규율 위반이다. 오디세이4의 macro
진입거부는 이 결과와 무관하게 `CONFIRMED` 상태를 유지한다. 증거신호 축 자체(라벨/신호
안정성)는 여전히 유효하지만, "확인 시 정상/미확인 시 절반"이라는 이분법적 사이징 설계는
이 구조에서 작동하지 않는다는 게 이번 실험의 실질적 결론이다.

## 추가 검증 (v2) — 신호 목록을 순위안정성 문서의 마스터 랭킹 상위 5개로 제한

사용자 요청: "이번엔 OOS 테스트까지 마친 증거들이니까"(순위안정성 문서가 두 독립 레짐에서
검증됐다는 근거) 신호 목록을 마스터 랭킹으로 정제해서 재검증. **배율(0.5×)은 v1과 동일하게
유지** — 이번 실험 결과를 보고 배율을 다시 고르는 건 사후선택이라 하지 않는다.

- 신호 목록을 8개(v1, momentum_divergence·cvd_divergence 포함)에서 순위안정성 문서가 명시한
  TOP-side "상위 5개"(orthogonal_combo, taker_buy_climax, volume_wick_climax_high,
  liquidity_sweep_high, short_term_return_z_high — 부록 v1에서 누락돼 있던 초단기 z-score를
  버그 수정으로 추가)로 축소. momentum_divergence는 그 문서가 "신뢰하지 말 것"으로 명시 확인한
  신호라 제외 — 이 신호 선정 자체는 zig075 P&L이 아니라 독립 검증 문서에 근거하므로 정당.
- **결과: v1보다 더 나빠졌다.** VAL with_gate 77.31%→**43.71%**(v1은 64.07%), 목표였던
  2025-Q3조차 베이스라인 20.17%보다 낮은 **17.68%**로 반전(v1은 +1.24pp였음).
- 원인: 신호 목록을 좁히면 "OR 결합" 확인 조건이 더 드물어져(sized_down_bars가 전 창에서
  증가: VAL 8→14건, OOS-Q1 14→17건) "대부분을 절반 크기로" 퇴화가 오히려 심해진다. 신호
  품질을 아무리 높여도 이분법적 규칙 구조 자체가 문제이므로 개선되지 않는다.
- **이 축을 여기서 종결한다.** 규칙 형태(이분법 크기조절)를 바꾸는 재설계는 이번 세션이 이미
  관찰한 목표 수치를 보고 설계하는 것이라 사후선택 없이는 불가능 — 별도 세션에서 Q3를 완전히
  배제한 새 사전등록으로만 재시도 가능.
