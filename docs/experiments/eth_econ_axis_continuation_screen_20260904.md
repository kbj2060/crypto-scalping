## 4. 판독
1. **"모양 → 경제 축"으로 바꿔도 움직임 방향 축은 새 사건원이 아니다.** BTC 충격·시장 이동·OI 해소·체결 폭발은 R 발동 봉의 다른 이름이고, 비겹침 부분엔 엣지가 없다. 대신 이것은 R 메커니즘의 확인이다: 지속 규칙이 버는 자리는 "시장 전체가 같이 움직이고 포지션이 강제 해소되는 봉"이다(상태 축 Q5 우위).
2. **유일한 새 축 = 포지셔닝(개미 계정 롱숏비 급변의 반대).** 방향이 움직임과 독립이고, 두 쪽·비겹침 부분·세 창 전부 양수, R에 하루 +3~7bp(자본 대비) 얹는다(이긴 날 60~67%, CI는 0 포함). 3.4건/일·창당 300건이라 **후보이지 증명이 아니다**. 라이브 타이밍에서는 사전 규칙 경계.
3. 상태 축은 규모 효과만 있고 필터는 손해, 사이징은 activity만 경계.
